Found a Cool Elisp Declaration

While looking up how I prettify my Org-mode checkboxes, I found that Emacs, since version 24.4, comes with a bultin prettify-symbols-mode. It swaps out text with a Unicode symbol. This led me to a post "Mathematical Notation in Emacs", which is convenient for me: I want to learn to read maths.

I'm not going to rewrite its explanation of its code blocks, but reproduce them here for my own use. The first enables the pretty-mode package and turns off some parts of it, to make room for features that will be enabled by later code blocks. 

(require 'pretty-mode)
(global-pretty-mode t)

(pretty-deactivate-groups
 '(:equality :ordering :ordering-double :ordering-triple
             :arrows :arrows-twoheaded :punctuation
             :logic :sets))

(pretty-activate-groups
 '(:sub-and-superscripts :greek :arithmetic-nary))

Let me see if I can't figure out how to write that as a use-package declaration, and since I'm not setting up the litagure stuff right now, I'll leave all the stuff on. 

(use-package pretty-mode
  :ensure pretty-mode
  :config
  (progn
    (global-pretty-mode t)
    (global-prettify-symbols-mode 1)
    (pretty-activate-groups
     '(:sub-and-superscripts :greek :arithmetic-nary))))

That seems to work! (And now gets appended to my Emacs configuration.

The article also has another quote introducing some Emacs commands I didn't know about:

The command insert-char, C-x 8 RET prompts for Unicode characters by name and inserts at point. There is also describe-char, M-m h d c which gives information on the character at point. Use in conjunction with eg. "Math Unicode Symbols List" to explore your options.

Nifty! Looking elsewhere, it looks like the only thing that is prettified in lisp dialects is the lambda symbol, and it suggests things can be added like this: 

(add-hook 'emacs-lisp-mode-hook
            (lambda ()
              (push '(">=" . ?≥) prettify-symbols-alist)))

Which, testing out, works just fine. I wouldn't mind mentions if the whole greek alphabet got replaced, and in Org-mode too - though there I'd do it with a prefix of \ since that's the LaTeX for it. I encounter a problem here, though: I don't actually understand the syntax above, so I don't know how I'd change it to add multiple things to the prettify-symbols-alist.

I guess what I need to know is what's a λ expression in Emacs, and what's the push function takes and returns.

I was reading about λ calculus on Wikipedia recently, so the Elisp Reference Manual's brief explanation of what λ expressions might make sense. It says they're "anonymous functions," but are more commonly associated with symbols to make a named function. A λ expression - contained within (), always starts with the lambda symbol, then takes a list of argument variables, called the "λ list." There can be a documentation string, an interactive declaration, and then the body - very similar to a normal function declaration, except with lambda instead of defun function-name.

(let ((alpha '(1 2 3))
      (beta '(4 5 6)))

This gives me a list of (6 5 4 1 2 3), which shows that push puts things at the start of a list. That's not relevant to my goals, but does give me a hypothetical syntax for my need: 

(add-hook 'emacs-lisp-mode-hook
          (lambda ()
            (let ((replacements
                   '((">=" . ?≥))))
              (dolist (alpha replacements)
                (push alpha prettify-symbols-alist)))))
