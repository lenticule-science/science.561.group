Introduction

This proposal is about a prototype specification. It is likely to be incomplete, self-contradicting, and flawed.

This proposal contains the specifications for media packages and media package channels, formats for maintaining a manifest about a piece of media content and a listing of those manifests.

Media Packages

Overview

A media package is a manifest of information about a piece of media content, providing information about the piece as well as information about from where it can be obtained. 

'("shaggy-dog-tale"
  ("versions"
   ("current"
    ("sourcehut"
     ("location" . "https://example.org/shaggy-dog-tale/")
     ("formats" . ("html"))))))

This example includes all the package's currently required elements. This tells us the package's identifier, shaggy-dog-tale, and gives us information on the one version available, current: it is available at a single origin, sourcehut, in one format, html. With that information and that origin's location, https://example.org/shaggy-dog-tale/, we have all the information necessary to download the current version of "A Shaggy Dog Tale" from example.org.

An actual media package may have additional elements, such as a description and license.

A media package channel is a list of media packages. There must not be any duplicated identifiers in a list.

Media Package Channel Data Structure

A media package channel is a list of packages. In the future, it may include information about the channel such as contact information for its maintainer or when it was last updated.

Example Package Channel

This is my actual package channel. 

(setq emsems-example-package-channel
      '(("brutstrap-css"
         ("name" . "Brutstrap CSS")
         ("description" . "a cascading stylesheet for representing HTML content as it is constructed.")
         ("creator" . "emsenn")
         ("license" . "CC0")
         ("versions"
          ("current"
           ("sourcehut"
            ("location" . "https://git.sr.ht/~emsenn/brutstrap-css/blob/master/")
            ("formats" . ("html" "md" "pdf" "tex" "txt"))))))))

Functions

Overview

Given a media package channel, there are several operations one might wish to do, such as downloading a given format of a version of a package from a specific origin, or return the list of origins for a given package, or search for all packages. This section contains implementations of such operations.

Because this project exists for my benefit, the channel used in these examples is my own, available in the "Example Package Channel" section in the "Supplements".

Channel Functions

Get Packages List

This expression builds a list of all the identifiers in a given channel. This is useful for browsing what's available on a channel. 

(defun emsems-get-packages-list
    (channel)
  "Return a list of the media package identifiers available on
  this channel."
  (loop for package
        in channel
        collect (car package)))
Get Package from Channel
(defun emsems-get-manifest-from-channel
    (channel id)
  "Get the media package manifest for ID from media package
  channel CHANNEL."
  (assoc id channel))
