*** Base URL Configuration
The =baseURL= variable is accessed through =.Site.BaseURL=.

=baseURL= is currently unused.
#+NAME: site-configuration-base-url
#+BEGIN_SRC text
  baseURL = "https://emsenn.net"
#+END_SRC
*** Language Configuration
The =languageCode= variable is accessed through =.Site.Language.Lang=.

=languageCode= is used in the [[#default-base-layout]["Default Base Layout"]].
#+NAME: site-configuration-language
#+BEGIN_SRC text
  languageCode = "en-us"
#+END_SRC
*** Emoji Configuration
The =enableEmoji= variable sets whether or not emoticon shortcodes in
documents are rendered. (:smile: to a smiling face emoji, for example.)

There are currently no templates which use emoji, but site content
might so it is recommended to set it to =true=.
#+NAME: site-configuration-emoji
#+BEGIN_SRC text
  enableEmoji = true
#+END_SRC

*** Site Document Types Configuration
The =documentTypes= variable is accessed through
=.Site.documentTypes=. Document types,
{{{document-types-definition}}}, are used to guide what templates are
used to construct and style a document.[fn:1]
#+NAME: site-document-types-configuration

    documentTypes = "essay fiction document letter manual"

** Hugo Layouts
*/Layouts/* are the instructions Hugo uses to construct a document.

Explanation TK.

If you're familiar with SMACSS, [[https://smacss.com/book/type-layout][layouts]] are equivalent to its' blocks.
#+TOC: headlines 1 local
*** Default Layouts
    :PROPERTIES:
    :CUSTOM_ID: default-layouts
    :END:
#+BEGIN Introduction
The */default layouts/*, located under =./layouts/_default/= are used
when there's not a more relevant layout to use with a document. See
[[https://gohugo.io/templates/lookup-order/]["Hugo's Lookup Order"]] in the {{{hugo-docs-link}}}.

Because Hugo is written as a static website generator, all the default
templates are in HTML.
#+END

#+BEGIN Introduction
The */base default layout/*, saved as
=./layouts/_default/baseof.html=, is the lowest-priority (except for
themes') base template, but even so is used as the base template for
every(?) HTML document on my website.

There are roughly two parts to the =baseof.html= layout - there is
some initialization of variables at the top, and then the rest pulls
in other layouts to render a complete HTML document.
