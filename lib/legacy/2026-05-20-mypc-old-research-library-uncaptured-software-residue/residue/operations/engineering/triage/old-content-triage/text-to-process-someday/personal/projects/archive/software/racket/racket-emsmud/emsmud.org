#+title: emsMUD
#+options: num:t
My MUD is implemented in Racket, using qtMUD, a MUD engine I'm making. In qtMUD, each dimension is represented as one or more "universes." Continuing that metaphor, the code of my MUD is arranged below chronologically from the "Big Bang" (establishing the rules of physics) through the "start of history," when the MUD becomes accessible to outside clients and time begins to progress.

This MUD is available as a [[https://code.cyberearth.systems/emsenn/emsmud][git repository]]
#+toc: headlines 4 local
* Requirements
Being written in Racket, my MUD requires that: this code snippet is actually to specify what parts of the qtMUD library are used by the MUD.

         "../qtmud/components/mudsocket.rkt")
#+end_src
* History
** Creating & building the emsverse
In the beginning, the =emsverse= is created, and =create-thing= is defined as a procedure for creating /things/ into that universe. Also, the logger is made and started running, so that Racket can report back what's happening inside the =emsverse=.
#+name: creating-the-emsverse-declarations
#+begin_src racket
(define emsverse (create-universe "emsVerse"))
(define create-thing (create-thing-creator-for-universe emsverse))
(run-universe-logger (make-universe-logger emsverse))
#+end_src

*** Adding library procedures to the emsverse
Once the =emsverse= has been built, we'll go ahead and add the procedures from two of the above library components to it: animation, which provides the mechanisms putting /things/ in "containers" and giving the container /things/ "contents". (/Container/ and /contents/ both being /qualities/ that a thing can possess.)

Continuing to view the =emsverse= as a universe, this can be seen as kind of adding the basic rules of physics.
#+name: adding-library-procedures-to-the-emsverse-declarations
#+begin_src racket
(add-animation-procedures-to-universe! emsverse)
(add-area-procedures-to-universe! emsverse)
#+end_src
*** Setting specific procedures
The library procedures added in the previous section provide some general procedures for handling "physics" within the =emsverse=. What follows are some procedures for setting procedures specific to the =emsverse=.
**** Make MUDSocket connection message
This procedure sets the message shown to folk when they connect to the MUDSocket server.
#+name: set-make-mudsocket-connection-message-procedure-for-emsverse-declaration
#+begin_src racket
  (define mudsocket-connection-message
    (string-join
     '("Your connection to emsenn's dimension from ~a:~a has been accepted."
       "Welcome."
       ""
       "Proceed intentionally, please:"
       "what exists here was created by one person wishing to communicate"
       "with others."
       ""
       "Interact with the universe by typing commands and pressing ENTER."
       "Try getting started with the \"help\" command.")
     "\n"))
  (set-universe-procedure!
   emsverse 'make-mudsocket-connection-message
   (λ (connected-thing)
     (format mudsocket-connection-message
	     (thing-quality connected-thing 'mudsocket-ip)
	     (thing-quality connected-thing 'mudsocket-port))))
#+end_src
**** Handle MUDSocket connection
When a person connects to the MUDSocket, a new /thing/ is made to represent them inside the =emsverse=. The MUDSocket does some stuff to set up that /thing/: this procedure comes after that to change the /thing/ more.

Namely, it adds some commands (look, move, and map) to the /thing/, and moves it into the lobby, an area of the =emsverse=.

Two of the new commands, look and move, come from the Animation library component, while the third, map, is defined right in this declaration.
#+name: set-handle-mudsocket-connection-procedure-for-emsverse-declaration
#+begin_src racket
  (set-universe-procedure!
   emsverse 'handle-mudsocket-connection
   (λ (logged-in-thing)
     (add-keyvalues-to-thing-quality!
      (list (cons "look" (make-look-mudsocket-command-for-thing logged-in-thing))
	    (cons "move" (make-move-mudsocket-command-for-thing logged-in-thing))
	    (cons "map" (λ (a) (add-string-to-thing-quality!
				areas-ascii-map logged-in-thing
				'mudsocket-output-buffer))))
      logged-in-thing 'mudsocket-commands)
     (add-element-to-thing-quality!
      logged-in-thing lobby 'contents)))
#+end_src
**** Set MUDSocket help response
This changes the text sent to folk when they use the =help= command.
#+name: set-make-mudsocket-help-response-procedure-for-emsverse-declaration
#+begin_src racket
  (define help-response
    (string-join
     '("You're connected to emsenn's dimension, a virtual universe they created."
       ""
       "To interact, type commands and press ENTER."
       ""
       "A few useful commands:"
       "- commands"
       "  lists available commands"
       "- look"
       "  shows you where in universe you are"
       "- move <exit>"
       "  can move you to another area of the universe")
     "\n"))
  (set-universe-procedure!
   emsverse 'make-mudsocket-help-response
   (λ (helped-thing)
   help-response))

#+end_src
** Creating & building areas of the emsverse
*** Map
The =emsverse= contains several /areas/, /things/ within the /universe/ that share several qualities, including:

- an "area description," text that describes what someone in the area would see.
- a list of "area exits," other places someone in the area could move to from there.

The following block creates the areas, defines an =areas= list of them, and gives them all the /contents/ quality.
#+name: creating-areas-declarations
#+begin_src racket
  (define lobby (create-thing "lobby"))
  (define gardens-courtyard (create-thing "gardens"))
  (define projects-hall (create-thing "projects"))
  (define library-area (create-thing "library"))
  (define makha-sa-garden (create-thing "Makȟá Šá Garden"))
  (define qtmud-exhibit (create-thing "qtMUD"))
  (define library-original-works-area (create-thing "library: original works"))
  (define library-collection-area (create-thing "library: collection"))
  (define areas (list lobby gardens-courtyard projects-hall
		      library-area makha-sa-garden
		      qtmud-exhibit library-original-works-area
		      library-collection-area))
  (map (λ (area)
	 (set-thing-quality! area 'contents '() #t))
       areas)
#+end_src

*** Building the lobby
The lobby is the room folk get moved into when they first connect to the MUD and enter the =emsverse=.

I really haven't decided how it should look, but it serves - for now - as the hub to other areas of the =emsverse=.

** Preparing for the start of time
Before I start the =emsverse= running, I add the MUDSocket's recurring tick event to the universe's schedule, so that the universe is available through the MUDSocket.
#+name: preparing-for-the-start-of-time-declarations
#+begin_src racket
(add-event-to-universe-schedule! (make-mudsocket-tick-event-for-universe emsverse) emsverse)
#+end_src
** Starting time
This declaration starts the =emsverse= running, making it "tick" every fifth of a second, calling various procedures that were added to its schedule, which is how "time" is simulated in qtMUD.
#+name: starting-time-declaration
#+begin_src racket
(define emsmud (run-universe emsverse))
#+end_src
