** Overview
A */media package/* is a manifest of information about a piece of
media content, providing information about the piece as well as
information about from where it can be obtained.

#+name: media-package-example-1 :eval no
#+caption: A basic /media package/ implemented as an /Elisp expression/.
#+begin_src elisp :eval no :tangle nil
  '("shaggy-dog-tale"
    ("versions"
     ("current"
      ("sourcehut"
       ("location" . "https://example.org/shaggy-dog-tale/")
       ("formats" . ("html"))))))
#+end_src

This example includes all the package's currently required elements.
This tells us the package's /identifier/, =shaggy-dog-tale=, and gives
us information on the one /version/ available, =current=: it is
available at a single /origin/, =sourcehut=, in one /format/, =html=.
With that information and that origin's /location/,
=https://example.org/shaggy-dog-tale/=, we have all
the information necessary to download the current version of "A Shaggy
Dog Tale" from =example.org=.

An actual /media package/ may have additional elements, such as a
/description/ and /license/.

A /media package channel/ is a list of /media packages/. There must
not be any duplicated /identifiers/ in a list.

** Media Package Channel Data Structure
A /media package channel/ is a list of packages. In the future, it may
include information about the channel such as contact information for
its maintainer or when it was last updated.

*** Overview
Given a /media package channel/, there are several operations one
might wish to do, such as downloading a given /format/ of a /version/
of a package from a specific /origin/, or return the list of origins
for a given package, or search for all packages. This section contains
implementations of such operations.

Because this project exists for my benefit, the /channel/ used in
these examples is my own, available in the [[#example-package-channel]["Example Package Channel"]]
section in the [[#supplements]["Supplements"]].
*** Channel Functions
**** Get Packages List
This expression builds a list of all the /identifiers/ in a given
/channel/. This is useful for browsing what's available on a channel.
#+name: define-get-packages-list
#+caption: An /Elisp expression/ defining the function =get-list-of-packages-from-channel=, which returns a list of all packages given a /channel/.
#+begin_src elisp
  (defun emsems-get-packages-list
      (channel)
    "Return a list of the media package identifiers available on
    this channel."
    (loop for package
	  in channel
	  collect (car package)))
#+end_src
**** Get Package from Channel
#+name: define-get-manifest-from-channel
#+caption: An /Elisp expression/ which, given an /identifier/, returns a /media package manifest/.
#+begin_src elisp
  (defun emsems-get-manifest-from-channel
      (channel id)
    "Get the media package manifest for ID from media package
    channel CHANNEL."
    (assoc id channel))
#+end_src
