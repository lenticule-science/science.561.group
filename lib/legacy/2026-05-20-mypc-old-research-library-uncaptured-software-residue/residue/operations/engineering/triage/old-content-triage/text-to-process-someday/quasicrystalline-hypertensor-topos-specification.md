Hypertensor Topos Specification (HTT-SPEC v1)

This document specifies the **Hypertensor Topos** structure as a mathematical object. Normative key words **MUST**, **MUST NOT**, **SHOULD**, **MAY** are used in the sense of RFC 2119.

The specification is written as Markdown + TeX. It is intended for mathematically literate readers and for direct translation into LaTeX or a proof assistant. markdown Copy code

0. Global Conventions

- A _category_ is always locally small unless stated otherwise.
- A _topos_ means an (elementary) Grothendieck topos.
- For a category (\mathcal{C}), (\mathbf{Sh}(\mathcal{C}, J)) denotes the category of set-valued sheaves on the site ((\mathcal{C},J)).
- For a set (X), (\mathcal{P}(X)) denotes its powerset.
- For a topos (\mathsf{R}), (\mathrm{Obj}(\mathsf{R})) denotes its class of objects.

We fix the following **categories**:

- (\mathbf{Heyt}): objects are bounded Heyting algebras; morphisms are Heyting homomorphisms.
- (\mathbf{HeytModal}): objects are tuples [ (H,\land,\lor,\Rightarrow,\bot,\top,\nu,\phi) ] where ((H,\land,\lor,\Rightarrow,\bot,\top)) is a bounded Heyting algebra and (\nu,\phi : H \to H) are unary operations satisfying HT-A1 (below). Morphisms are Heyting homomorphisms preserving (\nu) and (\phi).

We also use the following **notation**:

- For a small category (\mathbf{T}), (\mathbf{T}^{op}) denotes its opposite.
- For an object (X) in a topos, (\mathrm{Sub}(X)) denotes the poset of subobjects of (X).
- For a functor (F : \mathcal{C}^{op} \to \mathbf{Set}) and (c \in \mathcal{C}), we write (F(c)) for the set of sections at (c). markdown Copy code

1. Primitive Structures

This section specifies the **primitive data** that define a Hypertensor Topos instance.

1.1 Hypertensor Trace Site (HTS)

**Definition HTS-1 (Hypertensor Trace Site).** A **Hypertensor Trace Site** is a pair (\mathrm{HTS} = (\mathbf{T},J)) where:

- (\mathbf{T}) is a small category (the **trace category**).
- (J) is a Grothendieck topology on (\mathbf{T}).

The pair ((\mathbf{T},J)) MUST satisfy Axiom HT-A0 below.

--------------------------------------------------------------------------------

Axiom HT-A0 (Trace Category Constraints)

Let (\mathbf{T}) be as above.

1. **Objects as traces.** There is a chosen set (\Sigma) (the **step alphabet**) and a surjection [ \mathrm{word} : \mathrm{Ob}(\mathbf{T}) \twoheadrightarrow \Sigma^\star ] such that each object of (\mathbf{T}) is identified with an equivalence class of finite words on (\Sigma) modulo a congruence generated by _admissible commutations_ and _deletions_.
2. **Morphisms as normalizations.** For objects (t,t' \in \mathrm{Ob}(\mathbf{T})), a morphism (f : t \to t') exists if and only if (t') is obtained from (t) via a finite sequence of normalization moves:
    - deletion of a neutral or redundant step,
    - commutation of adjacent independent steps,
    - rebracketing or reassociation moves compatible with independence.
3. The set (\mathbf{T}(t,t')) of morphisms MUST be finite for all (t,t').
4. **Free partially commutative monoid structure.** The isomorphism classes of objects of (\mathbf{T}) MUST form the free partially commutative monoid over (\Sigma), modulo the given independence relations.
5. **Composition.** Composition in (\mathbf{T}) MUST coincide with concatenation of normalization sequences followed by re-normalization, and MUST be associative by confluence of normalization.
6. **Identities.** For each object (t), the identity (\mathrm{id}_t : t \to t) MUST be represented by the empty normalization sequence.

--------------------------------------------------------------------------------

Axiom HT-A0.1 (Trace Topology)

The Grothendieck topology (J) on (\mathbf{T}) MUST satisfy:

- For each (t \in \mathrm{Ob}(\mathbf{T})), there exists at least one covering family ({u_i : t_i \to t}_{i \in I} \in J(t)) (non-degenerate topology).
- (J) MUST be stable under pullback along morphisms of (\mathbf{T}), contain isomorphisms as covers, and be closed under composition of covers (standard Grothendieck axioms). markdown Copy code

1.2 Fiber Heyting–Modal Algebras

**Definition HT-H (Fiber Heyting–Modal Family).** Given a trace category (\mathbf{T}), a **fiber Heyting–modal family** over (\mathbf{T}) is an assignment: [ t \ \mapsto\ \mathsf{H}_t ] with (\mathsf{H}_t \in \mathbf{HeytModal}) for each (t \in \mathrm{Ob}(\mathbf{T})).

Each fiber (\mathsf{H}_t) MUST satisfy HT-A1.

--------------------------------------------------------------------------------

Axiom HT-A1 (Fiber Constraints)

For each trace (t \in \mathrm{Ob}(\mathbf{T})):

1. **Finite bounded Heyting algebra.** (\mathsf{H}_t) MUST be a finite bounded Heyting algebra [ (\mathsf{H}_t,\land_t,\lor_t,\Rightarrow_t,\bot_t,\top_t). ]
2. **Modal endomorphisms.** There MUST exist two unary operations [ \nu_t, \phi_t : \mathsf{H}_t \to \mathsf{H}_t ] such that:
    - (Monotonicity) (a \le_t b \Rightarrow \nu_t(a) \le_t \nu_t(b)) and (\phi_t(a) \le_t \phi_t(b)).
    - (Nucleus) (a \le_t \nu_t(a)) and (\nu_t(\nu_t(a)) = \nu_t(a)).
    - (Flow) (a \le_t \phi_t(a)) and there exists (n \ge 1) such that (\phi_t^{n+1}(a) = \phi_t^n(a)) for all (a \in \mathsf{H}_t).
    - (Commutation) (\nu_t(\phi_t(a)) = \phi_t(\nu_t(a))) for all (a).
    - (Heyting compatibility) (\nu_t) preserves finite meets and (\top_t); (\phi_t) is meet-subdistributive and preserves finite joins.
3. **Invariant fiber.** Define [ \mathsf{H}_t^\ast := { a \in \mathsf{H}_t \mid \nu_t(a) = a = \phi_t(a) }. ] This MUST be nonempty and MUST form a bounded Heyting _subalgebra_ of (\mathsf{H}_t).

--------------------------------------------------------------------------------

1.3 Reindexing Functor

**Definition HT-F (Hypertensor Reindexing Functor).** A **Hypertensor Reindexing Functor** is a functor [ \mathsf{H} : \mathbf{T}^{op} \to \mathbf{HeytModal} ] such that:

- (\mathsf{H}(t) = \mathsf{H}_t) for each (t),
- each (\mathsf{H}(f) : \mathsf{H}_{t'} \to \mathsf{H}_t) is a morphism in (\mathbf{HeytModal}).

This MUST satisfy HT-A2.

--------------------------------------------------------------------------------

Axiom HT-A2 (Reindexing Constraints)

For every morphism (f : t \to t') in (\mathbf{T}):

1. (\mathsf{H}(f)) MUST be a Heyting homomorphism: [ \mathsf{H}(f)(a \land_{t'} b) = \mathsf{H}(f)(a) \land_t \mathsf{H}(f)(b), ] [ \mathsf{H}(f)(a \lor_{t'} b) = \mathsf{H}(f)(a) \lor_t \mathsf{H}(f)(b), ] [ \mathsf{H}(f)(a \Rightarrow_{t'} b) = \mathsf{H}(f)(a) \Rightarrow_t \mathsf{H}(f)(b), ] [ \mathsf{H}(f)(\bot_{t'}) = \bot_t,\quad \mathsf{H}(f)(\top_{t'}) = \top_t. ]
2. (\mathsf{H}(f)) MUST preserve modalities: [ \mathsf{H}(f)(\nu_{t'}(a)) = \nu_t(\mathsf{H}(f)(a)),\quad \mathsf{H}(f)(\phi_{t'}(a)) = \phi_t(\mathsf{H}(f)(a)). ]
3. Functoriality MUST hold: [ \mathsf{H}(\mathrm{id}_t) = \mathrm{id}_{\mathsf{H}_t},\quad \mathsf{H}(g \circ f) = \mathsf{H}(f) \circ \mathsf{H}(g). ]
4. Invariants MUST be preserved: [ \mathsf{H}(f)(\mathsf{H}_{t'}^\ast) \subseteq \mathsf{H}_t^\ast. ] markdown Copy code

1.4 Sheaf Condition

**Definition HT-SH (Hypertensor Sheaf).** The underlying set-valued functor of (\mathsf{H}), [ |\mathsf{H}| : \mathbf{T}^{op} \to \mathbf{Set}, \quad |\mathsf{H}|(t) := \mathsf{H}_t, ] is called the **hypertensor presheaf**.

--------------------------------------------------------------------------------

Axiom HT-A3 (Sheaf Condition)

The presheaf (|\mathsf{H}|) MUST be a **sheaf** for the topology (J):

For each (t \in \mathrm{Ob}(\mathbf{T})) and each covering family ({u_i : t_i \to t}_{i \in I} \in J(t)):

1. (**Locality**) If (a,b \in \mathsf{H}_t) satisfy (\mathsf{H}(u_i)(a) = \mathsf{H}(u_i)(b)) for all (i), then (a = b).
2. (**Gluing**) If (a_i \in \mathsf{H}_{t_i}) satisfy (\mathsf{H}(v)(a_i) = \mathsf{H}(w)(a_j)) for all morphisms (v : s \to t_i, w : s \to t_j) with (u_i \circ v = u_j \circ w), then there exists a unique (a \in \mathsf{H}_t) such that (\mathsf{H}(u_i)(a) = a_i) for all (i).
3. (**Modal-compatibility**) The gluing MUST commute with (\nu,\phi): if (a) is the glued global section of ((a_i)), then (\nu_t(a)) and (\phi_t(a)) MUST be the glued global sections of ((\nu_{t_i}(a_i))) and ((\phi_{t_i}(a_i))), respectively.

--------------------------------------------------------------------------------

Axiom HT-A4 (Invariant Subsheaf)

The assignment (t \mapsto \mathsf{H}_t^\ast) and (f \mapsto \mathsf{H}(f)|_{\mathsf{H}_{t'}^\ast}) MUST define a subsheaf [ \mathsf{H}^\ast : \mathbf{T}^{op} \to \mathbf{Heyt}, ] i.e.:

- (\mathsf{H}^\ast) MUST satisfy the sheaf locality and gluing conditions (as above), and
- any glued section of invariant locals MUST be invariant globally. markdown Copy code

1.5 Internal Lambda Structure (HTLC)

**Definition HT-L (Hypertensor Lambda Calculus, HTLC).** A **Hypertensor Lambda Calculus** over ((\mathbf{T},J,\mathsf{H})) consists of:

1. A set of **types** generated by:
    - a base type (\mathrm{Rec}),
    - ((A,B) \mapsto A \times B),
    - ((A,B) \mapsto A \Rightarrow B),
    - (optionally) sums and fixed-point types.
2. For each trace (t), a set of **terms** with **typing judgments** of the form: [ \Gamma \vdash_t M : A ] where (\Gamma) is a finite context (x_1 : A_1, \dots, x_n : A_n).
3. A **typing system** implementing at least:
    - variable, weakening, exchange rules,
    - introduction/elimination rules for (\times) and (\Rightarrow),
    - (optionally) rules for sums and fixed-point types,
    - term formers (\mathbf{Nucleus}, \mathbf{Flow} : \mathrm{Rec} \to \mathrm{Rec}).
4. A **semantics** mapping:
    - (\llbracket A \rrbracket \in \mathrm{Obj}(\mathsf{R})) for each type (A),
    - (\llbracket \Gamma \rrbracket \in \mathrm{Obj}(\mathsf{R})) for each context (\Gamma),
    - (\llbracket \Gamma \vdash M : A \rrbracket : \llbracket \Gamma \rrbracket \to \llbracket A \rrbracket) for each judgement.

The semantics MUST satisfy Axiom HT-A5.

--------------------------------------------------------------------------------

Axiom HT-A5 (Lambda Semantics Constraints)

Let (\mathsf{R} := \mathbf{Sh}(\mathbf{T},J)) (to be defined in Section 2).

The HTLC semantics MUST satisfy:

1. (\llbracket \mathrm{Rec} \rrbracket = \mathsf{H}) (the hypertensor object).
2. Products and exponentials MUST interpret as categorical products and exponentials in (\mathsf{R}).
3. Term constructors for logical operations MUST interpret as the internal Heyting operations on (\mathsf{H}).
4. (\mathbf{Nucleus}) and (\mathbf{Flow}) MUST interpret as the natural transformations (\nu,\phi : \mathsf{H} \to \mathsf{H}).
5. Reindexing along morphisms in (\mathbf{T}) MUST commute with interpretation: for each (f : t \to t'), the semantics of reindexed judgments MUST coincide with pulling back the internal morphism along the corresponding geometric morphism induced by (f).
6. The semantics MUST be **sound and complete** for the internal logic of (\mathsf{R}) restricted to the object (\mathsf{H}), in the following sense:
    - Any derivable judgment or equation of HTLC MUST hold in (\mathsf{R}).
    - Any morphism (f : \llbracket \Gamma \rrbracket \to \llbracket A \rrbracket) generated by products, exponentials, subobjects, and the operations interpreting HTLC constructors MUST be denotable by some term (M) with (\Gamma \vdash M : A). markdown Copy code

1.6 Structural Operations (Constructors)

**Definition HT-FS (Hypertensor Structural Operations).** A **Hypertensor Structural Signature** is a finite set [ \mathcal{F} = {F_i}_{i \in I} ] of primitive operations on objects of (\mathsf{R}), including at least:

- trace-level concatenation (\star) on objects of (\mathbf{T}),
- the internal Heyting operations on (\mathsf{H}): (\land,\lor,\Rightarrow,\top,\bot),
- the internal modal operations (\nu,\phi : \mathsf{H} \to \mathsf{H}),
- their corresponding term constructors in HTLC at type (\mathrm{Rec}).

--------------------------------------------------------------------------------

Axiom HT-A6 (Structural Closure)

The structural operations (\mathcal{F}) MUST satisfy:

1. **Naturality.** For any (F_i) acting on (\mathsf{H}) or its powers, the action MUST be natural with respect to (\mathsf{H})-reindexing induced by (\mathbf{T}).
2. **Sufficiency.** Every object of (\mathsf{R}) that arises in this specification (Sections 2–7) MUST be constructible from:
    - representables (y(t) = \mathrm{Hom}_{\mathbf{T}}(-,t)),
    - the hypertensor object (\mathsf{H}),
    - application of finite limits, finite colimits, exponentials, subobjects,
    - the operations in (\mathcal{F}),
    - sheaf gluing and restriction.
3. **No extra primitives.** No additional primitive object-forming operations beyond those above are permitted in the core hypertensor universe. markdown Copy code

4. Hypertensor Topos Construction

Given primitive data satisfying HT-A0–HT-A6, this section defines the **Hypertensor Topos**.

2.1 Hypertensor Sheaf Topos

**Definition HT-R (Hypertensor Topos).** Let (\mathrm{HTS} = (\mathbf{T},J)) be a Hypertensor Trace Site satisfying HT-A0–HT-A3, and let (\mathsf{H} : \mathbf{T}^{op} \to \mathbf{HeytModal}) be a Hypertensor Reindexing Functor as in HT-F.

Define:

- (\mathsf{R} := \mathbf{Sh}(\mathbf{T},J)) (the **Hypertensor Topos**),
- (\mathsf{H} \in \mathsf{R}) as the sheaf corresponding to the presheaf (|\mathsf{H}|),
- (\mathsf{H}^\ast \hookrightarrow \mathsf{H}) as the subsheaf of invariants.

The tuple [ \mathrm{HTT} := (\mathsf{R},\mathsf{H},\nu,\phi,\mathsf{H}^\ast) ] is called a **Hypertensor Topos instance**.

--------------------------------------------------------------------------------

2.2 Existence and Uniqueness (Specification Form)

**Requirement HT-R1 (Existence).** Given any primitive data satisfying HT-A0–HT-A6, a corresponding Hypertensor Topos instance (\mathrm{HTT}) **MUST** exist as in Definition HT-R.

**Requirement HT-R2 (Uniqueness up to equivalence).** If two sets of primitive data ((\mathbf{T},J,\mathsf{H},\nu,\phi)) and ((\mathbf{T}',J',\mathsf{H}',\nu',\phi')) satisfy HT-A0–HT-A6 and induce Hypertensor Topoi (\mathsf{R}) and (\mathsf{R}'), then there **MUST** exist a topos equivalence [ F : \mathsf{R} \simeq \mathsf{R}' ] preserving the distinguished structure (up to isomorphism): [ F(\mathsf{H}) \cong \mathsf{H}', \quad F(\nu) = \nu', \quad F(\phi) = \phi', \quad F(\mathsf{H}^\ast) \cong \mathsf{H}'^\ast. ] markdown Copy code

3. Generative Closure Mechanism

This section specifies the **generative closure operator** and the self-generation property of (\mathsf{R}).

3.1 Atomic Objects

**Definition HT-A (Atomic Object Set).** Let (\mathsf{R} = \mathbf{Sh}(\mathbf{T},J)). Define the **atomic object set**: [ \mathcal{A} := { y(t) \mid t \in \mathrm{Ob}(\mathbf{T}) } \cup { \mathsf{H} }, ] where (y : \mathbf{T} \to \mathsf{R}) is the Yoneda embedding.

--------------------------------------------------------------------------------

3.2 Generative Closure Operator

**Definition HT-G (Generative Closure Operator).** Define a function [ \mathcal{G} : \mathcal{P}(\mathrm{Obj}(\mathsf{R})) \to \mathcal{P}(\mathrm{Obj}(\mathsf{R})) ] as follows:

For any (X \subseteq \mathrm{Obj}(\mathsf{R})), (\mathcal{G}(X)) is the **smallest** subclass (Y \subseteq \mathrm{Obj}(\mathsf{R})) satisfying:

1. (**Atoms and base set included**) (\mathcal{A} \subseteq Y) and (X \subseteq Y).
2. (**Isomorphism-closure**) If (A \in Y) and (B \cong A) in (\mathsf{R}), then (B \in Y).
3. (**Finite limits/colimits**) If (A,B \in Y), any object obtained as a finite limit or finite colimit of diagrams built from (A,B) MUST be in (Y).
4. (**Exponentials**) If (A,B \in Y), then the exponential object (B^A) MUST belong to (Y).
5. (**Subobjects**) If (A \in Y) and (S \hookrightarrow A) is a subobject, then (S \in Y).
6. (**Structural operations**) If (F_i \in \mathcal{F}) is an (n)-ary structural operation and (A_1,\dots,A_n \in Y) are in its domain, then (F_i(A_1,\dots,A_n) \in Y).
7. (**Sheaf gluing/restriction**) If (A \in Y), and (A') is obtained from (A) by:
    - restriction along a geometric morphism induced by a subsite of ((\mathbf{T},J)), or
    - sheaf gluing along a covering family in (J),
8. then (A' \in Y).

--------------------------------------------------------------------------------

3.3 Generative Properties

**Requirement HT-G1 (Monotonicity & Inflationarity).** For all (X,Y \subseteq \mathrm{Obj}(\mathsf{R})):

- If (X \subseteq Y), then (\mathcal{G}(X) \subseteq \mathcal{G}(Y)).
- (X \subseteq \mathcal{G}(X)).

**Definition HT-GC (G-closed subclass).** A subclass (X \subseteq \mathrm{Obj}(\mathsf{R})) is **(\mathcal{G})-closed** if (\mathcal{G}(X) \subseteq X).

**Requirement HT-G2 (Idempotence on closed subclasses).** If (X) is (\mathcal{G})-closed, then (\mathcal{G}(X) = X).

--------------------------------------------------------------------------------

3.4 Generated Subuniverse

**Definition HT-Rgen (Generated Object Class).** Define: [ \mathrm{Obj}(\mathsf{R}_{\mathrm{gen}}) :=__\bigcap { X \subseteq \mathrm{Obj}(\mathsf{R})__\mid \mathcal{A} \subseteq X \text{ and } \mathcal{G}(X) \subseteq X }.__]__We call (\mathsf{R}_{\mathrm{gen}}) the **Hypertensor Generated Subuniverse**.

**Requirement HT-G3 (Generated Subuniverse is G-closed).** (\mathrm{Obj}(\mathsf{R}_{\mathrm{gen}})) MUST be (\mathcal{G})-closed and MUST contain (\mathcal{A}). markdown Copy code

3.5 Self-Generation and Initiality

**Requirement HT-G4 (Self-Generation).** The Hypertensor Topos (\mathsf{R}) MUST satisfy: [ \mathrm{Obj}(\mathsf{R}) = \mathrm{Obj}(\mathsf{R}_{\mathrm{gen}}). ] Equivalently, (\mathrm{Obj}(\mathsf{R})) is the least (\mathcal{G})-closed subclass containing (\mathcal{A}).

--------------------------------------------------------------------------------

**Definition HT-HM (Hypertensor Model).** A **Hypertensor Model** is a tuple [ \mathrm{HM} = (\mathsf{S},\mathsf{K},\nu^{\mathsf{S}},\phi^{\mathsf{S}},\mathsf{K}^\ast,\mathcal{A}_{\mathsf{S}}) ] such that:

- (\mathsf{S}) is a topos,
- (\mathsf{K} \in \mathsf{S}) is a Heyting–modal internal object with invariant subobject (\mathsf{K}^\ast),
- there exists a trace site ((\mathbf{T},J)) whose representables and (\mathsf{K}) form an atomic set (\mathcal{A}_{\mathsf{S}}),
- the analogues of HT-A0–HT-A6 hold internally in (\mathsf{S}).

A morphism of Hypertensor Models MUST be a geometric morphism of topoi preserving all distinguished structure up to isomorphism.

--------------------------------------------------------------------------------

**Requirement HT-G5 (Initiality).** Let (\mathrm{HTT} = (\mathsf{R},\mathsf{H},\nu,\phi,\mathsf{H}^\ast)) be the Hypertensor Topos instance associated to a given trace site ((\mathbf{T},J)).

Then, in the category of Hypertensor Models over ((\mathbf{T},J)), (\mathrm{HTT}) MUST be **initial**: for any other Hypertensor Model (\mathrm{HM}) over the same trace site, there MUST exist a unique (up to isomorphism) structure-preserving morphism [ F : \mathrm{HTT} \to \mathrm{HM}. ] markdown Copy code

4. Internal Lambda Calculus and Normalization

This section specifies additional requirements on HTLC and its normalization properties.

4.1 HTLC Soundness and Completeness

**Requirement HT-L1 (Soundness).** For any derivable judgment (\Gamma \vdash M : A) in HTLC:

- The semantic morphism (\llbracket \Gamma \vdash M : A \rrbracket) MUST exist in (\mathsf{R}).
- \llbracket \Gamma \vdash N : A \rrbracket \text{ in } \mathsf{R}. ]

**Requirement HT-L2 (Completeness for Hypertensor Fragment).** Let (\mathsf{R}) be the Hypertensor Topos and HTLC be its lambda calculus.

If a morphism (f : \llbracket \Gamma \rrbracket \to \llbracket A \rrbracket) is generated from:

- finite limits, finite colimits,
- exponentials,
- subobjects,
- and the operations interpreting HTLC term constructors,

then there MUST exist a term (M) with (\Gamma \vdash M : A) such that [ \llbracket \Gamma \vdash M : A \rrbracket = f. ]

--------------------------------------------------------------------------------

4.2 Normalization and Canonical Forms at Type (\mathrm{Rec})

**Definition HT-NF-Alg (Normalization Algorithm NF_Term).** There MUST exist an algorithm [ \mathrm{NF_Term} : {\text{HTLC terms}} \to {\text{HTLC terms}} ] satisfying:

- **Termination**: For every term (M), (\mathrm{NF_Term}(M)) is defined and in normal form.
- **Confluence**: If (M) reduces (by β, η, modal reductions) to both (N_1) and (N_2), then (\mathrm{NF_Term}(N_1) = \mathrm{NF_Term}(N_2)).
- **Equivalence preservation**: If (M) and (N) are provably equivalent, (\mathrm{NF_Term}(M) = \mathrm{NF_Term}(N)).

**Definition HT-NF-Rec (Canonical Rec-Terms).** For closed terms (M : \mathrm{Rec}), define the **canonical representative**: [ \mathrm{NF_Rec}(M) := \mathrm{NF_Term}(M), ] restricted to closed terms of type (\mathrm{Rec}).

A closed (\mathrm{Rec})-term (N) is **canonical** iff (N = \mathrm{NF_Rec}(N)).

--------------------------------------------------------------------------------

**Requirement HT-L3 (Canonical Forms for (\mathrm{Rec})).** For closed terms (M : \mathrm{Rec}):

1. There MUST exist a unique canonical term (N : \mathrm{Rec}) such that [ \vdash M \equiv N : \mathrm{Rec}. ]
2. \llbracket \vdash N : \mathrm{Rec} \rrbracket \in \mathsf{H}. ]
3. \llbracket \vdash N_2 : \mathrm{Rec} \rrbracket, ] then (N_1) and (N_2) MUST be syntactically identical (modulo α-renaming). markdown Copy code

4. Invariant Locale and Spectral Structure

This section specifies the invariant locale and a deviation operator at a specification level.

5.1 Invariant Locale (Phase Space)

**Definition HT-Phase (Invariant Locale).** The invariant subsheaf (\mathsf{H}^\ast) is regarded as an internal frame in (\mathsf{R}). The **Hypertensor Phase Locale** is a locale object (\mathsf{Phase} \in \mathsf{R}) with [ \mathcal{O}(\mathsf{Phase}) \cong \mathsf{H}^\ast. ]

**Requirement HT-P1 (Frame Laws).** (\mathsf{H}^\ast) MUST satisfy the internal frame (complete Heyting algebra) axioms in (\mathsf{R}), and the identification (\mathcal{O}(\mathsf{Phase}) \cong \mathsf{H}^\ast) MUST be an isomorphism of internal frames.

--------------------------------------------------------------------------------

5.2 Sheaf of Invariant Modes

**Definition HT-V (Sheaf of Invariant Modes).** Fix a commutative ring object (K) in (\mathsf{R}) (e.g. a constant sheaf on a commutative ring).

Define (\mathsf{V} : \mathbf{T}^{op} \to \mathbf{Mod}_K) by:

- (\mathsf{V}(t)) is a finite free (K)-module induced from (\mathsf{H}_t^\ast) (e.g. (K^{\mathsf{H}_t^\ast})),
- (\mathsf{V}(f)) is induced by reindexing of invariants along (\mathsf{H}^\ast(f)).

(\mathsf{V}) MUST satisfy the sheaf condition and thus defines a (K)-module object in (\mathsf{R}), called the **Sheaf of Invariant Modes**.

--------------------------------------------------------------------------------

5.3 Deviation Operator and Spectral Decomposition

**Definition HT-D (Deviation Operator).** There MUST exist a natural (K)-linear endomorphism [ D : \mathsf{V} \to \mathsf{V} ] such that:

1. For each trace (t), the component [ D_t : \mathsf{V}(t) \to \mathsf{V}(t) ] is a (K)-linear map.
2. The collection ((D_t)) is natural with respect to reindexing: for each (f : t \to t'), [ \mathsf{V}(f) \circ D_{t'} = D_t \circ \mathsf{V}(f). ]
3. (D) vanishes on “fully invariant” directions: any vector corresponding to a globally invariant mode MUST be in the kernel of (D).

**Requirement HT-S1 (Fiberwise Spectral Decomposition).** Under a chosen algebraic condition (e.g. each (D_t) is diagonalizable over (K)):

- Each (D_t) MUST admit a spectral decomposition [ \mathsf{V}(t) \cong \bigoplus_{\lambda \in \Lambda_t} E_{t,\lambda} ] into eigenspaces.

**Requirement HT-S2 (Spectral Sheaves).** For each eigenvalue (\lambda), the assignment (t \mapsto E_{t,\lambda}) with reindexing induced by (\mathsf{V}(f)) MUST define a subsheaf [ \mathsf{E}_\lambda \subseteq \mathsf{V},__]__and there MUST be an internal decomposition__[__\mathsf{V} \cong \bigoplus_{\lambda \in \Lambda} \mathsf{E}_\lambda ] in (\mathsf{R}).

Here (\Lambda) is the internal set of eigenvalues realized across the site.

In particular, (\mathsf{E}_0) MUST correspond to stable modes (kernel of (D)). markdown Copy code

6. Meta Properties (Normative Summary)

This section restates key global properties that MUST hold for any Hypertensor Topos implementation.

6.1 Presentation Independence

**Requirement HT-M1 (Presentation Independence).** If two primitive specifications ((\mathbf{T},J,\mathsf{H},\nu,\phi)) and ((\mathbf{T}',J',\mathsf{H}',\nu',\phi')) satisfy HT-A0–HT-A6 and define Hypertensor Topoi (\mathsf{R}) and (\mathsf{R}'), then:

- There MUST exist a topos equivalence (F : \mathsf{R} \simeq \mathsf{R}') preserving all distinguished structures up to isomorphism as in HT-R2.
- All derived constructions (phase locale, deviation operator, spectral sheaves, HTLC semantics) MUST be transported along this equivalence.

6.2 Refinement Robustness

**Requirement HT-M2 (Refinement Robustness).** If ((\mathbf{T}',J')) is a refinement of ((\mathbf{T},J)) (e.g. finer trace discretization or stronger topology) and the fiber and modal data are refined compatibly, then the resulting Hypertensor Topos (\mathsf{R}') MUST be equivalent to (\mathsf{R}) as a Hypertensor Model.

6.3 Structural Maximality

**Requirement HT-M3 (Maximality Under A0–A6).** Any additional primitive object-forming operation that:

- is not definable via the closure operator (\mathcal{G}) built from (\mathcal{F}), limits, colimits, exponentials, subobjects, and sheaf gluing/restriction, and
- is intended to be _primitive_,

MUST be understood as changing the underlying axiom set (i.e. resulting in a structure that is no longer a pure Hypertensor Topos instance under HT-A0–HT-A6).

6.4 Universality

**Requirement HT-M4 (Universal Hypertensor Model).** A Hypertensor Topos instance (\mathrm{HTT} = (\mathsf{R},\mathsf{H},\nu,\phi,\mathsf{H}^\ast)) associated to a trace site ((\mathbf{T},J)) MUST be:

- **Self-generated** under (\mathcal{G}) (HT-G4),
- **Initial** among Hypertensor Models over ((\mathbf{T},J)) (HT-G5).

This universality property MUST be preserved under any equivalence of Hypertensor Models.
