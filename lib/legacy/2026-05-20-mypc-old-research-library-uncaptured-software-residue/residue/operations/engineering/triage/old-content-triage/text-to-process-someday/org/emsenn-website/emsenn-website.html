emsenn's Website

Overview

My personal website is a static website: a collection of unchanging files on a webserver, that folk can retrieve. I emphasize the static nature of the site to highlight that there's no interactivity on the site - no comments or anything like that.

I create the files with Hugo, a static site generator, from information extracted from this file. For instructions on using this file, see the "Operations" section.

Other sections contain the information to I extract:

  • "Hugo Configuration" contains Hugo configuration that informs Hugo and my chosen Hugo themes.
  • "Git Configuration" contains a few configuration files used by Git.
  • "Native Content" contains sections that I export with Ox-Hugo, into Hugo-compatible Markdown. The text of the webpage is here, in this document, formatted as Org-mode text (for the most part).
  • "Native Data" contains sections of TOML-serialized data, such as my recent activities and plans.
  • [BROKEN LINK: included-content] includes sections that I export with Ox-Hugo, but the content itself is inside other files, outside the directory where I keep my website.

Operations

  • Install This Website

Install This Website

Regardless of how you install this website, you'll need to install Hugo, which is not covered in this document.

Install with Git
git clone https://git.sr.ht/~emsenn/emsenn-website
Install from Org-mode Source

This shell script makes all the directories Hugo will expect to have. 

mkdir -p ../{content,data,static}

Hugo Configuration

The configuration below tangles to ./build/theme.toml. Explaining it in detail is beyond the scope of this document. https://gohugo.io/themes/ 

# baseURL = "https://emsenn.net"
title = "emsenn"
theme = ["hugo-personal-website-theme"]
[author]
  name = "emsenn"
  homepage = "https://emsenn.net"

Services

Tarot Reading

I think tarot readings can be a wonderful problem-solving tool, regardless of the beliefs of anyone involved: they're a great way for framing a question in a unique way.

I've structured my tarot readings like my other consultation sessions: you can click the button below to fill out a short form to apply. If my service seems like a good fit, we can schedule your session. Otherwise, I'll try to refer you to more useful information.

Generally, I consider a tarot reading to be most useful when you feel like you're struggling with something, but can't seem to think clearly about the problem.

If I accept you for a session, it'll take 30 to 40 minutes. We'll meet through an online video conference, but you don't have to use your microphone or video if you don't want. Afterward, you'll get a brief reporting on the cards that were drawn, and a recording of the session.

"I wasn't interested in any of the mysticism behind tarot, but it didn't matter: emsenn's reading still helped me understand why I was butting heads with my coworker." -- Anonymous Client

To apply for a session, please [send an email](mailto:emsen@emsenn.net) containing the following information:

  • Some personal information: the name you'd like me to call you, and the pronouns you'd like me to use in reference to you.
  • A mention of this service: Put Tarot Reading as your email's subject, or include it prominently in the body.

/(I'm also developing free reading materials on this topic, so please [send an email](mailto:emsenn@emsenn.net) if you're interested in receiving updates about that.)/
