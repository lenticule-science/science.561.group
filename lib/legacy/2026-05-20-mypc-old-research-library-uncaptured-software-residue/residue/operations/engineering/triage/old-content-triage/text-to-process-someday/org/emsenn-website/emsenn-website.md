## Overview

My *personal website* is a *static website*: a collection of unchanging files on a *webserver*, that folk can retrieve. I emphasize the static nature of the site to highlight that there's no interactivity on the site - no comments or anything like that.

I create the files with *Hugo*, a *static site generator*, from information extracted from this file. For instructions on using this file, see the ["Operations"](#operations) section.

Other sections contain the information to I extract:

-   ["Hugo Configuration"](#hugo-configuration) contains *Hugo configuration* that informs *Hugo* and my chosen *Hugo themes*.
-   ["Git Configuration"](#git-configuration) contains a few configuration files used by *Git*.
-   ["Native Content"](#native-content) contains sections that I export with *Ox-Hugo*, into *Hugo*-compatible *Markdown*. The text of the webpage is here, in this document, formatted as *Org-mode* text (for the most part).
-   ["Native Data"](#native-data) contains sections of *TOML*-serialized data, such as my recent activities and plans.
-   [BROKEN LINK: included-content] includes sections that I export with *Ox-Hugo*, but the content itself is inside other files, outside the directory where I keep my website.

## Hugo Configuration

The configuration below *tangles* to `./build/theme.toml`. Explaining it in detail is beyond the scope of this document. <https://gohugo.io/themes/>

```toml
# baseURL = "https://emsenn.net"
title = "emsenn"
theme = ["hugo-personal-website-theme"]
[author]
  name = "emsenn"
  homepage = "https://emsenn.net"
```
