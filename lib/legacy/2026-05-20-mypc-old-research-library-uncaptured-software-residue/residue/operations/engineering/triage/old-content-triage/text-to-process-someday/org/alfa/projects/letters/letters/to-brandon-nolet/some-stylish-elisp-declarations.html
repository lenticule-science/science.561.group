I know you like a bit of style to your stuff, so thought I'd pass on some of the things I've done to prettify my own Emacs, or that I know to do but choose not to.

The reason I had you open this in an Org-mode buffer is so you can run the things directly from here, without having to copy paste. For most of these, just place your cursor anywhere in the source block and press C-c C-c. If you want to edit one of the source blocks, press C-c '. You can close that window with the same hotkey. In it, you can evaluate any bit of Elisp with C-x C-e. And to look up any given... anything, near about, do C-h d, and then type the thing you'd like to search for. If that doesn't work, do C-h ? and look for another hotkey to search - maybe you want v for "variable"?

I'm just looking through my ~/.emacs/init.el and let's look at what I've got: 

(setq inhibit-startup-messaget)
(setq initial-scratch-message nil)
(setq initial-major-mode 'org-mode)

In order, these turn off the "this is Emacs, here are links to manuals," message you get when you start - the default buffer that isn't the *scratch* buffer. The second line turns off any content in the scratch buffer - you could set this to a string if you'd like.2 This third line sets your scratch buffer - now the window that is open and empty and showing when you start Emacs - to Org-mode. Handy for getting started writing, without even needing to go to where it needs to end up, because you can use refile to move your entry to where it should go.3
