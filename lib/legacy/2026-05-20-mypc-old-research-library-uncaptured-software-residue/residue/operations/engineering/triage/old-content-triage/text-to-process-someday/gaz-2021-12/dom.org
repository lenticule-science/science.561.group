***** Vent equation
:PROPERTIES:
:header-args: :var vol=6800 aws=0.5 awo=40 wap=2 wre=0.4 p=2 cyc=5
:END:
vol = volume of room
aws = average wind speed
awo = average wind offset from window
wap = window aperature
wre = window resistance (due to screen)
p = playtime
****** Cycle Time
See http://www.fsec.ucf.edu/en/publications/pdf/FSEC-CR-163-86.pdf
