*/Data/* is the "content" of [[file:information.org][information]], as contrasted to [[file:meta_data.org][meta-data]], which can be seen as the information's "context."

Using [[file:computer.org][computer]], data is often associated with a /type/, which is meta-data about the class of information. Common computer data types are [[file:numbers.org][numbers]], [[file:computer_string.org][computer string]], and [[file:associative_array.org][associative array]].
