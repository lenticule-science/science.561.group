#+name: ox-org-definition
*/[[file:ox_org.org][Ox-org]]/* is a built-in part of the [[file:org_ecosystem.org][Org ecosystem]] that allows for the export of [[file:org_mode_format.org][Org-mode format]] files into Org-mode, itself.

** Use

   To have your [[file:emacsen.org][Emacsen]] enable Org-mode export, use the following declaration:
   
   #+name: ox-org-use-package-declaration-elisp
   #+caption: An Elisp declaration for setting up /Ox-org/ using /use-package/.
   #+begin_src elisp
     (use-package ox-org)
   #+end_src

   #+name: ox-org-key-sequences-table
   #+caption: A table of /key sequences/ used to operate /Ox-org/.
   | Key sequence      | Command                 | Description                                    |
   |-------------------+-------------------------+------------------------------------------------|
   | =C-c C-e S-o o=   | =(org-export-dispatch)= | Export the current buffer as an Org-mode file. |
   | =C-c C-e S-o S-o= | =(org-export-dispatch)= | Export the current buffer as an Org-mode buffer. |
