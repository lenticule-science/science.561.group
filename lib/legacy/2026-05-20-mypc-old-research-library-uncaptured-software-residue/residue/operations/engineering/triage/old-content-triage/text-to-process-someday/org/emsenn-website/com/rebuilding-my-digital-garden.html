Rebuilding my digital garden

In my last communication, I shared that I changed my plans for how I was going to use a computer through the 2023 warm season. I mostly just briefly covered where I'd be posting & hanging out on the Web, though.

Since that communication, I've been rebuilding my digital garden using the tools I'm most familiar with for that purpose: Emacs.

A digital garden is a collection of digital information that emerges from using note-taking software.

Emacs is a very customizable text editor.

I've done this - or at least something very very similar - a few times already, so it was pretty easy to get things basically set up.

The "garden" itself might be said to be the various text files here on my computer: the text file representing this communication, text files defining things like digital garden and Emacs, and so on.

One of these files contains InfoPonEmacs, the configuration I've written to help me use Emacs for cultivating this garden.

InfoPonEmacs is an Emacsen for cultivating a digital garden.

There's a few parts to this, for now, with plans for more in the future.

Org-mode capture templates let me quickly add new notes to the garden, and Org-mode publishing lets me publish all the notes as a collection of HTML documents - which are what I upload as my Website. (That might be where you're reading this.)

I'd like to include a diagram of the rough flow, but I don't currently have that configured - I've noted to plan it though.

In plaintext, though, information comes in from the outside world, through me, into capture templates, where it then goes into notes, which are published as a collection of HTML documents.

Its worth mentioning that a lot of notes share similar sections - for example, there's a section of the garden where I take notes on projects, and most projects contain a section outlining operations, which in turn list tasks.

Tasks share special markup that lets me use them with the Org-mode agenda to make an itinerary for me, of what it is I need to do across various projects.

All the components of this I've mentioned so far are part of the Org-mode package for Emacs; another important component - that I'm not so familiar with, and so not sure how to best integrate into the garden - is Beancount - software for doing accounting, that I also have used for some inventory management in the past. (I'll probably ramble about this in a future communication.)

Right now, since I've only just begun setting things up, nothing looks very sensible - much like a real garden. You can head to the "front gate" as it were by checking out the homepage, but if you want to look at the garden from another perspective, there's also an index.
