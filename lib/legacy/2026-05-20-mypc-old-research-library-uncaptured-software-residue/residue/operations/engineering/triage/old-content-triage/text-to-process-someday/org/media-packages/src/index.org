* Media Packages
#+TOC: headlines 1 local
** Overview
A */media package/* is a manifest of information about a piece of
media content, providing information about the piece as well as
information about from where it can be obtained.

A */media package channel/* provides a listing of /media packages/.
** Media Package Specification
A /media package/ is the core concept around which these
specifications are built, representing information about a piece of
media content, such as a painting, song, or story.

Here's the currently defined parts of a /media package/:
- Required:
  - =identifier=
  - =version=
- Optional:
  - =title=
  - =creator=
*** Media Package Requirements
#+TOC: headlines 1 local
**** Media Package Identifier
Every /media package/ must have a unique =identifier= - unique to the
channel, at least. In the /Hugo Media Package Channel Generator/, each
package is identified by its /slug/, which is the "kebab-case"
filename at which the package is saved, stripped of its extension.

The =identifier= is expected to be semantically meaningful.
**** Media Package Versions
Every /media package/ must have at least one =version=

** Media Package Channels
A */media package channel/* is a listing of /media packages/.
** Implementations
*** Media Package Channel Generators
A */media package channel generator/* is a piece of software that
creates a /media package channel/. In my implementation, it does that
by reading files written in /TOML/ and /Markdown/ and, using /Hugo/,
generates /HTML/ and /JSON/ files.

- I'm working on a collection of /Hugo/ templates that take
  /Hugo/-compatible /Markdown/ (a combination of /Markdown/ and
  /TOML/) /media packages/ and turn them into a /media package
  channel/ in /HTML/ and /JSON/.
