While looking up how I prettify my /Org-mode checkboxes/, I found that /Emacs/, since version 24.4, comes with a bultin =prettify-symbols-mode=. It swaps out text with a /Unicode/ symbol. This led me to a post [[http://www.modernemacs.com/post/prettify-mode/]["Mathematical Notation in Emacs",]] which is convenient for me: I want to learn to read maths.

I'm not going to rewrite its explanation of its code blocks, but reproduce them here for my own use. The first enables the =pretty-mode= package and turns off some parts of it, to make room for features that will be enabled by later code blocks.

#+begin_src elisp
(require 'pretty-mode)
(global-pretty-mode t)

(pretty-deactivate-groups
 '(:equality :ordering :ordering-double :ordering-triple
             :arrows :arrows-twoheaded :punctuation
             :logic :sets))

(pretty-activate-groups
 '(:sub-and-superscripts :greek :arithmetic-nary))
#+end_src

Let me see if I can't figure out how to write that as a =use-package= declaration, and since I'm not setting up the litagure stuff right now, I'll leave all the stuff on.

#+name: pretty-mode-use-package-declaration-alpha
#+begin_src elisp :noweb yes
  (use-package pretty-mode
    :ensure pretty-mode
    :config
    (progn
      (global-pretty-mode t)
      (global-prettify-symbols-mode 1)
      (pretty-activate-groups
       '(:sub-and-superscripts :greek :arithmetic-nary))))
#+end_src

That seems to work! (And now gets appended to my /Emacs configuration/.

I guess what I need to know is what's a \lambda expression in /Emacs/, and what's the =push= function takes and returns.

I was reading about \lambda calculus on /Wikipedia/ recently, so the /Elisp Reference Manual's/ brief explanation of what \lambda expressions might make sense. It says they're "anonymous functions," but are more commonly associated with symbols to make a named function. A \lambda expression - contained within =()=, always starts with the =lambda= symbol, then takes a list of argument variables, called the "\lambda list." There can be a documentation string, an interactive declaration, and then the body - very similar to a normal function declaration, except with =lambda= instead of =defun function-name=.
