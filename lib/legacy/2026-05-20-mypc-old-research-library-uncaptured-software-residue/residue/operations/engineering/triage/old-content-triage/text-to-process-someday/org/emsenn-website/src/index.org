** Overview
My /personal website/ is a /static website/: a collection of
unchanging files on a /webserver/, that folk can retrieve. I emphasize
the static nature of the site to highlight that there's no
interactivity on the site - no comments or anything like that.

I create the files with /Hugo/, a /static site generator/, from
information extracted from this file. For instructions on using this
file, see the [[#operations]["Operations"]] section.

Other sections contain the information to I extract:
- [[#hugo-configuration]["Hugo Configuration"]] contains /Hugo configuration/ that informs
  /Hugo/ and my chosen /Hugo themes/.
- [[#git-configuration]["Git Configuration"]] contains a few configuration files used by
  /Git/.
- [[#native-content]["Native Content"]] contains sections that I export with /Ox-Hugo/, into
  /Hugo/-compatible /Markdown/. The text of the webpage is here, in
  this document, formatted as /Org-mode/ text (for the most part).
- [[#native-data]["Native Data"]] contains sections of /TOML/-serialized data, such as
  my recent activities and plans.
- [[#included-content]["Included Content"]] includes sections that I export with /Ox-Hugo/,
  but the content itself is inside other files, outside the directory
  where I keep my website.

*** Install This Website
Regardless of how you install this website, you'll need to install
/Hugo/, which is not covered in this document.
**** Install with Git
#+begin_src sh
  git clone https://git.sr.ht/~emsenn/emsenn-website
#+end_src
**** Install from Org-mode Source
This shell script makes all the directories Hugo will expect to have.
#+begin_src sh :results none
  mkdir -p ../{content,data,static}
#+end_src

**** Tarot Reading
   :PROPERTIES:
   :EXPORT_FILE_NAME: ./build/content/services/tarot-reading
   :END:
I think */tarot readings/* can be a wonderful problem-solving tool,
regardless of the beliefs of anyone involved: they're a great way for
/framing a question in a unique way/.

I've structured my tarot readings like my other consultation sessions:
you can click the button below to fill out a short form to apply. If
my service seems like a good fit, we can schedule your session.
Otherwise, I'll try to refer you to more useful information.

Generally, I consider a tarot reading to be most useful when you
/feel/ like you're struggling with something, but can't seem to
/think/ clearly about the problem.

If I accept you for a session, it'll take 30 to 40 minutes. We'll meet
through an online video conference, but you don't have to use your
microphone or video if you don't want. Afterward, you'll get a brief
reporting on the cards that were drawn, and a recording of the
session.
