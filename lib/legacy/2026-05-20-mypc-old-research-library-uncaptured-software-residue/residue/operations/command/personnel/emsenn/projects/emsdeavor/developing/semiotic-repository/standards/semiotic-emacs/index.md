# Semiotic Emacs

This repository is the consolidated Emacs configuration module for the emsemioverse.

It is intended to replace older configuration fragments spread across:

- `emacs-config` (literate Org tangling into `~/.emacs.d/`)
- `emacsen` (configuration embedded alongside other material)

This module focuses on a single Emacs user directory (`emacs/`) that can be treated as the configuration surface.
