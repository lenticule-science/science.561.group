Hevi Mala is a fiction project set in the Hala Basin, a fictionalized
border region shaped by war, displacement, logistics, and the ordinary
work of keeping people alive. The project centers a clinic that also
functions as a relay node, waypoint, and pressure point.

This first batch establishes the project frame and setting. Character
pages, story texts, and additional support material should be added
only when a concrete intake pass needs them.
