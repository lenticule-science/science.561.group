- Repository operability and required top-level files: `semiotic-repository`.

- Spec writing (when writing norms/constraints): `spec-spec`.
- Git semantics for stability/provenance: `semiotic-git`.
- GitHub-hosted execution/publication (if used): `semiotic-github`.
