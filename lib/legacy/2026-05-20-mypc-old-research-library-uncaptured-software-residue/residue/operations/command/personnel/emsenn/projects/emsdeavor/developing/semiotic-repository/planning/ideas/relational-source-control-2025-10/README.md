The ***Relationing Research Program Repository*** is a research program developing an understanding of *relationing*, a framework of logic, algebra, calculus, geometry, and physics derived by emsenn from Lakota cosmogeny.

***Why?*** The research program exists as an extension of Lakota culture and spiritual practice into the scientific community, picking up threads of work left by Vine Deloria Jr. and Aragorn!

***How?*** Poorly, at the moment; the program is in its early days and is just starting the process of organizing into a coherent method. But: a specialized Emacs configuration, GnoponEmacs, is used to manage a Org-roam database whose nodes are themselves Things, Morphisms, Systems, etc. within a Modality of Relationing.



-   **`org/`:** The canonical files which make up the research program itself.
    -   **`org/ref/`:** Reference nodes: external publications, terms.
    -   **`org/txt/`:** Research texts: Papers with theorems, experiments, etc.
-   **`src/`:** Computer programs and scripts for doing relationing.
-   **`pub/`:** Publications for external distribution.
