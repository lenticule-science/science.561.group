# semiotic-emacs

This repository is the consolidated Emacs configuration module for the emsemioverse.

It exists to replace the older, scattered Emacs configuration repositories (notably `emacs-config` and the configuration embedded in `emacsen`) with a single canonical configuration surface.

This module is intended to be used in an emsemioverse workspace (a metarepo with `./library/` and `./engine/`).

## Layout

- `emacs/`: the Emacs “user directory” (intended to be used as `user-emacs-directory`)
- `index.md`: documentation entrypoint (publishable as a “book”)

## Status

Draft; consolidation in progress.
