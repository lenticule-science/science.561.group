---
name: forgetting-the-negation
description: The functor U from Bilattice to Pre-bilattice that drops the unary negation. Induced by the signature inclusion ⟨∧_t, ∨_t, ∧_k, ∨_k⟩ ⊂ ⟨∧_t, ∨_t, ∧_k, ∨_k, ~⟩.
having-domain: bilattice
having-codomain: pre-bilattice
---

Forgetting-the-negation is the functor $U : \mathbf{Bilattice} \to \mathbf{Pre\text{-}bilattice}$ that sends $\langle B, \wedge_t, \vee_t, \wedge_k, \vee_k, \sim \rangle$ to $\langle B, \wedge_t, \vee_t, \wedge_k, \vee_k \rangle$ and is the identity on underlying functions. $U$ is faithful, not full. Its left adjoint, where it exists, is given on interlaced bounded pre-bilattices by the twist product equipped with the swap-negation.
