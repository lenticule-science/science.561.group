---
name: sigma-algebra
description: A σ-complete Boolean lattice — a Boolean algebra closed under countable suprema (equivalently, countable infima).
specializing: lattice

---

A **σ-algebra** on a set Ω is a collection 𝓕 ⊆ 2^Ω that contains Ω, is closed under complementation (A ∈ 𝓕 ⟹ Ω\A ∈ 𝓕), and is closed under countable unions (A_1, A_2, ... ∈ 𝓕 ⟹ ⋃_n A_n ∈ 𝓕). Abstractly: a σ-algebra is a σ-complete Boolean lattice — a Boolean algebra (a complemented distributive lattice) with countable suprema. The carrier set Ω is recoverable as the top element of the lattice. Generated σ-algebras: given a collection 𝓒 ⊆ 2^Ω, σ(𝓒) is the smallest σ-algebra containing 𝓒. Standard examples: the Borel σ-algebra σ(open sets) on a topological space; the σ-algebra generated by a random variable. Specializes [lattice](../../../lattice.md).
