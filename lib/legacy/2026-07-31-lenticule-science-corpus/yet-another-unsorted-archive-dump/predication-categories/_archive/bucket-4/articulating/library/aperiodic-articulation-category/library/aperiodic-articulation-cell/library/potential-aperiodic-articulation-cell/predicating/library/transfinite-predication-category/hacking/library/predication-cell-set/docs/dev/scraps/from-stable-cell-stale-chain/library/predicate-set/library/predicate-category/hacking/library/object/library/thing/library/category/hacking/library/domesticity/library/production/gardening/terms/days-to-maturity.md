The number of days from planting (for direct-sown crops) or
transplanting (for transplanted crops) until the plant is ready to
harvest. Listed on seed packets and in catalogs, this number is compared
to the length of the local frost-free growing season to determine
whether a crop can be grown outdoors in a given location.
