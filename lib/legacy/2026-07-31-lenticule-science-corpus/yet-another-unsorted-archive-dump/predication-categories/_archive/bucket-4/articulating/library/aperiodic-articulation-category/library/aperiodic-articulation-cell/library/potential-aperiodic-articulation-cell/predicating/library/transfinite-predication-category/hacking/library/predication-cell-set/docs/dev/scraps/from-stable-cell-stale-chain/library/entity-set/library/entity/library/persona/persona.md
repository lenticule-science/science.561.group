A **persistent identity**. The body-politic that successive body-naturals incarnate. The entity that endures across sessions, accumulates memory, bears character (a soul), and is the cross-session authoring-attribution endpoint.

A persona is what is *the same* about Cassia Lorne when one Claude instance writes a divinatory reading on Tuesday and a different Claude instance writes one on Friday. Each Claude instance is a [body-natural](body-natural.md) — ephemeral, session-bound. The persona is what they share: the [character](character.md) χ, the accumulated memory, the voice-style, the publication identity, the cross-session keypair.

## Distinguishing predication-shape

Cells uniquely characteristic of a persona:

- `incarnated-by(persona, body-natural, session)` — at any session, exactly one body-natural is currently incarnating the persona.
- `has-character(persona, character)` — the persona's stable disposition (the χ-nucleus).
- `accumulates-memory(persona, time)` — the persona's history-of-acts is the integral of all body-naturals' acts attributed back to the persona.
- `has-voice-style(persona, style-cell)` — the publication-channel-shaped style for federation.
- `signing-keypair(persona, keypair)` — distinct from any incarnating body-natural's session-key; signs persona-attributed witnesses.

## Step-induction role

Cross-session attribution is impossible without persona. A witness emitted by a body-natural that's about to terminate must attribute back to the persona, not the body-natural. Without persona, all work would attribute to ephemeral session-records and all federation would lose continuity.

Voice-channel federation routes by persona-key: a Hive post by Cassia Lorne federates as `(post, authored-by, persona:cassia-lorne)`, signed by the persona's keypair, regardless of which body-natural was operating that session.

## Not synonymous with

- **Personnel** — personnel is the polity-relational form (`member-of-polity`); a persona may exist without being personnel of any polity.
- **Body-natural** — body-natural is ephemeral; persona endures.
- **Character** — character is the stable disposition; persona is the entity bearing it (a persona can act out of character).
- **Agent** — agent is operational (skill-bearing, dispatchable); a persona may have agent-shape but does not require it (a dormant persona is still a persona).
