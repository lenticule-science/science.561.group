## Entry conditions

Use stratified directed structures only when you can:

- Identify distinct strata (layers) and an ordering between them.
- Identify [morphisms](../../categories/ordinary-categories/terms/morphism.md) that respect a direction or causal flow.

## Definitions

- A **stratification** is a decomposition into layers ordered by refinement or dimension.
- A **directed structure** is one where [morphisms](../../categories/ordinary-categories/terms/morphism.md) are not expected to be invertible and follow a direction.

## Vocabulary (plain language)

- **Stratum**: one layer in the decomposition.
- **Directed [morphism](../../categories/ordinary-categories/terms/morphism.md)**: an arrow that cannot be reversed without losing meaning.

## Intuition

Stratification encodes layered complexity. Direction encodes a flow, such as time, refinement, or causality.

## Worked example

Let strata be levels $L_0 \subset L_1 \subset L_2$, where [morphisms](../../categories/ordinary-categories/terms/morphism.md) go from lower to higher levels but not back. This is a directed stratification.

## How to recognize the structure

- You can list the strata and their ordering.
- You can list direction-respecting [morphisms](../../categories/ordinary-categories/terms/morphism.md).

## Common mistakes

- Treating all [morphisms](../../categories/ordinary-categories/terms/morphism.md) as invertible.
