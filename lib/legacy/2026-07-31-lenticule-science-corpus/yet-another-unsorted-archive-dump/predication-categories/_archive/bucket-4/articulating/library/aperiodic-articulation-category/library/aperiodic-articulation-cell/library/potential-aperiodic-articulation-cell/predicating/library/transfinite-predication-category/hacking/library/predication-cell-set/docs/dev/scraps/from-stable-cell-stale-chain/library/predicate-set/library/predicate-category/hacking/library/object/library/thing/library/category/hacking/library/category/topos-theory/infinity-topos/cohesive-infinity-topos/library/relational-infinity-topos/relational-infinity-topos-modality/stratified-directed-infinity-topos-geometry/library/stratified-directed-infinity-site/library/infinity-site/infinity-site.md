An ∞-site is an [∞-category](../../categories/infinity-categories/terms/infinity-category.md) equipped with a Grothendieck topology — a specification of [covering families](./covering-family.md) for each object, satisfying higher-categorical analogues of the axioms for a [site](../../../disciplines/sheaf-theory/terms/site.md). The Grothendieck topology on an ∞-category determines which [presheaves](../../../disciplines/sheaf-theory/terms/presheaf.md) (∞-[functors](../../categories/ordinary-categories/terms/functor.md) to spaces) satisfy the [sheaf condition](../../../disciplines/higher-topos-theory/terms/sheaf-condition.md), now understood as homotopy descent.

The category of sheaves on an ∞-site is an [(∞,1)-topos](../../../disciplines/higher-topos-theory/terms/infinity-1-topos.md) — the higher-categorical analogue of a Grothendieck topos. The objects are [sheaves of spaces](../../../disciplines/higher-topos-theory/terms/sheaf-of-spaces.md) (∞-sheaves), and the [sheaf condition](../../../disciplines/higher-topos-theory/terms/sheaf-condition.md) requires that compatible local data glues uniquely up to coherent [homotopy](../../../disciplines/homotopy-theory/terms/homotopy.md). This is the natural setting for homotopy-coherent geometry and logic.

In a [stratified directed ∞-site](./working-definition.md), the ∞-site structure is combined with [stratification](./stratification.md) (layers) and [directedness](./directed.md) (irreversible [morphisms](../../categories/ordinary-categories/terms/morphism.md)). The resulting structure supports sheaf conditions that respect both the layering and the directional constraints — covering families must be compatible with strata and with the preferred direction of [morphisms](../../categories/ordinary-categories/terms/morphism.md).
