Felt weight is one of five operational outcomes defined by [visual engineering practices](../_index.md). It names the artifact's capacity to carry perceptual mass — blocks, contrasts, voids, and alignments that feel load-bearing. Weight is used as structure, not as decoration.

Felt weight arises from [Bauhaus](../../../texts/bauhaus-pedagogy.md) constructive typography (type as mass), structured ground (void as beam), and [brutalist](../../../texts/brutalism.md) bluntness (blocks that declare their load-bearing role). Weight is then constrained by [Tuftean](../../../texts/tuftean-information-design.md) honesty: weight must correspond to structural priority, not hype.

The concept is related to how the visual system uses coarse structure to guide subsequent detailed inspection [@wolfe2004]. Large typographic blocks function as structural beams; typographic contrast allocates attention instantly.
