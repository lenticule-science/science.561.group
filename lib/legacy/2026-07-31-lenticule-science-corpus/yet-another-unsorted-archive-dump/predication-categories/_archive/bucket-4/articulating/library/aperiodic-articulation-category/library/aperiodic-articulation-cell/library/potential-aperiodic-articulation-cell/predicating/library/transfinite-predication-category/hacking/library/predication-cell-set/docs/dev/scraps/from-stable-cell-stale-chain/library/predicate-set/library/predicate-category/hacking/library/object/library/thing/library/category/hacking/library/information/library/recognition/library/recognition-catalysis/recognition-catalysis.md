# Recognition Catalysis

Recognition whose presence enables flow or collapse that would otherwise be
impossible.

## Definition
- Components: catalytic recognition, target process (flow/collapse), and witness
  that process succeeds only when catalyst present.
- Role: models enabling effects in relational dynamics.

## Invariants
- Necessity: without catalyst, process fails; with catalyst, succeeds.
- Stability: catalyst effect persists under admissible flow.

## Proof
- Uses: recognition carrier and flow operations to exhibit catalytic effect.
- Shows that: catalysts can be identified as enablers of otherwise forbidden
  transitions.
