To raise in [poker](../_index.md) is to increase the current wager [@britannica2026poker]. A raise keeps the player in the [hand](./hand.md) while forcing later players to pay more if they want to continue.

Raising is the action that gives poker much of its strategic depth. It can build the [pot](./pot.md) when the raiser expects to be ahead, pressure weaker ranges into [folding](./fold.md), or represent a stronger hand than the player actually holds. Because a raise changes both information and price, it does more than move chips [@sklansky1999].
