A soft hand in [blackjack](../_index.md) is a hand that contains an ace counted as 11 without causing a [bust](./bust.md) [@thorp1966]. For example, ace-six is a soft 17. If the player takes another card and would otherwise go over 21, the ace can convert from 11 to 1 and the hand becomes hard instead of busting.

Soft hands matter because they are more flexible than [hard hands](./hard-hand.md) with the same visible total. A soft 17 can take another card without immediate failure, while a hard 17 cannot. This flexibility changes optimal decisions about hitting, standing, and doubling, and it is one reason dealer rules about soft 17 affect the [house edge](../../../terms/house-edge.md) [@shackleford2025blackjackcalculator].
