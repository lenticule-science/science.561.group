Non-linear reading is one of five operational outcomes defined by [visual engineering practices](../_index.md). It names the artifact's capacity to support scanning, jumping, and revisiting without collapse into a single linear sentence-by-sentence path. It treats reading as navigation across anchors, not as pure flow.

Non-linear reading arises when [cubist](../../../texts/cubism.md) discontinuity and multi-frame layout interrupt smooth flow, while [Bauhaus](../../../texts/bauhaus-pedagogy.md) rhythm provides recurring footholds and [Tuftean](../../../texts/tuftean-information-design.md) micro/macro coherence ensures that jumps remain meaningful rather than arbitrary.

The concept draws support from eye-movement research showing that scanning behavior is task-dependent [@rayner1998] — reading is not a fixed left-to-right process but a set of strategies shaped by the layout's affordances.
