A natural blackjack in [blackjack](../_index.md) is a two-card total of 21 made from an ace and any ten-value card [@shackleford2025blackjackcalculator]. It is structurally distinct from reaching 21 with three or more cards because casino rules usually pay it at a premium rather than at even money.

That premium matters mathematically. A game paying natural blackjacks at 3:2 is materially better for the player than a game paying them at 6:5, even if the rest of the visible procedure looks identical. This is one of the clearest examples of how a small rule change can shift the [house edge](../../../terms/house-edge.md) [@shackleford2025blackjackcalculator].
