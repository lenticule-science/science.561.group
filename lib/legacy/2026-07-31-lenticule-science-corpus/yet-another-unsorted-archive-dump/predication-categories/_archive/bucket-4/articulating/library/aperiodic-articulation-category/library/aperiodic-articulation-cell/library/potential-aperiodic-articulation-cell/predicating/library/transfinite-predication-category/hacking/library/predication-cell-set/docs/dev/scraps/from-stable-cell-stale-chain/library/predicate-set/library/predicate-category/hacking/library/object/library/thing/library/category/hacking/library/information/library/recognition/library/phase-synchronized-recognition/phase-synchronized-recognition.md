# Phase-Synchronized Recognition

Recognitions that maintain phase coherence under flow disruptions.

## Definition
- Elements: recognitions/sections whose harmonic components remain in fixed
  phase relationships under [Harmonic Flow](../operator/harmonic-flow.md) and
  perturbations.
- Role: signal synchronizable patterns.

## Invariants
- Phase coherence: relative phases stay locked.
- Robustness: small perturbations do not break synchrony.

## Proof
- Uses: harmonic flow analysis on sections.
- Shows that: synchronizable patterns form a recognisable carrier.
