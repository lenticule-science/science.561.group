A layered underground storage organ that contains a compressed stem
surrounded by fleshy scale leaves filled with stored nutrients. A bulb
produces a new plant each growing season from its center. In the garden,
bulbs are planted at a specified depth and orientation (pointed end up).
Common garden bulbs include garlic and onions.
