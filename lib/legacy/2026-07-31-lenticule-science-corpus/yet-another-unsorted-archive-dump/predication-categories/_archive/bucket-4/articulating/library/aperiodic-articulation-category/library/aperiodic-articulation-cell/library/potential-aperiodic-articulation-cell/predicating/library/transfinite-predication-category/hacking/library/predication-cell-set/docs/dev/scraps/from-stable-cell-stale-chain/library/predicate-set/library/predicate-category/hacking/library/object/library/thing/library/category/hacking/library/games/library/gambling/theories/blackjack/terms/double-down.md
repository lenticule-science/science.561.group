To double down in [blackjack](../_index.md) is to double the original [wager](../../../terms/wager.md) in exchange for committing to receive exactly one additional card [@thorp1966]. The action increases both risk and reward: the player invests more precisely when the expected value of one more card is favorable enough to justify the larger stake.

Double-down rules vary by ruleset. Some tables allow doubling on any first two cards. Others restrict it to totals such as 9, 10, or 11, or prohibit it after a [split](./split.md). Because doubling changes how much money enters favorable situations, its availability materially affects the [house edge](../../../terms/house-edge.md) [@shackleford2025blackjackcalculator].
