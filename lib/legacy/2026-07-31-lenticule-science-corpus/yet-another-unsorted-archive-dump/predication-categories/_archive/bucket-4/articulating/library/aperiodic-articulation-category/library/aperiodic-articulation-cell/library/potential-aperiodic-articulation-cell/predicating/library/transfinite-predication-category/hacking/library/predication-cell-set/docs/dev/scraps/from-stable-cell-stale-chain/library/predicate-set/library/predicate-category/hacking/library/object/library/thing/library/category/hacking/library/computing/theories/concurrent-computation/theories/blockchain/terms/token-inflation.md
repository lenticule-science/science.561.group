Token inflation occurs when the supply of a cryptocurrency grows faster than demand for it, decreasing the value of each token.

**Two mechanisms**:

1. **Supply growth**: New tokens are continuously minted and distributed to users (e.g., farming rewards, staking yield).
2. **Demand insufficiency**: The sinks for tokens (ways tokens are destroyed or locked) don't consume tokens as fast as new ones are minted.

**The Axie Infinity case**:

Smooth Love Potion (SLP) had an uncapped supply. Supply grew from multiple sources:
- PvP battles (44% of daily supply)
- Adventure mode grinding (40%)
- Daily quests (14%)

Demand (breeding, which consumes SLP) was too low. Over one year, SLP supply grew 16,000% while demand remained flat. The result: token price fell from $0.34 to less than half a penny.

**Solutions**:

- **Supply caps**: Fix the maximum supply upfront.
- **Multiple sinks**: Create many ways to spend or lock tokens.
- **Governance oversight**: Monitor supply/demand ratios and adjust if they diverge.
- **Utility focus**: Ensure tokens have real uses beyond speculation.
