- Generate a balance sheet and confirm assets = liabilities + equity.
- Generate an income statement for the period and calculate net income.
- Compare income statement to budget to identify over/under-spending.
- Check cash flow to confirm sufficient liquidity for upcoming obligations.
- Identify trends across periods: growing debt, declining savings, seasonal patterns.
