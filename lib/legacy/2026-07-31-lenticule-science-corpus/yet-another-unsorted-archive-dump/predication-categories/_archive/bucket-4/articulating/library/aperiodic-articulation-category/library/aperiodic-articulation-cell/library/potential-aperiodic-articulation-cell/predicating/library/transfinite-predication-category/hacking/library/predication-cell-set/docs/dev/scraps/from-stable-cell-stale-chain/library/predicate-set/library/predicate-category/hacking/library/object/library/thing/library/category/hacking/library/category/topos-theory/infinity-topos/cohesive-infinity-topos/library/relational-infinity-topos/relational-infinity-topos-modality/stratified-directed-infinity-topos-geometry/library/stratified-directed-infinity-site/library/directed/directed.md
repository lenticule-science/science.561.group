A directed structure on a category or [∞-category](../../categories/infinity-categories/terms/infinity-category.md) means that [morphisms](../../categories/ordinary-categories/terms/morphism.md) have a preferred direction: not all [morphisms](../../categories/ordinary-categories/terms/morphism.md) are invertible. In an ordinary [category](../../categories/ordinary-categories/terms/category.md), this is the default — [morphisms](../../categories/ordinary-categories/terms/morphism.md) go from source to target and need not have inverses. The term "directed" is emphasized when contrasting with groupoids or [∞-groupoids](../../../disciplines/homotopy-theory/terms/homotopy-type.md), where all [morphisms](../../categories/ordinary-categories/terms/morphism.md) are invertible.

In [directed homotopy theory](../../../disciplines/homotopy-theory/terms/directed-homotopy.md), paths have a preferred direction and cannot be freely reversed. The fundamental category of a directed space replaces the [fundamental group](../../../disciplines/homotopy-theory/terms/fundamental-group.md) of classical homotopy theory, capturing asymmetric connectivity. This directedness models irreversible processes — state transitions, time evolution, causal order.

In a [stratified directed ∞-site](./working-definition.md), the directed structure constrains how [morphisms](../../categories/ordinary-categories/terms/morphism.md) move between [strata](./stratum.md): [refinement](./refinement.md) maps go from coarser to finer layers, and this directedness is not invertible. The combination of directedness with [stratification](./stratification.md) and higher categorical structure produces a site suited for modeling processes that are both layered and irreversible.
