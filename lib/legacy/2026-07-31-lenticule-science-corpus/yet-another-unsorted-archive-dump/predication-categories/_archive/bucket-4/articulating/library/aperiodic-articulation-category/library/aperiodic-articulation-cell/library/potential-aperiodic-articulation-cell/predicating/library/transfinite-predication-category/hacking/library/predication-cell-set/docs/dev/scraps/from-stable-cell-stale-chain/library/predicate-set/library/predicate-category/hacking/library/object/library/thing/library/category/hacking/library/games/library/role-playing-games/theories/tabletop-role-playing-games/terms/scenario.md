A scenario is the prepared package of situations, locations, non-player characters, pressures, and clues that a [tabletop role-playing game](../_index.md) group will engage during play. It is not a script for what the players must do. It is the authored starting state and the actionable parts of the world that the [game master](../../../terms/game-master.md) can bring to the table.

A good scenario gives players meaningful things to interact with: places to investigate, people with goals, dangers in motion, and information that points toward further choices. In practice, this is why strong TTRPG prep focuses on situations rather than plotted outcomes. The scenario should make action possible without predetermining the path through it.
