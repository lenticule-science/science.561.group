To call in [poker](../_index.md) is to match the current wager so the player can remain in the [hand](./hand.md) [@britannica2026poker]. Calling neither ends the action nor increases the price for later players. It accepts the current price of continuation.

Calling matters because poker decisions are comparative. A player calls when the expected value of continuing at the current price is better than [folding](./fold.md), but not strong enough to justify a [raise](./raise.md). This relation between hand strength, draw potential, and price is one of poker's central analytical problems [@sklansky1999].
