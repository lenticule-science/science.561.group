Initiative is a rule for sequencing actions during conflict in a [tabletop role-playing game](../_index.md). When multiple [characters](../../../terms/character.md) act simultaneously — typically in combat — initiative determines who goes first.

Most systems determine initiative by rolling dice and adding a [modifier](./modifier.md) derived from a speed or agility attribute. The resulting order persists for the duration of the encounter. Some systems re-roll each round; others use fixed or narrative-based ordering (the fiction determines who acts next based on the situation).

Initiative systems carry design trade-offs. Strict turn order creates clarity but can feel artificial when a slow character must wait while faster characters take multiple actions. Some systems address this by grouping actions into phases (everyone declares, then everyone resolves) or by using a popcorn initiative where the acting player chooses who goes next. The choice of initiative system affects pacing, tactical depth, and how much time players spend waiting for their turn.
