name: goal
description: A directional ambition that orients work without being a decidable target. An entity-form whose characteristic predication-shape names a direction, not an endpoint.

## Pure form

A goal is a direction the polity is trying to bring about. The defining predication: `(goal, has-direction, direction-description)`. Unlike an [objective](objective.md), the goal is *not* decidable — at no moment does inspection of the goal alone settle whether the goal is reached. A goal is reached, partly reached, advanced, set back. The decidability work is delegated to the objectives that serve it.

Goals carry normative weight: abandoning a goal is not a scheduling choice but a revision of what the agent is committed to. A goal that no project or campaign serves is an aspiration, not a goal in the operational sense.

## Characteristic predication-shape

- `has-direction(goal, direction-description)` — the orientation; the individuating predication.
- `served-by(goal, project | campaign)` — work organized to advance the goal.
- `serves(goal, goal)` — instrumental goal serving a higher (terminal) goal.
- `has-temporal-kind(goal, {aim-terminated | indefinite | aim-open})` — whether the goal has an endpoint, persists indefinitely, or self-modifies as the work advances.
- `held-by(goal, agent | ship | polity)` — the committing locus.

## Temporal kinds

A single goal can be all three at once. The 561 Group's core endeavor — founding the polity as a tiyóšpaye and the RSC Quiescent — is *indefinite* (the polity persists), *aim-open* (what founding concretely means transforms as the polity advances), and *aim-terminated at scale* (specific founding milestones can be reached). The recognition shape appropriate to a goal depends on its temporal kind; coverage of contributing projects is the right recognizer only for aim-terminated goals.
