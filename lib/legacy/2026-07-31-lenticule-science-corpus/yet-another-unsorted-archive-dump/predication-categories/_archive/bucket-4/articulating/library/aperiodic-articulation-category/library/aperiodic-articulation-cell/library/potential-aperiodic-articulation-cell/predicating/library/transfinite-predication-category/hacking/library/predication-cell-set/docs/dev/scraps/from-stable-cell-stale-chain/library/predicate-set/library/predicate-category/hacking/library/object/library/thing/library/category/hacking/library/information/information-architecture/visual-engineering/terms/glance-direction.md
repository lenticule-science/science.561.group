Glance-direction is one of five operational outcomes defined by [visual engineering practices](../_index.md). It names the artifact's capacity to produce a fast "first grasp" of where to look and what to do next. This is not the same as comprehension; it is the reduction of initial uncertainty.

Glance-direction arises when [Bauhaus](../../../texts/bauhaus-pedagogy.md) construction (clear relational field) is paired with [brutalist](../../../texts/brutalism.md) hierarchy (hard, sparse contrasts) under [Tuftean](../../../texts/tuftean-information-design.md) budgeting (few marks that matter). The eye is not asked to choose among many equal candidates; it is given a small number of structurally meaningful anchors.

The concept can be related to empirical findings on attentional deployment: attention can be guided both endogenously (by task goals) and exogenously (by salient cues) [@posner1980]. Glance-direction works by aligning both pathways — making the salient cues coincide with the structurally important elements.
