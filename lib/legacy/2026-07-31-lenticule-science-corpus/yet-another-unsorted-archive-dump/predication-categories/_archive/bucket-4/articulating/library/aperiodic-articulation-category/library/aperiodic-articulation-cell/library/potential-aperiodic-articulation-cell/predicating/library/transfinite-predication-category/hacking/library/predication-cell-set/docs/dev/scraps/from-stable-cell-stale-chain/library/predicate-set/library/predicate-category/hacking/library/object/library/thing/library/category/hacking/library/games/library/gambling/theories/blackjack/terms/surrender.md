To surrender in [blackjack](../_index.md) is to concede the hand before play is completed and lose only part of the original wager, usually one half [@thorp1966]. Surrender exists because some starting positions are weak enough that cutting the loss is better than continuing.

Not all blackjack tables offer surrender, and the timing matters. Late surrender, where the option is available only after the dealer checks for a [natural blackjack](./natural-blackjack.md), is more favorable to the house than early surrender. Because surrender gives the player a controlled way to cap losses in especially weak positions, its presence lowers the [house edge](../../../terms/house-edge.md) [@shackleford2025blackjackcalculator].
