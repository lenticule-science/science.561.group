Decomposed organic material (plant scraps, leaves, food waste) used as
a soil amendment. Compost improves soil structure, adds nutrients,
increases water-holding capacity, and supports beneficial soil organisms.
It is produced by piling organic material and allowing microorganisms to
break it down over weeks to months. Finished compost is dark, crumbly,
and earthy-smelling.
