The **fediverse** (a portmanteau of *federated* and *universe*) is the network of interconnected servers that communicate through open protocols — principally [ActivityPub](../../topics/activitypub/index.md) — to provide social networking, blogging, media hosting, and other services without centralized ownership.

The fediverse includes software projects that serve different functions: [Mastodon](../../../../disciplines/computing/software/mastodon/index.md) for microblogging, Lemmy for link aggregation, PeerTube for video hosting, Pixelfed for image sharing, and many others. Because they all speak [ActivityPub](../../topics/activitypub/index.md), a user on a Mastodon instance can follow and interact with a user on a PeerTube instance, even though the two platforms look nothing alike.

Each server in the fediverse is independently operated. There is no central authority that sets rules, moderates content, or controls the network topology. This means the fediverse as a whole has no single point of failure and no single entity that can unilaterally change the terms of participation. It also means that the experience varies across instances: each community sets its own norms, moderation policies, and [federation](./federation.md) choices.

The fediverse emerged from earlier federated social projects (StatusNet, GNU Social, diaspora*) and gained wider adoption after 2017 with the release of Mastodon and the W3C standardization of ActivityPub. As of the mid-2020s, it remains small relative to commercial platforms but represents one of the more developed alternatives to centralized social media infrastructure.
