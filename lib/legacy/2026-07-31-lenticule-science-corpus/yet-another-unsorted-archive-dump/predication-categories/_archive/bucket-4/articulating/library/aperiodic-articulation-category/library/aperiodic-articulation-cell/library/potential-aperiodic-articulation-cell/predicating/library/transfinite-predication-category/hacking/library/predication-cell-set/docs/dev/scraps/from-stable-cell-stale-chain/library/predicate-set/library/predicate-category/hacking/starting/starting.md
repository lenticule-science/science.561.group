---

A starting transformer maps a session-specification (an agent or a character, plus the host environment) to a running session: a process bound to a scope, an MCP tool surface, and a witness log. The input names what kind of session to run; the output is the running session itself, with its surface already exposed to the caller.

## Morphological forms in naming grammar

- `gerund: starting` heads skills built on this transformer: `starting-a-session`, `starting-a-session-with-character`, etc.
- `agent-noun: starter` heads agents that invoke such skills: `starter-of-session-with-agent`, `starter-of-session-with-character`, etc.
- `imperative: start` heads scripts that body such skills: `start-a-session.mjs`, `start-a-session-with-character.mjs`, etc.
