# Step-n substitution rule

A **formal closure-rule object** capturing the step-`n` recurrence structure. A step-`n` substitution rule is a closure rule with antecedent depending on the prior `n` settled stages and consequent producing new cells via an `n`-term recurrence pattern.

## Definition

A step-`n` substitution rule on a base `B = (L, C, E, λ)` with predicate `P` on `dom(P) = E × E` (or `Δ_E`) is a closure rule of the form:

$$\sigma_n \;:\; \quad \bigwedge_{i = 1}^{n} \phi_i\bigl(v|_{[k - i, k]}\bigr) \;\Longrightarrow\; \psi\bigl(v(P)(k+1, \cdot)\bigr)$$

where:

- The antecedent is a conjunction of `n` predicates `φ_i`, each depending on the settlement restricted to the window `[k - i, k]` — the prior `i` settled stages.
- The consequent `ψ` produces a new cell-value at stage `k + 1` via an `n`-term recurrence.

## What the formula encodes

The rule's behavior is **look-back-`n`**: to determine what happens at stage `k + 1`, the rule examines the prior `n` stages `k, k-1, ..., k-n+1`. The closure operator's action at any step depends on this fixed-length history window.

This is what makes the rule **step-`n`**: not step-`m` for `m < n` (the rule genuinely uses all `n` prior stages), and not step-`m` for `m > n` (the rule doesn't look further back than `n`).

## Primitivity

A step-`n` substitution rule is **primitive** if some power of the induced substitution matrix is strictly positive — equivalently, the rule eventually substitutes through every letter of its alphabet.

Primitivity is required for:

- The **rank-theorem-based step-depth invariance** (which makes step-`n` a well-defined invariant of the closure-equivalence class).
- The **Anderson–Putnam direct-limit cohomology rank** (which equals `n` for primitive step-`n` rules).
- **Placement in the step-`n`-moduli substack** `M^(n)`.

Non-primitive substitution rules form a separate sub-class with different invariants; the step-`n` stratification doesn't directly apply.

## Generated closure operator

The closure operator generated by a step-`n` substitution rule has:

- **Closure ordinal `κ = ω`** for finite alphabets and primitive rules — the orbit unfolds in `ω` steps reaching a self-similar fixed point.
- **Substitution matrix** of size `n × n` (where `n` is the alphabet size) encoding how each letter rewrites.

For primitive rules, the closure ordinal sits in the Scott-continuous regime, and the orbit's cohomology is computable via Anderson–Putnam direct limit.

## Worked example: Fibonacci as a step-2 substitution rule

The Fibonacci substitution `ω(a) = ab`, `ω(b) = a` is a step-`n = 2` substitution rule:

- Antecedent: `(v|_{k}, v|_{k-1})` — uses the prior 2 stages.
- Consequent: `v(P)(k+1, ·) := ω(v(P)(k, ·))` — the Fibonacci substitution applied to the current letter sequence.
- Recurrence: `v_{k+1} = v_k + v_{k-1}` (the Fibonacci recurrence on counts).

The induced substitution matrix `[[1, 1], [1, 0]]` is primitive (eigenvalues `φ, 1−φ` with `φ > 0`). Closure ordinal `κ = ω`. Anderson–Putnam cohomology rank `= 2`.
