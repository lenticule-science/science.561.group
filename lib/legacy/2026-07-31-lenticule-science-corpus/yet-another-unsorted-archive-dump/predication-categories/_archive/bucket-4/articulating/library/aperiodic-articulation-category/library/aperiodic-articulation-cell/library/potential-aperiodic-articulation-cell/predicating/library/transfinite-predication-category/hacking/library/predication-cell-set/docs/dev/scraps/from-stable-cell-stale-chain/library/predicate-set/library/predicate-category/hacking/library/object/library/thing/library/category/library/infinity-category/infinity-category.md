An (∞,1)-category is the higher-categorical generalization of a category in which the hom-collections are themselves higher-categorical (∞-groupoids in the (∞,1)-case). The k-morphisms for k>1 are invertible up to higher coherent isomorphisms. Standard model presentations are quasi-categories (Joyal, Lurie), complete Segal spaces (Rezk), simplicial categories (Bergner), and relative categories (Barwick–Kan); these are Quillen-equivalent — they present the same homotopy theory of (∞,1)-categories with different combinatorial machinery. Selecting among them is a presentation choice, recorded as a transformer at [doing/working/selecting-an-infinity-category-model/](doing/working/selecting-an-infinity-category-model/). Sub-structures under [library/](library/) carry each model presentation.
