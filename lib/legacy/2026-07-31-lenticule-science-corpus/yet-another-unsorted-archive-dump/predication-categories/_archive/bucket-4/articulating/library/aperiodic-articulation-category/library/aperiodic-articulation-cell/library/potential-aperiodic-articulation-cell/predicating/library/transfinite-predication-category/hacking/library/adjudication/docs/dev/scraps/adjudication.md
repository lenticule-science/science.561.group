# Adjudication

The role of producing an *epistemic state* at every [predication cell](predication-cell.md) from accumulating, possibly conflicting, possibly partial sources of information.

A framework realizes adjudication when it represents three features of practical knowledge systems on a single structure:

- **Inconsistency.** Distinct sources may assert contradictory facts about the same predication cell. The framework must represent contradiction directly, without trivialization — without contradictory predication cells causing the inferential structure to collapse globally.
- **Partial information.** A predication cell may be uninformed — neither asserted nor refuted. The framework must distinguish *unknownness* from [negation](negation.md); absence of information is not denial.
- **Temporal accumulation and distribution.** Information about a predication cell arrives over time and from independent sources, in varying orders and possibly with duplication. The framework must produce a state that depends on the set of information received, growing monotonically as more information arrives, and converging to the same final state across *knowledge replicas* without requiring them to coordinate every update.
