John Sweller's cognitive load theory reframed instructional design around the limits of working memory. His core claim: working memory is small (roughly four to seven elements at a time) and easily overloaded; effective instruction reduces *extraneous* load (effort caused by poor design) so learners can spend their working-memory capacity on *intrinsic* load (the actual complexity of the material) and *germane* load (effort devoted to building understanding).

## Core ideas

- **Three load types**: intrinsic, extraneous, germane.
- **Worked-example effect**: studying worked examples often produces better learning than solving problems from scratch, because problem-solving consumes working memory that could otherwise build schemas.
- **Split-attention effect**: information that must be mentally integrated should be presented physically integrated; otherwise readers spend working memory on the integration.
- **Modality effect**: presenting complementary information in different modalities (e.g. spoken narration with visual diagram) avoids overloading any one channel.
- **Element interactivity**: complexity comes from how many elements must be processed *simultaneously*, not from element count alone.

## Key works

- *Cognitive Load During Problem Solving: Effects on Learning* (1988)
- *Cognitive Load Theory* (with Ayres and Kalyuga, 2011)
- *Evolution of Human Cognitive Architecture* (2003)
