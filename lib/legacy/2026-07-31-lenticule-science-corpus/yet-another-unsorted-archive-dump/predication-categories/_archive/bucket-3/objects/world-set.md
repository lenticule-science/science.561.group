# World set

A set, denoted $W$, of *worlds* over which the modal structure on a knowledge presheaf is indexed. The world set may be the [settling bound](settling-bound.md) itself — that is, $W = \lambda$, taking settling ordinals as worlds — or a separate index set chosen for the modal application.
