## What this node is
This node is generated by the **predicate** morphism in the unfolding articulate -> predicate -> posit -> settle. A set is the extension of a predicate: the collection of exactly those entities of which the predicate holds. Membership ($x \in S$) is the predicate applied as a yes-or-no question, and extensionality — two sets are equal iff they have the same members — is the principle that a set is nothing more than the entities its predicate ranges over. Set theory is therefore discrete predication made into an object: where articulation names entities, predication gathers them, and a set is what that gathering produces.

- **Set, element, membership** — the primitive $\in$ relation and the extensionality that determines a set by its members.

- **Operations** — union, intersection, complement, and Cartesian product that build new sets from old.
- **Ordered pairs and relations** — the ordered pair, the binary relation as a subset of a product, and its specializations: function, equivalence relation, partial order.
- **Domain and codomain** — the source and target sets a relation or function ranges between.
- **Foundations** — ZFC, Russell's paradox, and the von Neumann encoding of number as set; plus an Agda treatment of the Banach-Tarski paradox.
