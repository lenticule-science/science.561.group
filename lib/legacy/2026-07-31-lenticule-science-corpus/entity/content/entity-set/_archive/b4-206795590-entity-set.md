An **entity-set**, denoted $E$, is a set whose elements are [entities](../entity/entity.md). The entity-set carries no required structure beyond set-hood in general; specific theorems and applications may impose finiteness, and the entity-set may be sort-stratified by an optional partition.

Pairs of entities form the index $E \times E$ over which predication fiber algebras $A_p = \mathbf{L}^{\bowtie\, E \times E}$ are built; the first and second coordinates of such pairs are the subject and object positions of predication cells. When $E$ is finite of cardinality $n$, the pair index $E \times E$ has $n^2$ positions and each fiber algebra has $|\mathbf{L}|^{2 n^2}$ elements (each pair gets a value in $\mathbf{L}^\bowtie = L \times L$).

A sort partition is optional structure: a map from sort-slugs to subsets of $E$. Sort membership constrains which entities can occupy the subject- and object-positions of cells under predicates with sort declarations, and which entities count as inhabiting a structure-form whose predication-shape carries sort constraints.
