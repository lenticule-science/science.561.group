# Entity set

A set, denoted $E$, whose elements are [entities](teaching/explanations/entity.md). The entity set carries no required structure beyond set-hood in general; specific theorems and applications may impose finiteness, and the entity set may be sorted.

Pairs of entities form the index $E \times E$ over which [predication fiber algebras](predication-fiber-algebra.md) are built; the first and second coordinates of such pairs are the [subject](teaching/explanations/subject.md) and [object](teaching/explanations/object.md) positions of [predication cells](teaching/explanations/predication-cell.md).
