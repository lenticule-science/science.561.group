name: entity set
description: A set whose elements are entities. The set $E$ over which predication fiber algebras are indexed (via $E \times E$).
---

A set, denoted $E$, whose elements are [entities](../../prose/teaching/explanations/entity.md). The entity set carries no required structure beyond set-hood in general; specific theorems and applications may impose finiteness, and the entity set may be sorted.

Pairs of entities form the index $E \times E$ over which predication fiber algebras are built; the first and second coordinates of such pairs are the [subject](../../prose/teaching/explanations/subject.md) and [object](../../prose/teaching/explanations/object.md) positions of [predication cells](../../prose/teaching/explanations/predication-cell.md).
