# Martin-Löf 1984 — Intuitionistic Type Theory

Per Martin-Löf, *Intuitionistic Type Theory* (Notes by Giovanni Sambin of a series of lectures given in Padova, June 1980), Bibliopolis, 1984.

The foundational reference for [dependent-type-theory](../objects/dependent-type-theory.md). Martin-Löf's lectures lay out the typing rules for [pi-types](../objects/pi-type.md), [sigma-types](../objects/sigma-type.md), [identity-types](../objects/identity-type.md), [inductive-types](../objects/inductive-type.md), the [universe](../objects/universe.md) hierarchy, and the philosophical motivation for an intuitionistic foundation grounded in the [curry-howard-correspondence](../theorems/curry-howard-correspondence.md).

## Why cited here

- Definitional source for [dependent-type-theory](../objects/dependent-type-theory.md) and every dependent type former.
- Introduces the four standard judgments — [typing-judgment](teaching/explanations/typing-judgment.md), type formation, type equality, term equality — that the directory uses throughout.
- The [universe-level](teaching/explanations/universe-level.md) stratification originates here.
