Audience: beginners comparing programming styles.

Learning goal: list common paradigms and what they emphasize.

Imperative paradigms focus on commands and state. Declarative paradigms focus on
describing results. Event-driven, logic, and dataflow paradigms structure how
programs react to events or express constraints.

Check for understanding: Which paradigm focuses on expressing rules instead of
explicit steps?
