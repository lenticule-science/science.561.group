# GnoponEmacs Interface

GnoponEmacs is the Emsemioverse's baseline Emacs interface for human and agent work.

## Scope

This interface defines the defaults for writing, navigation, and light automation in
the Emsemioverse.

## Notes

GnoponEmacs is not a specification repository; it is a working interface and may
evolve alongside the rest of the semioverse.
