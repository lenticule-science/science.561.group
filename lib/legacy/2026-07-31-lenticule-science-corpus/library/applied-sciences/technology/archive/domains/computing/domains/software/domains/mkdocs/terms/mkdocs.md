***MkDocs*** is a [static site generator](../../../../../../general/terms/static-site-generator.md) designed for building project documentation from Markdown files. It reads a YAML configuration file (`mkdocs.yml`) and converts a directory of Markdown into a navigable website. MkDocs supports themes, plugins, and extensions for customizing the output. Its built-in development server provides live-reloading previews during writing.
