# SRI: Synthetic Reflexive Intelligence

This repository provides a modular knowledge graph stack, starting with:

- **Fuseki** (RDF graph store, SPARQL endpoint)
- **OpenSearch** (search projection over RDF literals/IRIs)

## Usage

1. Install [Docker](https://docs.docker.com/get-docker/).
2. Run:

   ```sh
   docker compose up -d
   ```

3. Access Fuseki at [http://localhost:3030](http://localhost:3030)
4. Access OpenSearch at [http://localhost:9200](http://localhost:9200)

## Data Persistence

- RDF data is stored in `./data/fuseki`
- OpenSearch data is stored in `./data/opensearch`

## Extending the Stack

This setup is ready to add:
- Postgres (event log, provenance)
- Qdrant (vector search)
- MinIO (object storage)
- NATS, Temporal (pipelines)
- Next.js UI, Keycloak, etc.

Feel free to edit `docker-compose.yml` to expand the services.
