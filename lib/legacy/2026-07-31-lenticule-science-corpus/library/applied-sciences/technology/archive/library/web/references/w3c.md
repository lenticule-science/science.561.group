The **World Wide Web Consortium** (**W3C**) is the main international standards organization for the Web. Founded by Tim Berners-Lee in 1994, the W3C develops specifications and guidelines intended to ensure the long-term growth and interoperability of web technologies.

Key W3C specifications include HTML, CSS, the Web Accessibility Guidelines (WCAG), and the [ActivityPub](../../technology/concepts/internet/topics/activitypub/index.md) protocol for federated social networking. The W3C also maintains specifications for RDF and JSON-LD, which provide structured data vocabularies for the semantic web.
