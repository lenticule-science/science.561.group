A ***conversational software interface*** is a [[software interface]] where [[user|users]] [[interacting|interact]] using [[natural language dialogue]]. The interfaces typically rely on [[Large Language Model|Large Language Models]] for their functionality.

It's a type of interface that's seen as useful in [[customer service]], as well as in [[brainstorming]] and [[notetaking]].
