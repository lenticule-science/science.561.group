#+title: Adding Org-cite to GnoponEmacs
#+date: [2025-08-28 Thu 08:53]
#+author: emsenn
#+index: Emacs!Org-cite!Adding Org-cite to GnoponEmacs

This [[id:8bbb445f-087c-4f32-bb5b-7542de0a9e6c][morning]], I'm [[id:6058a04d-2258-4ba7-80b7-26a5a4dd9d47][planning]] on [[id:c449af7f-8dcd-4686-a3d8-f92048d29861][adding]] [[id:6d5673b0-6072-4c48-bcee-771e5f3e705c][Org-cite]] to [[id:edc48bf0-336b-4b63-8505-a3730b328c9d][GnoponEmacs]]. This is part of the [[id:efcf985e-f185-4616-a41e-94e06154076f][2025 Relaunch of emsenn.net]], where I'm using [[id:b59c6255-b760-4a18-9ee2-f548c2e9c11a][my Omnibook]] (my new laptop) to finally get back to [[id:c6b43295-422c-4835-be91-09d60fb33e4a][taking notes]] and [[id:54213c5a-a48a-4976-acff-cc89ebf673c0][writing]] the way I feel I should. (I'm still struggling to figure out how to term [[id:b3fd50b7-4d4c-493b-92f4-959a0925a86d][my work]], beyond generally: I want some way to refer to this [[id:04bb8f02-8fed-4180-9e80-5a745a4e465d][digital gardening]] that does something to hint at its orientation toward [[id:ca7fc9c5-9820-4bf2-ba1f-6b90f323d7f4][formalism]], [[id:fe386e4a-6f91-4687-ac60-42e96b6a6579][computability]], and [[id:bba6fc48-dcf2-4884-a726-35469155e0fb][relational coherence]].)

(Why Org-cite and not [[id:49602de9-5395-4841-90da-8a43d3e3b45e][Org-ref]]? While newer, Org-cite is a native part of Org-mode, and aligns more closely with Org-mode conventions.)

The first step in adding Org-cite to GnoponEmacs is [[id:8815e6f3-76fe-4408-894b-b6da595982d9][teaching my self]] about how [[id:3bb7a408-2522-42c1-937d-a01ca22ea23f][Org-mode]] handles [[id:12e8f72c-0e76-4dbe-948d-39f671623a98][citations]]. Looking at [[https://orgmode.org/manual/Citation-handling.html][the manual]], it looks like Org-cite builds on concepts from [[id:cbf90606-c58e-45d8-89dc-096d3d624e52][LaTeX bibliographies]], which I've used in the past, but not recently enough to remember much.

I have to make sure a file knows what [[id:cafbefe4-8762-41ca-97e7-35e06f9f9073][bibliographies]] to check, which can be done (like most [[id:c93054e0-33b5-4859-b83d-9e37cbc382c3][Org-mode configuration]]) through either local (=#+bibliography: some-refs.bib=) or global variables (=org-cite-global-bibliography=).

I keep the PDFs and such that I use as references in =./org/ref/=; each file is named for its DOI or after its title, if there isn't a DOI. So, it makes sense (to me) to put a global bibliography file in that directory.

Checking, I apparently already have a line in GnoponEmacs that sets a global bibliography, just to the wrong path. But, that indicates that I was at least looking at using Org-cite at some point as recently as [[id:3bfd9dde-2784-4cf2-9794-b1b8129824de][2021]], so maybe more will become familiar as I progress. (Seeing that is when Org-cite was released, so I guess I was hip, at the time.)

Reading through the rest of the relevant manual, I find no guide on how to actually format this ~.bib~ file. [[id:40dc6248-3999-4722-9699-2fb1c409d7c3][Searching the Web]] brought me to [[https://kristofferbalintona.me/posts/202206141852/][this blog post]] from [[id:87523d6d-5aa8-4013-92bf-28e811e0ad7f][2022]], which at a [[id:e984ba2b-ffbb-4be7-b45e-99241c6f824f][skim]] seems to be much more [[id:f6a12b83-6f10-4f9d-960a-26bcf077cbdd][educational]] than the manual itself, which seems to presuppose a lot of knowledge I just don't have.

Notably, early on into reading the post, I see it say that while users can write their own [[id:430860bd-e008-4942-93ce-0abe277131b4][BibTex bibliography]] (that's what a .bib file is), "the most common way is exporting a [[id:1e963c4b-6ef8-4bb1-9c9e-ed9058972a3c][Zotero]] library).

Zotero is one of those softwares I've heard of from exposure to [[id:09c83f0e-e6af-426e-93e7-32965b415ee8][institutional academics]], but I'll be honest: I don't actually know what it is or what it does. I'm continuing to read through this Balintona blog post, but it sounds like I might want to look at Zotero for building a bibliography.

I'm glad to read the following quote, as it conveys I'm more experienced with some tools than the author, but equally unfamiliar with the core packages at hand:

#+begin_quote
To those not familiar with another citation workflow (e.g. biblatex in LaTeX), it is quite daunting to leap into citations in Emacs. This was certainly the case for me: I leapt into org-mode citation integration with Zotero and LaTeX with no experience in org, Zotero, or LaTeX! Nonetheless, org-cite is quite simple once laid out.
#+end_quote

Then, the author does me the great service of linking to the [[https://blog.tecosaur.com/tmio/2021-07-31-citations.html][post announcing Org-cite]], which does a lot to explain a lot!

The post explains that Org-cite is split into two parts: the part that interacts with citations, and the part that renders those citations. It goes into some detail about how this interacts with different citation processors: there's four things Org-cite uses them for:

- Inserting and editing citations (in Org-mode buffers, I assume? I think Zotero is what's for doing that to the bibliography itself.)
- Follow citations to their definitions (Open the PDF? Or... Org-roam file? I don't know.)
- Fontifying citations in the buffer (that is, I think, just making them render pretty)
- Exporting citations (making them show up in exported files)

The concept of "citation processors" has come up a few times this morning, and I've mostly skipped past, but here, I feel like I have enough context to start trying to understand it. As explained in the announcement post, there are four citation processors bundled in Org-mode:

- ~basic~ :: no dependencies, can do all the citation stuff (insert, edit, follow, fontify, export)
- ~biblatex~ and ~natbib~ :: exports, but only for LaTeX?
- ~csl~ :: exports using Citation Style Language(?), to HTML, LaTeX, Org, and plain text. Depends on citeproc.el?

It sounds like, because I am planning to export things to [[id:cc253409-9a82-4c5d-a4cd-8013f4e350c6][my website]], I will need to look at Citation Style Language, but for now, I'm trying to stay focused on initializing my bibliography file, so I can start with some hands-on learning.

Luckily the next part of the announcement post gives an example ~orgcite.bib~:

#+begin_src bibtex
  @article{OrgCitations,
           author={org, mode and Syntax, Citation and List, Mailing and Effort, Time},
           journal={Journal of Plain Text Formats},
           title={Elegant Citations with Org-Mode},
           year={2021},
           month={7},
           volume={42},
           number={1},
           pages={2-3}}  
#+end_src

I got down this rabbithole because I started [[id:59a01374-1869-49dc-a443-46cd77548bf0][reading]] [[id:2614bec9-1d58-4227-92e2-1e4b0bcd746a][A Two-Dimensionalist Guide to Conceptual Analysis]], and wanted a way to start [[id:f2829f05-2e51-461e-bcaa-c62c396b7cd7][babbling]] or whatever about it, so lets make that our first entry:

#+begin_src bibtex
  @book{Kipper2012,
    author    = {Jens Kipper},
    title     = {A Two-Dimensionalist Guide to Conceptual Analysis},
    year      = 2012,
    publisher = {De Gruyter},
    series    = {Epistemic Studies},
    volume    = 25,
    isbn      = {978-3-11-032270-5},
    doi       = {10.1515/9783110322705},
    url       = {https://www.degruyterbrill.com/document/doi/10.1515/9783110322705/html},
    address   = {Berlin/Boston},
    keywords  = {conceptual analysis, epistemic opacity, two-dimensionalism}
  }
#+end_src

Apparently, after that, I should be able to simply do =[cite:@Kipper2012]=, and get... [cite:@Kipper2012]

And if I want to insert the bibliography of this file, I can do =#+print_bibliography:=, and get...

#+print_bibliography:

Testing this as an export to a plain text file, that worked fine. So, I'm not sure (yet) what I'll need to do to care about the export processors: for now, how it works seems to be acceptable.

So, from here, there are two things to do:

1. Figure out how I want to add citations to the bibliography
2. Figure out how this integrates with [[id:59181fb6-bc78-4d87-8384-c9f52f5c505e][Org-roam]]

That second one is actually the first one I'll do, because I suspect it will influence how I want to add citations. My thinking is, I suspect that unlike most folk using Org-cite, I have an [[id:e5474b02-2852-4c8a-91cd-4a683e0db672][Org-roam node]] for some entries that'll be in [[id:88c32478-d3e6-47ff-a3a4-b33635ef3764][my bibliography]].

The rest of the announcement post goes into detail about citation styles and other useful tools like Zotero, so I can put it aside for now, and it looks like the same is true for the other blog posts.

Instead, I can come back to [[id:1f5d69ac-ffe0-4802-8464-f59698f50249][Org-roam manual]], where it talks about citations. As it explains it, I can simply add the unique citation link to a node's =ROAM_REF= properties.
