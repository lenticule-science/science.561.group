# Composite Profile Geometry

## Interpretation

Combining the restricted flow and nucleus yields the composite profile’s relational geometry.  *Flow Composite Profile* witnessing *Nucleate Composite Profile* produces ***Geometry Composite Profile*** ([GeometryCompositeProfile](0224-geometry-composite-profile.md)).

This composition matches the proposition that commuting filters support a relational geometry, so *Geometry Composite Profile* follows.
