# Interprofile Functor

Functor mapping recognitions from one profile to another while preserving
flow/nucleus coherence.

## Definition
- Data: functor between [Profile Topos](profile-topos.md) objects of source and
  target profiles, respecting the [Flow–Nucleus Adjunction](flow-nucleus-adjunction.md).
- Preservation: carries recognitions, flow, and nucleus structure to the target
  without violating admissibility.

## Invariants
- Functorial: preserves identities/composition of profile morphisms.
- Adjunction-compatible: commutes with flow/nucleus witnesses.
- Logical preservation: respects classifier/modal structure in profiles.

## Proof
- Uses: profile toposes and flow/nucleus adjunction to constrain the functor.
- Shows that: profile recognitions can be transported across worlds coherently.
