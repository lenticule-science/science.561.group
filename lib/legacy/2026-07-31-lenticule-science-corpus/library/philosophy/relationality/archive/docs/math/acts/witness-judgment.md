# Witnessing Judgment

## Interpretation

*Reflex Judgment* relates a stabilized context to a stabilized term but does not state which stabilized judgment class records it.  Forcing *Stabilize Judgment* to witness *Reflex Judgment* yields ***Witness Judgment*** ([WitnessJudgment](witness-judgment.md)).

Composing with *Stabilize Judgment* classifies the primitive act, so *Witness Judgment* follows.
