## Interpretation

The normalization proof uses candidates closed under reductions and term constructors.  *Construct Types* witnessing *Normalize Strongly* produces ***Select Reducibility Candidate*** ([SelectReducibilityCandidate](0157-select-reducibility-candidate.md)).

Using only earned recognitions, this act records the assignment of a strongly normalizing set to each type, so *Select Reducibility Candidate* is valid.
