## Interpretation

Using the negating act we dualize principal closure into an interior operator.  *Negate* witnessing *Close Principally* yields ***Dualize Interior*** ([DualizeInterior](0196-dualize-interior.md)).

This mirrors the closure via negation, so *Dualize Interior* is established.
