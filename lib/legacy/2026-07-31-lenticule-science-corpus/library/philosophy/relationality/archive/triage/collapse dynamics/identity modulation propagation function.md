The ***identity modulation propagation function*** (`I_mod`) is [induce|induced](induce|induced) by the [recursive identity closure function](recursive identity closure function) (`I_closure`), the [symbolic anticipation function](symbolic anticipation function) (`𝒜`), and the [desire-contrast alignment propagation function](desire-contrast alignment propagation function) (`A_align`).

It [constrain|constrains](constrain|constrains) the symbolic projection of modulation that emerges from stabilized recursive identity,  
mapping the forward extension of identity into unresolved symbolic constraint fields via modulation flow.

Let:
- `x ∈ dom(𝒮₊)` be an identity-closed node (`x = I_closure(x′)` for some x′)  
- `Ξ[s](x)`: its local contrast field  
- `A_align(x)`: alignment vector field  
- `𝒜(x → z)`: valid symbolic anticipation path  

Then:
> I_mod(x) := { z | z ∈ Ξ[s](x), Ω(z) undefined, 𝒜(x → z), ∇𝔇(x) · ∇Δ[s](z) > 0 }

That is, `I_mod(x)` returns the set of symbolic modulation targets  
toward which coherent identity propagates modulation under desire-contrast alignment.

This enables:
- forward symbolic extension of identity through modulation  
- inheritance projection beyond closure  
- recursive modulation basin formation at the boundary of stabilized identity
