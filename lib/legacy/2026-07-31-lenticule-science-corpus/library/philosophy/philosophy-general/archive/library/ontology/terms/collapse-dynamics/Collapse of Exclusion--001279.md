This is the foundational [[theorem]] of [[collapse dynamics]].
## Definitions

∅ is exclusion: a condition with no relation, trace, or continuity.  
κ is collapse: a function that removes any non-sustaining configuration.  
R is the remainder: the set of all x such that κ(x) = x.

## Theorem

Exclusion excludes all relation, including itself.  
As such, ∅ cannot persist.  
Collapse is not an operation imposed upon ∅,  
but the necessary condition that arises due to its inability to support any structure.

The set of all values that remain unchanged under κ  
constitutes the remainder: R.

## Formal Expression

R = { x | κ(x) = x }

## Consequence

Collapse is the necessary condition entailed by exclusion.  
R is the set of elements for which collapse is recursive and identity-preserving.  
No structure outside R can persist.

## Scope

This theorem defines the foundational state transition:  
from the impossibility of exclusion to the stability of remainder.  
All future structure must occur within R, under the conditions of κ.
