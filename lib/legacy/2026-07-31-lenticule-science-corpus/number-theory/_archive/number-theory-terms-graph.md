A graph $G = (V, E)$ is a pair consisting of a set $V$ of vertices and a set $E$ of edges, where each edge connects two vertices. In an undirected graph, an edge is an unordered pair $\{u, v\}$; in a directed graph, an edge is an [ordered pair](../../../objects/sets/terms/ordered-pair.md) $(u, v)$.

Graphs formalize [relations](../../../concepts/relation/index.md) between discrete objects. A symmetric binary [relation](../../../concepts/relation/index.md) on a set corresponds exactly to an undirected graph; a general binary relation corresponds to a directed graph.

In [category theory](../../../objects/categories/index.md), a directed graph (or quiver) is a diagram in the category of sets — a pair of [functions](../../../concepts/function/index.md) $s, t : E \to V$ assigning source and target to each edge. A [category](../../../objects/categories/ordinary-categories/terms/category.md) can be seen as a graph with composition and identities.
