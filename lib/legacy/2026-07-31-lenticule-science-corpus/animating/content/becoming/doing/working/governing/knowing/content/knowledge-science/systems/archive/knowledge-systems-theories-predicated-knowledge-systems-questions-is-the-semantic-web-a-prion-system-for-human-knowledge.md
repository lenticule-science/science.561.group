# Is the Semantic Web a prion system for human knowledge?

The source question is not merely whether ontology reuse can cause lock-in. The source question is whether the Semantic Web functions as a prion system in relation to human knowledge: a substrate of transmissible semantic conformations that can induce other knowledge practices to adopt their shape.

## The question

Does the Semantic Web merely represent human knowledge, or does it propagate ontological conformations back into human knowledge practices?

Equivalently: when a vocabulary, ontology, identifier regime, or linked-data hub becomes widely reused, does it act like a templating structure that converts nearby knowledge practices into its own conformation?

The source triage material describes the Semantic Web / Linked Data stack as structurally analogous to prion propagation: carriers can adopt multiple stable conformations; some conformations locally template conversion; repeated local conversions produce network-scale aggregation. The predicated-knowledge-systems version should ask whether this is only an analogy, or whether it identifies a real mechanism in human knowledge infrastructure.

## Predication restatement

A predicated knowledge system has predication cells as its unit of storage, a predicate category as its vocabulary of possible relations, and closure rules that determine how assertions settle. On that substrate, the Semantic Web can be studied as a knowledge system in which identifiers, predicates, classes, ontologies, documentation, software, institutional trust, and reuse practices participate in closure.

The prion-system question becomes:

1. What is the carrier?
2. What is the conformation?
3. What is the interaction relation?
4. What is templated conversion?
5. What is network-scale aggregation?
6. What distinguishes healthy interoperability from pathological semantic conversion?

A URI alone is probably not the carrier. The carrier is more likely a compound: URI, formal ontology, documentation, examples, tooling, institutional recognition, validation rules, search visibility, and accumulated reuse.

A conformation is not merely a definition. It is the effective semantic posture a knowledge community takes when it begins to express its claims through a vocabulary: what counts as a person, event, organization, relation, identifier, equivalence, location, work, source, or evidence.

Templated conversion occurs when adopting the dominant vocabulary becomes easier than maintaining a local one, and future knowledge production is therefore generated in the adopted vocabulary's shape.

## Answer-enabling questions

Can ontology reuse be represented as closure-rule propagation? If a dataset adopts an ontology, its future assertions may be constrained by domain/range restrictions, subclass hierarchies, equivalence mappings, validation rules, and application assumptions. These are candidate closure rules.

Can semantic conformations be stable without being pathological? Most knowledge systems need shared vocabularies. The question is not whether standardization is harmful. The question is when a vocabulary spreads because it improves interoperability, and when it spreads because the surrounding infrastructure rewards conformity even when the conformation damages expressive capacity.

What is semantic damage? Possible diagnostics include suppressed distinctions, forced equivalences, ontology drift from community practice, increasing cost of local deviation, lossy migration, and inability to express relations that matter to the people or practices being represented.

Can there be semantic strains? Biological prions have strain diversity. In knowledge systems, different ontology families may propagate different conformations over the same apparent substrate. A single term such as `Person`, `Organization`, `Event`, or `Place` may carry incompatible conformations across institutional, commercial, archival, Indigenous, bureaucratic, and platformal systems.

Can semantic refolding be designed? If the prion analogy is real, then mitigation is not simply better schema design. It requires mechanisms for versioning, plural ontologies, reversible mappings, local refusal, controlled non-equivalence, and repair after harmful conformation.

## What would resolution require

A resolution would require at least one worked case where a Semantic Web vocabulary or linked-data hub changes not only a dataset's representation but a community's knowledge practice. The case should identify the preexisting local conformation, the adopted vocabulary, the conversion path, the closure rules involved, and the resulting gain or loss of expressive capacity.

A formal resolution would model vocabulary adoption as a predication settling and show whether dominant ontological commitments propagate under closure rules in a way that matches the prion template: stable conformations, templated local conversion, and network-scale aggregation.

A critical resolution would then decide whether the Semantic Web is prion-like only in special cases, structurally prion-like but not necessarily pathological, or genuinely a prion system for human knowledge.

## What this question should not collapse into

This question should not be reduced to "can ontology reuse be modeled as lock-in?" That is an answer-enabling technical question. The real question remains: is the Semantic Web a prion system for human knowledge?

Nor should the question be answered by rejecting the analogy because the Semantic Web is not literally biological. The source claim is structural. The relevant issue is whether the same pattern of conformational propagation occurs in knowledge infrastructure.
