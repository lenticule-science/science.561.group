# Morphisms

The discipline's transformations on the substrate. Each morphism is a substrate-respecting operation: it takes a relation-graph state to a relation-graph state, preserves the substrate's invariants, and is the canonical way to perform the move it names.

- [term-to-typed-migration](term-to-typed-migration.md) — promotion of an older `type: term` note to its typed successor (concept, object, reference, or other).
- [theory-promotion](theory-promotion.md) — promotion of a directory from staging-area to theory-directory once the discipline's six requirements hold.
