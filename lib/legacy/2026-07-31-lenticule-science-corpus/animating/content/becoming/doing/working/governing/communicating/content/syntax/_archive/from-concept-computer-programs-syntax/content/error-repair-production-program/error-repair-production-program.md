# Error and Repair in Language Production Program

This program models slips and repairs in speech and writing so difficulty,
sensitivities, and care patterns become observable.

## Behaviour

- Capture slips, self-repairs, other-repairs, and repair episodes as
  recognitions with context and provenance.
- Link repairs to subjects, topics, interlocutors, and situational factors to
  see where language work is hard.
- Measure frequency, location, and affective correlates (anxiety, excitement)
  of repairs over time.

## Intended operators

- Annotate conversations for slips and repairs.
- Analyse repair patterns by subject/topic or participant.
- Guide agent behaviour to repair gently and transparently.
