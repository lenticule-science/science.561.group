# Parametric Semantics Program

This program treats parametric semantics as recognitions to make meaning under
parameters explicit and traceable.

## Behaviour

- Represent semantic parameters, environments, and interpretations as
  recognitions with provenance.
- Link parameters to domains and contexts; ensure parameter lifting respects
  earned semantics.
- Measure stability and variation of meanings under parameter changes.

## Intended operators

- Instantiate and apply parametric interpretations.
- Compare semantic outcomes across parameter settings.
- Surface where parameters must be constrained for coherence.
