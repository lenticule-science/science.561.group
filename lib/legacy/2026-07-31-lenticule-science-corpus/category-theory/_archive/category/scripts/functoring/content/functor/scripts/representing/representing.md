# representing

Generates [presheaf](content/presheaf/presheaf.md) from [`functor`](../../functor.md): a contravariant functor C^op → Set, assigning data to each object and a restriction map to each morphism. The representable presheaf Hom(−, A) is where the corpus recovers an **object** from its arrows (Yoneda) — so `object` is generated below presheaf, not given above it. Presheaves are also the building blocks of sheaf theory and of the simplicial machinery feeding the ∞-branch.
