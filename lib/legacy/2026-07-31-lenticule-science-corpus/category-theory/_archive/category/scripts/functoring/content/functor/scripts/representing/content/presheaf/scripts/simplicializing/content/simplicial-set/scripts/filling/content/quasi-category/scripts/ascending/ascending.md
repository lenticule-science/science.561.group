# ascending

Generates [infinity-category](content/infinity-category/infinity-category.md) from [`quasi-category`](../../quasi-category.md): read the inner-horn-filling simplicial set as a category with morphisms in every dimension — arrows between arrows at every height, with coherent composition at each level. The quasi-category is one (the standard) model of the abstract ∞-category.
