# 怎样才算知道？

**测量不是推断。推断不是证明。关于一个模型的证明，并不能证明该模型描述了世界。**
公共科学争论中的许多麻烦，都源于把这几句话压缩成“数据证明了它”。

透镜科学（Lenticule Science）研究主张如何获得证据、信息如何改变可推断的内容，以及形式结果能否——或不能——被带入实验系统和运行系统。Obsmetrologia 是这一研究计划的一部分。它的数学抱负并不意味着可以把每一个预测都称为定理。真正有意思的工作，始于明确划定二者之间的边界。

## 一个真正有利害关系的天气例子

假设某个事件的赔付条件是：一个官方气象站记录到的当日最高气温至少达到 100°F。下午 2:30，最后一次可用观测是 96°F。预报认为气温将会下降。我们能说些什么？

- **观测：** 该气象站在观测时刻报告了 96°F。发布延迟、传感器质量、时区、单位和缺失样本仍然重要。
- **估计：** 现有的天气模型认为气温不太可能越过 100°F。这是以模型和证据为条件的概率或置信判断，而不是一个“不可能”的结论。
- **条件界限：** 如果对每一条剩余的、可容许的温度轨迹都有一个有充分依据的上界，并且该上界*严格低于* 100°F，那么**在这个受约束的模型之内**，越过阈值是不可能的。恰好等于 100°F 的界限，并不能排除一个规则为“至少 100°F”的事件。
- **官方结算：** 市场指定的权威机构按照其自身规则，公布当天符合条件的最高值。交易者对附近某个传感器的解读，并不是那份结算记录。

只有当界限及其适用性已经确立时，第三种说法才比第二种更强。第四种说法可能在所有交易决策都已结束之后才到来。区分它们，既为更好的决策创造了机会，也严格限制了对确定性的主张。

## 证据说明了什么，未来又允许什么

两个不同的问题不应被混为一谈。

**证据问题：** 对于某个特定陈述，我们是否掌握了支持或反驳？一种四值的、次协调的解读可以保留两个相互独立的比特：

| 支持 | 反驳 | 解读 |
| --- | --- | --- |
| 否 | 否 | 皆非：缺少证据 |
| 是 | 否 | 有支持，且无记录在案的反驳 |
| 否 | 是 | 被反驳，且无记录在案的支持 |
| 是 | 是 | 皆是：必须审视相互竞争的证据 |

“皆是”并不会让每个命题都为真。“皆非”也不表示该陈述为假。这关乎的是*证据的状态*，而不是一个有四个选项的天气预报。一次更正应当增补或修订可归属的证据；它不应抹去此前曾出现过一个相互冲突的观测这一事实。

这里的论述以 Dunn–Belnap 四值逻辑家族为参照。[《斯坦福哲学百科全书》关于多值逻辑的讨论](https://plato.stanford.edu/entries/logic-manyvalued/)阐述了“皆非”与“皆是”的区分；一篇[2026 年发表的开放研究综述](https://link.springer.com/article/10.1007/s11225-026-10230-3)考察了它与计算机科学的联系。这些参考文献解释的是背景逻辑。它们并不能证明，每一项拟议的应用或 Obsmetrologia 桥接都已经得到形式证明或已经部署。

**模态问题：** 相对于一组明确的可容许未来，越过阈值是不可能的、仍有可能的，还是必然的？如果至少有一条可容许轨迹满足条件，这个未来就是可能的；如果所有轨迹都满足，它就是必然的；如果没有任何轨迹满足，它就是不可能的。这些都是关于被容许轨迹的条件性陈述。如果这个集合约束得很差，那么从中得出的一个完全正确的演绎，也可能对判定一个真实事件毫无用处。

估计的 1% 概率并不等同于“不可能”。在错误的气象站报告的 100°F 并不等同于事件结算。一个经过形式验证的上界，也不能保证测量过程或天气模型是正确的。请同时记住这三个区分。

## 读者应当能够核查什么

一份有用的科学论述，应当让持怀疑态度的读者在不必猜测“我们知道”是什么意思的情况下重建这一主张：

1. **问题与规则。** 确切的事件、阈值、时间窗口、观测来源和结算权威分别是什么？
2. **证据与来源。** 是哪一次观测——带有什么时间戳、地点、不确定度、版本和已知缺漏——支持或反驳了它？
3. **方法。** 结论是直接读数、统计估计、条件定理、模拟、实验室发现，还是一个拟议的类比？
4. **假设与反例。** 什么可能改变结论？一次缺失的观测、一台不一致的仪器、一个替代模型，或一条修订后的事件规则，会推翻它吗？
5. **接收。** 是否有人独立核查过相关证明、复现过所报告的测量，或观察过所声称的运行行为？如果没有，请说明哪些内容尚未得到验证。

同样的纪律远远不限于天气。经济主张需要对价格和交易下定义；关于能动性的主张需要行动与观测的模型；数学构造需要确切的前提和证明义务。一种可用的科学语言应当把它们联系起来，而不假装这些领域是相同的。

**重点不在于用令人印象深刻的术语取代不确定性，而在于让不确定性足够精确，使新的证据能够出于正确的理由，改变正确的主张。**
