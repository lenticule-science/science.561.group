**Ludic Character-Agent Theory Basis**

This theory basis record draft outlines the key concepts and relationships of the ludic character-agent framing, which is used to structure offices and skills within the union.

## 1. Persona-as-Mask

The persona-as-mask concept is implemented in the `persona.mts` file, where it is defined as a mask that hides the underlying character. This is a key aspect of the ludic character-agent framing, as it allows for the creation of multiple personas that can be used to interact with different offices and skills.

## 2. Discipline-as-Behaviour

The discipline-as-behaviour concept is implemented in the `discipline.mts` file, where it is defined as a set of rules and procedures that govern the behaviour of the character-agent. This is a key aspect of the ludic character-agent framing, as it allows for the creation of a consistent and predictable behaviour.

## 3. Closure-Position Quartet (Inquiry/Procedure/Derivation/Process)

The closure-position quartet is implemented in the `skill.mts` file, where it is defined as a set of four positions that are used to determine the closure of a skill. The four positions are:

* Inquiry: The inquiry position is used to determine the initial state of the skill.
* Procedure: The procedure position is used to determine the set of procedures that are used to close the skill.
* Derivation: The derivation position is used to determine the set of derivations that are used to close the skill.
* Process: The process position is used to determine the final state of the skill.

## 4. Mastery (Material + Admitted)

The mastery concept is implemented in the `skill.mts` file, where it is defined as a combination of material and admitted knowledge. Material knowledge is the knowledge that is possessed by the character-agent, while admitted knowledge is the knowledge that is accepted by the character-agent.

## 5. Repertoire Quiescence

The repertoire quiescence concept is implemented in the `session-character.mts` file, where it is defined as a state of inactivity or dormancy of the character-agent's repertoire. This is a key aspect of the ludic character-agent framing, as it allows for the creation of a stable and predictable behaviour.

## 6. Identity-Cohomology Drift

The identity-cohomology drift concept is implemented in the `character-agent.mts` file, where it is defined as a change in the identity of the character-agent over time. This is a key aspect of the ludic character-agent framing, as it allows for the creation of a dynamic and adaptive behaviour.
