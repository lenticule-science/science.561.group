## Writing standard

Lenticule Science uses Plain Technical General American English (PTGAE) for technical prose. State the proposition first and encode real uncertainty as claim status instead of stacking caveats.

The current PTGAE standard is in `docs/plain-technical-general-american-english.md`. Run `node tools/ptgae-lint.mjs FILE [...]` to detect recurring tonal-poison patterns. The linter ignores Markdown code examples and fails only on patterns classified as hard corpus contamination.
