## Writing standard

Lenticule Science uses Plain Technical General American English (PTGAE) for technical prose. State the proposition first. Encode uncertainty as a precise claim status when it changes meaning, action, safety, or evidence.

The existing PTGAE writing standard is in `docs/plain-technical-general-american-english.md`. The new [PlainEng/PTGAE science research section](services/information-science-services-section/services/communication-science-services-section/services/language-science-services-section/services/english-science-services-section/services/ptgae-science-services-section/README.md) develops its scientific basis and evidence with Red Cup Engineering, without silently replacing the current standard.

- Run `node tools/ptgae-lint.mjs FILE [...]` to lint specific files.
- Run `node tools/ptgae-corpus-scan.mjs PATH [...]` to scan a text corpus.
- Run `node tools/ptgae-corpus-scan.mjs --literal='TEXT' PATH [...]` to verify exact occurrences before a migration.
- Run `node tools/ptgae-rewrite.mjs FILE [...]` only for allow-listed semantics-preserving rewrites.
- Run `node tools/ptgae-corpus-rewrite.mjs PATH [...]` for a dry-run corpus rewrite report; add `--write` only after reviewing the proposed changes.

The linter ignores Markdown code and quoted source text. Automatic rewriting is narrower than linting: a flagged phrase is not permission to change substantive meaning. Automatic rewriting also preserves Markdown blockquotes and straight or curly quoted source text. Corpus scanning does not follow symbolic links.

## Research operations and publication boundary

This repository is the canonical **scientific domain** tree, not a consolidated
method-operations bureau or publishing ledger. Reusable research **execution**
(source collection, study running, evidence custody, reproducibility and receiving)
is supplied by [Coesite Research Operations](https://github.com/coesite-operations/operations-services-section/tree/main/services/research-operations-services-section).
Scientific questions, domain-appropriate methodology, reviewed results, and
formal proofs remain with their actual scientific field or separately owned
specialist repository; the operations provider does not determine their truth.

An author's essay is a distinct literary/publication resource. In particular,
[emsenn's Substack service](https://github.com/emsenn/substack) owns its published
editions, manuscript custody, and publication-state accounting. Neither a
poetic research-program title nor a missing local manuscript establishes that
an essay is unpublished. Literature and experiments must not be written to
imitate an author, and authored writing must not be rewritten as a science paper
merely to satisfy an editorial workflow.
