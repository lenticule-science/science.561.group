# RelCrypt-Σ2-SIV-24 Document Bundle

This bundle freezes the current RelCrypt encryption branch into a downloadable documentation set.

## Files

```text
relcrypt-sigma2-siv-24-spec.md
  Frozen algorithm specification for the Σ2-SIV-24 branch.

relcrypt-sigma2-siv-24-test-vectors.json
  Deterministic test vectors for reimplementation and regression testing.

relcrypt-sigma2-siv-24-design-rationale.md
  Why the construction has its current shape.

relcrypt-sigma2-siv-24-attack-plan.md
  Cryptanalysis and evaluation plan.

relcrypt-sigma2-lean-roadmap.md
  Lean formalization roadmap for the structural scaffolding.
```

## Status

This is research cryptography, not production cryptography.

The intended next step is independent reimplementation from the spec and test vectors, followed by reduced-model cryptanalysis.
