## Mathematical question

For a finite Markov kernel P on state space X and a partition π:X→Y, does there exist a quotient transition kernel Q on Y satisfying for every pair x,x' in the same block and every target block B,

    Σ_{z∈B} P(x,z) = Σ_{z∈B} P(x',z) = Q(π(x), B) ?

This is strong lumpability, a test of exact aggregated predictive closure. It is *not* a sufficient condition for an institutional boundary, agency, autonomy, governance competence or legal identity. Trivial one-block and identity partitions can be lumpable but provide no useful individuation evidence.

## Discriminating cases and negative controls

The committed fixture names four cases: exact closure, a broken transition equality, and two valid but uninformative partitions. An independent implementation must parse the probabilities, reject invalid stochastic rows, compare all states inside each block against every target block, and use a declared numerical tolerance. Expected classifications are deterministic for these synthetic matrices; no empirical institutional result follows.

## What would count as empirical science

Define states, organizational boundary candidates, event sampling, time window, missingness, interventions and practical prediction loss before fitting a model. Compare a constrained block kernel with an unrestricted baseline on independently held-out future windows. Report uncertainty and robustness to re-partitioning and unobserved coordination. A failure of held-out closure is evidence against the specified abstraction for the sampled process; a successful fit merely supports bounded predictive adequacy, not autonomy. Never promote labels such as 'institution' from a successful matrix check alone.
