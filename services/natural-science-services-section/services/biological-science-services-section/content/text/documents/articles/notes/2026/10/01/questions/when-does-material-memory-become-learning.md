# When does material memory become learning?

R1 memory is satisfied when present material state contains recoverable information about prior perturbation after the perturbation is removed.

R2 learning requires more: repeated experience must persistently alter the material such that performance on a preregistered held-out task improves while the external decoder/controller remains frozen.

The assay must distinguish this from ordinary hysteresis, fading memory, damage accumulation, changing environmental conditions, and external machine-learning updates.
