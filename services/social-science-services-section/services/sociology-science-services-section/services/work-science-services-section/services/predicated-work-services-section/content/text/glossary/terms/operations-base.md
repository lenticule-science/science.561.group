# Operations base

The base $B_{\mathrm{op}} = (\mathbf{2}, \mathcal{C}_{\mathrm{op}}, E_{\mathrm{op}}, \lambda)$ over which operational work is a [predication settling](../../../../../../../../../../../library/theories/humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-settling.md). Each component:

- **Residuated lattice $\mathbf{L} = \mathbf{2}$.** Operational evidence is binary at the bilattice's per-coordinate level; an event either witnesses a positive or negative datum, or it does not. The fiber values live in $\mathbf{2}^\bowtie \cong \mathbf{FOUR}$ — the four-element bilattice.
- **Predicate category $\mathcal{C}_{\mathrm{op}}$.** Objects: the predicates of the work vocabulary in [library/.../sociology/work/](../../../../../../../../../../../library/theories/humanities/theories/sociology/theories/work), including action–agent (`assigned-to`, `completed-by`, `dispatched-by`, `failed-by`), action–capability (`requires-capability`, `provides-capability`), action–goal (`has-goal`, `terminates-on`), action–action (`decomposes-into`, `depends-on`), and Hohfeldian-position predicates (`holds-power-over`, `has-duty-to`, `has-privilege-of`, `bears-immunity-from`). Morphisms: those generated by the four [predicate-category generators](../../../../../../../../../../../library/theories/humanities/theories/math/theories/categories/theories/predication-categories/theorems/predicate-generator-exhaustiveness.md) on these predicates. The category is small and finite (the predicate set is finite by enumeration).
- **Entity set $E_{\mathrm{op}}$.** Disjoint union of agents, offices, tasks, plans, workflows, capabilities, scopes, and the operational records (witnesses, observations, sessions). $|E_{\mathrm{op}}|$ is countably infinite in principle (ongoing operations admit new agents, tasks, scopes), finite at any given moment.
- **Settling bound $\lambda$.** $\omega$ for the standard reading: operations advance through countably many event-driven stages.

The base is in the [Scott-continuous regime](../../../../../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/valuation/content/knowledge-least-valuation/settling/references/four-regime-dichotomy.md) when all closure rules are Scott-continuous — typical for finitary dispatch and capability-propagation rules. Sub-bases restricted to a finite scope (e.g., a single ship's operations during a finite period with a fixed agent set) collapse to the [strict regime](../../../../../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/valuation/content/knowledge-least-valuation/settling/references/four-regime-dichotomy.md). Bases extended to admit $\Pi_2$ or higher closure rules — e.g., charter rules that quantify over all prior cycles — can land in the transfinite-bounded or aperiodic regime.

The standard worked instance is a single ship's operations: $E_{\mathrm{op}}$ enumerated from the ship's agents/personas/personnel/tasks; $\mathcal{C}_{\mathrm{op}}$ generated by the ship's vocabulary commitments; $\lambda = \omega$. The strict-regime sub-base is the same data restricted to a finite operational period.
