The base $B_{\mathrm{op}} = (\mathbf{2}, \mathcal{C}_{\mathrm{op}}, E_{\mathrm{op}}, \lambda)$ over which operational work is a [predication settling](../../../../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-settling.md). Each component:

- **Residuated lattice $\mathbf{L} = \mathbf{2}$.** Operational evidence is binary at the bilattice's per-coordinate level; an event either witnesses a positive or negative datum, or it does not. The fiber values live in $\mathbf{2}^\bowtie \cong \mathbf{FOUR}$ — the four-element bilattice.
- **Predicate category $\mathcal{C}_{\mathrm{op}}$.** Objects: the predicates of the work vocabulary, partitioned into two layers per [normative-operational-layering](../../../../../../../social-theory-science-services-section/content/text/glossary/concepts/normative-operational-layering.md):
  - *Operational predicates*: `assigned-to`, `completed-by`, `dispatched-by`, `failed-by`, `requires-capability`, `provides-capability`, `has-goal`, `terminates-on`, `decomposes-into`, `depends-on`, `abandoned-by`, `cancelled`, `suspended-by`, `activation-permitted`.
  - *Normative predicates*: `holds-power-over`, `has-duty-to`, `has-privilege-of`, `bears-immunity-from`, `recognized-as-incumbent-of`, `inducted-into`, `subject-to`, `within-jurisdiction-of`, `settled-by-tier` (tier-settlement markers from [precedence-in-least-fixed-point](../../documents/articles/notes/undated/precedence-in-least-fixed-point.md)).
  - Morphisms: those generated by the four [predicate-category generators](../../../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/pre-bilattice/content/bilattice/content/predication-fiber-algebra/content/predication-fibration/explanations/exhaustiveness-of-four-predication-cell-complex-site-generators.md) on these predicates. The category is small and finite (the predicate set is finite by enumeration; the generator set is fixed).
- **Entity set $E_{\mathrm{op}}$.** Disjoint union of:
  - *Work entities*: agents, tasks, plans, workflows, capabilities, scopes.
  - *Governance entities*: offices, incumbency propositions, jural relations, jurisdictions, charter rules.
  - *Record entities*: witnesses, operational events, session records, tier-settlement-marker cells.
  - $|E_{\mathrm{op}}|$ is countably infinite in principle (ongoing operations admit new agents, tasks, and governance entities); finite at any given operational snapshot.
- **Settling bound $\lambda$.** $\omega$ for the standard reading: operations advance through countably many event-driven stages. For a bounded operational period (a single sprint, a single session), $\lambda$ is a finite ordinal. For the operations settling of an aim-generative enterprise (the function), $\lambda = \omega_1$ per [function-as-aperiodic-settling](../../theorems/function-as-aperiodic-settling.md).

## Regime of the base

The base's regime is not fixed but depends on which closure rules are active in $\mathcal{S}_{\mathrm{op}}$:

- **Strict-regime base.** When $\mathcal{S}_{\mathrm{op}}$ contains only finitely-antecedented rules over a finite entity set (a fixed operational period with finite agents and tasks), the closure ordinal is finite.
- **Scott-continuous-regime base.** When $\mathcal{S}_{\mathrm{op}}$ contains Π₁ rules with bounded-FOL antecedents (guidelines-tier rules per [charter-tier-fragment-correspondence](../../../../../../../../../philosophy-services-section/services/relationality-services-section/services/agency-services-section/content/text/documents/articles/learning-articles/questions/charter-tier-fragment-correspondence.md)), the closure ordinal is at most $\omega$. This is the typical regime for the standard ship's operations base.
- **Aperiodic-regime base.** When $\mathcal{S}_{\mathrm{op}}$ includes the aim-settling rules of an enterprise (the $\Gamma$ mechanism from [aim-generativity](../../../../../../../social-theory-science-services-section/content/text/glossary/concepts/aim-generativity.md)), the base's closure ordinal reaches $\omega_1$.

The base does not have a single regime; the regime is a property of the base *together with* its closure-rule system. The operations base $B_{\mathrm{op}}$ provides the *predicate structure* and *entity set* from which the settling is built; the settling's regime is determined by $\mathcal{S}_{\mathrm{op}}$.

## Normative/operational partition of $\mathcal{C}_{\mathrm{op}}$

The predicate category $\mathcal{C}_{\mathrm{op}}$ is a two-colored category: predicates carry a type label O (operational) or N (normative). The four cross-layer rule types from [normative-operational-layering](../../../../../../../social-theory-science-services-section/content/text/glossary/concepts/normative-operational-layering.md) (N→O, O→N, N→N, O→O) correspond to morphisms in $\mathcal{C}_{\mathrm{op}}$ that cross or stay within the color partition.

This two-coloring is a structural commitment of the predicated-work program: the base exposes both layers as first-class predicate structure, not as a meta-level annotation. The [closure-rule-system](../../../../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/closure-rule-system.md) $\mathcal{S}_{\mathrm{op}}$ exploits the two-coloring to implement the normative-conditioned operational closure rules that gate dispatch, delegate capability, and propagate incumbency.

## Standard worked instance

For a single ship's operations: $E_{\mathrm{op}}$ enumerated from the ship's agents/personas/personnel, tasks, offices; $\mathcal{C}_{\mathrm{op}}$ generated by the ship's vocabulary commitments; $\lambda = \omega$. The strict-regime sub-base is the same data restricted to a finite operational period. The aperiodic-regime extension is the same base plus the enterprise's aim-settling rules, with $\lambda$ extended to $\omega_1$.
