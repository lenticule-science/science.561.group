The **kinematic space of work** is the space whose points are the runs of the
Group's agents. A run is a diamond: an ingress, a settled exit and the witnessed
events between. The space is a [causal set](../../../../../../../../../natural-science-services-section/services/physical-science-services-section/services/physics-services-section/content/text/glossary/terms/causal-set.md)
under sequencing: run a precedes run b when a's exit reaches b's ingress through
witnessed events. Nesting (a session holding subagents, a project holding tasks)
is containment, shown as grouping, and is never the order. A live run is a lower
endpoint with a growing interior and needs no exit. A move is one run of one
[skill](skill.md) by one office holder; only witnessed moves are points, so work
done and not recorded is a hole in the space.

The **causal set of an agent's moves** is the finite poset of move types
(incumbency, office, duty, skill) the agent's records permit, ordered by the
dependence of one duty's `to` on another's `from`, with each duty's receiving as
a later type held by its receiver. Each real move is an instance of a move type
and the instance map preserves order. A move with no type is outside method. A
type with no instance whose predecessors are all received is an available move.
The work board is the history and this poset read together.

See the [dreaming routine](../../../../../../../../../information-science-services-section/services/intelligence-science-services-section/services/dreaming-science-services-section/content/text/glossary/terms/dreaming-routine.md),
whose dreams are moves in this space.
