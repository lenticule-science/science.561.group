# Learn Lesson Design

A lesson is one unit of teaching: one core idea, structured so the reader builds the understanding rather than receiving deposited information. Lesson design is the work of arranging concept introduction, examples, and exercises so that arrangement holds.

## When to use

You are about to write or critique a lesson and want the structure right before
you commit prose. Or you are evaluating an existing lesson and need a vocabulary
for what's working and what isn't.

## How it works

### Backward design

Start from the desired result — a specific thing the learner can *do* after the lesson, not "understand X" but "given Y, do Z." Pick the example, exercise, and concept introduction *because* they reach that result. If you cannot state the result concretely, the lesson is a reference document, not a lesson.

### Concrete before abstract

For every concept: an intuitive explanation or analogy, then a worked example the reader can hold in their head, then (if applicable) the formal definition. Definition-first ordering reverses how learning actually happens — the learner has nowhere to land the formal claim.

### Scaffolded prerequisites

State what the reader needs from each prerequisite specifically. "Familiarity with X" is not specific. "The definition of Y and the ability to do Z" is.

### Exercises aligned to the goal

Self-check exercises test application, not recall. "Define X" is a recall exercise; "Given Y, determine whether X applies and explain why" is an application exercise. Each exercise should map to a stated learning result.

### Reference vs teaching

A lesson with no exercise and no worked example is a reference document. References list and define; lessons build understanding through *what the reader does*. If the reader is only reading, the document is acting as a reference.

## Verification

Pick an existing lesson. Answer: (1) Does it state what the learner should be able to do afterward? (2) Does it introduce each concept with a concrete example before the formal definition? (3) Are prerequisites specific enough that the reader knows what to review? (4) Does it include at least one application exercise? Naming what it does well or poorly on each count is the skill.
