# A sprint is a recurrent practice with variable strict cadence

A *sprint* — the standard agile-software unit of cadence-bounded work — instantiates the [recurrent-practice](../../../../../../../sociology-science-services-section/services/work-science-services-section/services/predicated-work-services-section/content/text/glossary/terms/recurrent-practice.md) object with a [variable strict cadence](../../research/2026/07/31/lenticule-import/library/social-sciences/working/_archive/teaching/explanations/cadence.md) and a per-cycle phase structure that mirrors the [operations-loop](../../../../../../../sociology-science-services-section/services/work-science-services-section/services/predicated-work-services-section/content/text/glossary/terms/operations-loop.md).

## The instance

A sprint is a recurrent-practice triple $R_S = (\mathcal{S}_S, T_S, \alpha_S)$ where:

- $\mathcal{S}_S$ — closure rules covering: *commitment* (sprint-start cells settle), *daily-standup* (daily increments are recorded), *demo-and-review* (sprint-end cells fire the milestone-settlement rule), *retrospective* (the practice's own meta-cells are updated).
- $T_S$ — the cadence boundaries: $\{\tau_n : n < \omega\}$ where $\tau_n$ is the start of sprint $n$. Spacing is *variable strict*: each sprint's length is fixed at planning-time, may differ between sprints, but is uniformly knowable in advance for any single sprint.
- $\alpha_S$ — *finite-history* aggregation of depth $1$: each sprint's closure rules read the immediately prior sprint's retrospective cells but no further back.

## Regime classification

By [regime-of-recurrent-practice](../../../../../../../sociology-science-services-section/services/work-science-services-section/services/predicated-work-services-section/content/glossary/concepts/regime-of-recurrent-practice.md), $R_S$ lives in the **Scott-continuous regime**: $\alpha_S$ is finite-history (depth $1$), $T_S$ has order type $\omega$, and the per-cycle closure rules are finitary. Closure ordinal $\kappa = \omega$.

## The cycle morphism

The [settle-cycle](settle-cycle.md) morphism $\Sigma_{R_S}$ advances the operations settling by exactly one sprint. Its action:

1. Takes the valuation at the sprint's start, $v^{\mathrm{op}}_{\tau_n}$.
2. Joins all daily-standup increments and any in-sprint witness increments recorded during $[\tau_n, \tau_{n+1})$.
3. Applies the closure operator generated by $\mathcal{S}_S$, which fires the demo-and-review rule (settling milestone cells) and the retrospective rule (settling the practice's meta-cells).
4. Returns $v^{\mathrm{op}}_{\tau_{n+1}}$.

By the monotonicity property of $\Sigma_R$, the sprint cannot retract knowledge-order content — i.e., evidence accumulated during the sprint persists into the next.

## Contrast: a generational review is *not* a sprint

The [generational-review-as-transfinite-bounded](../../../../../../../sociology-science-services-section/services/work-science-services-section/services/predicated-work-services-section/content/glossary/concepts/generational-review-as-transfinite-bounded.md) example uses *limit-aggregating* $\alpha_R$ with countable cofinality, landing it in the transfinite-bounded regime. Sprints, by their finite-history aggregation, cannot be transfinite-bounded — the cycle structure is what fixes the regime.

## CALM for sprint-boundary queries

The sprint-boundary witness cells $\langle R_S, \texttt{cycle-boundary-at}, \tau_n\rangle = \mathbf{t}$ are $\leq_k$-monotone once settled. By the [predication-settling CALM corollary](../../../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/formalization/infomaterial/lib/infomaterial/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/valuation/content/knowledge-least-valuation/settling/content/sheaf/content/settling-cohomology/references/settling-calm-corollary.md):

- Confirming "has sprint $n$ ended?" is coordination-free: any node with the boundary-witness cell can confirm it locally.
- Confirming "are we still in sprint $n$?" (boundary not yet crossed) requires coordination.

The sprint-retrospective cell $\langle R_S, \texttt{retrospective-settled-at}, \tau_n\rangle = \mathbf{t}$ — the output of the settle-cycle morphism — is also $\leq_k$-monotone. The next sprint's cycle-start rule reads this cell: once the retrospective is settled, the next sprint's activation is coordination-free to confirm. This is the CALM-theoretic content of "sprint handoff is coordination-free in the forward direction": the new sprint's start is locally confirmable by any node that has received the prior sprint's retrospective witness.

## Temporal 2-category of the sprint sequence

In the [temporal 2-category](../../../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/valuation/content/knowledge-least-valuation/settling/content/temporal-2-category/temporal-2-category.md) $\mathbf{T}(\mathcal{C}_{\mathrm{op}}, \lambda)$, each sprint cycle is a 1-cell:

$$\Sigma_{R_S}^{(n)} : (\tau_n, \mathcal{C}_{\mathrm{op}}) \to (\tau_{n+1}, \mathcal{C}_{\mathrm{op}})$$

The sprint sequence $\Sigma_{R_S}^{(0)}, \Sigma_{R_S}^{(1)}, \ldots$ is a sequence of composable 1-cells whose composite $\Sigma_{R_S}^{(N)} \circ \cdots \circ \Sigma_{R_S}^{(0)}$ is the $N$-sprint program's execution.

The depth-1 (Markov) aggregation $\alpha_S$ means each sprint's 1-cell reads only the prior sprint's 0-cell's fiber — the retrospective cells from sprint $n$ suffice for sprint $n+1$'s starting state. The KZ-lax-idempotent structure collapses: the temporal 2-category's 2-cells between sprint 1-cells are all invertible. The sprint sequence lives in the *1-categorical* part of $\mathbf{T}$: no transfinite limit behavior, no non-invertible 2-cells. This is the temporal-2-category content of "Scott-continuous regime": the settling behavior at the $\omega$-limit is determined by the pointwise 1-cellular settling, with no higher-categorical obstruction.
