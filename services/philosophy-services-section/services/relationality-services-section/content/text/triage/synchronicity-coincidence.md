# Idea: Synchronicity & Coincidence Graphs

Represent “this felt meaningfully connected” moments as recognitions, without
presupposing any causal story.

## 1. Recognitions

- `EventRecognition` (from other domains) reused here as building blocks.
- `CoincidenceRecognition`
  - when multiple events are experienced as meaningfully linked.
- `PatternRecognition`
  - recurring coincidence structures (e.g., same symbol, timing, theme).

## 2. Measurement and topology

- Measurement:
  - subjective intensity, frequency, emotional impact.
- Topology:
  - links between coincidences via shared features (people, symbols, times,
    domains).

This allows you to explore synchronicities as relational patterns without
flattening them into “real/not real”.
