constraint horizon function
The constraint horizon function (`H`) is induced by constraint propagation (`P`) and quantum entity emergence (`Q`).

When modulation cannot extend beyond a boundary within a constraint field,
a horizon emerges — the set of points at which propagation fails or ceases.

H(Q) := { x ∉ Q | ∇C(x) > θ ∧ ∄ d: P(x, d) = True }

That is, the horizon of a quantum entity is the set of external points beyond which constraint propagation does not occur.
