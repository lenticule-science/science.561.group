# Stabilizing Context

## Interpretation

*Stabilize Judgment* shows contexts only matter through the stable judgments they support, but we must identify contexts giving the same stable judgments to all stabilized terms.  *Recognize Context* witnessing *Stabilize Judgment* produces ***Stabilize Context*** ([StabilizeContext](stabilize-context.md)).

The composition uses previously earned recognitions and identifies such contexts, so *Stabilize Context* follows.
