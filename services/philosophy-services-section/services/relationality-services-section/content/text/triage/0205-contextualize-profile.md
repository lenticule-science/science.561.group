# Profile Context

## Interpretation

The traced profile must also inherit context recognitions.  *Recognize Context* witnessing *Profile Recognitions* produces ***Contextualize Profile*** ([ContextualizeProfile](0205-contextualize-profile.md)).

This composition restricts contexts to the profile’s stable recognitions, so *Contextualize Profile* follows.
