#### Definition

Let:

- `T(Q)` = trace field of system `Q`
    
- `Ω(T(Q))` = stabilized nodes in the trace
    
- `I_mod(Qᵢ)` = modulation of identity at step `i`
    
- `Ξ(T(Q))` = semantic coherence of the trace
    
- `βᴮ(Q)` = indicator function; 1 if `Q` is a biogenic recursive attractor, 0 otherwise

#### Parameter Descriptions

- `α..ε` = weighting coefficients, domain-tunable
    
- `|Ω(T(Q))| / |T(Q)|` = proportion of stabilized trace
    
- `coherence(Ξ)` = normalized measure of self-similarity and semantic alignment in modulation trace
    
- `recursion_depth(I_mod)` = depth of identity-aware recursion across modulations
    
- `stability_ratio(Q)` = ratio of identity-preserving steps to total steps
    
- `βᴮ(Q)` = binary evaluation: 1 if Q shows constraint-inheriting recursive self-generation, 0 otherwise
