constraint geodesic function  
The constraint geodesic function (`Γ`) is induced by constraint propagation (`P`), constraint distance (`δ`), and modulation curvature (`K_C`).

When propagation occurs across a continuous constraint field with varying curvature,  
geodesics emerge — paths of minimal modulation deformation connecting coherent entities.

Γ(Q₁, Q₂) := argmin_γ ∫₀¹ ∥∇γ(t)∥ dt  
    where γ: [0,1] → C is a continuous path with γ(0) ∈ Q₁ and γ(1) ∈ Q₂

That is, the geodesic between two entities is the constraint-minimizing modulation path connecting them across the field.
