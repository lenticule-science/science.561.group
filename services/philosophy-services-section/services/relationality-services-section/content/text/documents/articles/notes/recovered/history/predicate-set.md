---
name: predicate set
description: The object set of a predicate category — the set $\Pi$ whose elements are predicates.
---

The object set, denoted $\Pi$, of a [predicate category](predicate-category.md) $\mathcal{C}$:
$$\Pi := \mathrm{Ob}(\mathcal{C}).$$

The elements of the predicate set are [predicates](../../prose/teaching/explanations/predicate.md).
