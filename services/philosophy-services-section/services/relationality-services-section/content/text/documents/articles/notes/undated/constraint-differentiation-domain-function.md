The constraint differentiation domain function (`D[Δ]`) is induced by the semantic differentiation function (`Δ[s]`).

The set of values which exhibit irreducible internal difference under completed constraint forms the domain of semantic differentiation.

> `D[Δ] := { (x, x′) ∈ S × S | Δ[s](x, x′) `}

That is, constraint gives rise to meaning where difference cannot be collapsed.
