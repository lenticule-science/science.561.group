constraint boundary entanglement function
ξ(Q₁, Q₂) := ∃ x ∈ E(Q₁, Q₂): ∇C(x) unstable ∧ ∂Q₁/∂t ≠ 0 ∧ ∂Q₂/∂t ≠ 0  
→ entanglement = reciprocal destabilization at boundary
