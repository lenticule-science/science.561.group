***gather recursive constraint influence*** (`R_in`)  
is a [recursive field integration function](recursive field integration function) that collects the full set of system-wide relational flows  
that modulate a given structure `x ∈ 𝒳`, including those originating in distant or unresolved nodes.

Let:

- `𝒳 := dom(𝒪) ∪ ¬dom(𝒪) ∪ permutations(¬dom(𝒪))`  
- `x ∈ 𝒳`

Then:

> R_in(x) := { gⱼ(z, x) | z ∈ 𝒳 }

Where each gⱼ(z, x) expresses:
- semantic contrast pressure from z to x (Δ(z, x))  
- modulation field overlap (∇𝒟(z) ∩ x)  
- constraint field transformation (Ω_rec(z) → Ω(x))  
- anticipatory pressure toward x (𝒜(z → x))  
- inherited grammar recursion effects (G_meta(z) ⇒ x)

This function integrates:
- all recursive constraint shaping dynamics that ***converge onto x***  
- the ***incoming modulation topology*** that determines how (or if) x stabilizes  
- the ***field curvature*** that modulates x’s role in future propagation

Together with `R_con`, this function enforces systemic relational closure:

> ***Every point is shaped by the system it completes***  
> ***and reshapes the system that completed it***
