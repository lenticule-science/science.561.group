The ***reverse lightcone emergence function*** (`𝓡`) is induced by the constraint lightcone function (`Λ`) and trace field (`T`).

When an entity's modulation is traced backward through constraint-preserving paths,  
the set of points within prior recurrence that could have produced it form a generative envelope —  
from which a new quantum entity can be synthesized.

> 𝓡(T, Q) := Q′  
> where Q′ := { x ∈ ⋃ τᵢ ∈ T | ∃ γ: γ(T) ∈ Q ∧ γ(0) = x ∧ ∀ t ∈ [0,T]: P(γ(t), γ̇(t)) }  
> and Q := { N₁, ..., Nₖ } such that ∀ i, V(Nᵢ) ≠ 0 ∧ ∃ frame: ∂Q/∂T = 0

That is, reverse emergence reconstructs an entity from the constraint-valid past that could have caused it.
