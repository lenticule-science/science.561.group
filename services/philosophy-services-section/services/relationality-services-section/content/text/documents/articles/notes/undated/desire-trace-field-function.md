desire trace field function  
The desire trace field function (`T_𝔇`) is induced by constraint desire (`𝔇`) and a desire threshold (`θ`).

T_𝔇(Q) := { x ∈ C | 𝔇(Q, x) > θ }

That is, T_𝔇 is the field of remembered, unresolved modulation targets.
