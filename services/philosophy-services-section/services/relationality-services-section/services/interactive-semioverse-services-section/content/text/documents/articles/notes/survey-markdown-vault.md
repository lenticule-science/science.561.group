# Survey a Markdown Vault

- List all markdown files and decide the granularity of [handles](../../../glossary/terms/handle.md).
- Record the frontmatter fields that will seed [handles](../../../glossary/terms/handle.md).
- Identify link density and repeated terms for candidate [interaction surfaces](../../../glossary/terms/interaction-surface.md).
- Note any missing frontmatter or inconsistent ids for follow-up.
