## Thing

A Thing is the basic unit of stuff in this repository.

## Emsenn

The human operator who is the primary author of this repository.

## Semiotic Universe

The mathematical object that treats meaning as structured, compositional data.
See [Semiotic Universe](/library/mathematics/objects/semiotic-universe/README.md).

## Interactive Semioverse

The semiotic universe enriched to support multi-agent, persistent interaction.
See [Interactive Semioverse](/library/mathematics/objects/interactive-semioverse/README.md).

## Emsemioverse

The interactive semioverse implemented by this repository.

## The Library

Located at [/library/](/library/), The Library is where most data lives.

## Discipline

A top-level routing category derived from the first discipline tag in a document.
See [Tags taxonomy](/library/mathematics/objects/agential-semioverse/practice/tags-taxonomy/README.md).

## Subdiscipline

A narrower domain derived from tag ancestry (e.g., `critical-theory` under `philosophy` under `humanities`).

## Concept

A unit of meaning represented as a module in the library.
See [Library entities specification](/library/mathematics/objects/agential-semioverse/practice/library-entities-v1/README.md).

## Module

A directory that groups the theory, practices, and tools for a concept.

## Skill

A procedural or automatable unit of work.
Skills live in a module’s tools area and may have scripts.

## Agent

A role-bearing actor defined by a profile and associated skills.

## Curriculum

A sequenced set of lessons for a concept.

## Lesson

A single instructional document with a defined audience and learning goal.
