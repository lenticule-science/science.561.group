An agent benchmark evaluates an [LLM agent](llm-agent.md) on whether it can complete a multi-step task against an environment, rather than scoring a single generated response against a reference answer. Because the environment has real or simulated state, grading is typically execution-based — did the environment end up in the correct state — rather than surface-form comparison of the agent's output text.

Carlos Jimenez et al.'s [SWE-bench](https://arxiv.org/abs/2310.06770) (ICLR 2024) is the canonical software-engineering instance: 2,294 real GitHub issues paired with the pull request that actually resolved them, graded by whether an agent's generated patch makes the repository's own test suite pass. John Yang et al.'s companion [SWE-agent](https://arxiv.org/abs/2405.15793) (NeurIPS 2024) paper shows that solve rate on this benchmark depends materially on the agent-computer interface used to touch the repository, not only on the underlying model. Shuyan Zhou et al.'s WebArena (arXiv:2307.13854, ICLR 2024) applies the same execution-based-grading principle to 812 long-horizon web tasks across four self-hostable, fully functional websites, and found the best evaluated agent solved only 14.41% of tasks against a 78.24% human baseline. Grégoire Mialon et al.'s [GAIA](https://arxiv.org/abs/2311.12983) (ICLR 2024) instead poses 466 tool-and-reasoning questions that are easy for humans (92% accuracy) but were hard for GPT-4-plus-plugins (15%) at publication. Xiao Liu et al.'s AgentBench (arXiv:2308.03688, ICLR 2024) spans eight distinct multi-turn environments in one suite, from operating-system and database tasks to household simulation and web shopping. Shunyu Yao et al.'s τ-bench (first posted arXiv:2406.12045, 2024, from Sierra Research; accepted to ICLR 2025, making it peer-reviewed rather than industry-lab-preprint tier) adds a further axis — a simulated human user in the loop, and domain policy the agent must follow while calling tools — and found even strong function-calling agents inconsistent across repeated trials of the same task.

A second family of agent benchmarks targets failure diagnosis rather than headline solve rate. Karthik Valmeekam and Subbarao Kambhampati's PlanBench (NeurIPS 2023, Datasets and Benchmarks Track) isolates planning and reasoning-about-change specifically, using obfuscated-vocabulary variants of classical planning domains to rule out the model merely pattern-matching against commonsense world knowledge. Thomas Kwa et al.'s METR time-horizon study (arXiv:2503.14499, March 2025, an industry-lab technical report rather than a peer-reviewed paper) measures how the length of task an agent can complete with 50% reliability has scaled over time. Kunlun Zhu et al.'s AgentErrorTaxonomy (arXiv:2509.25370, September 2025, an arXiv preprint under review at time of writing) classifies failures into memory, reflection, planning, action, and system-level categories from annotated failure trajectories.
