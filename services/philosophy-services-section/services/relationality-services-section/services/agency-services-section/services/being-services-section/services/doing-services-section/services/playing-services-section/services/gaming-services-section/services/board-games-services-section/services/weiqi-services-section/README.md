# Weiqi Services Section

The Weiqi Services Section maintains knowledge and practices for this service domain, and is the constituted home for the weiqi web platform build described below.

## What is here

**Corpus** (`content/text/`), organized by artifact role:

- `documents/articles/notes/` — a five-lesson sequenced curriculum (overview, living groups and eyes, komi and handicap, how a game ends, history) plus the rules-completeness reference pair — [Rulesets](content/text/documents/articles/notes/rulesets.md) and [Regression Positions](content/text/documents/articles/notes/regression-positions.md) — plus this section's operating notes, including the [Weiqi Platform Plan](content/text/documents/articles/notes/weiqi-platform-plan.md), [Provenance Policy](content/text/documents/articles/notes/provenance-policy.md), and the [Weiqi Market Teardown](content/text/documents/articles/notes/weiqi-market-teardown.md). A 2026-08-29 working session added seven further notes recording that session's findings, each written to stand as a complete record in its own right: [Platform State](content/text/documents/articles/notes/2026-08-29-note-on-platform-state.md) (verified state of every app, tests, deployment, and open decision gates), [Upstream Integration](content/text/documents/articles/notes/2026-08-29-note-on-upstream-integration.md) (reusable infrastructure elsewhere in the repository and the gaps it doesn't cover), [Reframe and Standards](content/text/documents/articles/notes/2026-08-29-note-on-reframe-and-standards.md) (the owner's course-correction on scope, and standards decisions for SGF/GTP/KataGo integration), [Engineering History](content/text/documents/articles/notes/2026-08-29-note-on-engineering-history.md) and [Go-Science History](content/text/documents/articles/notes/2026-08-29-note-on-goscience-history.md) (the full recovered project chronology, split engineering/doctrine, including every bug's exact mechanics, dated test-count arcs, and one still-open owner action in the weiqi-lsp governance saga), [Weiqi/Go App Landscape](content/text/documents/articles/notes/2026-08-29-note-on-go-app-landscape.md) (the full 2026 competitive-landscape study behind the market teardown's addendum), and [WeiqIdol Product Vision](content/text/documents/articles/notes/2026-08-29-note-on-weiqidol-product-vision.md) (owner-originated fiction-layer and arcade-lane direction, not yet built).
- `glossary/terms/` — seventeen dependency-linked glossary terms in four clusters (tactical: liberty, atari, capture, ko, superko, suicide; scoring: territory, komi, handicap, area scoring, territory scoring, pass, dead stones; structural: connection, eye, life-and-death, seki).
- `glossary/topics/weiqi.md` — the start-here index linking the lessons and terms.
- `documents/articles/recovered-research/` and `glossary/recovered-research/` — retired/imported historical copies, never the live source; see the provenance policy for how these are marked and why they exist alongside the live documents.

**Platform build.** This corpus is the foundation for a weiqi web platform — real-time and correspondence play, an interactive learn track built from the lesson template, and a glossary served as both pages and an API — fusing playing and learning around one concept graph, per house doctrine that "the engine is the executable form of the glossary." Full thesis, architecture, roadmap, and board-decision gates are in the [Weiqi Platform Plan](content/text/documents/articles/notes/weiqi-platform-plan.md) — read it before adding code here, alongside the 2026-08-29 [Reframe and Standards](content/text/documents/articles/notes/2026-08-29-note-on-reframe-and-standards.md) note, which corrects the plan's education-first emphasis toward a fuller feature web. The rules kernel is materialized at [`apps/weiqi-kernel`](apps/weiqi-kernel/README.md), constituted by the [Weiqi Kernel Constitution](content/text/documents/articles/notes/weiqi-kernel-constitution.md). It is no longer uncoded: [`apps/weiqi-web`](apps/weiqi-web) is deployed and live at weiqi.561.group (Capture Go onboarding, tsumego with spaced repetition, one interactive lesson — undocumented by any constitution); a second, constitutionally-licensed Learn face is materialized at `services/weiqi-platform/apps/weiqi-learn` but not deployed; and [`apps/weiqi-lsp`](apps/weiqi-lsp), a corpus doctrine checker (not a Go language server, despite its name), enforces this section's own conventions against the kernel. See [Platform State](content/text/documents/articles/notes/2026-08-29-note-on-platform-state.md) for the verified detail, including the unreconciled two-parallel-Learn-apps situation and the status of every open decision gate. Both constitutions and the plan's remaining open decisions still gate any further code here.

## Tooling

- `scripts/check-links.mts` — zero-dep Node script (run via `npm run check-links` or `node scripts/check-links.mts`) that walks this section's `content/` tree and verifies every relative markdown link resolves to a real file. Scoped strictly to this section.

Node runs `.mts` files directly via type stripping; no build step, no external npm dependencies (house doctrine: zero-dep). Tests, when added, follow the house `node --test` convention with `.test.mts` files.
