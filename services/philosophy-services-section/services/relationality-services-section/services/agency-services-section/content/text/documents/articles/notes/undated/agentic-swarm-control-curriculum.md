This curriculum links the research library's agent-team theory, swarm theory, and drone-swarm control records. The point is to give agents a stable path through concepts that cross public literature boundaries: paraconsistent multi-agent witness propagation, swarm coordination as a mathematical regime, and meaningful human control as a decidable boundary discipline.

## Reading Path

1. Start with [Context Spacesuit](../../../../../../../../../../../social-science-services-section/content/text/glossary/terms/context-spacesuit.md). It explains what an agent is equipped to see and do before acting.
2. Read [Witness Propagation](../../../../../../../../../../../social-science-services-section/content/text/glossary/terms/witness-propagation.md) and [Descent-Clean Propagation](../../../../../../../../../../../social-science-services-section/content/text/glossary/terms/descent-clean-propagation.md). These describe how a local witness becomes team-visible or fails to glue.
3. Read [Toward agentic swarm theory](../../../../../../../../../logic-services-section/content/text/documents/articles/notes/undated/toward-agentic-swarm-theory.md). It identifies the bridge from bilattice-valued multi-observer systems to network-sheaf consensus, CRDT/CALM, and swarm coordination.
4. Read [Multi-agent RL as swarm](multi-agent-rl-as-swarm.md). It separates learning-time multi-agent dynamics from deployed fixed-rule swarm behavior.
5. Read [Meaningful Human Control](/library/applied-sciences/technology/automatic-control/systems-control/drone-swarms/terms/meaningful-human-control.md) and [Verified Safe Envelope](../../../../../../../../../../../../../engineering-services-section/content/text/glossary/terms/verified-safe-envelope.md). These turn embodied swarm control into checkable boundary conditions.

## Core Distinctions

A swarm is not just many agents. A swarm-coordinated system has bounded local rules, scaling behavior, and a coordination pattern that does not require a central expensive orchestrator at every step. Multi-agent RL may train such rules, but training-time learning dynamics are not automatically swarm dynamics.

A drone swarm is not only a swarm. It is an embodied control system whose workitems can affect the physical world. That changes the admissibility boundary. The library's drone-swarm records require witness chains, safety-envelope prechecks, charter-tier discipline, and persistent human interrupt/resume capability before embodied work composes downstream.

An agent team is not only a swarm either. It carries witness statements, local cell-systems, channels, adjudication modes, and inconsistency latency. The agent-team theory explains how a claim becomes common operational material or remains an unresolved obstruction.

## How Agents Should Use This

When adding content about swarms, avoid treating "swarm" as a vibe word. Ask whether the system is fixed-rule, learned-then-fixed, orchestrated, embodied, or witness-propagating. Link to the exact term page. Use canonical tags for discovery. Put claims and relations in the body as ordinary Markdown links so backlinks can read them.
