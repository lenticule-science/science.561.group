# Flatfile Agential Resource System Math Unit

**Superseded.** This concept has been renamed to [FlatfileAgentialResourceSystemMathEntity](../flatfile-agential-resource-system-math-entity/flatfile-agential-resource-system-math-entity.md).

The rename follows the repo-wide switch from "unit" to "entity" for named, globally addressable individuals with persistent identity.
A file in `math/` has an `id:`, is addressed by other files, and persists across content changes — that is entity semantics, not value semantics.

See [unit](unit.md) for the abstract concept of a value/unit.
See [entity](entity.md) for the abstract concept of a named addressable individual.
