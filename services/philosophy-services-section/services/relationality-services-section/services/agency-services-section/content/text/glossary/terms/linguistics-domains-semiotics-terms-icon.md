An icon is a [sign](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/language/_archive/sign.md) that represents its object by resemblance. The [representamen](../../../../../../../../../information-science-services-section/services/communication-science-services-section/services/linguistics-services-section/services/semiotics-services-section/content/text/glossary/terms/representamen.md) shares some quality or structural feature with the thing it stands for — a portrait resembles the person depicted, a map resembles the territory, a diagram resembles the structure it represents.

[Peirce](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/humanities/domains/general/domains/people/charles-sanders-peirce.md) distinguished three subtypes of icon [@peirce_CollectedPapers_1931]:

- **Image**: resembles the object in simple qualities (a photograph, an onomatopoeia)

- **Diagram**: resembles the object in relational structure (a flowchart, a mathematical graph)

- **Metaphor**: represents one thing by its resemblance to another in some respect

Iconic [signs](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/language/_archive/sign.md) are never purely iconic — a map uses conventional markings ([symbols](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/language/_archive/symbol.md)) and is produced through a causal process ([indexical](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/language/_archive/index-sign.md)). The classification identifies which aspect of the [sign](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/language/_archive/sign.md) relation predominates, not which is exclusively present [@chandler_Semiotics_2007].
