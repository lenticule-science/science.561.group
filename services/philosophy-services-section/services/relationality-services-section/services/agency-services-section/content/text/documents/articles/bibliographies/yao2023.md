# Yao et al. (2023) — ReAct: Synergizing Reasoning and Acting

**Full citation:** Yao, S., Zhao, J., Yu, D., Du, N., Shafran, I., Narasimhan, K., and Cao, Y.
"ReAct: Synergizing Reasoning and Acting in Language Models." arXiv 2210.03629, 2022.
Published at ICLR 2023.

## Summary

ReAct (Reasoning + Acting) is a prompting framework that interleaves language model reasoning traces (thoughts) with action calls (tool invocations).
The cycle is: Think → Act → Observe → Think → Act → Observe → ... until the task is complete.

The key insight: reasoning traces help the model plan, track progress, and handle exceptions; action results provide grounded information that reduces hallucination.
The combination outperforms either pure reasoning (chain-of- thought without tool access) or pure action (tool calling without explicit reasoning) on question answering and interactive decision-making benchmarks.

ReAct was among the first frameworks to demonstrate that language models could engage in interleaved multi-step reasoning and tool use to accomplish tasks requiring real-world information lookup.
It predates the mainstream adoption of function calling APIs and used in-context prompting to elicit the behavior.

## Contribution to the agents theory

ReAct is the empirical grounding for the ReAct-style decomposition strategy described in the [task-decomposition](../notes/undated/task-decomposition.md) morphism: decomposition interleaved with execution, where the plan emerges from the reasoning-action-observation cycle rather than being produced upfront.

The ReAct framework realizes [goal-directed planning](../../../glossary/concepts/goal-directed-planning.md) in a specific form: the reasoning trace is the plan representation, and the interleaving of reasoning steps with action calls is the causal decomposition made adaptive and step-by-step rather than prescriptive and upfront.

ReAct's observation that grounded action results reduce hallucination is related to the MASFT study's finding that specification failures (FC1) are a primary failure mode: ReAct's Think phase helps the model maintain a coherent specification of the current goal and progress.
