# Code

The *convention by which sign-vehicles are paired with sign-objects within a community* — the mapping that licenses the standing-for. A code is what makes a particular sign-relation *available*: outside the code, the sign-vehicle does not stand for the sign-object; inside the code, it does, and predictably.

Eco (per [Eco 1976](../../documents/articles/bibliographies/eco1976.md) §3) treats *code* as the foundational system-level primitive: a semiotic system *is* a (possibly composite) code, and semiotic competence is the ability to operate codes. Hjelmslev's *form vs. substance* distinction (per [Hjelmslev 1943](../../documents/articles/bibliographies/hjelmslev1943.md)) sharpens this: the code is the *form* of the sign-relation, abstracting from the *substance* (the physical or material instantiation) that any particular sign-act realises.

A code is *neither* the sign-vehicle nor the sign-object nor the interpretant; it is the structure that makes the triad possible. Different codes can pair the same sign-vehicle with different sign-objects (homography); different codes can pair different sign-vehicles with the same sign-object (synonymy across systems); two communities sharing no code share no sign-relations across their boundary, only sign-vehicles read against incompatible interpretants.

The discipline holds open whether *code* and [semiotic-system](../terms/semiotic-system.md) are the same object viewed from two registers (a code seen from outside is a system; a system seen from its rule-set is a code) or genuinely distinct — see [code-vs-system-distinction](../../documents/articles/learning-articles/questions/code-vs-system-distinction.md).

The substrate-level reading places a code at the *closure-rule subset* of the [predicated knowledge system](../../documents/articles/research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/information/theories/knowledge-systems/theories/predicated-knowledge-systems/objects/predicated-knowledge-system.md): the code's licensing of sign-relations *is* the closure-rule system's derivation of cells, restricted to the scope corresponding to the code's community.
