The base parameters $(\mathbf{FOUR}, \mathcal{C}, E)$ of a FARS substrate:

- $\mathbf{FOUR}$: the [four-bilattice](four-bilattice.md) — the fixed value space.
- $\mathcal{C}$: the predicate category — a small category whose objects are [transformers](transformer.md) and whose morphisms are generated by [specializing](../transformers/specializing.md), [conversing](../transformers/conversing.md), [projecting-to-subject](../transformers/projecting-to-subject.md), and [projecting-to-object](../transformers/projecting-to-object.md).
- $E$: the [entity](entity.md) set — all `.md` files in the substrate.

A predication fibration is a cloven Grothendieck fibration $p : \mathcal{E} \twoheadrightarrow \mathcal{C}$ satisfying: (A1) every fiber $\mathcal{E}_q \cong \mathbf{FOUR}^{\bowtie E \times E}$; (A2) the four generator classes induce reindexing functors as specified; (A3) every reindexing is a bilattice-residuated homomorphism.

In the FARS filesystem realization: $E$ = all `.md` files; $\mathrm{Ob}(\mathcal{C})$ = files in `transformers/` directories; a frontmatter entry `q: e₂` in file $e_1$ asserts [predication-cell](predication-cell.md) $(e_1, q, e_2)$ at [true](teaching/explanations/true.md); absence leaves the cell at [mystery](../../bilattice/mystery/mystery.md).
