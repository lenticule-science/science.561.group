"Agents and the Semantic Web." *IEEE Intelligent Systems*, 16(2), 30–37, 2001.

## Form

Magazine article.
Companion to [berners-lee-hendler-lassila2001](../../../berners-lee-hendler-lassila2001/berners-lee-hendler-lassila2001.md) developing the agent-side of the Semantic Web vision: the argument that machine-readable web data (RDF, OWL ontologies) and software agents are co-dependent — the data needs agents to use it intelligently, and the agents need the data to act intelligently.

## Content summary

Argues that the Semantic Web's promise depends critically on agents that can: discover relevant ontologies and data sources; integrate information from heterogeneous sources via shared vocabularies; reason over the integrated information using ontology-grounded inference; and coordinate with other agents to accomplish multi-step tasks (the canonical Berners-Lee–Hendler–Lassila example: an agent plans a hospital appointment combining the user's calendar, the medical-provider directory, and the insurance coverage database).
Hendler develops what each of those four capabilities requires from the agent side and from the web-data side, arguing that progress requires *concurrent* development of richer ontologies, more capable agents, and standardized agent-to-web-data interaction patterns.
The article is the canonical statement of the Semantic-Web-agents research program that ran through the early 2000s (DAML-S / OWL-S service descriptions, semantic web services, the W3C's Semantic Web Activity).
