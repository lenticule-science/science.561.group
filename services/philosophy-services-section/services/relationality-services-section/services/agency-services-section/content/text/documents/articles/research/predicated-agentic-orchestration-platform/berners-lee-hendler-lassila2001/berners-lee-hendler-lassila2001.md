## Form

Magazine article.
The founding popular-press articulation of the *Semantic Web* vision and the most-cited reference for the program of machine-readable, ontology-grounded web data with agent-mediated interaction.

## Content summary

Argues for a *Semantic Web*: an extension of the World Wide Web in which web content carries machine-readable meaning (in the form of RDF assertions grounded in shared OWL ontologies), enabling software agents to discover, integrate, and act on web content automatically.
The article's load-bearing examples — the medical-appointment planner that combines provider directory, insurance coverage, and personal calendar; the conference travel agent that books flights and hotels — illustrate the agent-mediated value the program intended to deliver.
The article positions three ingredients as necessary: (1) machine-readable data (RDF triples); (2) shared vocabularies and ontologies (OWL); (3) software agents capable of reasoning over the data and acting on the user's behalf.
The W3C's Semantic Web Activity (RDF, RDFS, OWL, SPARQL, SKOS, SHACL specifications) developed the data and ontology layers; the agent layer attracted active research through the early 2000s (DAML-S, OWL-S, semantic web services, JADE-based semantic-agent platforms) without producing a comparable industry-standard surface.
