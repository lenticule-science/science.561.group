# Are code and semiotic system the same object viewed from two registers, or genuinely distinct?

The discipline carries two terms — [code](../../../../glossary/concepts/code.md) and [semiotic-system](../../../../glossary/terms/semiotic-system.md) — whose relation is not yet settled. Eco (per [Eco 1976](../../bibliographies/eco1976.md)) treats *code* as foundational and *system* as derivative (a system is a composite code). Hjelmslev (per [Hjelmslev 1943](../../bibliographies/hjelmslev1943.md)) inverts the priority (a system has a *function* that is the system's code; the function is structurally derivative of the system's components).

## Statement

> Are *code* and *semiotic system* the same structural object, viewed from two registers (rule-set vs. component-tuple), or are they genuinely distinct objects related by an asymmetric structural morphism?

## Partial decomposition

The question splits into:

- **(P1) Reducibility direction.** If they are the same object, which register is primary — code-as-rule-set, or system-as-component-tuple? Both reductions are coherent; the discipline must commit to one for explanatory purposes.
- **(P2) The substrate-side parallel.** On the predicated-knowledge-systems substrate, [closure-rule system](../../research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/communication/archive/library/information/theories/knowledge-systems/theories/predicated-knowledge-systems/concepts/discourse-community-as-fiber.md) and [predicated-knowledge-system](../../research/2026/07/31/lenticule-import/animating/content/becoming/doing/working/governing/communicating/content/communication/archive/library/information/theories/knowledge-systems/theories/predicated-knowledge-systems/objects/predicated-knowledge-system.md) are clearly distinct (the rule-system is a component of the knowledge-system tuple). If the semiotic-side parallel is the same, then code is one component of system, not the same object.
- **(P3) The Hjelmslevian function.** The function in Hjelmslev's framework is *the structural relation* between expression-form and content-form; it is not itself a code in Eco's sense (which carries cultural-historical convention). The function-vs-code distinction may be load-bearing for resolving the question.

## What is established

- The substrate-level reading places code and system as distinct objects with code being one component of the six-component system tuple. This favours the reading "they are distinct".
- The Saussurean langue and the Lotmanian semiosphere both behave like *systems containing codes*, not like *codes alone*; the multi-coded character of natural systems argues against the reduction code = system.

## What remains open

- Whether Eco's reduction of system to composite-code can be sustained against the multi-coded systems Lotman documents.
- Whether the substrate-side parallel is faithful to the semiotic-side question, or whether the two distinctions are differently grounded.
