# Deadly triad

The **deadly triad** is Sutton and Barto's name for the combination of
three features whose simultaneous presence breaks the convergence
guarantees of value-based reinforcement learning:

1. **Function approximation** — the value function is represented by
   a parameterized function class rather than a lookup table.
2. **Bootstrapping** — value estimates are updated using other value
   estimates (as in TD-learning) rather than only from full Monte-Carlo
   returns.
3. **Off-policy learning** — the data used to update the value function
   was generated by a behavior policy different from the policy being
   evaluated.

Any two of the three features individually are safe. All three together
can cause value estimates to diverge: the parameter vector grows without
bound, and the policy derived from the diverging estimates becomes
arbitrary. Baird's counterexample (1995) is the canonical demonstration.

## Why each pair is safe

- **Approximation + bootstrapping (on-policy):** SARSA with linear
  function approximation has convergence guarantees on-policy
  (Tsitsiklis–Van Roy 1997).
- **Approximation + off-policy (no bootstrap):** Monte-Carlo policy
  evaluation with function approximation is consistent off-policy
  with importance sampling.
- **Bootstrapping + off-policy (tabular):** Tabular Q-learning is the
  paradigm case; converges with probability one under standard
  conditions ([q-learning-convergence](../../documents/articles/notes/undated/q-learning-convergence.md)).

## Why all three together break

Bootstrapping makes the update target depend on the current parameters.
Off-policy weighting changes the distribution under which the update is
averaged. Function approximation introduces correlations between the
predictions at different states. The composite update is no longer a
contraction in any norm in which the parameter vector lives, and there
is no Lyapunov function to bound the iterates. See
[deadly-triad-divergence](../../documents/articles/notes/undated/deadly-triad-divergence.md).

## Practical mitigations

Modern deep-RL practice (DQN, its descendants) operates with all three
features present and relies on engineering devices — target networks,
experience replay, gradient clipping, careful step sizes — to *empirically*
contain divergence rather than to *prove* convergence. The deadly triad
is therefore the structural reason that "deep RL works in practice but
the theory is open." Convergence analysis for the deep-RL regime remains
a frontier research program; nontrivial guarantees exist for narrow
algorithm-and-environment classes (gradient TD, emphatic TD) but not
for the full deep-RL regime.
