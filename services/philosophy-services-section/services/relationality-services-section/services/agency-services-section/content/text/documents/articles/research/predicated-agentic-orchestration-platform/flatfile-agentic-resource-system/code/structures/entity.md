An element $e \in E$ of the entity set $E$ fixed by the [predication-fibration](predication-fibration.md) $(\mathbf{FOUR}, \mathcal{C}, E)$.
Every `.md` file in a FARS substrate is an entity.
No further internal structure is required of an entity beyond membership in $E$.

Entities appear as the first coordinate (subject $e_1$) and third coordinate (object $e_2$) of [predication-cells](predication-cell.md).
A [transformer](transformer.md) is also an entity — transformers inhabit $E$ as a subset.
A predication-cell, when reified as a file, is also an entity.

The entity set $E$ carries no required ordering or topology.
It is a plain set whose elements are individuated by their substrate paths.
