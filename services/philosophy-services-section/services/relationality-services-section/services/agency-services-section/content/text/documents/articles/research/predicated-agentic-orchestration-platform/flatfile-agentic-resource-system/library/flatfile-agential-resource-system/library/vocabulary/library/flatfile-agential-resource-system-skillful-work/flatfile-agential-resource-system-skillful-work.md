# Flatfile Agential Resource System Skillful Work

## What this is

**Flatfile Agential Resource System Skillful work** is [Work](work.md) for which a documented, repeatable method exists — a [Skill](skills.md) file.

Not all Work is skillful.
Ad-hoc work happens when no documented method exists yet.
FlatfileAgentialResourceSystemSkillfulWork is the subset of Work that has been formalized: the method is written down, the output type is named, and the same work can be done reliably again.

## The four positions

The algebra of all Work units carries two commuting nuclei: σ (meaning-closure) and Δ (execution-closure).
The [nuclear quartet theorem](../../../../../../../library/relational-hyperverse-repository/math/nuclear-quartet-theorem.md) proves that two commuting nuclei on an algebra produce exactly four canonical sub-algebras.
Applied to FlatfileAgentialResourceSystemSkillfulWork:

| Position | σ | Δ | Character |
|------|---|---|-----------|
| [Process](process.md) | stable | stable | Fully determined; same input → same output |
| [Procedure](../../../../../../../../../../../../../../../../../../social-science-services-section/services/sociology-science-services-section/services/work-science-services-section/content/text/glossary/terms/procedure.md) | stable | open | Meaning settled; execution branches on conditions |
| [Derivation](derivation.md) | open | stable | Rules fixed; produces a judgment |
| [Inquiry](inquiry.md) | open | open | Both open; explores unknown territory |

Every FlatfileAgentialResourceSystemSkillfulWork unit occupies exactly one position.
There is no fifth position — the nuclear quartet is exhaustive.

## Relationship to other concepts

- [Work](work.md) — FlatfileAgentialResourceSystemSkillfulWork extends Work: it is Work that additionally carries a documented method.
- [Operation](operation.md) — Operation names the abstract transformation; Work names its invocation; FlatfileAgentialResourceSystemSkillfulWork is an invocation with a documented method.
- [Skill](skills.md) — a Skill IS a documented method for one unit of FlatfileAgentialResourceSystemSkillfulWork.
- [FlatfileAgentialResourceSystemClosureKind](../flatfile-agential-resource-system-closure-kind/flatfile-agential-resource-system-closure-kind.md) — the relation that declares which nuclear quartet position a given Skill occupies.
