# Including Recognition

*Story.*  An explicit inclusion recognition clarifies when one recognition is contained in another.  OrderRecognition witnessing MeetRecognition produces IncludeRecognition.


IncludeRecognition = (OrderRecognition MeetRecognition)


*Proof Sketch.*  This composition packages the order with meets to state inclusion, so IncludeRecognition is valid.
