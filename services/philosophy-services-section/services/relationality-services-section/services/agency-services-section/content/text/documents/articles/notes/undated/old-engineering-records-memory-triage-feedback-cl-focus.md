The captain's focus is continuous learning integrated into workflow operations so the first officer can orchestrate more autonomously over time. Workflows become more deterministic through settlement — and cheaper is a consequence, not the goal.

**Why:** The settlement path (observation → instinct → skill → tool → hook) makes each step more deterministic. When orchestration is deterministic, the first officer can dispatch without judgment calls. That's autonomous operation — not because inference is removed, but because the work itself has settled.

**How to apply:** When evaluating harness improvements, ask "does this make orchestration more autonomous?" not just "does this save tokens?" The progressive automation path (agents becoming tools) is one mechanism. The CL pipeline (failures → instincts → duty updates) is another. Both serve the same goal: workflows that settle into determinism through use.
