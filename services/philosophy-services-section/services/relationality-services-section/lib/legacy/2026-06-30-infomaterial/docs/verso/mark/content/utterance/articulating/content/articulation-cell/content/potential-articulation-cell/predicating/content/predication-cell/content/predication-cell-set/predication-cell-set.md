# Predication cell set

The Cartesian product, denoted $\Phi$, of an [entity set](entity-set.md), a [predicate set](predicate-set.md), and the entity set: $$\Phi := E \times \Pi \times E.$$

The elements of the predication cell set are [predication cells](../concepts/predication-cell.md) at which [predication valuations](predication-valuation.md) assign values.
