# Causal-set substitution settling

A **causal-set substitution settling** is the direct-limit settling produced by a causal-set substitution rule — a rule that grows a causal set by adding new events with prescribed causal links to existing events. It is the causal-set analog of the [step-$n$ substitution settling](step-n-substitution-rule.md): as letter-substitutions grow symbolic sequences, causal-set substitutions grow discrete spacetimes.

This object lifts the corpus's [Anderson–Putnam direct-limit construction](anderson-putnam-direct-limit.md) from tiling sequences to causal sets, combining it with the [Lorentzian causal settling](lorentzian-causal-settling.md) object.

## Definition

### Causal-set substitution rule

Fix a finite set of **event types** $A = \{a_1, \ldots, a_n\}$ and a **causal-set substitution rule** $\mathcal{S}$: a map assigning to each event type $a_i$ a finite labeled causal set $\mathcal{S}(a_i) = (E_i, \prec_i, \ell_i)$ where:
- $E_i$ is a finite set of new events (each labeled by a type in $A$),
- $\prec_i \subseteq E_i \times E_i$ is a partial order of seed causal links among the new events,
- and $\ell_i : E_i \to A$ assigns a type to each new event.

The rule $\mathcal{S}$ also specifies **interface links**: causal connections from the original $a_i$-typed event to specific events in $\mathcal{S}(a_i)$, and from events in $\mathcal{S}(a_i)$ to whatever events are causally downstream of the original.

### The substitution tower

Starting from a seed causal set $(E_0, \prec_0)$ with events typed by $A$, apply $\mathcal{S}$ to obtain $(E_1, \prec_1)$ by replacing each $a_i$-typed event with $\mathcal{S}(a_i)$, inheriting all causal links via the interface specification. Repeating produces a tower:
$$(E_0, \prec_0) \hookrightarrow (E_1, \prec_1) \hookrightarrow (E_2, \prec_2) \hookrightarrow \cdots$$

Each inclusion is an order-embedding: causal links in $(E_k, \prec_k)$ restrict to causal links in $(E_{k-1}, \prec_{k-1})$ on the embedded events.

### The limit settling

The **causal-set substitution settling** $v^\mathrm{CS}_\mathcal{S}$ is the settling on the countable union $E_\infty = \bigcup_{k \geq 0} E_k$ whose closure operator is causal transitivity (as in the [Lorentzian causal settling](lorentzian-causal-settling.md)):
$$T_{\mathrm{caus}}(v)(e_1, e_3) := v(e_1, e_3) \vee \bigl(\exists e_2 .\; v(e_1, e_2) \wedge v(e_2, e_3)\bigr),$$
with initial seed $\prec_0^\infty := \bigcup_k \prec_k$ (all seed causal links across all substitution stages).

The fixed point $v^\mathrm{CS}_{\mathcal{S},\kappa}$ is the full causal order on $E_\infty$ generated by the substitution tower's seed links.

## Substitution matrix

Define the **substitution matrix** $M \in \mathrm{Mat}_{n \times n}(\mathbb{N})$ by:
$$M_{ij} = \text{number of $a_j$-typed events in $\mathcal{S}(a_i)$}.$$

This is exactly the substitution matrix of the corresponding symbolic substitution rule on the alphabet $A$, viewing the causal set as a labeled sequence.

The **Perron eigenvalue** $\lambda_\mathrm{PF}(M) > 0$ (the largest real eigenvalue of $M$, existing by Perron–Frobenius for primitive $M$) gives the **event-count growth rate**:
$$|E_k| \;\sim\; C \cdot \lambda_\mathrm{PF}^k \qquad \text{as } k \to \infty.$$

Physically: $\lambda_\mathrm{PF}$ is the **spacetime volume growth rate** of the substitution causal set. For a spatially-flat expanding universe analog, $\lambda_\mathrm{PF} > 1$ corresponds to expansion; $\lambda_\mathrm{PF} = 1$ to a flat (non-expanding) causal-set universe.

## Regime classification

For a primitive causal-set substitution (i.e., $M$ primitive: some power $M^k$ has all entries $> 0$):

**Event-count growth.** $|E_k| \to \infty$ as $k \to \infty$, so $E_\infty$ is countably infinite.

**Closure ordinal.** The causal transitivity closure on the countably-infinite $E_\infty$ requires $\omega$-many stages for each finite-level approximation, and the full limit requires an $\omega \cdot \omega = \omega^2$ or higher ordinal for the transitive closure across all substitution levels. The settling $v^\mathrm{CS}_\mathcal{S}$ is in the **Scott-continuous or transfinite-bounded regime** depending on the causal-link structure of the substitution rule:

- If every causal path in $E_\infty$ has finite length (the typical case for local substitution rules): **Scott-continuous regime** ($\kappa = \omega$), because each causal connection is established after finitely many substitution steps.
- If the substitution rule creates causal paths whose lengths grow without bound across substitution levels (e.g., "temporal spine" substitutions): **transfinite-bounded regime** ($\omega < \kappa < \omega_1$), because establishing the transitivity across all levels requires a transfinite closure.

## Apex and void cones

The apex/void structure of $v^\mathrm{CS}_\mathcal{S}$ is:

- **Apex** $\mathrm{Apex}_{v^\mathrm{CS}}$: pairs $(e_1, e_2) \in E_\infty \times E_\infty$ with $e_1 \preceq_\infty e_2$ — causally connected pairs in the limit causal order.
- **Void** $V_\infty$: pairs $(e_1, e_2)$ with $e_1 \not\preceq_\infty e_2$ and $e_2 \not\preceq_\infty e_1$ — permanently spacelike-separated pairs.

By the [Lorentzian apex/void as timelike/spacelike theorem](../theorems/lorentzian-apex-void-as-timelike-spacelike.md), the apex = timelike/null pairs and void = spacelike pairs. The substitution structure gives the causal-set's spacetime a self-similar geometry: the causal order at scale $k+1$ contains scaled copies of the order at scale $k$, with the growth rate $\lambda_\mathrm{PF}$ controlling the scaling.

## Example: the "diamond-substitution" causal set

The simplest non-trivial causal-set substitution: one event type $A = \{a\}$, substitution rule $\mathcal{S}(a) = \{a_1, a_2, a_3, a_4\}$ with $a_1 \prec a_2, a_1 \prec a_3, a_2 \prec a_4, a_3 \prec a_4$ (a diamond pattern), and interface: the original $a$'s causal predecessors link to $a_1$, and $a_4$ links to $a$'s causal successors.

Substitution matrix: $M = (4)$ (a $1 \times 1$ matrix), $\lambda_\mathrm{PF} = 4$.

After one step: 4 events, 5 causal links (the diamond). After two steps: 16 events. After $k$ steps: $4^k$ events. The limiting causal set $E_\infty$ has countably many events with a self-similar diamond-nested causal structure.

The apex/void structure: every pair $(e_1, e_2)$ where $e_1$ is in the causal past of $e_2$ (going "forward" in the diamond hierarchy) is in the apex. Pairs at the same "level" of the diamond hierarchy but in different branches are spacelike-separated (void). The ratio of timelike pairs to spacelike pairs encodes the "dimensionality" of the substitution causal set via the [void-apex-as-dimension-estimator question](questions/void-apex-as-dimension-estimator.md).

## Connection to existing structure

**Relation to step-$n$ substitution settling.** The causal-set substitution settling is to the Lorentzian causal settling what the [step-$n$ substitution settling](step-n-substitution-rule.md) is to a general predication settling: a self-similar, substitution-generated special case within the general framework. The symbolic letter = event type; the substitution word = new events in $\mathcal{S}(a_i)$; the causal links within $\mathcal{S}(a_i)$ provide the spatial structure absent in the purely symbolic case.

**Relation to Anderson–Putnam.** The substitution tower $(E_k, \prec_k)$ gives a directed system of Lorentzian causal settlings, with the colimit $v^\mathrm{CS}_\mathcal{S}$ computed as the direct limit. The Anderson–Putnam framework applies: the cohomology of $v^\mathrm{CS}_\mathcal{S}$ is the direct limit of the cohomologies of the finite-level settlings — see the [causal-set substitution cohomology theorem](../theorems/causal-set-substitution-cohomology.md).

**Relation to causal-set physics.** The object models Sorkin-style causal-set growth with a substitution structure: events spawn new events according to a fixed local rule, producing a self-similar discrete spacetime. The Perron eigenvalue $\lambda_\mathrm{PF}$ plays the role of the "expansion factor" in models of discrete cosmology. The substitution structure provides a computationally tractable subclass of general causal-set dynamics where the cohomological invariants are explicitly computable.

## Position in predication categories

First object combining the corpus's substitution-dynamics infrastructure (from the step-$n$ and Anderson-Putnam cluster) with the Lorentzian-causal settling. Opens the [causal-set substitution cohomology theorem](../theorems/causal-set-substitution-cohomology.md) as an immediate downstream.

**Open downstream:**
- *Non-primitive substitutions* (reducible $M$): regime and cohomology classification for reducible causal-set substitutions. The Perron–Frobenius structure generalizes but requires more care.
- *2+1 and 3+1 dimensional causal-set substitutions*: extending from 1-dimensional substitution rules (sequences of events) to 2- and 3-dimensional rules (where the "spatial" structure within each $\mathcal{S}(a_i)$ has its own geometry). The regime and cohomology in these cases are open.
- *Causal-set action*: the discrete analog of the Einstein–Hilbert action on a causal-set substitution settling, using the void-cone cohomological invariants (see the [Lorentzian apex/void theorem](../theorems/lorentzian-apex-void-as-timelike-spacelike.md) for the Myrheim–Meyer dimension connection).
