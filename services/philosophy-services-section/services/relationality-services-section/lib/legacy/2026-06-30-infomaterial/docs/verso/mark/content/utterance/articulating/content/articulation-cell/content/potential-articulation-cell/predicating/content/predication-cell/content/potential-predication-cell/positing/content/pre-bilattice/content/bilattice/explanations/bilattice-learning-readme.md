# @561-group/math/bilattice — learning docs (Diátaxis)

Documentation for `@561-group/math/bilattice`, organized by the [Diátaxis](https://diataxis.fr) four quadrants.
Every doc here explains the **math and the software side by side**: the mathematical object (the
bilattice, the orders, the cones, the cohomology) and the morphism that realizes it (a named export in `src/`),
in the same breath.

| quadrant | orientation | for | here |
|---|---|---|---|
| **[tutorials](tutorials/)** | learning | a newcomer doing | guided runs of the descent, building understanding by doing |
| **[guides](guides/)** | task | a practitioner with a goal | how to do a specific thing (assert evidence, read the void, extend the carrier) |
| **[references](references/)** | information | someone looking it up | precise spec of each morphism, the charge, the four states, the laws |
| **[explanations](explanations/)** | understanding | someone wanting *why* | the bilattice, measured-not-seeded, the two cones, evidence, the σ-duality, the Chu adjunction |

The two axes Diátaxis splits on:

```
            PRACTICAL  ──────────────  THEORETICAL
   acquire   tutorials  │  explanations
            ───────────┼────────────
   apply     guides     │  references
```

Start with a **tutorial** to get the descent running, reach for a **guide** for a specific task,
look up exact behavior in **reference**, and read **explanation** for the why behind it.
