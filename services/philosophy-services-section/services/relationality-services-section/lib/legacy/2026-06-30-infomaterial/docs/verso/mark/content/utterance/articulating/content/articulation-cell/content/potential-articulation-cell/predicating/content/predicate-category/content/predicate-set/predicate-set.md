# Predicate set

The object set, denoted $\Pi$, of a [predicate category](predicate-category.md) $\mathcal{C}$: $$\Pi := \mathrm{Ob}(\mathcal{C}).$$

The elements of the predicate set are [predicates](../concepts/predicate.md).
