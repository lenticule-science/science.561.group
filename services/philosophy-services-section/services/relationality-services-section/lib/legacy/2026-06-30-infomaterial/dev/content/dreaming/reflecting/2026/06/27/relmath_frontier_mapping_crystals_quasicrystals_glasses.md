# Relational-Math frontier mapping: crystals, quasicrystals, glasses

## 0. Purpose and scope

This document maps the three attached frontier memos on **quasicrystals**, **crystals**, and **glasses** against the current `emsenn/relational-math` Lean repository.
The goal is not to re-survey those fields.
The goal is to identify the mathematical definitions and theorems from those papers and research directions that connect to the repository’s present formal program, and to sort them into three operational classes for a proofing agent:

1. **Realized within the territory**: the repo already has Lean definitions and theorems representing the relevant mathematical shape.
2. **On the horizon**: the repo has the right interface, projection, or finite model, and a proofing agent can pursue a plausible formalization without adding a whole new analytic foundation.
3. **Not yet visible from the program**: the external mathematics is real and relevant, but the present repository lacks the required primitives.

The attached quasicrystal memo emphasizes Delone/FLC sets, tiling hulls, model sets, pure point diffraction, substitution tilings, Anderson--Putnam cohomology, gap labeling, sofic/substitution structure, aperiodic monotiles, Fourier quasicrystals, and inverse/design frontiers.
The attached crystal memo emphasizes decorated lattices, space groups, reciprocal lattices, diffraction, Bloch/Floquet theory, phonons, elasticity, defects, topological crystalline phases, DFT, databases, and generative crystal models.
The attached glass memo emphasizes configuration spaces, spin glasses, structural glasses, overlaps, RFOT/MCT, jamming, dynamic heterogeneity, persistent homology, Lyapunov/free-energy ideas, and machine-learning structure--dynamics relations.

The current repository is not a physics library.
It is a dependency-free Lean 4 library built around the chain

```text
Mark → Utterance → Articulating → Predicating → Positing/FOUR
→ Settling/Closure → Sheaf/Cohomology → Aperiodic/Lorentzian/Flow
```

That makes its present “territory” finite, combinatorial, order-theoretic, sheaf-theoretic, and cohomological.
Its strong suit is not yet Euclidean geometry or Fourier analysis.
Its strong suit is the formalization of local-to-global obstruction, fixed-point closure, four-valued valuation, factor maps, finite local constraints, substitution projections, and cohomological classification.

# 1. Executive map

## 1.1 The repo’s actual mathematical center

The current `RelMath` program has several already-formalized cores that are directly relevant to the attached research directions.

### FOUR / bilattice / value carrier

The repo identifies the four articulation phases, the four bilattice charges, the four Boolean status pairs, and the four predicate generators as one recurring four-element object.
In Lean, `Charge := Corner`, and the four points are:

```lean
kBot : Charge  -- no evidence, potential
tTop : Charge  -- evidence-for, active
tBot : Charge  -- evidence-against, stable
kTop : Charge  -- evidence both ways, absurd
```

The repository proves the knowledge and truth operations, the two orders `≤ₖ` and `≤ₜ`, distributive laws, negation, conflation, and the Klein-four symmetry generated by negation and conflation.

**Field connection:** This is already a finite palette, a four-state local value algebra, and a bilattice of evidence.
It is directly useful for graph coloring, local tile labels, finite local rules, defect labels, local section values, and “amorphous order” markers.

### Predication cells and valuations

A predication cell is an oriented triple:

```lean
PredicationCell := (subject, predicate, object)
Valuation := PredicationCell → Charge
```

This is the basic finite site over which settling, sections, gluing, cohomology, and closure operate.

**Field connection:** This is not yet a Delone set, atomic lattice, or particle configuration.
But it is already a local cell language for “relations with values,” which is exactly the shape needed for finite local rules, adjacency constraints, colored graphs, contact graphs, causal relations, and local-to-global obstruction.

### Settling and closure

Settling is formalized as a closure/fixed-point process over the knowledge order.
The repo proves:

- `≤ₖ` is a partial order.
- `∨ₖ` and `∧ₖ` are lub/glb.
- a closure operator is inflationary, monotone, idempotent.
- the settled value is a fixed point and least fixed point above a seed.
- on the finite FOUR lattice, every inflationary endomap settles by step `3`.

**Field connection:** This is a finite Tarski/Knaster--Tarski closure theory.
It is already relevant to cellular automata-like local closure, finite constraint saturation, Datalog-like transitive closure, CRDT convergence, finite causal closure, and Lyapunov descent.
It is only a projection of physical relaxation, Gibbs equilibrium, or glassy dynamics.

### Sheaf and H¹ obstruction

The repo packages the settled valuation as a sheaf-like global section.
It models:

- `H⁰` as a count of designated/truth-firing cells.
- `H¹` as a gluing obstruction.
- `H¹ = 0` as order-independent local merge / CRDT-CALM convergence.
- finite strict/Scott regimes as cohomologically flat.
- a classifying invariant `cl-inv ∈ H¹`.

**Field connection:** This is the strongest bridge to tiling cohomology, Anderson--Putnam complexes, gap-labeling heuristics, defect cohomology, and persistent/topological summaries of amorphous systems.
The repo does not yet have full Čech cohomology of compact tiling hulls, C*-algebraic K-theory, or Bloch bundles.

### Aperiodic machinery

The repo already has files for:

- Jeandel--Rao finite H¹ witnesses.
- Anderson--Putnam-style direct systems.
- step-`n` substitution recurrence.
- Fibonacci and Padovan substitution matrices.
- Cayley--Hamilton identities for those matrices.
- sofic shifts as factor images of finite-type shifts.
- graph coloring as factor maps.
- substitution universality via shift equivalence.

**Field connection:** This is clearly the closest match to the quasicrystal memo.
The repo has real tiling-symbolic-cohomological territory.
It does not yet have Delone geometry, diffraction, Meyer/model-set theory, cut-and-project windows, or tiling hull C*-algebras.

### Flow / Laplacian / free-energy projection

The repo also has:

- Lawvere Laplacian as a modal round-trip closure.
- harmonic states as closure fixed points / quiescent states.
- diffusion as monotone Tarski ascent to the harmonic kernel.
- a finite spectral-gap bound in the strict regime.
- free-energy deficit as a `Nat`-valued Lyapunov function.
- closure-flow curvature-regime correspondence, with H¹ as curvature module.

**Field connection:** This creates a serious formal bridge to graph/sheaf Laplacians, relaxation, H-theorem language, jamming contact closures, and glassy landscape metaphors.
But it is not yet analytic spectral theory, thermodynamic free energy, phonon spectra, or Parisi/RFOT.

Example: “finite autocorrelation / homometry projection of diffraction” is on the horizon.

Example: “regular model sets have pure point diffraction” is not yet visible.
It requires locally compact Abelian groups, Haar measure, Fourier transform of measures, autocorrelation limits, and model-set windows.

## 3.2 Graph coloring as factor map

### External definitions and theorems

The quasicrystal memo’s aperiodic coloring frontier depends on the idea that coloring constraints are finite local constraints and often factor through finite symbolic objects.
In symbolic dynamics, a factor map between shifts forgets or relabels local data.
In graph theory, a proper coloring is a homomorphism to a complete graph on the color palette.

### Repo realization

The repository directly realizes this.
It defines:

```lean
def ProperColoring {V C : Type} (G : Graph V) (c : V → C) : Prop
def Colorable {V : Type} (G : Graph V) (C : Type) : Prop
def completeGraph (C : Type) [DecidableEq C] : Graph C
def GraphHom {V W : Type} (G : Graph V) (H : Graph W) (f : V → W) : Prop
```

and proves:

```lean
theorem properColoring_iff_hom :
  ProperColoring G c ↔ GraphHom G (completeGraph C) c
```

It also proves that colorings pull back along graph homomorphisms:

```lean
theorem ProperColoring.comp :
  GraphHom G H f → ProperColoring H d → ProperColoring G (d ∘ f)
```

The four-color case is formalized as:

```lean
def fourColouring {V : Type} (G : Graph V) : Prop := Colorable G Charge
theorem fourColouring_iff_hom :
  ProperColoring G c ↔ GraphHom G (completeGraph Charge) c
```

### Why this matters mathematically

This is a genuine realized bridge between:

- graph coloring,
- finite symbolic factors,
- local constraints,
- decorated tiling covers,
- and the repo’s FOUR value algebra.

In field terms, this is already a formal “coloring = factor map to a finite shift” theorem in the repo’s finite graph language.

### Proof-agent opportunities already inside the territory

A proofing agent can extend this into a reusable finite local rule framework:

```lean
structure LocalConstraint (A : Type) where
  allowed : A → A → Bool

abbrev SFT := LocalConstraint
```

Then prove that a graph coloring is an SFT factor into `completeGraph C`.

Suggested theorem targets:

```lean

```

```lean

```


## 3.5 Sofic shifts and finite-type constraints

### External definitions and theorems

The quasicrystal memo emphasizes that substitution tilings/subshifts often have sofic or finite-type covers: a decorated finite-type system can project to an undecorated aperiodic/substitution system.
This is the symbolic-dynamics language of local rules, matching rules, and finite local complexity.

Definitions:

- A **shift of finite type** is defined by finitely many forbidden local patterns.
- A **sofic shift** is a factor image of an SFT.
- A **1-block factor map** relabels each symbol locally.

### Repo realization

The repo defines:

```lean
def Path {A : Type} (step : Graph A) : List A → Prop
def SoficImage {A B : Type} (step : Graph A) (π : A → B) (w : List B) : Prop
```

and proves:

```lean
theorem sft_is_sofic :
  Path step p → SoficImage step id p
```

```lean
theorem sofic_of_decorated :
  Path dstep p → SoficImage dstep forgetDecoration (p.map forgetDecoration)
```

```lean
theorem SoficImage.factor :
  SoficImage step π w → SoficImage step (ρ ∘ π) (w.map ρ)
```

The repo also gives the golden-mean/Fibonacci case:

```lean
def goldenStep : Graph Bool := fun a b => !(a && b)
theorem golden_forbids_bb
def fibSub : Bool → List Bool
theorem fib_substitute_golden
```

and a general substitution-preserves-path theorem under follower compatibility.

### Why this matters mathematically

This is a genuine symbolic aperiodic-order object already formalized.
It does not prove Goodman--Strauss recognizability or exact decorated SFT covers for arbitrary substitution tilings, but it establishes the right factor-map language.
