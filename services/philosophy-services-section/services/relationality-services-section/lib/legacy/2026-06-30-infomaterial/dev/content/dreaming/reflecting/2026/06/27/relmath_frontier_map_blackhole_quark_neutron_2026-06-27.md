## 0. Scope and reading rule

This memo studies `emsenn/relational-math` as a proof territory and compares it against three attached research directions:

1. **Black-hole mathematics**: Lorentzian geometry, horizons, causal structure, singularities, stability, thermodynamics, holography, and quantum information.
2. **Quark mathematics**: nonabelian gauge matter, QCD, confinement, dense quark matter, color superconductivity, anomalies, and finite-density computation.
3. **Neutron mathematics**: dense fermionic/nuclear constraint matter, equations of state, TOV structure, nuclear pasta topology, superfluid defects, and multimessenger inverse inference.

The repository is not a physics library in the usual sense.
It is a dependency-free Lean 4 derivation spine in which the rule is: **after `Mark` and `Articulating`, no free mathematical data are introduced**.
The repository itself describes the import spine as a proof: each module is generated by what precedes it.
The core program currently derives articulation cells, a predication category, the FOUR bilattice, closure/fixed-point settling, hyperdoctrine-style quantifiers, truth/knowledge orders, sheaf/cohomology projections, aperiodic regimes, Lorentzian causal-set projections, causal d'Alembertians, discrete Einstein-Hilbert action, Lambek curvature, flow/free-energy dynamics, and optimization-as-settling.

This means the classification below is intentionally **not** “which physical theories are already solved.” Instead it asks:

> Which mathematical objects from the attached research directions already have a finite relational / closure / cohomological / causal-set incarnation in the repository, which objects are close enough to pursue as Lean proof targets, and which objects require mathematical foundations that the repository simply does not yet contain?

The most important conclusion is:

* The **black-hole direction is strongly in-territory** at the causal-set / discrete Lorentzian / incidence-algebra / boundary-curvature / cohomology-projection level.
* The **quark direction is mostly horizon**: the repository has bilattice gauge-like structure, cohomology, charged causal microsupport, and internal `ℤ/2` gauge, but it does **not** yet have nonabelian gauge bundles, Wilson loops, `SU(3)`, spinors, QCD actions, confinement, or mass-gap infrastructure.
* The **neutron direction is mostly horizon-to-not-visible**: the repository has fixed-point/optimization/free-energy/topological/flow machinery that can model EOS-like equilibrium, pasta-like finite morphology, and defect cohomology, but it does **not** yet have fermionic Hilbert spaces, antisymmetric many-body theory, nuclear interactions, TOV differential equations, or realistic multimessenger inference.

## 4. Black-hole mathematics already in the territory

### 4.1 Causal order as settling

**External definition/theorem.** In mathematical relativity, causal structure is built from causal precedence: event `p` can causally influence event `q` if there is a future-directed causal curve from `p` to `q`.
In the black-hole memo, this underlies `J^\pm`, event horizons, causal boundaries, Penrose diagrams, and cosmic censorship.

**RelMath realization.**

The module `RelMath.
Lorentzian.
Causal` defines a finite causal set as:

```lean
structure CausalSet (E : Type) where
  events : List E
  prec0 : Graph E
  acyclic : Graph.StrictOrderClosure prec0
```

The seed relation `prec0` is a finite direct-causal-link relation.
The closure step is:

```lean
def causalStep (es : List E) (v : E → E → Bool) : E → E → Bool :=
  fun e₁ e₃ => v e₁ e₃ || es.any (fun e₂ => v e₁ e₂ && v e₂ e₃)
```

The theorem `causal_settling_is_transitive_closure` proves that causal settling is exactly the transitive closure of the seed relation.
It packages:

* seed links are reachable;
* reachability is transitive;
* any transitive fixed relation is `causalStep`-fixed;
* reachable pairs lie in a strict order;
* reachability is irreflexive and asymmetric.

**Status:** **Territory.**

**Proof-agent note.** This is the main substrate for every finite horizon, causal boundary, topological-censorship, and causal propagation target.
Do not start black-hole work by re-deriving reachability; build on `CausalSet`, `C.reaches`, `ConeField.
CausalLe`, and `CausalAlexandrov.causalTopology`.

### 4.2 Light cones, spacelike separation, and causal diamonds

**External definition/theorem.** Black-hole mathematics depends on future and past cones, spacelike separation, causal diamonds, and causal domains of dependence.

**RelMath realization.**

`RelMath.
Lorentzian.
ConeField` defines:

```lean
def Future (e : E) : E → Prop := fun x => C.reaches e x
def Past (e : E) : E → Prop := fun x => C.reaches x e
def CausalLe (x y : E) : Prop := x = y ∨ C.reaches x y
def ClosedFuture (e : E) : E → Prop := fun x => CausalLe C e x
def ClosedPast (e : E) : E → Prop := fun x => CausalLe C x e
def Spacelike (x y : E) : Prop := ¬ C.reaches x y ∧ ¬ C.reaches y x
def Diamond (a b : E) : E → Prop := fun x => C.reaches a x ∧ C.reaches x b
def ClosedDiamond (a b : E) : E → Prop := fun x => CausalLe C a x ∧ CausalLe C x b
```

It proves:

* `CausalLe` is reflexive, transitive, antisymmetric;
* future cones are upward-closed;
* past cones are downward-closed;
* spacelike separation is symmetric;
* diamonds contain endpoints when the lower apex reaches the upper apex;
* bundled theorem `causal_reachability_is_cone_geometry`.

**Status:** **Territory.**

**Proof-agent note.** This is the exact place to define horizon projections, no-escape regions, trapped future-closed regions, and finite causal boundary operators.
