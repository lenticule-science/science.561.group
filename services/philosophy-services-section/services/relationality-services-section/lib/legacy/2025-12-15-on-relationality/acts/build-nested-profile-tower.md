# Nested Profile Tower

## Interpretation

Nested profiles also inherit the full relational chain.  *Build Profile Tower* witnessing *Nest Profile* yields ***Build Nested Profile Tower*** ([BuildNestedProfileTower](build-nested-profile-tower.md)).

This act records the recursive tower property promised for nested filters, so *Build Nested Profile Tower* is valid.
