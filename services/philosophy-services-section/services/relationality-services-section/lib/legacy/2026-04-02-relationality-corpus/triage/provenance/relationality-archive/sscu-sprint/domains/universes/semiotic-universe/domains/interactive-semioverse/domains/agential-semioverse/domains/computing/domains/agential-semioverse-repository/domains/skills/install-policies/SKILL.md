Install policies into Claude Code rules.

## Instructions

Run the install script:

```bash
bash install-policies.sh
```

The script reads policy files from
`content/personal/projects/emsemioverse/policies/` (source of truth)
and generates compact rule files in `.claude/rules/policies/`
(build artifact). Each rule file contains the policy's description
and operational implications, plus a source pointer.

### When to run

- After creating or modifying a policy
- After initializing a new session (as part of setup)
- After pulling changes that may include policy updates

### Architecture

Policy files (in `content/`) are the authoritative source. They
contain full rationale, connections to theory, and operational
implications. Rule files (in `.claude/rules/`) are build artifacts
generated by the script — compact, actionable, automatically loaded
by Claude Code at session start. Do not edit rule files directly.
