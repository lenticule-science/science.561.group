## Source

E. F. Codd. "A Relational Model of Data for Large Shared Data Banks." *Communications of the ACM*, 13(6):377–387, June 1970. https://doi.org/10.1145/362384.362685

## Form

Foundational journal article. The paper that introduced the relational model and launched the entire relational-database tradition.

## Content summary

Proposes a model of data based on relations (subsets of the Cartesian product of attribute domains) as the user-facing abstraction, with the goal of insulating applications from changes in the underlying storage representation. Introduces the relational data sublanguages: a *relational algebra* (with operations of selection, projection, Cartesian product, set union, set difference, and join) and a *relational calculus* (a tuple-relational and a domain-relational form of first-order logic). Establishes the equivalence of the algebra and the calculus as expressive powers ("relational completeness"). Develops the ideas of *normalization* (decomposition of relations to eliminate redundancy and update anomalies, leading to first / second / third normal forms in this paper, with higher normal forms following in later work). Argues for the database-management-system architecture as a layer that hides physical storage, indexes, and access paths behind a relational interface, so that applications written against the relations remain valid as the physical layer evolves.
