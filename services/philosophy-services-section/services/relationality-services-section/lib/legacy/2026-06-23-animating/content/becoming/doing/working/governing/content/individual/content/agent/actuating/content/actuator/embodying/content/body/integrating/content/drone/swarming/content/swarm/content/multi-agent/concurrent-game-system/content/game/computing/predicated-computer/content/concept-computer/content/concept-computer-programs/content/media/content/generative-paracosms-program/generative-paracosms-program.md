# Generative Paracosms Program

This program represents rich, evolving imaginary worlds—paracosms—as
recognitions and lets them grow generatively inside the relational computer.

## Behaviour

- Define paracosms (premise, themes, boundaries), regions, entities, rules, and
  history events as recognitions with provenance.
- Provide templates/grammars and procgen runbooks to expand regions, introduce
  entities or conflicts, and simulate consequences under stated rules.
- Map intra-paracosm topology (maps, kinship/social graphs, causal links) and
  inter-paracosm links to real-world recognitions or other paracosms.
- Measure visit frequency, recurring motifs, and paracosm “health” (stagnant vs
  generative).

## Intended operators

- Seed new paracosms from prompts, dreams, or themes.
- Expand regions where detail is needed; trace motifs between paracosms and
  other domains.
- Co-simulate paracosms with agents under constraints without overwriting core
  canon.
