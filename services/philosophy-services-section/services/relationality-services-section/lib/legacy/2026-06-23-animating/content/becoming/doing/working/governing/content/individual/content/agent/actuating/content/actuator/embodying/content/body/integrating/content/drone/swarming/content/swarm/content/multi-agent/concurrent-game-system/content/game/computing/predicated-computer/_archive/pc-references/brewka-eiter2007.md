## Content summary

*Pending direct read.* Standard reference for heterogeneous multi-context systems: a network of reasoning contexts, each running in its own (possibly nonmonotonic) logic, exchanging conclusions through *bridge rules* whose firing produces equilibria across the network. The framework is the load-bearing reference for paraconsistent reasoning across federated reasoning systems with different logics. The substrate's [federation-trust-bilattice-graded](../theorems/federation-trust-bilattice-graded.md) and [federation-convergence](../theorems/federation-convergence.md) theorems are positioned against this framework; the substrate's contribution is collapsing the bridge-rule layer into the substrate's value-domain join, so federation between paraconsistent contexts is the same operator as intra-substrate merge rather than a separate equilibrium-finding procedure.
