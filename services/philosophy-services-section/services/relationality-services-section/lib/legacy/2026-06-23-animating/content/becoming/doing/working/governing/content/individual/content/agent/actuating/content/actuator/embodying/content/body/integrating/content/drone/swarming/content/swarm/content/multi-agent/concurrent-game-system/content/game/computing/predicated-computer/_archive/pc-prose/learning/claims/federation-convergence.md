# Federated substrates converge under bidirectional event exchange

**Claim.** Let $S_1$ and $S_2$ be two predication substrates sharing the same closure-rule system $\mathcal{S}$, the same value-domain $\mathbf{L}^\bowtie$, the same [predicate category](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predicate-category.md) $\mathcal{C}$, and the same [entity set](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/entity-set.md) $E$ within the federated scope. Suppose $S_1$ and $S_2$ exchange their reified-message event streams in any order, applying received events through their normal admission discipline. After all messages have been exchanged in both directions and both substrates have re-settled, the converged state at each substrate equals

$$v^\infty(p) \;=\; \mathrm{cl}_p\!\left(\bigvee_k U\right)$$

cellwise in every fiber $A_p$, where $U$ is the union of all writes issued anywhere in the system, $\bigvee_k$ is the cellwise [knowledge-order](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/knowledge-order.md) join, and $\mathrm{cl}_p$ is the [closure operator](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-operator.md) generated by $\mathcal{S}$ at predicate $p$.

The convergence is *order-independent*: any sequence of message exchanges, any number of round-trips, any pattern of network partitions during exchange produces the same converged state.

## Why this holds

The substrate's [merge](../morphisms/merge.md) is exactly the cellwise $\vee_k$ on each [predication fiber algebra](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-fiber-algebra.md), and the substrate's [settle](../morphisms/settle.md) is the closure operator $\mathrm{cl}_p$ applied fiberwise. The convergence claim is the substrate-level instance of [crdt-convergence](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/theorems/crdt-convergence.md), whose technical heart is the **closure-merge commutation lemma**:

$$\mathrm{cl}_p\!\left(\mathrm{cl}_p(X) \vee_k Y\right) \;=\; \mathrm{cl}_p\!\left(X \vee_k Y\right)$$

for any $X, Y \in A_p$. The lemma follows from the four [closure-operator](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-operator.md) axioms (monotonicity, inflationarity, idempotence, $\mathcal{C}$-naturality) and is verified mechanically in the corpus's Lean development as `applyWrites_perm_invariant`.

By induction on the local settling using the lemma, replica $i$'s state at any local time $\tau$ equals $\mathrm{cl}_p(\bigvee_k U_{i,\tau})$ — the closure of the join of all writes received so far — *regardless of the order* in which writes were received and closures applied. Once every write has been delivered to every substrate (i.e., $U_{i, \tau} = U$ at every replica), each substrate's state is the common limit $\mathrm{cl}_p(\bigvee_k U)$.

The substrate's operational discipline is what makes the math hypotheses hold for real networks:

- **Content-addressed messages preserve $U$ under transport.** Per [reification](teaching/explanations/reification.md) and [hash-discipline](teaching/explanations/hash-discipline.md), every reified message has a canonical-hash identifier and the substrate's admission discipline treats duplicate-identifier messages as no-ops. The set of distinct writes received by each substrate, modulo deduplication, is the same set $U$ regardless of how many times messages traverse the network.
- **Deterministic admission preserves the math hypotheses across hosts.** Per [settlement-determinism](settlement-determinism.md), the same admitted message produces the same settled-state increment at any conformant substrate. This is what lets the math claim "all replicas converge to $\mathrm{cl}_p(\bigvee_k U)$" hold across genuinely independent host machines.

**Byte-identity is downstream.** When the substrate's value-equality is checked via the canonical-form hash of [content-addressed-store](../objects/content-addressed-store.md), two substrates whose fiber values are equal also have byte-identical serialized state. Byte-identity is a property of hash discipline; the convergence claim itself is about *value-equality in the fiber algebra*.

## Regime hypotheses

The convergence claim holds in all four regimes of the [four-regime dichotomy](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/theorems/four-regime-dichotomy.md), but the *cost* and the *federation discipline* differ:

- **[Strict regime](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/theorems/four-regime-dichotomy.md)** (finite $\mathbf{L}, E, \mathcal{C}$). Closure ordinal $\kappa < \omega$. Convergence in finitely many close-and-merge cycles. Federation can ship endpoint state alone.
- **Scott-continuous regime** (infinite base, quantifier-free closure-rule antecedents). Closure ordinal $\kappa = \omega$. Each finite-prefix exchange converges at finite cost; the global limit is the colimit. Federation can still ship endpoint state.
- **Transfinite-bounded regime** ($\omega < \kappa < \omega_1$). Closure operator is non-Scott-continuous; convergence requires countably many transfinite stages. Each [non-Scott-continuous firing ordinal](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/non-scott-continuous-firing-ordinal.md) contributes a $\mathbb{Z}$-generator to $H^1$ of the merged settling. **A federation engine in this regime that ships only endpoint state loses the cohomological invariant** — two substrates that exchange only $v^\infty$ converge to byte-identical state but lose the firing-ordinal pattern that distinguishes MLD-classes.
- **Aperiodic regime** ($\kappa \geq \omega_1$). Same trajectory-irreducibility consequence as transfinite-bounded, at the $\omega_1$-scale.

The substrate's choice of [closure-rule language](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/closure-rule-language.md) fragment determines its regime. Implementations restricted to quantifier-free antecedents stay in the strict or Scott-continuous regime and may federate by shipping endpoint state. Implementations admitting $\forall$-blocks over infinite domains may enter the non-Scott-continuous regimes and **must carry trajectory** — at minimum the increment-sequence and firing-ordinal record — in their federation protocol. The federation discipline is regime-determined, not freely chosen by the implementation.

## Engineering consequence

Federation between substrates does not require a coordination protocol layer. The substrate's algebra *is* the protocol — the closure-merge commutation lemma is structurally what makes the substrate's value-domain join *together with* its closure operator a CRDT. Per [federation-as-substrate-join](teaching/explanations/federation-as-substrate-join.md), the work that a federation protocol would otherwise have to do (ordering, conflict resolution, retry) is absorbed into the substrate's value-domain join and closure operator. The transport protocol is reduced to "send bytes" with no semantic responsibility — modulo the trajectory-shipping requirement in the non-Scott-continuous regimes.

The result generalizes to N substrates: a federation among $S_1, \ldots, S_N$ in which each substrate exchanges events with every other (eventually) converges all $N$ substrates to the same federated state. Eventual consistency under partition is the typical operating mode: substrates separated by a network partition continue to record events independently; on rejoin, the merged event-set is the union of both sides's logs and convergence follows from the same lemma.

## What the theorem rules out

- A substrate whose value-domain is not a [predication fiber algebra](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-fiber-algebra.md) — i.e., whose join is not commutative-associative-idempotent under the four bilattice operations — cannot federate by this discipline. Such substrates require an ordering protocol (last-write-wins, vector clocks, primary-replica precedence) that the substrate-level federation discipline does not provide.
- A substrate whose closure operator fails $\mathcal{C}$-naturality (axiom 4 of [closure-operator](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-operator.md)) cannot federate: closures at different predicates won't agree across reindexing, so two substrates' merged states can disagree at a generator-related cell even with identical writes.
- A substrate whose admission discipline branches on host-runtime conditions — a violation of [settlement-determinism](settlement-determinism.md) — does not produce convergent state under exchange; the same content settles differently depending on host conditions.
- A substrate in the transfinite-bounded or aperiodic regime that ships only endpoint state in its federation protocol loses the $H^1$ cohomological invariant. Two such substrates converge to byte-identical state but lose the firing-ordinal pattern that distinguishes [mutually-locally-derivable](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/mutually-locally-derivable.md) classes. This is regime-incompatible federation: the protocol must ship trajectory.
- A substrate that admits events without verifying their content-hash signatures cannot guarantee that exchanged events represent the same content; signature failures must be detected and rejected at the boundary.

## What the theorem requires

- Both substrates share the closure-rule system $\mathcal{S}$ (and hence the closure operator $\mathrm{cl}$ it generates).
- Both substrates share the value-domain $\mathbf{L}^\bowtie$ (the [predication fiber algebra](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-fiber-algebra.md) construction's parameters).
- Both substrates share the predicate category $\mathcal{C}$ and entity set $E$ within the federated scope.
- The closure operator satisfies the four axioms (monotone in $\leq_k$, inflationary, idempotent, $\mathcal{C}$-natural).
- Reified messages are content-addressed and signed by their senders (per [reification](teaching/explanations/reification.md), [hash-discipline](teaching/explanations/hash-discipline.md)).
- The substrate's admission discipline rejects signature failures and surfaces them as substrate events.
- For substrates in the non-Scott-continuous regimes, the federation protocol ships trajectory (increment sequence + firing-ordinal record), not just endpoint state.
