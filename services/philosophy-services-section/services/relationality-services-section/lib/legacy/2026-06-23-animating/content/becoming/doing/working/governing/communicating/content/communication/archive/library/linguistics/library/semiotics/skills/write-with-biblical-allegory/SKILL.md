# Write With Biblical Allegory

Biblical allegory frames a contemporary situation through a scriptural pattern — exodus, prodigal son, the wilderness, the burning bush — so that the resonance of the original carries part of the meaning. The discipline is to keep the allegory in service of the message rather than the other way around.

## When to use

You are drafting or revising prose where biblical motifs would frame the contemporary situation productively, and the audience can be expected to recognize the references.

## How it works

1. Identify the core message — what the text needs to say without the allegory.
2. Choose a fitting biblical motif. The fit is structural, not decorative: the situation should map naturally onto the pattern, not be forced into it.
3. Write the allegory in service of the message. If the reader misses the reference, the message should still come through.
4. Check against doctrine (see `revise-under-catholic-doctrine`) — biblical allegory creates plenty of room for accidental doctrinal contradiction.

## Rules

- Allegory is subordinate to clarity. If the motif obscures the message, drop the motif.
- A working allegory should resonate, not require explanation.
- Avoid claims that conflict with doctrinal interpretations of the source passage.
