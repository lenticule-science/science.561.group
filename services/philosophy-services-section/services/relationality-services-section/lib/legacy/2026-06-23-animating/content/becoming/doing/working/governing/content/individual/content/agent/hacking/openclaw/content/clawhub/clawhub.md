ClawHub is the public skill registry for OpenClaw.
It provides a discovery and distribution surface for versioned skill bundles.

## Role

The official docs position ClawHub as the normal way to search, install, update, and publish OpenClaw skills.
Its CLI supports search, installation, updates, and sync-based publishing.

## Function

ClawHub turns skills into portable, shareable artifacts rather than only local folders.
It therefore extends OpenClaw's skill system with a public registry layer.
