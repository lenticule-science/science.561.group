External works the curation theory cites. Each reference is one annotated note with frontmatter declaring author, year, title, and class (academic, monograph, standard, engineering-system); the body follows the corpus's `## Source / ## Form / ## Content summary / ## Position in the corpus` shape.

This directory is sparse on purpose: the curation theory's load-bearing literature — knowledge organization (Dahlberg, Hjørland, Ranganathan, Foskett, the BCG/CRG tradition), knowledge representation (RDF, OWL, description logics, Sowa's conceptual graphs, FCA), communication theory and pragmatics (Shannon, Grice, Halliday, Bell, Clark) — is largely cited from the parent [predicated-knowledge-systems/references/](../../../predicated-knowledge-systems/references/), which serves as the shared upstream library across the knowledge-systems family. References here are reserved for works whose load-bearing weight is *specifically* on this theory's curation discipline rather than on the broader predicated-knowledge-system program.
