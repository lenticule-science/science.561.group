# Theory of System

`@561-group/theory-of-system` — systems, endeavors, concurrent games, and social form.

The relations are derived, not imposed: **a concurrent-game player is an agent in a game role**, and **an agent is a kind of system**.
So this theory sits beneath [`theory-of-agency`](../agency/) in the order of generality and feeds the social and game-theoretic readings built on top of it.

This is knowledge, not a runnable product.
The directory tree *is* the type language; prior thought collects at each object's `docs/dev/notes/`.

Tracked as a submodule of the [`emsenn/theories`](../) umbrella.
