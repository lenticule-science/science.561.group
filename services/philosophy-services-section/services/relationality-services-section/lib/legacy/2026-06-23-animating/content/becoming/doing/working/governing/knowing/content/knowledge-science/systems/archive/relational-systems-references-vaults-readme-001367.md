This is the root directory of an Obsidian Vault focused on the development and application of a formal and generative relational system.

## Contents

This vault is organized into the following main categories:

- A system of acts, conditions, and structures, created by derivation and shaped into theorems.
	- Derivations
		- Derived truths based on prior derivations, inducing new potential acts, conditions, and structures, which prove new theorems and corollaries.
	- Acts
		- Acts induce, relate, and/or transform relational structures.
	- Conditions
		- Acts describe the relational potential that results from the act(s).
	- Structures
		- Structures describe the relational structures induced by the constraints of relational conditions.
	- Theorems
		- Proven consequences of derivations, including any corollaries.
- A catalog of the system applied in various domains. Unless the record is under `./applications/[domain]/conceptual/`, it must be grounded firmly in the material present in the relational system.
	- [[Applied Relational Mathematics|Mathematics]]
		- [[Applied Relational Mathematics#Modeling]]
	- Meta
		- Writing about relational epistemics, i.e. [[On Relating]]
## Use
### System Development Flow
The development of the formal system induces a specific set of records in response to each new derivative.

- Every derivation must include a claim, a derivation, and mathematical formalism of the derivation. In doing so, a derivation will establish one or more of the following, each of which must be recorded in its own file.
	- Acts
		- Describe the derivation in terms of the act of relating it enables.
	- Conditions
		- Describe the new relational constraints or potentials the derivation enables.
	- Structure
		- Describe any new relational structures that emerge from the existence of these conditions.
	- Theorems
		- Describe any things that must be true, given the derivation, including any corollaries.
### Application Development
Applications developed with the relational system must derive formally from its system, unless they are placed in the conceptual subdirectory of an application domain, and their `conceptual` property marked as `True`.
### Triaging Ideas
- If you have an insight, question, or hunch:
	- Create a record in `./applications/[domain]/concept/`
- Give it an appropriate type:
	- [[hypothesis]]
	- [[conjecture]]
	- [[interpretation]]
	- [[intuition]]
- If possible, formalize it by deriving it within the relational system.
- Otherwise, make sure to say what you'd need to formalize it.
