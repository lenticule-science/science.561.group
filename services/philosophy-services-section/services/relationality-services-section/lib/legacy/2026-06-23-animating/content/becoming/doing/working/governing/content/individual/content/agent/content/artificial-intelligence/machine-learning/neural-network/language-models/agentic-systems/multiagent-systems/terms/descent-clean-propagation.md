# Descent-Clean Propagation

Descent-clean propagation is the case where propagated witness data glues into one compatible global cell-pattern across a team. In ordinary operational language, the team can incorporate the witness without producing unresolved divergent local views.

In [Witness-network propagation as fibration-comonad descent](/library/social-sciences/economics/work/archive/witness-network-propagation-as-fibration-comonad-descent.md), descent-clean propagation is characterized by cocycle compatibility across overlaps in the communication topology. If the cocycle holds, the propagated witness assembles. If it fails, the failure is a cohomological inconsistency class rather than generic confusion.

The guide [Witness Propagation for Agent Teams](/library/information/computing/artificial-intelligence/multiagent-systems/guides/witness-propagation-for-agent-teams.md) gives the agent-facing reading: ask which local cell-system receives the witness, which channels carry it, and which adjudication mode handles failure.

## Use

Use this term to distinguish successful team-level witness incorporation from mere message delivery. A message can be received everywhere and still fail descent if the local incorporations do not glue.
