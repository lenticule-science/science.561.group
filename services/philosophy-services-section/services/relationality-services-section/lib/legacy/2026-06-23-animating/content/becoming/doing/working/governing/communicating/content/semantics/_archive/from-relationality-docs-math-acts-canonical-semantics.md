# Structuring Canonical Semantics

## Interpretation

The syntactic recognitions inherit a structure mirroring the semantics.  *Structure Semantics* witnessing *Recognize Syntax* yields ***Canonical Semantics*** ([CanonicalSemantics](canonical-semantics.md)).

Composing these recognitions asserts that the syntactic structure satisfies the same algebraic laws, so *Canonical Semantics* follows.
