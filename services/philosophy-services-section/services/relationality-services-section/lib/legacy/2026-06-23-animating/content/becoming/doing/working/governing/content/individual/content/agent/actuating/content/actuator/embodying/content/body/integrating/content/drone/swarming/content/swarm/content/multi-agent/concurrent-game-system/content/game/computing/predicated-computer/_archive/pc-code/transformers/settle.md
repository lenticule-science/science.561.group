# Settle

The composed operator that drives the substrate's [closure-rule applications](closure-rule-application.md) on a region until either *quiescence* (per [settling-quiescence](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/concepts/settling-quiescence.md): no rule's premise matches against an unrecorded conclusion anywhere in the region) or *fuel exhaustion* (the declared [fuel bound](teaching/explanations/fuel-bound.md) is consumed before quiescence). Settle is the substrate-side instance of the [closure 2-monad](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-2-monad.md) $\mathrm{Cl}^{\mathcal{S}}$ applied fiberwise to a region: it iterates the closure operator generated by the active closure-rule system to fixed point. Every operator that needs to bring a region to a settled state invokes settle.

## Signature

`settle(region, rule-system, fuel) → (settled-region, witness)`

Inputs:

- **`region`** — references to a region of the [predication-graph store](../objects/predication-graph-store.md): an entity, a [scope](teaching/explanations/scope.md), a [sublocale](../objects/application-sublocale.md), or a [snapshot](../objects/snapshot.md). The region is canonical-form addressable.
- **`rule-system`** — reference to the active [closure-rule system](../objects/closure-rule-system.md) and the [repair catalog](../objects/repair-catalog.md). Generates the closure operator $\mathrm{cl}^{\mathcal{S}}$ that settle iterates.
- **`fuel`** — the bound on iteration layers per [fuel-bound](teaching/explanations/fuel-bound.md).

Outputs:

- **`settled-region`** — the region with $\mathrm{cl}^{\mathcal{S}}$ applied to fixed-point (or fuel-exhausted state). A settled region is a $\mathrm{Cl}^{\mathcal{S}}$-algebra in the math sense — its [predication valuation](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/objects/predication-valuation.md) satisfies $\mathrm{cl}^{\mathcal{S}}_p(v(p)) = v(p)$ on every fiber.
- **`witness`** — a [witness](../objects/witness.md) recording the settle's input region's hash, the rule-system version, the fuel consumed, every layer's intermediate hash, every repair invoked, the output region's hash.

## Operational semantics

Settle proceeds in *layers*. Each layer is one breadth-first sweep applying every closure rule whose premise matches against the region's current predications. The order of rule applications within a layer is determined by lexicographic canonical hash (per [determinism](teaching/explanations/determinism.md)), not by the substrate's internal data-structure traversal order. Per [closure-driven settling-monotonicity](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/theorems/closure-driven-settling-monotonicity.md), each layer's effect is monotone in $\leq_k$ — values can rise but never fall. Successive layers continue until either:

- No rule's premise matches against an unrecorded conclusion (quiescence — the region is settled).
- The fuel bound is exhausted (the witness records consumed fuel and the last stable hash; the region is returned in its last canonical state).

Per layer, applicable [repairs](teaching/explanations/repair.md) declared in the repair catalog fire when their triggering conditions match. Repair invocations contribute their own witness entries, citing the repair's catalog code.

The number of layers settle takes to reach quiescence is the closure ordinal $\kappa$ of the region's settling — bounded per [regime-classification-for-substrate](../theorems/regime-classification-for-substrate.md): finite for strict-regime substrates, $\omega$ for Scott-continuous, transfinite for the non-Scott-continuous regimes.

## Engineering invariants

- **Deterministic.** Two invocations of settle on the same canonical input region under the same rule-system version and fuel produce byte-identical settled regions and byte-identical witnesses (per [settlement-determinism](../theorems/settlement-determinism.md)).
- **Locality-respecting.** Each closure-rule application reads at the rule's declared match-radius, not the global region. Memory consumed scales with the active wavefront width (per [wavefront-termination](../theorems/wavefront-termination.md)), not with region size.
- **Witness-emitted.** Every settle produces a witness; the witness goes into the [event log](../objects/event-log.md). Settles that fail to produce witnesses violate the substrate's audit contract.
- **Idempotent on settled input.** Per the [closure 2-monad](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-2-monad.md)'s lax-idempotence, a region already at fixed-point is returned unchanged after one layer (which finds no matches); the witness records "no advance," the fuel is unconsumed.
- **Monotone in $\leq_k$.** Per [closure-driven settling-monotonicity](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/theorems/closure-driven-settling-monotonicity.md), settle never decreases a cell's knowledge-order value.

## Failure modes

- **Fuel exhaustion.** When the rule system on this input would require more layers than declared fuel, settle aborts with the witness recording the last stable state. For substrates in the non-Scott-continuous regimes (per [regime-classification-for-substrate](../theorems/regime-classification-for-substrate.md)), fuel exhaustion is expected at limit ordinals; the substrate's [fuel-bound](teaching/explanations/fuel-bound.md) discipline determines what the caller does next (retry with more fuel, escalate, accept the partial settlement).
- **Repair failure.** When an applicable repair has no admissible recipe (e.g., a coherence repair where the conflicting sections cannot be reconciled), the catalog entry's severity determines the outcome: a repairable invariant produces a recorded warning; a hard invariant aborts settle entirely.
- **Closure-rule-system mismatch.** If the cited rule-system version does not match the substrate's current version, settle either (a) runs against the cited version (deterministic replay), or (b) aborts (the cited version is no longer authoritative). The choice is per-implementation; both are admissible.

## Position in the substrate

Settle is the operator that *makes* a predicated computer compute. Per the [closure 2-monad](../../../../../../../humanities/theories/math/theories/categories/theories/predication-categories/morphisms/closure-2-monad.md), settle realizes the math iteration $v_{\tau+1} = \mathrm{cl}^{\mathcal{S}}_p(v_\tau \vee_k u_{\tau+1})$ at the substrate level. The substrate's other composed operators — [merge](merge.md), [project](project.md), application-nucleus projection — invoke settle as a sub-operation when they need a region to be at fixed-point. The substrate's correctness-of-replay (per [settlement-determinism](../theorems/settlement-determinism.md)) rests on settle being deterministic; the substrate's replayability of audit chains is settle's witness chain accumulated in the event log.
