# Job Search and Career Program

This program represents jobs, applications, interviews, and skill gaps as
recognitions to manage career development systematically.

## Behaviour

- Model job opportunities, applications, interviews, and skill gaps as
  recognitions with provenance.
- Link jobs to skills, people/organizations, and projects; track application
  stages and outcomes.
- Measure application counts, response rates, time-in-stage, and offer quality.

## Intended operators

- Track applications and prepare for interviews as auditable runbooks.
- Review offers and align choices with skills, goals, and value recognitions.
- Surface skill gaps and connect to learning/curriculum programs.
