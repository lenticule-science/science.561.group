A scheduled transaction is a template for a recurring transaction that GnuCash can create automatically or with user confirmation.
Users define the accounts, amounts (which can include formulas), recurrence pattern (weekly, monthly, etc.), and whether the transaction should be created automatically or only after review.

Scheduled transactions handle things like rent, subscriptions, and regular transfers.
They can use variables and simple formulas for amounts that change predictably.
