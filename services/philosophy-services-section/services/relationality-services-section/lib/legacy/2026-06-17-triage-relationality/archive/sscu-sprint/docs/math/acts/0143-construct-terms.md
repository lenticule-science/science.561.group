## Interpretation

The syntactic calculus’s term formers arise from the function and application recognitions we already earned.  *Form Function Term* witnessing *Form Application Term* yields ***Construct Terms*** ([ConstructTerms](0143-construct-terms.md)).

These recognitions capture the syntactic constructors; composing them records the syntax of terms, so *Construct Terms* is established.
