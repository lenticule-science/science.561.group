## Interpretation

Typing judgments encode entailment between types under a context, but we require the explicit preorder that records this entailment.  *Judge Typing* witnessing *Imply Recognition* yields ***Order Provability*** ([OrderProvability](order-provability.md)).

Composing the judgment with implication records precisely when a context proves that type A implies type B, so *Order Provability* follows.
