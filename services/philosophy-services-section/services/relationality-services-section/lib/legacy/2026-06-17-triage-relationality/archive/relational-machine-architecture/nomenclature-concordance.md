This document records the canonical terminology adopted by the research
program and maps it to legacy terms still found in older documents.

## Primary Mapping

| Legacy Term | Current Term | Symbol Change |
|---|---|---|
| Hypertensor Topos | **Generative Sheaf Universe** | — |
| topos (ambient sheaf object $R$) | **universe** | — |
| Nucleus / $\nu$ | **Stabilizer** / $\sigma$ | $\nu \to \sigma$ |
| Flow / $\varphi$ | **Drift** / $\Delta$ | $\varphi \to \Delta$ |
| Invariant (objects, fibers, sheaves) | **Fixed** (objects, fixed fibers, Fix subsheaf) | — |
| Hypertensor structure / $\otimes$ | **trace convolution structure** / $\circledast$ | $\otimes \to \circledast$ |
| PTL (Profile Term Language) | **Recognition Term Language (RTL)** | — |
| Generative closure / $G$ | **generative universe closure** / $U_G$ | $G \to U_G$ |
| Deviation operator / $D$ | **defect operator** / $\delta$ | $D \to \delta$ |
| Spectral decomposition | **defect mode decomposition** | — |

## Usage Notes

- Legacy phrases may still appear in documents predating this concordance
  and in quoted material; they should always be read according to the
  identifications above.
- Documents with `nomenclature: legacy-hypertensor` in their frontmatter
  use the legacy column.
- Documents with `nomenclature: generative-sheaf-universe` use the current
  column.
- Documents without a `nomenclature` field should be checked against this
  table on a case-by-case basis.
