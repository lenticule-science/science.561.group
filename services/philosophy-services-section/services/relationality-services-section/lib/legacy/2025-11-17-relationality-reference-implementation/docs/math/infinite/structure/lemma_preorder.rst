Preorder
========

Lemma — *Preorder*
------------------

.. meta::
   :induced-by: math/infinite/structure/definition_order

The relation :math:`\le` on recognitions is reflexive and transitive.

*Proof.* Reflexivity: any context recognised by :math:`x` is
recognised by :math:`x`, so :math:`x \le x` by definition.
Transitivity: if :math:`x \le y` and :math:`y \le z`, then any context
recognised by *x* is recognised by *y* and hence by *z*, so
:math:`x \le z`. :math:`\square`
