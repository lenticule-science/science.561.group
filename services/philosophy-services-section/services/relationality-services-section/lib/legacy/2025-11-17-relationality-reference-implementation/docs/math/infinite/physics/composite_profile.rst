Composite Profile
=================

Definition — ***Composite Profile***
------------------------------------

For commuting Filters :math:`\{\mathrm{Filter}_i\}`, define the
*Composite Profile*

.. math::

   \mathrm{Profile}(\{\mathrm{Filter}_i\})
      := \bigcap_i \mathrm{Profile}(\mathrm{Filter}_i).

Equivalently,

.. math::

   \mathrm{Profile}(\{\mathrm{Filter}_i\}) =
   \mathrm{Profile}(\mathrm{Filter}_1 \circ
                    \mathrm{Filter}_2 \circ \dots \circ
                    \mathrm{Filter}_n).
