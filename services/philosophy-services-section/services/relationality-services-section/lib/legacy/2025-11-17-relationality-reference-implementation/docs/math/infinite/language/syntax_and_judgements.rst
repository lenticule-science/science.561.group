Syntax and Judgements
=====================

Definition — ***Types***
------------------------

Types are generated from base recognition types by ``∧, ∨, ⇒``,
together with ``⊥, ⊤``. We write ``A, B, C`` for types.


Definition — ***Contexts***
---------------------------

A *context* ``Γ`` is a finite list ``x₁:A₁, …, xₙ:Aₙ``. Its
denotation is the meet of its components.


Definition — ***Terms***
------------------------

Terms are generated by:

- variables ``x``,
- Reflex operator ``ρ`` acting on recognition terms,
- logical constructors:

  - pair ``⟨t, u⟩`` for ``∧``,
  - injections ``\mathrm{inl}\ t`` / ``\mathrm{inr}\ u`` for ``∨``,
  - abstraction ``λx.t`` and application ``t\,u`` for ``⇒``,

- constants ``⋆ : ⊤`` and ``\mathrm{abort} : ⊥ → C``.

Judgements consist of:

- Typing: ``Γ ⊢ t : A``.
- Equality/conversion: ``Γ ⊢ t ≡ u : A``.

For many metatheoretic arguments it is convenient to work not only
with the fact that a typing judgement holds, but with an explicit
*derivation object* witnessing the inference tree for
``Γ ⊢ t : A``. At the implementation level these are represented by
finite trees whose nodes are labelled by a rule name
(``var``, ``lam``, ``app``, product/sum rules, ``⊥``-elim,
``⊤``-intro, ``ρ``-intro), a context, a term, and its type, with
premise derivations as children.
