Profile Tower
=============

Theorem — Profile Tower
-----------------------

Given Filters acting on Profiles of Filters, the iterated construction

.. math::

   \mathrm{Profile} \to \mathrm{ProfileStructure} \to
   \mathrm{ProfileLanguage} \to \mathrm{ProfileGeometry} \to
   \mathrm{ProfilePhysics}

reconstructs at every level. Nested Profiles and Composite Profiles
both inherit the full Relationality chain.

*Proof.* Immediate from the Profile and Composite Profile propositions
and from the fact that restrictions of nuclei, flow, Reflex, and the
Heyting operations satisfy all axioms on each stable domain. ∎
