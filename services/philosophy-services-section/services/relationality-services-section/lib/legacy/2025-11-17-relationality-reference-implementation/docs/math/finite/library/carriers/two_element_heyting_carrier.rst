Two-element Heyting carrier
===========================

.. meta::
   :xref-spec: math/infinite/structure/heyting_algebra_theorem

Statement
---------

This fragment records the canonical ***Two-element Heyting Algebra***
used throughout the tests as a minimal finite witness to the Heyting
Algebra theorem on :math:`R = \{\bot, \top\}` with the standard order
and operations:

- :math:`\bot \le \top`, with :math:`\bot` as bottom and :math:`\top`
  as top;
- meets/joins given by logical and/or; and
- implication given by the usual truth table on the two-element chain.
