Composite Profile as RelationalStructure
========================================

Proposition — Composite Profile as RelationalStructure
------------------------------------------------------

The composite profile :math:`\mathrm{Profile}(\{\mathrm{Filter}_i\})`,
with the inherited operations

.. math::

   (\le, \wedge, \vee, \Rightarrow, \bot, \top),

is a *Relational Structure*.

*Proof.* Each :math:`\mathrm{Profile}(\mathrm{Filter}_i)` is a
Heyting-closed substructure. Finite intersections of
Heyting-closed subsets remain Heyting-closed. ∎
