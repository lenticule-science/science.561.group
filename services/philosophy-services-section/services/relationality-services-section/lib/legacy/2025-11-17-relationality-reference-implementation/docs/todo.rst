Relationality TODOs
===================

This page aggregates open TODO items recorded throughout the
documentation using the Sphinx ``todo`` extension. Each entry should
point back to a concrete definition, theorem, section in the
Relational Mathematics Specification, or a clearly-scoped repository
process task. These TODOs are primarily *mathematical* tasks (proving
results, tightening definitions, extending the specification), but may
also include small process or tooling items when they directly support
the relational workflow described in :doc:`guides/computation`.

TODOs are listed here once, using the built-in Sphinx TODO index.
Per-TODO ``:phase:`` values (see the “TODOs, backlog, and phases”
section of :doc:`guides/computation`) still apply and are included in
the text of each entry.
