Order
=====

Definition — ***Order***
------------------------

.. meta::
   :induced-by: math/infinite/structure/definition_recognition,
                math/infinite/structure/definition_reflex

For :math:`x, y \in R`, write :math:`x \le y` and read “:math:`x` is
at least as recognising as :math:`y`” iff any context recognised by
*x* is also recognised by *y*. Intuitively, *x* is included in *y* as
a region of recognition.
