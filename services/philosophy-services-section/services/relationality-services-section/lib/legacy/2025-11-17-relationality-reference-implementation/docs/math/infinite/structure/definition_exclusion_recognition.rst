Exclusion Recognition
=====================

Definition — ***Exclusion Recognition*** (``ExclusionRecognition``)
-------------------------------------------------------------------

.. meta::
   :induced-by: math/infinite/structure/theorem_articulation

An ***Exclusion Recognition*** (``ExclusionRecognition``) is a
recognition whose content is “not‑with”: it marks off what is excluded
from what it is excluded by. Exclusion is relational in form (it
relates an interior to an exterior by denying overlap).
