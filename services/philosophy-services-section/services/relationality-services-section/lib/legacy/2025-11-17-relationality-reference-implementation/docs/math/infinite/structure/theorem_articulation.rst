Articulation
============

Theorem — ***Articulation***
----------------------------

.. meta::
   :induced-by: math/infinite/structure/definition_relationlessness

Effective *Articulation* (including denial) manifests as a
recognition.

*Proof.* To describe the state “without relation” is already to effect
an Exclusion between “relation” and “this field.” Exclusion is
relational in form, hence it constitutes a recognition. Therefore,
from the very definability of *Relationlessness*, at least one
recognition is induced. :math:`\square`
