Proposition — Flow Distributes over Meets
-----------------------------------------

If :math:`F` is a monotone flow, then:

- if :math:`F` is inflationary,
  :math:`F(x \wedge y) \le F(x) \wedge F(y)`;
- if :math:`F` is deflationary,
  :math:`F(x) \wedge F(y) \le F(x \wedge y)`.

**Proof.** Use monotonicity and directionality: inflationary gives
:math:`x \le F(x)`, :math:`y \le F(y)`, hence
:math:`x \wedge y \le F(x) \wedge F(y)` and by monotonicity
:math:`F(x \wedge y) \le F(x) \wedge F(y)`. The deflationary case
dualises. ∎
