Finite Relational Structure
===========================

Finite Relational Structure notes will specialise the infinite
Relational Structure definitions to concrete finite carriers and
structures. At present, all finite structure material is expressed
indirectly via the finite library fragments.

For the finite carriers themselves (for example, the Two-element
Heyting carrier and finite powerset Heyting carriers), see:
