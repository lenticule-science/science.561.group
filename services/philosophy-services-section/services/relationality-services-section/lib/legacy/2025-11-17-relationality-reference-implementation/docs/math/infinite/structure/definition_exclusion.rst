Exclusion
=========

Definition — ***Exclusion***
---------------------------

.. meta::
   :induced-by: math/infinite/structure/definition_meet,
                math/infinite/structure/proposition_bounded_distributive_lattice

Let a *Relational Structure* (``RelationalStructure``) *R* carry a
preorder :math:`\leq` and finite meets as in *Finite Meet*. For
recognitions :math:`x, y \in R`, we define *Exclusion* (orthogonality)
by:

.. math::

   x \perp y \quad\text{iff}\quad x \wedge y = \bot.
