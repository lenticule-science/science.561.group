Nested Profile
==============

Definition — ***Nested Profile***
---------------------------------

Let :math:`\mathrm{Filter}` be a Filter on *Geom* and let
:math:`\mathrm{GFilter}` be a Filter on
:math:`\mathrm{ProfileGeom}(\mathrm{Filter})`. Then
:math:`\mathrm{GFilter}` is a Filter on
:math:`\mathrm{ProfileGeom}(\mathrm{Filter})`, and

.. math::

   \mathrm{Profile}(\mathrm{GFilter})

is called a *Nested Profile* within
:math:`\mathrm{Profile}(\mathrm{Filter})`.
