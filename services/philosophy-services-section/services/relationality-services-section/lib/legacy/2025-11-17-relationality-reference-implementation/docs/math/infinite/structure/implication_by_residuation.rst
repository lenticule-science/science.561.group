Definition — ***Implication by Residuation***
--------------------------------------------

For :math:`x, y \in R`, define :math:`x \Rightarrow y` to be the
greatest :math:`z \in R` such that :math:`z \wedge x \leq y` (if it
exists). Read: “when :math:`x` holds, :math:`z` is sufficient for
*:math:`y`*”.
