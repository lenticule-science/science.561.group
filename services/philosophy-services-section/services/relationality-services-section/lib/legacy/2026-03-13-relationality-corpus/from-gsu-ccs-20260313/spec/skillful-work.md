## What this is

A unit of **work** is anything that gets done. **Skillful work** is work for which a documented, repeatable method exists — a skill file. The four types of skillful work correspond to the four canonical sub-algebras of a nuclear quartet ([NuclearQuartetSubalgebra](../math/nuclear-quartet-subalgebra.md)): the raw algebra A (Inquiry), Fix(σ) (Procedure), Fix(Δ) (Derivation), and H\* = Fix(σ)∩Fix(Δ) (Process). This correspondence is generated by two commuting nuclei σ (meaning-closure) and Δ (execution-closure) on the algebra of all work units; the nuclear quartet theorem (§nuclear-quartet-theorem) guarantees exactly four types and no fifth.

## MUST

- Be of exactly one of the four types: Process, Procedure, Derivation, or Inquiry — §nuclear-quartet-theorem (the quartet is exhaustive; "Why exactly four" proves no fifth canonical sub-algebra exists)
- Have a skill file that declares its type in the file header
- Produce a SkillResult (§skill-result) — either a named success output or a structured SkillError; a unit of skillful work that produces neither has not completed
- Declare its `skill-closure-kind` in frontmatter matching the type header

## By type: output and feedback obligations

**Process and Procedure** — MUST emit a SkillError (§skill-result) when they
cannot produce their codomain output. The error propagates to the calling skill
or, if unhandled, to the enclosing improvement cycle (§improving) which routes
it to PLANS.

**Derivation and Inquiry** — in addition to producing their output, MUST
accumulate a CoursOfWork (§improving) during execution: the skills invoked,
files read, and any unexpected outputs or errors encountered. When executed
within an Improving context, the CoursOfWork is passed to
`skills/post-work-update.md` as findings at the end of the work unit.
A Derivation or Inquiry that produces a judgment without examining its CoursOfWork
has not closed its loop.

## CAN

- Call skills of any type as sub-skills
- Be organized in any directory structure
- Span multiple files if a single skill's output is too large

## CANNOT

- Mix type properties across a single skill file — §nuclear-quartet-theorem (the four sub-algebras are disjoint except at their intersections; a file that is simultaneously a Process and a Procedure would require Fix(σ)∩Fix(Δ) = Fix(σ), which holds only when Δ is trivial)
- Claim to be a fifth type — §nuclear-quartet-theorem (the quartet is exhaustive)
- Fail silently — every failure MUST be a named SkillError
