This is a **how-to** text. It gives a practical procedure for evaluating
a specific argument.

## Goal

Determine whether an argument uses dialectics as method, not only as
style.

## Steps

### 1) Isolate the object

Write one sentence naming the object under analysis (institution,
concept, social relation, historical process).

If the object is unclear, stop. No dialectical evaluation is possible.

### 2) Extract the claimed contradiction

Identify the exact internal contradiction the argument claims.

If the contradiction is external only ("outside pressure changed it"),
ask whether the argument has become causal narrative rather than
immanent analysis.

### 3) Trace mediation

List every mechanism the author gives for the transition.

If the argument jumps from contradiction to outcome without intermediate
relations, mark this as a major weakness.

### 4) Test determinate transition

Ask: does the new form follow from specific limits of the prior form, or
could any outcome have been inserted?

If any outcome could fit, the argument is underdetermined.

### 5) Check historicization

Verify that the argument specifies period, conditions, and constraints.

If no historical bounds are given, mark over-generalization risk.

### 6) Score the argument

Use this simple rubric:

- **Strong dialectical analysis**: all five dimensions present.
- **Partial dialectical analysis**: contradiction present but mediation or
  historicization weak.
- **Rhetorical dialectics**: contradiction language present, method absent.
