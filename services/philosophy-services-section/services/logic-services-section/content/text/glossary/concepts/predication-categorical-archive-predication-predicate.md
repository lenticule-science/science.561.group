# Predicate

An object of a [predicate category](../../documents/articles/research/2026/07/31/lenticule-import/objects/predicate-category.md) $\mathcal{C}$ — equivalently, an element of the [predicate set](../../documents/articles/research/2026/07/31/lenticule-import/objects/predicate-set.md) $\Pi = \mathrm{Ob}(\mathcal{C})$, denoted $p$.

A predicate occupies the second coordinate of a [predication cell](../../documents/articles/research/2026/07/31/lenticule-import/from-predicate-category/predication-cell.md). The predicate category equips predicates with morphisms in four classes — [predicate specialization](../../../../../../../information-science-services-section/services/math-services-section/content/text/glossary/terms/predicate-specialization.md), [predicate converse](../../../../../../../information-science-services-section/services/math-services-section/content/text/glossary/terms/predicate-converse.md), [predicate subject-projection](../../../../../../../information-science-services-section/services/math-services-section/content/text/glossary/terms/predicate-subject-projection.md), [predicate object-projection](../../../../../../../information-science-services-section/services/math-services-section/content/text/glossary/terms/predicate-object-projection.md) — and each predicate has an associated [predication fiber algebra](../../documents/articles/research/2026/07/31/lenticule-import/objects/predication-fiber-algebra.md) at which [predication valuations](../../../../../../../information-science-services-section/services/math-services-section/content/text/glossary/terms/predication-valuation.md) are assigned.
