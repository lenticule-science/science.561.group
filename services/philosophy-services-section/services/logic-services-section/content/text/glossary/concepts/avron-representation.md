# Avron's representation

**Theorem ([@avron1996]; [@rivieccio2010] Thm 1.3.9–10).** A bounded [pre-bilattice](../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/pre-bilattice/pre-bilattice.md) is interlaced iff it is isomorphic to a [twist product](../../../../../../../information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/residuated-lattice/content/twist-product/twist-product.md) $\mathbf{L}_1 \bowtie \mathbf{L}_2$ for some bounded lattices $\mathbf{L}_1, \mathbf{L}_2$. A bounded [bilattice](../../documents/articles/research/2026/07/31/lenticule-import/yet-another-unsorted-archive-dump/predication-categories/_archive/bucket-3/objects/bilattice.md) is interlaced iff it is isomorphic to $\mathbf{L}^\bowtie$ for some bounded lattice $\mathbf{L}$.

## Proof

[@avron1996], *The structure of interlaced bilattices*; [@rivieccio2010] PhD thesis, Theorems 1.3.9 and 1.3.10. $\square$

## What this buys

The representation theorem makes the twist product a *canonical and exhaustive* construction for interlaced bounded pre-bilattices: every such pre-bilattice arises this way, up to isomorphism. The two-coordinate description $\langle a_+, a_- \rangle$ — positive evidence in the first coordinate, negative evidence in the second — is therefore not a special case but the universal form.

Specializing to $\mathbf{L} = \mathbf{2}$ recovers $\mathbf{2}^\bowtie \cong \mathbf{FOUR}$ as the smallest non-trivial interlaced bilattice, with $\mathbf{f} = \langle 0, 1 \rangle$, $\bot = \langle 0, 0 \rangle$, $\top = \langle 1, 1 \rangle$, $\mathbf{t} = \langle 1, 0 \rangle$.

Distributivity transfers: if $\mathbf{L}$ is distributive, so is $\mathbf{L}^\bowtie$ ([@fitting2006]). The variety $\mathbf{DBiLat}$ of distributive bilattices is generated by $\mathbf{FOUR}$ ([@bou-rivieccio2011].
