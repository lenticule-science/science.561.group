## Annotation

The **CALM theorem**: a program has a consistent, coordination-free distributed implementation if and only if it is **monotonic** in a suitable lattice-theoretic sense. CALM = *Consistency As Logical Monotonicity*.

For the program: knowledge-presheaf-based computation is a CALM instance — knowledge-presheaf updates are monotone in $\leq_k$, so by CALM all queries computable as $\leq_k$-monotone functions of the knowledge-presheaf state can be evaluated without cross-replica coordination.
