  # Concepts — visual engineering

  The portable, parameterized disciplines that visual languages instantiate. Where the [terms](../../research/2026/07/31/lenticule-import/yet-another-unsorted-archive-dump/predication-categories/_archive/bucket-4/articulating/library/aperiodic-articulation-category/library/aperiodic-articulation-cell/library/potential-aperiodic-articulation-cell/predicating/library/transfinite-predication-category/hacking/library/predication-cell-set/docs/dev/scraps/from-stable-cell-stale-chain/library/predicate-set/library/predicate-category/hacking/library/object/library/thing/library/category/hacking/library/information/information-architecture/visual-engineering/terms) name the operational outcomes a visual language is responsible for (felt weight, glance direction, peripheral uptake, …), the concepts here name the *shapes* a visual language can take to be responsible for them.

  Each concept is parametric: it states a pattern, the parameters that pattern accepts, the shape of a conformance check, and its lineage to the methodological [texts](../../research/2026/07/31/lenticule-import/yet-another-unsorted-archive-dump/predication-categories/_archive/bucket-4/articulating/library/aperiodic-articulation-category/library/aperiodic-articulation-cell/library/potential-aperiodic-articulation-cell/predicating/library/transfinite-predication-category/hacking/library/predication-cell-set/docs/dev/scraps/from-stable-cell-stale-chain/library/predicate-set/library/predicate-category/hacking/library/object/library/thing/library/category/hacking/library/information/information-architecture/visual-engineering/texts/visual-engineering-practices.md). Subtheories — the [561 Group Design Bible](../../research/2026/07/31/lenticule-import/yet-another-unsorted-archive-dump/predication-categories/_archive/bucket-4/articulating/library/aperiodic-articulation-category/library/aperiodic-articulation-cell/library/potential-aperiodic-articulation-cell/predicating/library/transfinite-predication-category/hacking/library/predication-cell-set/docs/dev/scraps/from-stable-cell-stale-chain/library/predicate-set/library/predicate-category/hacking/library/object/library/thing/library/category/hacking/library/information/information-architecture/visual-engineering/concepts/theories/five-six-one-design-bible/_index.md), the [emsenn visual language](../../research/2026/07/31/lenticule-import/yet-another-unsorted-archive-dump/predication-categories/_archive/bucket-4/articulating/library/aperiodic-articulation-category/library/aperiodic-articulation-cell/library/potential-aperiodic-articulation-cell/predicating/library/transfinite-predication-category/hacking/library/predication-cell-set/docs/dev/scraps/from-stable-cell-stale-chain/library/predicate-set/library/predicate-category/hacking/library/object/library/thing/library/category/hacking/library/information/information-architecture/visual-engineering/concepts/theories/emsenn-visual-language/_index.md) — bind the parameters and inherit the conformance shape, then prove conformance with their own theorems.

  A concept here is *not* a stylistic preference. It is a structural commitment a visual language makes about how it constrains itself. Two languages may instantiate the same concept with very different parameter values and remain mutually legible as members of the same family of practice.

  ## Inventory

  - [closed-palette](closed-palette.md) — color is an enumerated finite set; no value outside the set is permitted.
  - [verb-assignment](verb-assignment.md) — each member of a small set of marks is bound to a verb (what it does), not a feeling.
  - [salience-scarcity](salience-scarcity.md) — the most attentionally weighty marks are the rarest, by quota stated as either coverage or count.
  - [type-role-discipline](type-role-discipline.md) — each text run plays one role from a closed set; weight and family mark role, not emphasis.
  - [rhythm-unit-system](rhythm-unit-system.md) — every spatial measurement derives from one base unit; the artifact has rhythm because the unit is shared.
  - [closed-geometry-set](closed-geometry-set.md) — page or layout geometries are enumerated; new geometries enter only by amendment.
  - [register-set](register-set.md) — imagery, voice, or treatment is partitioned into a small set of named registers, each with its own discipline.
  - [refusal-list](../../../../glossary/concepts/refusal-list.md) — a load-bearing list of named refusals, each carrying a falsifiable check.
  - [conformance-check](conformance-check.md) — every constraint carries a procedure that can be run on the artifact to decide pass or fail.
  - [earned-addition](../../../../glossary/concepts/earned-addition.md) — a new resource enters the language only after three independent uses have demanded it.
  - [template-as-floor](template-as-floor.md) — templates are the floor, not the ceiling; an artifact may inherit, fork, or write a new one.
  - [mark-as-composition](mark-as-composition.md) — the identifying mark is composed from primitives the language already uses, not drawn as a separate object.
  - [resource-graph](../../../../glossary/concepts/resource-graph.md) — every value, geometry, and rule is a named resource; the language is the graph of citations between them. *(Currently load-bearing only in emsenn; 561 operates on the FARS resource graph implicitly without promoting it to a named concept.)*
