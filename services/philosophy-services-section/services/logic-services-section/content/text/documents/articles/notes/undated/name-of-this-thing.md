title: name of this thing
---

A name-of-this-thing is the self-identification a running 561 MCP server reports for the character it serves. The MCP server is spawned with `CHARACTER_NAME` set; the bound character's canonical basename is its name-of-this-thing. From inside any skill the server runs, the deictic "this thing" refers to the server itself — a singleton during the session — and the server's name-of-this-thing is the identifier under which the session's tool surface was registered.
