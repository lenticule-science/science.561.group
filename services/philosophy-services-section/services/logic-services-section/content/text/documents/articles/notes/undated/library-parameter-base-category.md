# Parameter-base category

The category `B` of substrate **parameter bases** `(L, C, E, λ)` with base-morphisms as 1-cells.

## Objects

Objects of `B` are 4-tuples `(L, C, E, λ)`:

- `L` — an integral commutative residuated lattice.
- `C` — a small predicate-category with finite limits.
- `E` — an entity-set.
- `λ` — a settling-bound (an ordinal).

Each tuple specifies a complete substrate setting where settlements can be defined.

## Morphisms

Morphisms `(L, C, E, λ) → (L', C', E', λ')` are **base-morphisms** consisting of:

1. A homomorphism `ℓ: L → L'` of integral commutative residuated-lattices.
2. A function `e: E → E'` between entity-sets.
3. A functor `π: C → C'` between predicate-categories, preserving generator classes.
4. An order-preserving map `φ_λ: λ → λ'` between settling-bounds.

These are the same `(ℓ, e, π, φ_λ)` data that the parameter-base component of `settlement-base-morphism` records.

## Composition

Compose component-wise: `(ℓ', e', π', φ'_λ) ∘ (ℓ, e, π, φ_λ) := (ℓ' ∘ ℓ, e' ∘ e, π' ∘ π, φ'_λ ∘ φ_λ)`. Identities are component-wise identities.

## Role: the base for moduli fibrations

`B` is the **base category** over which the substrate's moduli prestacks are fibered:

| Moduli prestack | Fiber over `B ∈ B` |
|---|---|
| `M^pre` (settlement-moduli-prestack) | `KP^vis(B)` — visible-settlement-fiber-groupoid over `B` |
| `M^meta_pre` (meta-moduli-prestack) | `Sys^~(B)` — groupoid of closure-rule-systems modulo closure-equivalence over `B` |

Both fibered structures use `B` as the parameter-variation direction. The moduli-stack theorems (`settling-moduli-stack-theorem`, `meta-moduli-stack-theorem`) establish that these prestacks are 1-stacks on `(B, J_B)` for the parameter-base-topology `J_B`.

## Parameter-base topology `J_B`

The category `B` carries a Grothendieck topology `J_B` — the parameter-base-topology — that records which collections of base-morphisms count as covers. The topology is generated by **Priestley-cover-topology-subcanonical** covers: covers where the base-morphism family respects Priestley duality on the algebraic side.

The substantive properties:

- **Subcanonical**: representable presheaves are sheaves. This makes `B` itself a good "base point" for the moduli theory.
- **Generated by Priestley covers**: covers on the algebraic side dualize to covers on the Priestley side.
- **Compatible with base-changes**: the topology is preserved under pullback along arbitrary base-morphisms.

## Worked example: minimal base

A minimal object of `B`: `(L, C, E, λ) = (2, {*}, {a, b}, ω)`. Two-element Boolean lattice, single-predicate trivial category, two-entity set, ω-bounded settlement.

A morphism from this minimal base to a larger one `(2, {p, q}, {a, b, c}, ω)` extends:

- `ℓ = id_2` (same residuated lattice).
- `π: {*} → {p, q}` sends `*` to either `p` or `q`.
- `e: {a, b} ↪ {a, b, c}` includes.
- `φ_λ = id_ω`.

The base-morphism then induces a base-change functor `KP^vis(2, {p, q}, {a, b, c}, ω) → KP^vis(2, {*}, {a, b}, ω)` restricting settlements over the larger base to the smaller.
