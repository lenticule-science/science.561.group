  # Closed geometry set

  A visual language uses a *closed geometry set* when the page or layout geometries available to an artifact are enumerated and finite. New geometries enter only by amendment to the kit, never by ad-hoc invention at the artifact.

  ## Pattern

  The kit names each permitted geometry — a column count, a gutter, a reservoir width, a fold pattern, a trim — and gives each a name. An artifact picks one geometry at the start of composition; the choice is the first decision made and locks subsequent decisions about reservoir, density, and component placement.

  ## Parameters

  - **`geometries`** — the enumerated geometries (e.g. `scholar`, `paired`, `index`).
  - **`dimensions`** — for each geometry, the column count, gutter, reservoir, and trim.
  - **`amendment-rule`** — the procedure by which a new geometry enters the set. Typically requires multiple independent uses before promotion.

  ## Conformance shape

  For each artifact, verify it declares its geometry, that the declared geometry is a member of `geometries`, and that the artifact's measurements match the geometry's `dimensions` table.

  ## Lineage

  Closed geometry sets derive from working print traditions: a publisher commits to a small number of trim sizes, a small number of column structures, a small number of fold patterns, because doing so makes the production line tractable and the catalog readable. The discipline supports [orientation before interpretation](../../../../../../../../../engineering-science-services-section/services/design-engineering-science-services-section/services/visual-engineering-services-section/content/text/glossary/terms/orientation-before-interpretation.md) by giving the reader a small set of recognizable artifact shapes, and [memetic repeatability](../../../../../../../../../engineering-science-services-section/services/design-engineering-science-services-section/services/visual-engineering-services-section/content/text/glossary/terms/memetic-repeatability.md) by guaranteeing that an artifact in this kit looks like other artifacts in this kit.
