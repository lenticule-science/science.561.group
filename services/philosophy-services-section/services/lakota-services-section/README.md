# Lakota Services Section

The Lakota Services Section holds Lakota cosmogonic and kin-metaphysical
philosophy. All of its content lives under one path,
`content/text/glossary/lakota/`, which carries its own package README
describing the material in full detail; this file orients at the section
level and should be read alongside that one.

The package (`@561-group/theories/existence/lakota`) is a **notes-only
consolidation**: prior, scattered notes on Lakota philosophy — the
cosmogony, the kin-metaphysics, the lifeway, the polity — unioned across
the trees they were scattered in, deduplicated by content, and tagged by
provenance (`--philA`, `--philB`, `--b4`, `--b4flat`, `--romkeldar`, and
others). Nothing was dropped in the consolidation, and no derived summary
document has been written yet — each `docs/dev/notes/` directory holds
raw note-versions, not a finished treatment.

The package is built the way the estate's `existence` and `voidmath`
packages are built: the directory tree itself is the type language, a
path is a typing judgment, and nesting is derivation. It begins at
Íŋyaŋ-in-Haŋhépi (the alone-stone-in-darkness prior to the cosmogonic
self-emptying) and unfolds outward through the `discharging/` morphism
into the four-fold field (Tóbtób Kiŋ: Škáŋ, Wí, Makȟá, Íŋyaŋ-residual),
Heyókha as the bearer of lived contradiction, and further predicated
kin-morphisms across four closure-ordinal regimes (aperiodic, transfinite,
scott-continuous, finite) that the corpus's own notes describe as
fractal rather than as four flat, separate corners.

Substantial "hacking" (derivation-in-progress, explicitly not yet
theorem-grade) buckets extend this into Lakota politics and governance —
tiyóšpaye, oyate, akíčita, wóphila and consensus-by-withdrawal, treaty
and wakȟáŋ declaration — and, further out, a detailed formal treatment of
Lakota aerophone music (cedar and duct flutes, courting songs, pentatonic
tuning, breath-pulse and whistle-drum heterophony), each with its own
claims, specifications, and open questions.

The package's own README states its ethical position directly, and this
section defers to it rather than restating it differently: the
substantive Lakota tradition is held by Lakota knowledge holders in
living tradition; this material carries it under the captain's vested
authority as a Lakota person; the substrate-algebraic form is a tool,
never the tradition itself; and any coordinate not yet derived is marked
as derivation-in-progress, not settled theorem.
