# Question. Are all five modal rotations attested in actual Lakotaean flute practice, or are some modes theoretical-only?

The pentatonic minor admits five modal rotations as a mathematical fact (C₅ acts on the scale).
In practice, mode I (the minor pentatonic with the lowest fingered note as tonic) dominates the documented corpus.
Internal tonal-center shifts are documented — players establish a different scale-degree as local center — but it is unclear whether all five modes appear in practice or only a subset.

Open: do the Densmore transcriptions, Belo Cozad recordings, Richard Fool Bull recordings, and Kevin Locke repertoire exhibit local tonal centers on each of the five scale degrees?
Or are some modes (e.g., mode III, mode IV) absent from practice?

If only a subset is used, the active modal set is a sub-structure of the full C₅ action — itself a music-theoretic object.

Sub-survey needed: tonal-center analysis on a representative repertoire sample.
