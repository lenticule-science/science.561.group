# flute-voice-duet

The ensemble object pairing the cedar courting flute with the *wiílowaŋ* vocal courting-song genre, sharing pitch space and phrase grammar.

## Definition

A **flute-voice duet** is a pair (V, F) of music streams in which:

- V is a vocal stream in the pentatonic-minor pitch space with rubato non-metric phrase-grammar.
- F is a cedar-flute stream in the same pitch space with the same phrase-grammar.
- The two streams are temporally synchronized: either V and F substitute for each other (one carries the line at any moment) or V and F alternate phrases (antiphony).

The shared pitch space is [pitch-space](./pitch-space.md).
The shared phrase-grammar is built on [non-metric-temporal-substrate](./non-metric-temporal-substrate.md).

## Properties

- **Two configurations**:
  - **Substitution**: F replaces V entirely.
    The dominant historical configuration.
  - **Antiphony**: V and F alternate phrases or phrase-halves.
- **Shared pitch space**: V and F operate in the same Z₅ × R⁺ structure, modulo the voice's continuous-pitch flexibility (quantized to the flute's degrees on flute realizations).
- **Shared phrase grammar**: V and F use the same set of phrase shapes (descending-cadence, peak-and-return, repeat-and-vary) and the same rubato pacing.
- **Instrumentalization morphism**: the [instrumentalization](../transformers/instrumentalization.md) transformer maps V to F.
