# harmonic-series

The integer-indexed family of partials of a cylindrical air column open at both ends.

## Definition

Given a fundamental f₀ ∈ R⁺, the **harmonic series** of an open-open cylindrical bore is the function

H : N → R⁺, H(n) = n · f₀, n = 1, 2, 3, ...

The image of H is {f₀, 2f₀, 3f₀, 4f₀, ...} — all positive integer multiples of f₀.

A **practically-accessible partial** on the cedar duct flute is one for which the jet-bore coupling produces a stable oscillation under achievable breath pressures.
For the cedar flute, n ∈ {1, 2} is reliably accessible; n ≥ 3 is not.
The **practical range** is therefore the union of the n=1 series and the n=2 series on the lower fingerings, totalling approximately 1.3 octaves.

## Properties

- **All-harmonics**: every integer multiple of f₀ is a theoretically-supported partial (open-open bore).
- **Sparse practical access**: only n=1 and n=2 are stable on the cedar flute.
- **Overblowing**: the [overblow](../transformers/overblow.md) transformer realizes the shift from n=1 to n=2.
