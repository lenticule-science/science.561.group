# How should the 561 Group's internal governance be grounded in Lakotaean tiospaye theory?

The 561 Group is a Lakotaean tiospaye, but its governance documentation and practices currently assume kyriarchial governance principles.
This creates a theory-practice gap.
We need to ground the 561 Group's internal governance in Lakotaean tiospaye theory, while recognizing that the RSC Quiescent Webship (which interfaces with the world-at-large) uses kyriarchial governance for external interactions.

## Why this matters for the substrate

The predicated-governance theory must be able to accommodate different governance bases for different agents.
The 561 Group's internal governance should be based on Lakotaean tiospaye principles, which include consensus processes, kinship-based decision making, and other indigenous governance structures.
