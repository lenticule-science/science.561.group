# overblow

The selection of the n-th harmonic partial as the sounding pitch, realized by sufficient breath pressure to shift the jet-bore coupling from the (n-1)-th to the n-th partial.

## Definition

Given a [bore](../structures/bore.md) producing a fundamental f₀ at moderate breath pressure, the **overblow to partial n** is the morphism

Ω_n : f₀ ↦ n · f₀

realized by increasing breath pressure beyond the (n-1) → n transition threshold.

For the cedar duct flute, Ω₂ is reliably accessible; Ω_n for n ≥ 3 is not.

## Properties

- **Octave shift at n=2**: Ω₂ doubles the fundamental, producing the octave above each fingered note.
- **Pressure threshold**: Ω_n requires breath pressure exceeding the (n-1) → n stability boundary.
- **Range-doubling**: the practical range of the flute is approximately the disjoint union of the n=1 register and the lower part of the n=2 register, totalling ~1.3 octaves.
