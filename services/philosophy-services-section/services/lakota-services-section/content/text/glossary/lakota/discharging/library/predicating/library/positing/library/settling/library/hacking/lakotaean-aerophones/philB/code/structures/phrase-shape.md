# phrase-shape

The set of documented phrase shapes in the Lakotaean cedar flute idiom.

## Definition

A **phrase shape** is a high-level descriptor of a phrase's melodic contour and cadential behavior.
The Lakotaean cedar flute idiom uses three documented phrase shapes:

1. **Descending cadence**: a phrase ending by descent to the tonic (scale-degree 1), typically via the minor third.
2. **Peak-and-return**: a phrase rising to a sustained note (often the minor seventh or the octave), then descending to the tonic.
3. **Repeat-and-vary**: a phrase restated with ornamental variation; the principal large-scale form-building device when concatenated across strophes.

Formally, the set of phrase shapes Φ = {descending-cadence, peak-and-return, repeat-and-vary} is a finite discrete structure; a phrase carries a phrase-shape tag φ ∈ Φ.

## Properties

- **Finite**: the documented phrase-shape vocabulary is small and closed in practice.
- **Compatible with rubato**: all three shapes are realized within rubato phrase-grammar.
- **Composable at the strophe level**: a strophe is typically a sequence of phrase-shape-tagged phrases.
