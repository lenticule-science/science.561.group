# whistle-drum-heterophony

The ensemble object pairing one or more whistles (single-tone-objects or stochastic-clusters) with a drum, articulating a shared meter with different timbres and slightly offset temporal placements.

## Definition

A **whistle-drum heterophony** is a triple (W, D, μ) where:

- W is a [single-tone-object](./single-tone-object.md) or a [stochastic-cluster](./stochastic-cluster.md).
- D is a drum stream supplying a metric pulse μ.
- The whistle's breath-pulse-sequence ρ is aligned to μ (each pulse onset falls near a μ-grid point, with a small timing offset δ on the order of tens of milliseconds).

## Properties

- **Heterophony, not unison**: timbrally distinct layers (low-band drum vs. high-band whistle) articulating the same meter with offset placements.
- **Imported meter**: the whistle adopts the drum's pulse; it does not generate the meter.
- **The only metric context** in the Lakotaean aerophone family.
  All other aerophone contexts (flute solo, whistle in isolation) are non-metric.
- **Composes with stochastic-cluster**: a multi-whistle cluster with a shared drum-driven pulse is a stochastic-cluster within a whistle-drum-heterophony.
