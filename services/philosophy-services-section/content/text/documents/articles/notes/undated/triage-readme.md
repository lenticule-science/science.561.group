# Bussard

A spaceflight adventure game.

Written in [Fennel](https://fennel-lang.org) with [LÖVE](https://love2d.org).

To contribute, email me a patch or find me on freenode in the
`#fennel` channel. If more folks are interested in discussing
contributions I may start a mailing list.

Right now it requires a copy of
[polywell](https://git.sr.ht/~technomancy/polywell) to be checked out
in the parent directory, since both polywell and bussard are changing
at a fast rate. Once polywell stabilizes a bit, I will switch to a
subtree or something.

https://man.sr.ht/git.sr.ht/send-email.md

## Running

Install [LÖVE](https://love2d.org) version 11.1 and run `love $PWD` to start.
