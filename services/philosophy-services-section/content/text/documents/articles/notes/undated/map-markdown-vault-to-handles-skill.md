# Map a Markdown Vault to Handles

- Assign stable [handles](../../../../../../services/relationality-services-section/services/interactive-semioverse-services-section/content/text/glossary/terms/handle.md) to each chosen unit (file, section, or heading).
- Build [interaction surfaces](../../../../../../services/relationality-services-section/services/interactive-semioverse-services-section/content/text/glossary/terms/interaction-surface.md) for each handle from headings, links, and definitions.
- Generate handle fragments and compute [footprints](../../../../../../services/relationality-services-section/services/interactive-semioverse-services-section/content/text/glossary/terms/footprint.md) for each handle.
- Store the mapping and [footprint](../../../../../../services/relationality-services-section/services/interactive-semioverse-services-section/content/text/glossary/terms/footprint.md) summaries in a vault index document.
