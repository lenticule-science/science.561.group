# Survey a Markdown Vault

- List all markdown files and decide the granularity of [handles](../../research/2026/07/31/lenticule-import/library/philosophy/relationality/archive/domains/universes/semiotic-universe/domains/interactive-semioverse/terms/handle.md).
- Record the frontmatter fields that will seed [handles](../../research/2026/07/31/lenticule-import/library/philosophy/relationality/archive/domains/universes/semiotic-universe/domains/interactive-semioverse/terms/handle.md).
- Identify link density and repeated terms for candidate [interaction surfaces](../../../../../../services/relationality-services-section/services/interactive-semioverse-services-section/content/text/glossary/terms/interaction-surface.md).
- Note any missing frontmatter or inconsistent ids for follow-up.
