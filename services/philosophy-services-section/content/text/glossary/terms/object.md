An object is a [thing](thing.md) that exists as physical matter. It has mass, takes up space, and can be observed. A rock, a cup, a chair, a person's body, a planet — all objects.

Objects have two properties that non-physical things lack: they are **massive** (they have weight and resist being moved) and they are **notable** (they can be seen, touched, or otherwise sensed). A thought has neither property. A number has neither. An object has both.

Objects occupy locations. A cup is on the table. A book is in the bag. A ship is at port. At any given moment, an object is somewhere — inside a [container](container.md), on a surface, in an area. Objects move between locations: you pick the cup up, carry it to the kitchen, set it down. The cup's identity persists through the move. Location changes; the object stays the same object.

Objects can be moved or be stationary. In TAB's model hierarchy, a **mobile** is an object that moves under its own power or by being carried. A chair is an object but not a mobile — it stays where you put it unless someone moves it. A person is a mobile — they walk from room to room on their own.

Objects can be inside containers but are not themselves containers unless they have an inside. A ball is an object but not a container — there is no inside to put things in. A box is both an object and a [container](container.md) — it has mass and takes up space (object), and it has an inside where you can put things (container). A bag, a jar, a room — all objects that are also containers.

The distinction between object and thing matters because some things are not objects. A rule is a thing but not an object. A promise is a thing but not an object. An institution is a thing but not an object. The word "object" picks out the physical subset of things — the ones you can drop on your foot.

An object is a [[thing]] that exists as [[matter|physical matter]] in the [[material universe]].

In the [relationality](../_index.md) framework, **object** names a position in a directed act of [relating](relating.md): the relatum *toward which* the predicate runs. With [subject](subject.md), the object completes the directed triadic structure of relating. What makes the object an object — rather than the subject — is the directionality of the relating: the predicate is asserted *of* the subject *in relation to* the object.

The object is not a thing-with-properties, an external world, or a target in the intentional-realism sense. An object in this framework is constituted by the relating in which it stands — it is what the predicate runs *toward*, and it would not be that object outside the relating. Like the [subject](subject.md), it is a *position*, constituted by the directed relating that gives the position content.

## Asymmetric pairing

Object and subject are not interchangeable. In a directed predication cell $(s, p, o)$, the predicate $p$ holds of subject $s$ in relation to object $o$, not the reverse. The asymmetry is structural: the converse relation (where $p^c$ would hold of $o$ in relation to $s$) is a *different* relation, related to the original by the [predicate converse](../../../../math/theories/voidmath/terms/predicate-category.md) generator.

In the special case where a predicate equals its own converse — a *symmetric* predicate, in the math-side vocabulary — the subject and object positions become indistinguishable for that predicate. In all other cases, *being* the object is structurally distinct from *being* the subject.

## Distinction from grammatical and realist object

Three readings of *object* should be kept apart:

- **Grammatical object** — the noun phrase in object position of a sentence. A surface feature of language.
- **Realist object** — the thing-out-there that perception or thought tracks; the world's furniture, conceived independently of perceivers. Substance-metaphysical; the relationality framework refuses this substrate.
- **Relationality object** — a position in a directed relating, constituted by the relating itself. *This* reading.

The three coincide in particular cases but the framework's term means the third.

## Object as second relatum, not as opposition

In some philosophical traditions, *object* connotes opposition (a subject opposes or objectifies an *other*). The framework's use is more austere: object is just the second coordinate of the directed cell. The position carries no inherent valence — neither superior, inferior, distant, nor opposed. It is what stands at the receiving end of the directed relating, nothing more.

This is significant for the framework's politics: *objectification* in the moral-philosophical sense is not what the framework's *object* names. Objectification names a particular practice that treats relational entities as if they had only object-position content (no subject-side, no other relatings); the framework's *object* is just the second coordinate of any directed predication cell, including in relatings where the *same entity* simultaneously occupies subject positions in many other cells.
