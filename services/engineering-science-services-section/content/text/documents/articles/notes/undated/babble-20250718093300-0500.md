After too long dealing with other [text editors](../../../../../../../information-science-services-section/services/communication-science-services-section/services/writing-services-section/content/text/glossary/terms/text-editor.md), I'm finally returning to [Emacs](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/emacs.md). A critical first step in this is dusting off my old [Emacs configuration](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/emacs-configuration.md), which I'd named InfoPonEmacs.

Since then ([2021ce](../../../../../../../social-science-services-section/content/text/glossary/terms/2021ce.md)), I've gotten more particular in my [neologisms](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/neologism.md), specifically about mixing [Latin](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/latin-language.md) and [Greek](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/greek-language.md) influences, and have also significantly developed my interest in philosophy, epistemology, etc. (See [emsean thought](../../../../../../../../../public-services-section/services/personal-services-section/services/emsenn-services-section/content/text/glossary/terms/emsean-thought.md)).

So, one of the first things I'm doing, to more than dust off the system, is renaming it *[GnoponEmacs](../2025/08/08/2025-08-08-gnoponemacs.md)*.

From there, I want to tweak a **lot** of how the system is implemented, in-line with the things I've been learning in other ways over the past few years.

I want to make it so there is, in the root directory of our [Gnoponograph](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/gnoponograph.md), a script for starting GnoponEmacs, specifically, rather than having InfoPonEmacs take over the users' Emacs configuration.

Additionally, I want to rely more on placing snippets of configuration (i.e. capture templates) into a directory (or set of subdirectories) that the relevant configurations look into. That way, the main source file doesn't have to have a bunch of stuff about my personal capture templates in there, and the whole thing can be a little more modular.

So, user runs a script that starts Emacs and, if necessary, runs the GnoponEmacs installation script, creating the directories that it needs for itself (a directory for [YASnippet snippet](../../../../../../../philosophy-services-section/content/text/glossary/terms/yasnippet-snippet.md)s, for example.)

From there, they use [Org-mode](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/org-mode.md)/[-roam](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/org-roam.md) capture templates and [Org-roam node](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/org-roam-node.md) lookups to create *[Gnoponograms](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/gnoponogram.md)* and navigate the resultant *[Gnopolology](../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/gnopolology.md)*?

Another thing I want to set up is a way to do audio input, and I do want to look into integrating in [large language model](../../../../../../services/computer-science-services-section/content/text/glossary/terms/large-language-model.md) conversations, in some way.
