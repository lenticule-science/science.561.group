See [the org-contribute page on Worg](https://orgmode.org/worg/org-contribute.html) for guidance on how to contribute effectively.

We value a nice tone in our discussions: please check and respect the [GNU Kind Communications Guidelines](https://www.gnu.org/philosophy/kind-communication.en.html).

# Contribute as an Org user

You can contribute by helping others in various channels.

See [these directions](https://orgmode.org/worg/org-contribute.html#org99b8f3e).

# Contribute as an Emacs Lisp hacker

You can contribute with bug reports and patches.

See these [directions](https://orgmode.org/worg/org-contribute.html#org069b83a).

# As an Org maintainer

We encourage you to volunteer to maintain one of the Org files.

Just [send an email to the list](mailto:emacs-orgmode@gnu.org) explaining which file and your motivations.

See what is [the role of a maintainer](https://orgmode.org/worg/org-maintenance.html).
