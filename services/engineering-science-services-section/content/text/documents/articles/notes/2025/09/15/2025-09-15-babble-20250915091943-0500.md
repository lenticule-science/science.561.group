The last time I "installed [Fennel](../../../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/fennel.md)", it was just by "installing" [TAB](../../../../../../../../../philosophy-services-section/services/relationality-services-section/content/text/documents/articles/notes/undated/tab.md). This go around I'd like to more properly get it set up as accessible from my user's shell, so I can use it like a proper interpreter across [GnoponEmacs](../../08/08/2025-08-08-gnoponemacs.md).

So I don't forget, there's this [wonderful post](https://andreyor.st/posts/2024-12-20-extending-emacs-with-fennel/) from [Andrey Listopadov](../../../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/andrey-listopadov.md) about using Fennel in [Emacs](../../../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/emacs.md). I'll be using that, [the Fennel docs](https://fennel-lang.org/setup), and the documentation for [fennel-mode](https://git.sr.ht/~technomancy/fennel-mode) to navigate through this process. My goal is to be able to use Fennel anywhere I might use another language with [Org-babel](../../../../../../../../../information-science-services-section/services/knowledge-services-section/content/text/glossary/terms/org-babel.md), but skimming through Andrey's blog post, I suspect I can do more than that.

Following the install instructions for the Fennel script works great, so I can move on to integrating it into GnoponEmacs, starting with fennel-mode.

The following are the use-package declarations I'm starting with.

``` elisp
  (use-package lua-mode
  :straight t
  :mode ("\\.lua\\'" . lua-mode))

(use-package eglot
  :straight t
  :commands (eglot eglot-ensure))

(use-package fennel-mode
  :straight (:host sourcehut :repo "technomancy/fennel-mode")
  :mode ("\\.fnl\\'" . fennel-mode)
  :commands (fennel-mode fennel-repl)
  :init
  (setq inferior-lisp-program "fennel")
  (autoload 'fennel-proto-repl-minor-mode "fennel-proto-repl" nil t)
  (autoload 'antifennel-mode "antifennel" nil t)
  (with-eval-after-load 'org
    (require 'ob-fennel))
  :hook
  (fennel-mode . fennel-proto-repl-minor-mode)
  (fennel-mode . eglot-ensure)
  (lua-mode . antifennel-mode)
  :config
  (with-eval-after-load 'eglot
    (add-to-list 'eglot-server-programs
                 '(fennel-mode . ("fennel-ls")))))
```

Opening a new buffer in fennel-mode and running `(print "test')`{.verbatim} asks me about starting up a Fennel proto-REPL, so I do, and it works fine. Lets see if it works for code blocks:

``` fennel
(+ 2 2)
```

From my end, that looks perfect, even if doesn't render right upon publishing.
