# Objects

The structural definitions of the artifact-bearing things the bible governs.
Each object carries geometry, color states, minimum sizes, and conflicts with other objects.
Where a concept names a discipline, an object names a *thing the bible can point at on the page*.

Each object's frontmatter declares its `class` (mark, wordmark, palette-entry, type-family, grid, frame, plate, stamp), the concepts it `realizes`, the upstream entities it `depends-on`, and the entries it is `see-also` adjacent to.
