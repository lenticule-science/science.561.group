# Morphisms

The operative procedures the bible specifies.
A morphism is a transformation: input → constrained output, with a stated check that decides whether the output passed.
Morphisms are how the bible turns a [concept](teaching/explanations/) into something a person actually does at the layout table.

Each morphism's frontmatter declares the objects it operates on (`depends-on`), the concept it `realizes`, and other morphisms it is `see-also` adjacent to.
