# Computer Science Services Section

This section holds computer-science work, with children including `living-web-science-services-section`, `artificial-intelligence-science-services-section`, `computer-systems-science-services-section`, and `tagging-services-section`. `lib/agency` and `lib/legacy` hold agency material and a prior capture; `content/text` holds current documents.

`lib/obsmetrologia-computing` is the Lean package `ObsmetrologiaComputing`: program formats, Hoare programs, causality packets and verification tournaments, formalized over the pure-mathematics package Obsmetrologia, which it imports.
