# Versioning Services Section

This science section organizes terms and notes about identities, precedence,
compatibility claims, and change across software releases. It explains what a
version relation means and records the 561 Group's local scientific profile; it
does not allocate package identities, edit manifests, publish carriers, or
authorize promotion.

Engineering enforcement remains with `npm-workspace-publication-service`.
Operations remains responsible for compatibility-review duties, release
authorization, publication, and retained receipts.
