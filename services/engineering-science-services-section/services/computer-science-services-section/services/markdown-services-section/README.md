# Markdown science

This section is the science home for research and explanatory material about Markdown files, frontmatter, and Markdown vaults.

Its active corpus is organized under `content/text/`:

- `documents/articles/notes/` holds lessons and investigations;
- `glossary/terms/` defines the domain vocabulary;
- `glossary/topics/markdown.md` is the short topic entry point;
- `references/` preserves external examples and test corpora used as research evidence.

Reusable parsers, renderers, file operations, vault observation, graph derivation, tests, and other executable implementations belong to the [engineering Markdown services](../../../../../../../engineering-services-section/services/computer-engineering-services-section/services/computer-data-services-section/services/computer-data-type-services-section/services/computer-text-data-services-section/services/markdown-services-section/README.md).
Reusable knowledge-vault compilation and application code belongs to the [knowledge-vault computer-system services](../../../../../../../engineering-services-section/services/computer-engineering-services-section/services/computer-systems-engineering-services-section/services/computer-knowledge-systems-services-section/services/knowledge-vault-computer-system-services-section/README.md).

Science-specific deployment configuration may remain beside the science corpus when it only parameterizes those engineering systems; it does not become the reusable implementation home.
