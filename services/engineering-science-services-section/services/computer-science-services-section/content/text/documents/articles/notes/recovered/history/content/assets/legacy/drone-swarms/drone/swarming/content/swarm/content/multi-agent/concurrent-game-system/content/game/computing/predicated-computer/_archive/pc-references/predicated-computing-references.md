# references/

Annotated entries for cited works and external engineering systems. One file per reference, with formal citations in `references.bib`.

The directory is currently empty. References will be added as the corpus accumulates citations to substantive external work.

## Frontmatter

```yaml
---
type: reference
class: academic | engineering-system | ...
status: cited | pending
see-also: [...]
---
```

## Body shape

A reference annotation has the structure:

1. **Source.** The path or formal citation.
2. **Form.** What kind of document it is.
3. **Content summary.** What the reference says.
4. **Position in the corpus.** What role the reference plays — what corpus claims cite it.

## When to add a reference

When a work is cited by name in the corpus. Internal triage material that informs the corpus's content is not separately referenced — the corpus is the distilled engineering theory, not a record of which triage files informed which claims.
