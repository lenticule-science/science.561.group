## What this node is, and why it sits here

A **system** is a **coordinated, multi-participant [predicated computer](../../predicated-computer.md)**:
many predication-substrate instances coupled into one settling collective —
CRDT-replicated, federated, or concurrent-game-coupled. It is generated by the
predicated computer because a system *is* a kind of predicated computer (the
multi-instance, coordinated kind), so by the generator rule it sits directly
beneath the predicated computer: the single predication-substrate computer must
exist before many of them can be brought into a coordinated whole.

It is placed here, and not invented as a sibling, on the corpus's own derivation.
The theory-of-system root states the relations are *derived, not imposed*: **"a
concurrent-game player is an agent in a game role, and an agent is a kind of
system"** — and the theory-of-agency root restates it: **"an agent is a kind of
system."** A system is therefore the genus of which the agent is the species, and
the concurrent-game-system (the $\mathbf{CGS}$ apparatus the drone-swarm survey
lifts its whole stack into) is the system read with game roles.

## What it generates

Because **an agent is a kind of system**, the system generates the **agent**, and
beneath the agent the whole agency unfolding hangs — `agent → acting → actuating
→ actuator → embodying → body → integrating → drone → swarming → swarm → …` — down
to the leaf surveys (the *flatfile agentic drone resource system swarm* theory and
the rest). That long chain is not free-floating: read upward, every rung is
generated by the one above it, and the chain terminates here, at *system*,
generated by the predicated computer, generated by the
[hyperdoctrine](../../../predication-hyperdoctrine.md) and the
[settling](../../../../../settling.md) apparatus, generated in turn back up the
spine to **articulating**. This node is the keystone that lets a drone-swarm
document at the bottom of the agency tree carry an honest proof-path all the way
to the base morphism.
