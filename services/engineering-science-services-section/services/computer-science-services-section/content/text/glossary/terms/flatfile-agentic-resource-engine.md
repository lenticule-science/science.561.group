**FAR**, Flatfile Agentic Resource, is a solid core acronym (Leader, 2026-08-26). Apps are engines that make systems, so **FARE**, the flatfile agentic resource engine, is the right non-cute name for the app that generates a [FARS](./flatfile-agentic-resource-system.md) when running.

The Leader's chain: TIR, the Topological Information Resource, is what the engine makes out of FROG(s) in a FERN. The Leader's wish for the thing is "something in the realm of a FARS: something that lets us bring in all the data here as a graph with many many edges".

Its place is `agent-platform-services-section/apps/flatfile-agentic-resource-engine`; the earlier `flatfile-agent-engine` directory and the several other `flatfile-agent[ial|ic]-` directories are consolidated there, and notes and code about it are brought together there (2026-08-26 17:32, 17:53).

`fae` (the Flatfile Agent Engine) is not meant to be a package and never was; it is decommissioned, with all its consumers cut over to the upstream providers of its capabilities (2026-09-10 18:10, 2026-09-11 03:48). That is not an order to remove the flatfile-agent resource system itself (2026-09-11 20:19). The Python application `pyfars`, a closure, lint and rule engine, is kept as one copy at `flatfile-agent-resource-system-engineering-services-section/apps/pyfars`, with its `lib/legacy` code consolidated into it (2026-09-11 20:17, 2026-09-22 17:26).
