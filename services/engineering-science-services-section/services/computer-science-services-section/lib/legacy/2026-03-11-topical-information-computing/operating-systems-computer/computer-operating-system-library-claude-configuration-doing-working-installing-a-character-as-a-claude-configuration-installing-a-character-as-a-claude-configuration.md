A morphism that takes a [character](../../character.md) record and produces a [claude-configuration](../../../../../../operating-system/library/computer-operating-system/library/claude-configuration/claude-configuration.md) installed at the repository root.
The morphism's body lives at [scripts/install-a-character-as-a-claude-configuration.mjs](scripts/install-a-character-as-a-claude-configuration.mjs).

## What it writes

- `.mcp.json` — registers the 561 MCP server with Claude Code, naming the launch command (`node`) and the path to [the serve script](../../../../../../operating-system/library/computer-operating-system/library/mcp/doing/working/serving-a-stdio-mcp-server-to-a-claude-session-running-locally/scripts/serve-a-stdio-mcp-server-to-a-claude-session-running-locally.mjs).
- `.claude/settings.json` — the per-event hook declarations gathered from each listed skill's `_index.md` `hooks:` cell.
- `CLAUDE.md` — the project-instruction surface.
  The body comes from the character's own `CLAUDE.md` (or a default template); the appended live-tool-surface section is generated by nunjucks from the character's skills list.
- The surface files at the repository root: `561.md` (the character surface itself), `SOUL.md`, `MEMORY.md`, `HEARTBEAT.md`, `DREAMS.md`, `TOOLS.md`, `USER.md`, `AGENTS.md` — copied verbatim from the source character's directory.

## Refuse-if-installed

The morphism refuses to overwrite an existing `.mcp.json`.
To replace the installed character, remove `.mcp.json` and `.claude/settings.json` first; then run the morphism with the new character name.

## Inputs

- `characterName` — the slug of the character record to install.
  The morphism reads the character record from the on-disk character directory.

## Outputs

- A `claude-configuration` realized as four files written at the repository root.
- A summary value returning the character name, the list of registered skills, the list of skill-discovery errors, the count of hooks, and the path to the written settings file.
