A fabricator is the process that performs a fabrication: it reads an admitted work order and produces the artifact the order names, together with the evidence that it did so. In the corpus's own figure it occupies the ribosome's role in the cell: universal, interchangeable, and constitutionally blind to intent the message did not carry.

A fabricator differs from an author in that it is structurally interchangeable: a lathe, a print head, or an inference process, each blind to any intent the work order did not carry, so that swapping the fabricator while holding the order fixed changes the trace and the cost but not what counts as a faithful result. A fabricator that supplies missing intent has performed translation without a template, and the order, not the fabricator, is what gets corrected. The jsnode fabrication line's package-birth program is the Group's first code fabricator; the research-question document service is its first resource fabricator.
