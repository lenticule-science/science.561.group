# Computer Code Fabrication Science Services Section

This section holds the theory of fabricating code resources: things whose
bound claims are executable, so that a work order's requirements become a
program's pre-state and post-state and its fidelity can be assayed by running
it. It carries the language-neutral code-fabrication specification under
`content/text/documents/articles/specifications/`, which states what a code
work order must carry, what a fabricator must derive rather than be handed,
and what counts as an independent assay.

Language-specific theory lives in the children:
`javascript-code-fabrication-science-services-section` and, beneath it, the
Node operation-package theory. The engineering mirror is
`engineering-services-section/services/fabrication-services-section/services/computer-fabrication-services-section/services/computer-code-fabrication-services-section/`,
which holds the language-neutral admission services (artifact fabrication
specification, requirements basis) this theory describes.
