# Javascript Node Code Fabrication Science

Javascript Node Code Fabrication Science is a domain within Javascript Code Fabrication Science, concerned with the theory of fabricating JavaScript code targeting the Node runtime specifically.

In landed practice, `jsnode-package-services-section` fabricates a complete JSNode operation package only after staged import, command, help, test, syntax, and pack assays pass.

`capability-cell-fabrication-services-section` (the CapCell PDK) fabricates a deployable capability-cell bundle — kernel, schemas, package, repository, wallet, web identity, receipts — from a package.json manifest and a capcell-spec.json.
