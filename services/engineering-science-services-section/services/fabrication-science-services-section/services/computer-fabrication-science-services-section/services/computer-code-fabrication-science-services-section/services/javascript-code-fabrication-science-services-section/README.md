# JavaScript Code Fabrication Science Services Section

This section holds what is specific to fabricating JavaScript code resources:
ECMAScript modules as the unit of a fabricated thing, exports as its bound
executable claims, and the module graph as the routing the fabricator must
respect. It inherits the code-fabrication specification from its parent and
adds only what JavaScript changes about it.

`javascript-node-code-fabrication-science-services-section`. The engineering
