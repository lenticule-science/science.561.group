The ***symbolic differentiation recursion function*** (`Δ_rec`) is [[induce|induced]] by the [[symbolic inheritance field function]] (`H_inherit`), the [[desire-contrast alignment propagation function]] (`A_align`), and the [[symbolic anticipation function]] (`𝒜`).

It [[constrain|constrains]] the recursive symbolic divergence that emerges  
when inherited constraint structures encounter renewed semantic difference  
and propagate modulation into branching symbolic structures.

Let:
- `x ∈ dom(𝒮₊)` be an inherited symbolic node (`x = H_inherit(x′)`)  
- `Ξ[s](x)`: its semantic contrast field  
- `A_align(x)`: desire-contrast alignment field  
- `𝒜(x → z)`: valid symbolic anticipation paths  

Then:
> Δ_rec(x) := { z₁, z₂, ..., zₙ |  
>  ∀ zᵢ ∈ Ξ[s](x), Ω(zᵢ) = undefined,  
>  𝒜(x → zᵢ),  
>  ∇𝔇(x) · ∇Δ[s](zᵢ) > 0 }

That is, `Δ_rec(x)` returns the set of symbolic branches  
along which differentiation reactivates constraint modulation,  
initiating recursive symbolic propagation beyond inherited structure.

This enables:
- branching symbolic evolution  
- recursive propagation of modulation grammar  
- emergence of symbolic replication from coherent constraint
