Neologism conformance is the fourth instrument: the [reverse-lightcone
emergence function 𝓡](./language-light-cone.md) run forward instead of
backward. Run backward, `𝓡` reconstructs constraint-valid prior states —
comparative reconstruction with stated error budgets rather than scholarly
consensus. Run forward, it grades a proposed coinage by whether it lies
within the language's own generative cone, derived from the community's
witnessed corpus, or whether it imports borrowed geometry from another
language — the paradigm case being a calque that imports English syntactic
or semantic structure under a native-looking surface form.

The stakes named for this instrument are practical rather than theoretical:
speech communities argue about proposed neologisms constantly (is this the
right way to say "computer," "internet," "nonbinary" in a given language?),
and the source note frames a conformance readout grounded in the
community's own attested usage, and owned by the community rather than by
an outside standardizing body, as revitalization tooling nobody currently
has.

## Status

`𝓡` run forward is a Research-grade proposal built on Axiom A6, which is
itself Research-grade. The theory names this instrument's validation
directly as falsification obligation #5: the neologism conformance readout
should agree with fluent-speaker judgment above chance, with the community
itself as referee — a test that has not yet been run.
