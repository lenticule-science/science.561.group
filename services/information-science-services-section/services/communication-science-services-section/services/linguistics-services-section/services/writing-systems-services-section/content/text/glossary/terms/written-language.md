Written language is language that is presented using a [writing
system](./writing-system.md) — the original 2021 personal-glossary
definition, retained here unchanged. The pairing matters: a writing system
is the gauge chart ([script as gauge](./script-as-gauge.md)); written
language is what that chart produces when applied to an actual language —
the coordinates fixed, not merely available.

This section's added claim is that the *kind* of writing system used
changes what written language is capable of preserving, independent of the
spoken language underneath it: a [hanzi](./hanzi.md) text carries visible
formation-provenance (radicals, phonetic components) that a phoneme-gauge
written text of the same spoken language would not, because the phoneme
gauge does not coordinate that layer at all. Two written languages can
encode the same spoken language and differ in what they make legible about
its history — that difference is the gauge, not the underlying language.
