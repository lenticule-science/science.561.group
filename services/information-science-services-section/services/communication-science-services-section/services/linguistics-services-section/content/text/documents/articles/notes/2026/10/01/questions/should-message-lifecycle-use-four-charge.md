# Should message lifecycle use FOUR charge?

Current communicating and socializing code uses a message's FOUR charge as a transport lifecycle:

`potential` = in transit / unconsumed,
`active` = received / spent.

This is not the same mapping as the underlying relating bilattice, where potential is truth/support only and active is falsity/against only.

The existing embodied-handedness duality does not justify this transition. Player/Opponent duality swaps the coordinate roles `recv ↔ send` and `observe ↔ actuate` while preserving the charge carried at each coordinate; it does not negate or exchange potential and active.

The research question is therefore whether message transport has a proved representation into the FOUR algebra that has not yet been recovered, or whether transport lifecycle and epistemic polarity have been conflated.

Candidate alternatives to test include:

- a separate linear-resource lifecycle carrier with states such as in-transit / consumed;
- a product carrier `MessageLifecycle × FOUR`;
- a lawful polarity/duality morphism if one can actually be derived.

No change should be made until the intended invariant is recovered and tested, because current socializing `broadcast` / `attend` semantics depend on this distinction.
