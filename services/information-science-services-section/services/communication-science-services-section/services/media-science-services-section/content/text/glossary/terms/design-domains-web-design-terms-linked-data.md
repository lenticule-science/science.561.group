Linked data is a set of practices for publishing structured data on the web so that it can be interlinked with data from other sources and become more useful through those connections. The term and principles were articulated by [Berners-Lee](../../../../../../../knowledge-services-section/services/research-services-section/content/text/documents/articles/notes/tim-berners-lee.md) in 2006, building on the W3C&rsquo;s Resource Description Framework (RDF) and the broader vision of the semantic web.

The four principles of linked data are:

- Use URIs (Uniform Resource Identifiers) to name things.

- Use HTTP URIs so those names can be looked up.

- Provide useful information (using standards like RDF) when someone looks up a URI.

- Include links to other URIs so that people and machines can discover related things.

Linked data extends the web&rsquo;s architecture of hyperlinked documents to hyperlinked data. Where a hyperlink connects one page to another without specifying the nature of the connection, linked data triples connect entities through typed relationships: a person *authored* a book, a city *is located in* a country, a chemical *has [property](../../documents/articles/research/2026/07/31/humanities/domains/sociology/terms/property.md)* solubility.

Widely used [linked data](../../../../../../../knowledge-services-section/services/knowledge-systems-services-section/services/semantic-web-services-section/content/text/glossary/terms/linked-data.md) systems include Wikidata (the structured knowledge base behind Wikipedia), Schema.org (vocabulary for embedding structured data in web pages), and the Library of Congress&rsquo;s BIBFRAME format for bibliographic records [@heath_LinkedData_2011].
