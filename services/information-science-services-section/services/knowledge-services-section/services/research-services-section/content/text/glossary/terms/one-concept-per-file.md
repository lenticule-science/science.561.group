title: "One Concept Per File"
specialization: duty
description: "Each file contains exactly one concept — index files compose, content files don't"
attached-to:
  - writer
  - researcher
  - triage-processor
triggers:
  - content-creation
  - content-editing
actions:
  - Each file defines one thing
  - When a text introduces a new term, that term gets its own file
  - Index files compose through cross-reference
  - If a file does two things, split it
policy: 002
---


Policy 002 enacted as a duty. The fundamental unit of composition is one concept in one file. This is how the knowledge graph stays navigable as it grows.
