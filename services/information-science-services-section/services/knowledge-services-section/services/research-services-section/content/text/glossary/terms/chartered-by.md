# chartered-by

`chartered-by` names the body whose authority issues a ship's charter. Inversion populates `charters` at the chartering body so a query at a confederacy returns the ships whose charter it grants. Distinct from `commissioned-by` (who calls the ship into being) — the same body usually does both, but the predicates separate the acts so each can be revoked or transferred independently.
