# contributes-to-project

`contributes-to-project` is declared on a plan's frontmatter to name the project it serves. Inversion cascades emit the reciprocal `contributed-to-by-plan` claim at the project subject.

Note: inversion negates values — see `contributes-to-plan.md` for the same caveat.
