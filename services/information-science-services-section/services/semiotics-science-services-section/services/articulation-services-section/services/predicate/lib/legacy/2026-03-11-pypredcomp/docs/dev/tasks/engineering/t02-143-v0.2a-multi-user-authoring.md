# t02-143 — Fiber-cache reconcile routine

## Description

Spec and source-cite the **fiber-cache reconcile** routine that runs in boot Phase 3 (sub-phase 4.2) on every boot.
The routine walks `events.jsonl`, groups events by target entity, and for each entity compares its on-disk fiber cache to the event-log-derived expected state.
Stale caches are rebuilt from the event log; under no circumstances is the cache patched to match a stale state, because **the event log is the truth-source and the fiber file is a cache of it**.

The implementation seed exists at [`src/init_boot/fiber_reconcile.py`](../../../../src/init_boot/fiber_reconcile.py) (well-documented module docstring naming the three-step routine + the snapshot-update logic).
This task hardens it against the spec, ensures `PCC_PROJECTION_DIVERGED` is emitted only on the canonical conditions, and adds the conformance fixture.

- Per recipe 6 step 5: the in-memory fiber map of any entity whose projection diverged is discarded and reads rebuild on demand; no code path ever writes the *stale* cache content back as truth.
