## Grounding

## Description

`specs/packaging/nix-flake-spec.md` is the long-form target.
This task lands the v0.2b *skeleton*: a `flake.nix` at the pypredcomp repo root that produces a wheel via `nix build .#default`, and the gate that two builds on the same host produce a byte-identical wheel.
The full diverse-double-compilation defence is deliberately scoped out to v0.3 per the decision.

**What this consumes from v0.2a.** v0.2a's shipped kernel + stratified facts pipeline are the build *target* — the wheel packages the v0.2a-shipped Python code.
This task does not consume any v0.2b-internal task; it is the structural surface every later v0.2b task implicitly ships through, but it can land in parallel with them.
