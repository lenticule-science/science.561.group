# t02-34f — Multi-user authoring fixture (paired)

## Description

Per [decisions/fixture-authoring-paired-task.md](../../decisions/fixture-authoring-paired-task.md), every `t02-NN` task that ships normative substrate behaviour has a paired `t02-NNf` fixture-authoring task with its own conformance gate.
This is that pair for [t02-34](t02-34-v0.2a-multi-user-authoring.md).

The fixture lives at `tests/conformance/test_t02_34f_multi_user_authoring.py` and exercises the ship-target-#4 behaviour from [milestones/v0.2a-multi-user-single-node.md](../../milestones/v0.2a-multi-user-single-node.md):

- **Scenario leg** (`test_admin_asserts_member_retracts_observer_reads`) — provisions the 3-user admin/member/observer manifest via `ensure_users_from_manifest`, opens one session per role with the `ROLE_CAPABILITIES` defaults, and walks: admin asserts `(task:demo, status-open) = TRUE`; admin succeeds at the gated `set_current_scope` surface; member retracts the same predicate (paraconsistent monotonicity → `Both`); member also passes `set_current_scope`; observer reads via `stdlib.project` and is denied `set_current_scope` with `PCA_SCOPE_INSUFFICIENT` per [specs/filesystem/capability-permissions.md](../../specs/filesystem/capability-permissions.md) §6.4.
- **Determinism leg** (`test_scenario_replays_byte_identical`) — runs the full provision + scenario sequence twice on fresh substrates with deterministic session-slug generation and no `wall_clock_ns` injection, and asserts byte-identical `events.jsonl`.
