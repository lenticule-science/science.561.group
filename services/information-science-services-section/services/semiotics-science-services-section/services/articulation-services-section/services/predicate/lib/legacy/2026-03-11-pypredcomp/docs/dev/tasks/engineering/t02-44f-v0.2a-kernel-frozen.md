# t02-44f — Fuel-composition replay fixture (paired)

## Description

Per [decisions/fixture-authoring-paired-task.md](../../decisions/fixture-authoring-paired-task.md), every `t02-NN` task that ships normative substrate behaviour has a paired `t02-NNf` fixture-authoring task with its own conformance gate.
This is that pair for [t02-44](t02-44-v0.2a-kernel-frozen.md).

The fixture lives at `tests/conformance/test_t02_44f_fuel_composition_replay.py` and exercises the ship-target-#6 behaviour from [milestones/v0.2a-multi-user-single-node.md](../../milestones/v0.2a-multi-user-single-node.md) and the §5 conformance gates of [specs/kernel/fuel-composition.md](../../specs/kernel/fuel-composition.md):

- **Replay leg** (`test_respond_with_explicit_fuel_replays_byte_identical`) — runs the same two-respond scenario (assert `True` then assert `False`, raising a paraconsistent contradiction so a settlement cell is actually emitted) against two fresh substrates with an explicit top-level fuel ceiling `F = 256`, then asserts byte-equality of `events.jsonl`, byte-equality of every file under `$ROOT/cost/`, and equality of the returned `RespondResult.cell_id` / `cost_cell_id` / `outer_iterations`.
  The literal milestone gate is the events.jsonl line; the cost-ledger and result lines are anti-ratification anchors that catch a regression where a future cost-cell change adds `wall_clock_ns` to its body.
- **Cost-class leg** (`test_settlement_emission_is_per_respond_under_quantale`) — anchors §3 + §4.2 commitment #2 by asserting per-invocation semantics: the first (no-op) respond emits no settlement cell (fold-invariant under the additive quantale's unit `0`); the second (contradicting) respond emits exactly one settlement cell tagged with the additive quantale and a finite non-negative value.
  Per-invocation rather than per-aggregate so the test states what each respond produces.
- **Reads-are-free leg** (`test_query_total_cost_preserves_quantale_fold`) — anchors §3 + the [`cost-discipline-reads-free`](../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/cost-discipline-reads-free.md) theorem at the spec's actual level: `query_total_cost` does not change the entity's quantale-fold across a read.
  The spec permits read-class cells (they MUST contribute the additive unit `0`), so the fold is invariant whether or not they are materialised.

## Acceptance

- The fixture file exists, is collected by pytest, and all three tests pass against the current implementation.
- The fixture exercises the spec's claims (§1 composition law boundary, §3 cost-class assignments, §4.2 single-cell-per-respond commitment, replay determinism), not just incidental implementation behaviour, per [decisions/fixture-authoring-paired-task.md](../../decisions/fixture-authoring-paired-task.md) §"Why".
