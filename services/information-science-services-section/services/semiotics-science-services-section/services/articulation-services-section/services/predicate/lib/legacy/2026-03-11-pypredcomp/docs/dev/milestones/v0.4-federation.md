## Goal

Multi-node sovereign operation.
Two OS instances exchange events under the federation protocol; $\odot$-merge produces consistent fibers where peers agree and $\top$ where they disagree.
The OS edges into the broader fediverse via ActivityPub, into the broader Matrix federation via S2S, and supports selective sync and trust graphs across confederacy peers.

## Deliverable

- Two OS instances federate; modifications on one appear on the other; disagreements visibly produce $\top$.
- A 561 peer with their own OS instance can be chatted with over Matrix federation.
- A persona-agent post on a configured ActivityPub instance is visible from a Mastodon-compatible client.
- Trust graphs allow capabilities to flow across federation safely.

## Conformance gate

1. All v0.3 vectors pass.
2. Two-node federation: write on node A, observe on node B; $\top$ on configured disagreement.
3. ActivityPub: publish a Note from the OS; observe it from a stock Mastodon instance.
4. Matrix S2S: send a message from the OS's homeserver to matrix.org's homeserver and back.
5. Selective-sync: peer A receives only events scoped to predicates A subscribes to.
6. GitHub Issues round-trip: per `t04-51`, the round-trip fixture passes; webhook signature rejection works; rate-limit backoff observed without driver failure transition; bilattice $\top$ surfaces on concurrent OS-side and GitHub-side title edits.
