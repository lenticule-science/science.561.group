# Milestone v0.7 — 561 group productivity stack

## Position in hierarchy

- Of campaign: [campaigns/ship-pypredcomp.md](../campaigns/ship-pypredcomp.md)
- Decomposes into goal: [goals/v0.7-productivity-stack-replaces-saas.md](../goals/v0.7-productivity-stack-replaces-saas.md)

## Goal

The captain's daily-driver replacement layer ships as a coherent set of applications: tasks, knowledge, governance, dispatch, fleet, review.
The captain migrates from external SaaS tools (Asana/Todoist/Linear/Obsidian/RFC-trackers) to substrate apps.
These are user-stack apps written *on* the OS using the v0.6 SDK; they are not OS components.

## Specs read

- All v0.6 specs.
- Each app's spec lives in its own project directory under `operations/command/projects/<app-slug>/`.
  The sprint references but does not specify these.

## Decisions in scope

All v0.6 decisions; per-app decisions live in the app's own project.

## Tasks (intra-milestone implementation slices)

Task families:

- **Tasks app** (`t07-01..t07-05`): plans/tasks/milestones/board view; dispatch integration; hledger-style reporting; SaaS migration; GitHub Issues integration.
- **Knowledge app** (`t07-10..t07-13`): library browser; search; monograph builder; cell linking + back-linking.
- **Governance app** (`t07-20..t07-24`): charter compliance; ADR workflow; vote/proposal flow; decision register; triage workflow surface (against an inactive pipeline; pipeline ships at v0.8).
- **Dispatch app** (`t07-30..t07-32`): office × task fiber composition; auto-dispatch daemon; rationale UI.
- **Fleet app** (`t07-40..t07-42`): sessions/agents/runbooks dashboard; real-time view; agent health metrics.
- **Review app** (`t07-50..t07-52`): failure analysis; observation log; instinct evolution UI (v0.9 preview).

## Deliverable

- A v0.7 OS image with the productivity stack apps installed.
- The captain has migrated daily task management from external tools to the tasks app.
- The captain's daily knowledge browsing happens in the knowledge app.
- An ADR is filed and approved through the governance app.

## Conformance gate

1. All v0.6 vectors pass.
2. The captain accomplishes a full week of work using only the productivity stack on the OS.
3. The captain migrates one external SaaS tool (Asana, Todoist, etc.) fully and decommissions the external account.

## Out of scope (deferred)

- Agential layer beyond fleet's monitoring view (v0.8).
- Continuous learning pipeline (v0.9).
- Self-developing OS (v1.0).
