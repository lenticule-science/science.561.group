## Description

The `project` verb is the substrate's `ls` / `grep` analogue — filter cells by predicate pattern, return matches.
The spec is normative; this task is the Python implementation that the dispatch shell calls.

**What this consumes from v0.2a.** v0.2a shipped the projection pipeline (stratified facts, `project_stratum`, `materialize_by_stratum_projections` per row 4 of theory-for-developers) and the cell record format.
`project` is a thin verb over those — pattern-match against cells in the projected stratum, respecting projection naturality.
Without v0.2a's projection naturality, `project` could return cells that have leaked across stratum boundaries.
