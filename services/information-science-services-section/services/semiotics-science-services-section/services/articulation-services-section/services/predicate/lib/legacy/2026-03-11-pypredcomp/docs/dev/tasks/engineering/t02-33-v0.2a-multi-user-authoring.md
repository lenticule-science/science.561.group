# t02-33 — Inter-session messaging plumbing

## Description

Wire inter-session messaging across users on the single node, per the multi-regime-session discipline.
A message from user A's session to user B's session is structurally a `respond` whose target is B's session-inbox entity and whose `sender` is A's boundary; A's authz fiber composes via $\Rightarrow$ in Phase 2 before the cell lands in B's inbox.
The receiving session's regime envelope governs what kind of cell is admissible — strict-regime sessions accept endpoint state; transfinite-bounded accept trajectories; aperiodic accept truncation-trajectories.

The implementation seed already exists at [`src/process/session_messaging.py`](../../../../src/process/session_messaging.py); this task hardens it against the multi-regime-session spec, ensures the sender's authz fiber actually restricts cross-session writes, and adds the conformance fixture.
