## Goal

The captain's existing harness machinery (Claude Code / Codex / specialist offices / observe→instinct→skill→tool→hook progression) lifts onto the OS as substrate-resident entities.
Sessions are OS-level processes; persona-agents author content under their own names through the OS; offices have formal capability fibers; Voidfleet Academy trains new agents through the OS.

This release operationalises the agential-orchestration-platform theory's full surface.
