## Grounding

[decisions/cheapest-sufficient-computation-tier](../../decisions/cheapest-sufficient-computation-tier.md) names the tier-routing principle: route a predicate request to the cheapest tier sufficient to discharge it.
The Tier-2 registry is the substrate-resident lookup table that *makes* this principle deterministic — without it, "cheapest sufficient" is a hand-wave.
Library grounding:

- [`graded-dispatch-via-q-enriched-fusion`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/graded-dispatch-via-q-enriched-fusion.md) — dispatch is a $Q$-enriched fusion over the predicate-signature space; the registry IS the fusion table for Tier 2.
- [`cell-set-fold-as-graded-dispatch-specialization`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/cell-set-fold-as-graded-dispatch-specialization.md) — the dispatch specialises by folding over the registry's cells; the spec must record that the registry is *itself* a substrate cell-set, not an external table.

## Description

OPEN-SPEC.
The Tier-2 registry lookup is the spec that makes "route to the cheapest sufficient model" deterministic.
The reflex implementation would be an external YAML config the kernel reads at boot.
The substrate's discipline is that the registry IS substrate cells: each model record is a cell `(model-record:<id>, signature, <predicate-signature>) = t` plus companion cells naming family, fiber-capacity, calibration cell-id (per `t02-204`), supersession chain.

**What this consumes from v0.2a + v0.2b.**

- v0.2a `t02-42` (kernel-shipped bilattice ops) supplies the bilattice-graded dispatch primitive — the registry's "sufficient" check is bilattice-graded, not boolean.
- v0.2a closure-rule discipline (the saturation engine the dispatch shell inherits) supplies the lookup-as-fold pattern.
- v0.2b `t02-100`/`t02-102` (stdlib + dispatch shell) supplies the dispatch entry-point this spec configures.
- v0.2b `t02-204` (calibration spec) supplies the per-model calibration cell shape this spec references.
