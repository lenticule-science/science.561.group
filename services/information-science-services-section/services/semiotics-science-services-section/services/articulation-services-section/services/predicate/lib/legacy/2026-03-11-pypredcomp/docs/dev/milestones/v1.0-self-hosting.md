# Milestone v1.0 — Self-developing OS

## Position in hierarchy

- Of campaign: [campaigns/ship-pypredcomp.md](../campaigns/ship-pypredcomp.md)
- Decomposes into goal: [goals/v1.0-self-host.md](../goals/v1.0-self-host.md)

## Goal

Agents inside the OS write OS code.
The OS develops itself: agents read the substrate's source cells, propose modifications, run conformance vectors, and submit changes through the governance app for captain review.
The OS image at v1.0 is built using only substrate events from the v0.9 → v1.0 development cycle.

## Specs read

- All v0.9 specs.
- The OS's own source tree, loaded as substrate cells per v0.2's self-hosting work.

## Decisions in scope

All v0.9 decisions plus (new for v1.0): self-development-is-the-natural-mode, captain-reviews-via-governance.

## Tasks (intra-milestone implementation slices)

Task families:

- **Self-development workflow** (`t10-01..t10-06`): agent reads task → identifies source cells → proposes closure-rule edit → vectors run → governance proposal → captain approves → merge.
- **Bootstrapping discipline** (`t10-10..t10-12`): no external compiler/editor/test infrastructure; substrate source fully introspectable + editable from inside; build pipeline runs entirely on the OS.
- **The OS runs itself** (`t10-20..t10-22`): real captain-priority feature shipped by an inside agent; 30 consecutive days of self-development; v1.0 image build provenance shows only substrate events.

## Deliverable

- A v1.0 OS image that develops itself.
- A real captain-priority feature was implemented entirely by agents inside the OS.
- 30 days of consecutive self-development without external dev tools.

## Conformance gate

1. All v0.9 vectors pass.
2. End-to-end self-development cycle demonstrated.
3. v1.0 image build provenance shows only substrate events; no external invocation.
4. Captain attests to having reviewed and approved at least 10 substantive changes through the governance app during the v0.9 → v1.0 cycle.

## Out of scope

- Anything beyond v1.0.
  The captain decides what 561 group computing looks like next; the OS supports them.
