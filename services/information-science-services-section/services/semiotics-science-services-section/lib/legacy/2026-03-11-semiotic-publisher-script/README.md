# `ssc-universe` (SSCU)

This directory is intended to be a standalone Python toolchain for evaluating and publishing a **Stewardable Semiotic Concept Universe (SSCU)**.

## Local development

- Run the CLI without installing:
  - `PYTHONPATH=src python -m ssc_universe.cli --help`
- Run tests:
  - `pytest`

## Installation

- Editable install:
  - `python -m pip install -e .
    `
- Then:
  - `sscu --help`
