## Grounding

Theory row 4 (stratified facts) and row 1 (bilattice value domain) of [references/theory-for-developers.md](../../references/theory-for-developers.md).
`filter` refines a fiber by a predicate value — given a fiber, retain only the cells whose value matches a bilattice predicate.
Critically, "matches" is bilattice-valued (`t`, `f`, `⊥`, `⊤`), not boolean: filter MUST handle `⊥` (unknown) and `⊤` (contradictory) explicitly per spec, never collapse them to false.

## Description

`filter` refines the result of a `project` call (or any fiber) by a value-predicate, returning the sub-fiber matching the predicate.
The spec is normative; this task is the Python implementation.

**What this consumes from v0.2b + v0.2a.** [`task:t02-100`](t02-100-v0.2b-stdlib-and-dispatch-shell.md) (`project`) is the typical upstream verb — `filter` consumes a fiber `project` produced. v0.2a's settled bilattice algebra (row 1 of theory-for-developers) is the value-comparison primitive; without it, `filter` cannot correctly handle `⊥` and `⊤` predicates.

The bilattice-value handling is the failure surface — treating `⊥` as `false` is the row-1 anti-pattern that the [pypredcomp AGENTS.md](../../../../AGENTS.md) discipline forbids; the verb MUST surface unknown / contradictory results explicitly to the caller.
