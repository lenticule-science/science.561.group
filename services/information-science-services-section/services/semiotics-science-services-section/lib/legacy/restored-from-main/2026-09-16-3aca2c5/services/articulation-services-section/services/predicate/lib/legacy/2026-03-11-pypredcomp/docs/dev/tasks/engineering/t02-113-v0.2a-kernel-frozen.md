## Cancellation rationale

Cancelled per captain's hard rule "no inventing features; decide from theory".
The substrate's stratum lattice is enumerated normatively in [specs/kernel/stratified-facts.md](../../specs/kernel/stratified-facts.md) §1 as exactly three strata — `asserted ⊑ saturated ⊑ settled`.
There is no `retracted` stratum.
Retraction is not a fourth stratum; it is the **inconsistency-repair lifecycle** specified in [specs/kernel/inconsistency-repair.md](../../specs/kernel/inconsistency-repair.md) and decomposed in v0.2a as `t02-120` … `t02-126`.
A cell whose evidence is repaired retains its existing stratum and is reflected in the witness fields (`derived_from`, `derived_via`) and in the inconsistency-repair event stream — not by promotion to a separate "retracted" sub-presheaf.

Authoring a fourth by-stratum projection file would require:

- Adding `"retracted"` to `KNOWN_STRATA` in [`src/substrate/projection.py`](../../../src/substrate/projection.py) — contradicting `stratified-facts.md` §1.
- Defining what cells qualify for it — no theoretical source defines such a predicate.
- Materialising a `by-stratum/retracted.json` file — no spec defers from this.

All three would constitute inventing a feature with no theoretical anchor.
The retraction story is owned by the t02-12X family; this task is theory-rejected.
