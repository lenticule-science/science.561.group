## Grounding

Theory row 13 (self-representation everywhere) and row 8 (capability/authz as modal restriction) of [references/theory-for-developers.md](../../references/theory-for-developers.md).
A skill is a substrate cell (`kind = "skill"`); the schema is its content-addressed encoding contract.
Per [decisions/canonical-json-conventions.md](../../decisions/canonical-json-conventions.md) and [decisions/content-hash-via-sha256.md](../../decisions/content-hash-via-sha256.md), the schema MUST validate canonical-JSON byte-form, not arbitrary JSON.

## Description

Author `boot/schemas/skill-spec-v1.schema.json` — a JSON Schema (Draft 2020-12) describing the v1 skill-record encoding.
This is the schema `pt-13` (operational skill packs) builds skill records against, and the schema the agential dispatch-shell validates against at registration time.

**What this consumes from v0.2a.** v0.2a shipped the cell record format ([specs/filesystem/cell-record.md](../../specs/filesystem/cell-record.md)) and the canonical-JSON convention; this schema is a JSON-Schema projection of the skill-cell shape that already serializes through the v0.2a canonicalization pipeline.
The schema is *derived from* the cell shape, not a parallel encoding.

**Spec citations.**

- [specs/agential/skill-registry.md](../../specs/agential/skill-registry.md) — the skill-record fields the schema encodes.
- [specs/agential/_index.md](../../specs/agential/_index.md) — agential surface index.
- [decisions/canonical-json-conventions.md](../../decisions/canonical-json-conventions.md) — the schema validates canonical bytes.

**Procedure.** Follow [implementation/workflows.md recipe 1](../../implementation/workflows.md#1-landing-a-v02a-task-end-to-end).
The schema is the source-of-truth; the Pydantic model is a projection of the schema, never the other way around.
When the schema and model disagree, the schema is right (per the [pypredcomp AGENTS.md](../../../../AGENTS.md) discipline that specs outrank code).

**Ship-target role.** Contributes to gate item 3 of [milestones/v0.2b-drivers-observability-packaging.md §Ship targets](../../milestones/v0.2b-drivers-observability-packaging.md) — "the stdlib dispatch shell exists and every verb's per-verb fixtures pass."
Skills are the operational unit the dispatch shell loads; without a settled schema, the shell's loader has no contract to check against.

**Depends on.** None at the v0.2b boundary.
Coordinate with `pt-13` (operational skill packs first batch) — this schema is the contract `pt-13` writes its packs against, so `pt-13` is downstream of this task.
