## Description

Round 4 §2.1 named the cross-cutting pattern-extraction candidate `_patterns/heartbeat-fiber-subscription.md` that composes:

- Round-3 §1.5 (cross-shell coherence — the discipline that two shells subscribed to the same substrate fiber see coherent state per heartbeat tick).
- Round-3 §2.1.1 (heartbeat fan-out as a single algebraic surface — every per-tick consumer subscribes through the same fiber-subscription primitive).
- Round-4 §1.6 (dashboard-refresh as fiber subscription — the dashboards consume the same primitive).

All three consuming specs land in the same v0.2b slice; round 4 named extraction in that slice as the natural shape.
This task authors the extraction.

The pattern records:

1. The fiber-subscription primitive shape (subscribe-to-fiber returning a per-tick view).
2. The heartbeat-driven coherence guarantee (all subscribers to the same fiber observe the same state at the same tick).
3. The cost discipline (subscriptions are quantale-unit reads per [`cost-discipline-reads-free`](../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/cost-discipline-reads-free.md)).
4. The per-class instantiation list (cross-shell unread surface; dashboard refresh; future heartbeat-driven consumers).
5. Conformance gates parallel to [`_patterns/witness-lifecycle.md`](../../specs/_patterns/witness-lifecycle.md) §4.

`status: draft` per the round-4 extraction discipline; promotion to `normative` happens when the first consuming spec ([t02-71](t02-71-v0.2b-dashboard-as-fiber-subscription.md), or the cross-shell coherence spec from round-3 §1.5) cites the pattern.
