## Description

Round-4 §1.8 named *pattern-cross-citation-discipline*: when a per-class spec instantiates a pattern (e.g., a witness emitter spec instantiates `witness-lifecycle.md`'s §2 table), there is no enforced cross-citation back.
The discipline is documented today only by `_patterns/_index.md`'s §"Why patterns matter" preface, not by a per-pattern conformance gate.

**What this consumes from v0.2a + v0.2b.**

- v0.2a substrate cell-shape discipline supplies the cell encoding for the citation cells.
- v0.2b `t02-82` (admin witness citation) is the *first set of consumers* — the admin specs cite `witness-lifecycle.md`; this task generalises the discipline to all patterns.
- v0.2b `t02-72` (heartbeat-fiber-subscription pattern extraction) is the second source pattern; this task adds the §"Pattern instances" to the new pattern file too.

**Spec citations.**

- Pattern index: [`specs/_patterns/_index.md`](../../specs/_patterns/_index.md).
- Per-pattern files: witness-lifecycle, approval-flow, anomaly-as-contradiction, hierarchy-and-supersession, time-predicates, closure-rule-activation, predication-category-grounding, principal, substrate-entity-records, and the t02-72-extracted heartbeat-fiber-subscription.

**Modules to touch.**

1. [`specs/_patterns/_index.md`](../../specs/_patterns/_index.md) — add §"Conformance" naming the bidirectional-citation requirement; name the cell shape `(spec:<X>, instantiates-pattern, pattern:<Y>) = t`.
2. Each per-pattern file under `specs/_patterns/` — add §"Pattern instances" listing consuming specs.
3. Document the deferred closure rule that asserts the cross-citation symmetrically (the rule itself is v0.7+ work; this task records the discipline only).

**Procedure.** Follow [implementation/workflows.md recipe 10](../../implementation/workflows.md#10-promoting-a-thin-t02-nn-task-record-into-a-procedural-plan).
For each per-pattern file: (a) walk the corpus for `instantiates X` or citation of the pattern; (b) list the consumers in §"Pattern instances"; (c) confirm bidirectionality.

**Ship-target role.** Pre-condition for the v0.2b pattern-coherence gate.
Without it, future agents will instantiate patterns without citing back, and the substrate cannot answer "who consumes pattern X?".

**Depends on.** None.
Pairs closely with [`task:t02-82`](t02-82-v0.2b-admin-workflow-witness-citation.md) (the admin specs are the witness-lifecycle pattern's first consumers).
