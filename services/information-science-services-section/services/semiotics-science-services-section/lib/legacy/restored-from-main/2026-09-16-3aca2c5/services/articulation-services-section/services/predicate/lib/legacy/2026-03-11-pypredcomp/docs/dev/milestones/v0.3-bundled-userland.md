## Goal

The OS ships with a standard userland in the base image.
The captain can use the OS for daily email, calendar, chat, file management, text editing, terminal work, calculation, and accounting — the things any general-purpose OS provides as built-in clients.

This release brings the OS to "daily-driver-replacement-ready" for the captain's at-the-keyboard work.
(Productivity-stack apps — tasks, knowledge, governance — are deferred to v0.7.)

## Deliverable

- A v0.3 OS image with the bundled userland.
- The captain reads and replies to a real email through the OS.
- The captain accepts a calendar invite through the OS, sees it on their CalDAV-published calendar.
- The captain chats with a 561 peer (or an external Matrix user) over the chat client.
- The captain edits one of their own substrate cells in the text editor and saves it.
- The captain computes a balance in the ledger tool against their existing hledger journals.
- The terminal, calculator, and file browser work for the captain's at-the-keyboard operations.

## Conformance gate

1. All v0.2 vectors pass.
2. The IMAP driver passes a test against an RFC 9051-conformant server (e.g., Dovecot in CI).
3. The SMTP driver passes a test against an RFC 5321-conformant server (e.g., Postfix in CI).
4. The CalDAV driver passes a test against an RFC 4791/6638-conformant server (e.g., Radicale in CI).
5. The Matrix client passes the matrix-test-suite (https://github.com/matrix-org/sytest or matrix-rust-sdk's tests).
6. The hledger driver round-trips a real hledger journal byte-identically.
7. The captain accomplishes one daily task end-to-end through the OS that the previous version could not support.
8. The TUI inbox panel (t03-90) renders unread session messages within one heartbeat tick of authoring; mark-read removes them from the panel on the next tick.
9. The streaming-output panel (t03-92, t03-93) renders subprocess output live; a session whose subprocess emits 1 MB of mixed UTF-8 text and ANSI escape codes renders without dropped chunks and without split codepoints.

## Out of scope (deferred)

- Federation between OS instances beyond what Matrix provides (full S2S federation is v0.4).
- Application development surface (no SDK for third parties — that's v0.6).
- ICS bindings (no MQTT, Modbus — that's v0.5).
- Productivity-stack apps (no tasks, knowledge, governance — that's v0.7).
- Persona-agents as authoring entities (that's v0.8).
