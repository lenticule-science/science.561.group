## Grounding

[decisions/skills-have-manifest-contracts](../../decisions/skills-have-manifest-contracts.md) — skills are content-addressed manifested capabilities; a skill pack is a bundle of manifest-conformant skills addressing one operational domain.
Library grounding:

- [`closure-rule-system-realizes-closure-2-monad`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/closure-rule-system-realizes-closure-2-monad.md) — skill packs ARE closure-rule families; each skill is a closure rule whose firing condition is the manifest's invocation predicate.
- [`witness-as-cell`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/witness-as-cell.md) — every skill firing emits a witness cell; the manifest's `emits` field declares the witness shape ahead of firing.
- [`umwelt-as-fiber-projection-with-coherence`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/umwelt-as-fiber-projection-with-coherence.md) — a skill pack defines an *umwelt* for the office consuming it: the skills the office can see and invoke, projected from the universal skill set by office-membership predicates.

## Description

The substrate's stdlib + dispatch shell is empty without skill packs to dispatch to.
By reflex the v0.2b implementer would author skills inline in test files.
The substrate's discipline is that skills are first-class manifest-conformant artefacts, content-addressed, replayable, with witness-emission shape declared up-front.

This task authors the *first batch* of operational skill packs — the minimum surface a v0.2b operator can do useful work against.
The batch is sized small (3–5 packs) and chosen for high-leverage operational domains: each pack covers one common operator workflow.

**What this consumes from v0.2a + v0.2b.**

- v0.2a closure-rule discipline (shipped) supplies the firing-condition primitive each skill manifest declares.
- v0.2a witness-cell discipline (shipped) supplies the emits-shape primitive.
- v0.2b `t02-23` (skill-spec-v1.schema.json + dispatch shell) supplies the manifest schema each pack conforms to.
- v0.2b `t02-100`/`t02-102` (stdlib + dispatch) supplies the invocation surface the packs are dispatched through.

**Spec citations.**

- Skill manifest schema: [`boot/schemas/skill-spec-v1.schema.json`](../../../../boot/schemas/skill-spec-v1.schema.json) (created by `t02-23`).
- Skill registry: [specs/agential/skill-registry.md](../../specs/agential/skill-registry.md).
- Stdlib + dispatch shell: see `t02-100`/`t02-102`/`t02-23`.

- Theory ground: rows 5 (closure rules) and 6 (projections) of [references/theory-for-developers.md](../../references/theory-for-developers.md).

**Modules to touch.**

- `.local/skills/<pack-name>/SKILL.md` for each pack (3–5 packs); each conforming to `boot/schemas/skill-spec-v1.schema.json`.
- `operations/engineering/skills/<pack-name>/SKILL.md` for the engineering-domain packs.
- [`specs/agential/skill-registry.md`](../../specs/agential/skill-registry.md) — add §"v0.2b first batch" listing the packs and their manifest hashes.
- [`tests/conformance/test_skill_pack_manifests.py`](../../../../tests/conformance/) — paired conformance test (`t02-205f`) asserting each pack's manifest validates against the schema and each declared witness cell-shape parses.

**Procedure.** For each pack: (1) draft `SKILL.md` with the manifest frontmatter; (2) run the schema validator from `t02-23`; (3) author 1–3 worked examples in the body; (4) register the pack's content-addressed hash in `specs/agential/skill-registry.md`; (5) extend `test_skill_pack_manifests.py` with the new pack.
Follow [implementation/workflows.md recipe 4](../../implementation/workflows.md#4-adding-or-extending-a-stdlib-verb) as the closest existing recipe (a skill is structurally a stdlib verb with extra metadata).

**Pack selection (proposed).**

1. `replay-debugging` — operator workflow for diagnosing replay divergence (per recipe 7).
2. `witness-trail-walk` — operator workflow for walking back from a surprising cell to its derivation (consumes `t02-75` diagnostic-projection).
3. `cross-shell-handoff` — operator workflow for handing off attention between TUI/web/headless shells (consumes `t02-73` cross-shell coherence).
4. `ship-target-witness-emission` — operator workflow for declaring a ship target satisfied with structured witnesses.

Confirm pack selection with captain before authoring.

**Ship-target role.** Discharges the v0.2b "operator can do useful work" gate.
Without this batch, the v0.2b shell + stdlib are technically functional but operationally bare.

**Depends on.** [`task:t02-23`](t02-23-v0.2b-stdlib-and-dispatch-shell.md) (manifest schema + dispatch shell — the schema each pack conforms to), [`task:t02-75`](t02-75-v0.2b-diagnostic-projection.md) (the witness-trail-walk pack reads `project_derivation`; pack cannot land before the projection), [`task:t02-73`](t02-73-v0.2b-cross-shell-coherence.md) (the cross-shell-handoff pack reads the cross-shell coherence discipline; pack cannot land before the spec).
