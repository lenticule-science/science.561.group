## Description

Pin gate item 3 of v0.2a's ship targets: `bootstrap_users` and `fiber_reconcile` boot-phase routines exist and produce **divergence-free reconcile against a ≥3-user manifest**.
This task is the assertion that the routines compose correctly across multiple users — bootstrapping three users, exercising authoring across them, then rebooting MUST produce no `PCC_PROJECTION_DIVERGED` and a byte-identical fiber state to before the reboot.

This is the **end-to-end multi-user boot determinism gate**.
It exists separately from the per-routine tasks (`t02-140`, `t02-141`, `t02-143`) because composition can fail even when the parts pass — a per-user routine that's individually deterministic can compose non-deterministically if iteration order across users is unsorted (per [implementation/workflows.md recipe 7 step 2](../../implementation/workflows.md#7-debugging-non-deterministic-replay)).

**Spec citations.**

- [specs/init-boot/boot-sequence.md §4.1, §4.2](../../specs/init-boot/boot-sequence.md) — the two routines this task gates.
- [specs/kernel/projection-naturality.md](../../specs/kernel/projection-naturality.md) — divergence-freeness IS the naturality square commuting after rebuild.
- [decisions/event-log-is-jsonl.md](../../decisions/event-log-is-jsonl.md), [decisions/event-ordinal-is-time.md](../../decisions/event-ordinal-is-time.md) — the determinism substrate.
- Theory grounding: row 12 (boot sequence and the four-layer rule architecture) of [references/theory-for-developers.md](../../references/theory-for-developers.md).
  Engineering theorem: [`predicated-computing/theorems/boot-determinism`](../../../../../../../../../theories/engineering/theories/tech/theories/computing/theories/predicated-computing/theorems/boot-determinism.md) — boot is a deterministic function of (deployment image, persistent set), even when the persistent set has multiple users.

**Modules to touch** (proposed; confirm exact file boundaries with captain when picking up).

  If a `dict` over users is iterated unsorted, fix it.
  This is exactly the bug recipe 7 step 2 names.
- [`tests/conformance/`](../../../../tests/conformance/) — primary deliverable is the multi-user boot-and-reboot conformance test (paired with `t02-144f`).
  The existing [`test_t02_145f_bootstrap_reconcile_joint.py`](../../../../tests/conformance/test_t02_145f_bootstrap_reconcile_joint.py) is the closely-related joint fixture (`t02-145`); coordinate with `t02-145` to avoid duplication — this task's fixture is the divergence-free assertion specifically, while `t02-145` is the broader joint exercise.
