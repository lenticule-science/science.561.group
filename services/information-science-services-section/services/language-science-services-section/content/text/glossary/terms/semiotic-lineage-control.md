**Semiotic Lineage Control (SLC)** names the 561 Group's proposed version-control discipline for *articulated changes*: distinguish what source bytes were revised, which situated `(token, claim)` utterance they witness, which prior changes they depend on, which independent witnesses support or oppose them, and whether an independently authorized consumer has received their effects. A Git commit, source path or PR is a provenance carrier, not the proposition or a legal power.

**Finite foundation.** A candidate history is a set of immutable, source-addressed change events with an acyclic, partially observed dependency relation. For each context-indexed articulation, retain positive and negative witness sets independently. Their mere non-emptiness projects to the existing Obsmetrologia/FOUR knowledge reading; no missing witness is automatically negative evidence. Union of event identities is commutative, associative and idempotent; this does not establish semantic commutation of concurrent changes. Different source objects and competing attempts to consume the same linear resource remain explicit *source divergences or resource disputes*, with neither history discarded. Authored event-parent relationships are situated claims, not authenticated Git commit ancestry: a fork/sequence classification requires independently observed commit roots and Git history. A changed file in a genuinely sequential history remains a distinct version, not automatically an unresolved concurrent conflict.

**Limits and proof obligations.** Structural Git-tree verification is conditional on the authentic source commit/root binding; a matching SHA or NI does not validate a person's authority, an interpretation, source rights or independent receiving. Resource *use claims* are not resource expenditures. Finite dependency depth is a natural-number ranking, **not** a proven transfinite grade. The June 14, 2026 [Obsmetrologia research memo](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/verso/mark/content/utterance/articulating/content/articulation-cell/content/potential-articulation-cell/predicating/content/predication-cell/content/potential-predication-cell/positing/content/pre-bilattice/content/bilattice/references/paraconsistent-transfinite-linear-logic-memo.md) proposes a paraconsistent, transfinitely-valued linear synthesis; a complete cut-elimination, ordinal-limit, monoidal resource and semantically faithful source/utterance correspondence remains to be proved. Do not identify Pijul/Darcs patch commutation with a theorem about SLC without a structure-preserving map.
