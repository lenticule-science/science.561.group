# Library Science Services Section

Library and information science as applied to digital text collections:
what a digital library is and how it differs from a database or a file
archive; how a collection decides what it holds; how many independent
copies keep a corpus safe against loss, and how that differs from an
ordinary backup; how a reader discovers and downloads a publication
programmatically; how a source-markup format becomes many delivered
formats, including a print-ready imposed booklet; how a repository
proves, over time, that what it holds remains readable and intact; how
a collection describes its own holdings so other systems can find them;
and how one holding gets copied to another host for resilience.

This section's material sits beside, and does not replace, the
[knowledge-organization services section](../knowledge-services-section/services/knowledge-organization-services-section/README.md),
which owns classification, ontology, and vocabulary theory generally
(including library classification schemes as an instance of that
theory). This section is narrower: it studies the digital library as an
operating system for a text collection — ingestion, formats, discovery,
preservation, and mirroring — not the classification theory a library
might use internally.

Its material is organized by artifact role under `content/`, following
the [science topic section model](../../../../../561-group-services-section/services/561-group-science-services-section/content/text/documents/articles/specifications/2026-08-30-science-topic-section-model.md).
