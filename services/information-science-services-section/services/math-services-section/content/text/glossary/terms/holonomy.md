It is undetectable from any single point or fiber; it is a genuinely global invariant, visible only by tracing a loop."

Classically, holonomy arises from a connection on a fiber bundle: transport
a vector (or more general fiber element) along a path using the connection,
and if the path is a closed loop back to its starting point, the
transported element need not equal the one you started with. The
discrepancy is an element of the bundle's structure group, and the set of
all such discrepancies, over every loop based at a point, forms the
*holonomy group* at that point. For a flat connection — zero curvature —
holonomy depends only on a loop's homotopy class, not its exact shape, so
flat connections modulo gauge equivalence are classified by group
homomorphisms out of the [fundamental group](./fundamental-group.md):
`Hom(π₁(X), G)`. This is why holonomy is inseparable from cohomology: a
non-trivial holonomy around a loop is exactly a non-vanishing class in the
cohomology that classifies flat `G`-bundles, `H¹` with coefficients in `G`.

A gauge-theoretic reading generalizes this to any structure group acting on
a fiber, not only orthogonal or unitary groups on vector bundles. Where the
fiber is a four-valued [bilattice](./bilattice.md) rather than a vector
space, the relevant structure group is the bilattice's own automorphism
group — generated by negation and converse — and a connection is a functor
from the base category into that group's one-object groupoid (its
classifying groupoid). Holonomy in this setting is exactly the classical
story transposed: it is only ever detectable by tracing a loop in the base
category (a round trip through converse and projection operations that
returns to its starting object without the fiber data returning to its
starting value), never visible by inspecting any single fiber in isolation.
A non-trivial holonomy of this kind is a genuine, structural obstruction —
not a bookkeeping error to be normalized away, but a twist that must either
be cancelled by a further transformation or accepted and recorded as a
permanent feature of the space it lives in.
