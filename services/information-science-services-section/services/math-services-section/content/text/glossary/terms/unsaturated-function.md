An unsaturated function is Frege's (1879) name for what a predicate is: a function that takes a subject and returns a value, so that a subject-predicate-object triple is function application, P(S) = O — the predicate is unsaturated because it has an argument position not yet filled, not because it is somehow incomplete as an object. The corpus's own algebraic reading sharpens this: a predicate is unsaturated not because it lacks some slot but because some slots in its fiber are at bottom, the bilattice's unattested value: planning, for instance, produces entities whose fibers commit some predicates to true and leave others at bottom until dispatch and execution saturate them.

This distinguishes an unsaturated function from the predicate object itself: the predicate category's predicate term names a structural element occupying the middle coordinate of a predication cell, a fixed object; unsaturation is a property of that object's argument positions being open, and saturating an unsaturated predicate is itself a named act (predicating) that a work item performs over time, not a static property the predicate carries once and for all.

The engineering consequence, stated in the house's own RFC-RMN reading of force: a founder utterance interpreted into a subject-predicate-object triple must leave its unsaturated slots open rather than have an agent guess them, because predication with a weighted, unsaturated predicate forces exactly four cells (each argument position independently saturated or not), and planning is exactly the production of that unsaturated form for later stages to fill.
