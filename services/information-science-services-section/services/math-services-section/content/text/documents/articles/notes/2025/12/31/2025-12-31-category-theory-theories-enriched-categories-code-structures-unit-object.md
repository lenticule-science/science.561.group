The unit object I in a [monoidal category](../../../../../../glossary/terms/monoidal-category.md) is the object that acts as an identity for the [tensor product](../../../../../../glossary/terms/tensor-product.md): I ⊗ A ≅ A ≅ A ⊗ I for every object A, via coherent [isomorphisms](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/tensoring/content/monoidal-category/scripts/uniting/content/ordinary-categories/morphisms/isomorphism.md). It is the categorical analogue of the [identity element](../../../../../../glossary/terms/identity-element.md) in a [monoid](../../../../../../glossary/terms/monoid.md).

In the category of [sets](../../../../../../glossary/terms/set.md) with Cartesian product, the unit object is any singleton set {∗}. In the category of vector spaces with tensor product, the unit is the base field. In the category of abelian groups with tensor product over ℤ, the unit is ℤ itself.

In an [enriched category](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/tensoring/content/monoidal-category/scripts/uniting/content/unit-object/_archive/enriched-category.md), the identity [morphism](../../../../../../glossary/terms/morphism.md) at each object is a map from the unit object I to the [hom-object](../../../../../../glossary/terms/hom-object.md) Hom(A, A). This mirrors how the identity element of a monoid is picked out by a map from the one-element set. The unit object thus provides the "do nothing" [morphism](../../../../../../glossary/terms/morphism.md) in the enriched setting.
