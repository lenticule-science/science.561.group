A simplicial set is a [functor](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/simplicializing/content/ordinary-categories/morphisms/functor.md) X: Δᵒᵖ → Set, where Δ is the simplex category (objects are the finite ordinals [0], [1], [2], ..., [morphisms](../../../../../../glossary/terms/morphism.md) are order-preserving maps) and Set is the [category](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/simplicializing/content/ordinary-categories/objects/category.md) of [sets](../../../../../../glossary/terms/set.md). Concretely, a simplicial set consists of a set Xₙ of n-simplices for each n ≥ 0, together with face maps dᵢ: Xₙ → Xₙ₋₁ (removing the i-th vertex) and degeneracy maps sᵢ: Xₙ → Xₙ₊₁ (repeating the i-th vertex), satisfying the simplicial identities.

Simplicial sets encode combinatorial topology: a 0-simplex is a point, a 1-simplex is an edge, a 2-simplex is a triangle, and so on. Every topological space has a singular simplicial set (whose n-simplices are continuous maps from the standard n-simplex into the space), and every simplicial set has a geometric realization as a topological space. This [adjunction](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/topology/morphisms/adjunction.md) connects combinatorial and topological approaches to [homotopy theory](../../../../../../glossary/terms/homotopy.md).

Simplicial sets provide the combinatorial foundation for higher [category theory](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/simplicializing/_index.md). A [quasi-category](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/simplicializing/content/simplicial-set/_archive/quasi-category.md) is a simplicial set satisfying a [horn](../../../../../../glossary/terms/horn.md)-filling condition, and this model of [∞-categories](../../../../research/2026/07/31/lenticule-import/_archive/category/scripts/functoring/content/functor/scripts/representing/content/presheaf/scripts/simplicializing/content/simplicial-set/_archive/infinity-category.md) is the basis of Lurie's framework for [(∞,1)-categories](../../../../../../glossary/terms/infinity-1-category.md) and [(∞,1)-topoi](../../../../../../glossary/terms/infinity-1-topos.md). Simplicial sets also serve as the base for simplicial enrichment of categories, replacing hom-sets with hom-simplicial-sets whose simplices witness homotopies between [morphisms](../../../../../../glossary/terms/morphism.md).
