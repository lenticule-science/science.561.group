# The Google Data Analytics Certificate as of September 2026

This note is the research phase of the third book in the Group's study
companion series, written to the education science section's pattern
(`education-science-services-section/content/text/documents/articles/notes/2026/09/27/2026-09-27-note-on-how-a-study-companion-should-teach-toward-a-credential.md`).
It lives in the math section because statistics lives here, and because the
section's teaching article on turning data tables into concept lattices gives
the book its theory.

What the section held before this note: `statistics-overview.md`,
`descriptive-statistics.md`, `sampling-and-bias.md` and `inference-basics.md`
under `teaching-articles/explanations/`, each a one-paragraph stub, and the
terms `mean`, `median`, `variance`, `distribution`, `sample`, `bias`. The
research below fills those out; the stubs are revised from it in the same
commit.

## Where sources disagree

1. **R or Python.** The certificate page's tool list still names R, ggplot2
   and R Markdown, while its seventh course, as published, teaches Python with
   NumPy and pandas [@google-da-python-2026]. Reviews report the program was
   refreshed from R to Python. *Reading:* both, of different versions: the
   course as offered teaches Python. The book teaches Python and tells readers
   who hold older materials that R played the same role.
2. **How many phases.** Google names six (ask, prepare, process, analyze,
   share, act); CRISP-DM also names six but different ones (business
   understanding, data understanding, data preparation, modeling, evaluation,
   deployment) [@chapman2000]. *Reading:* both; the book follows Google's,
   because the courses do, and shows CRISP-DM's side by side.
3. **Credibility checklists.** Google teaches a checklist for judging a data
   source; library and statistics practice use others. *Reading:* the book
   teaches the underlying questions (who collected it, how, when, is it
   complete, is it cited) and lets the reader map them onto the course's
   version.
4. **Sample size rules of thumb.** Courses and blogs quote fixed minimums
   (such as 30). Cochran gives the formula n = z²p(1 − p)/e² for estimating a
   proportion, with a finite-population correction [@cochran1977]; the
   "30" rule concerns when a sample mean's distribution is roughly normal,
   not how many people to survey. *Reading:* the fixed rule is refuted as a
   general sample-size rule; the book teaches the formula.

## How the section's theory reads the same material

- **A data table is a formal context.** The section's article on data tables
  and concept lattices reads rows as objects, columns as attributes and cells
  as the incidence relation; formal concept analysis then extracts the
  concepts the table already contains [@ganter-wille1999]. Tidy data's rules
  (each variable a column, each observation a row, each value a cell)
  [@wickham2014] are exactly the conditions under which a spreadsheet *is* a
  well-formed context, so tidying is making the context explicit.
- **A missing value isn't a false one.** The same article reads cells in the
  four-valued bilattice: unattested, affirmed, denied, contested. That
  bilattice is Belnap's four-valued logic, which he proposed for a computer
  combining reports from sources that may be silent or contradict one another
  [@belnap1977]. Data
  cleaning meets all four. A blank cell is *unattested*, not zero or "no"; two
  sources that disagree about one record make it *contested*. Cleaning that
  fills blanks with zeros, or silently keeps one of two conflicting values,
  collapses the distinction and changes the answer. The book teaches the
  practice (don't impute silently; record conflicts; document every change
  in a changelog) and names the reason.
- **Scales limit operations.** Stevens's nominal, ordinal, interval and ratio
  scales say which calculations a column supports [@stevens1946]; averaging
  a satisfaction rating treated as ratio data is the common error. The book's
  data-types section is built on the scales.

## What the book is

*Data Analytics, Course by Course: An Independent Study Companion to the
Google Data Analytics Professional Certificate.* Series number 3. A chapter
for each of courses 1 to 7, a case-study guide for course 8, a spaced study
plan, and a glossary. The job-search course is out of scope. One running
example: a county library system asking why weekend visits fell. It teaches
spreadsheets, SQL, Tableau and Python as the course does, with formulas and
code the reader can type, and never reproduces course material.
