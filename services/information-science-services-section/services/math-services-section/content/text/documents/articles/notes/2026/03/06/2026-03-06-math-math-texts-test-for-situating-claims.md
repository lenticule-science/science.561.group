---
title: "Test For Situating Claims"
type: "page"
date-created: 2026-03-06
---

Given a claim C and a context X:

- Enumerate the operations O that X actually performs.

- For each o ∈ O, ask: does C constrain o?

- If C constrains nothing, mark C = decorative.

- If C constrains o but is never consulted, mark C = ceremonial.

- If C is consulted but violations are tolerated, mark C = aspirational.

- If violations cause repair, mark C = operative.

- If repair changes X’s future structure, mark C = structural.

- Only structural claims may be exported.

- All others decay locally.
