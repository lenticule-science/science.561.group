# Attention Services Section

This section owns the dies that price and allocate limited attention against
a declared budget. There is no section-level runtime or package.

`attention-allocation-readout-service` attests the pinned Obsmetrologia
mathematical source bytes for the monotone-budget greedy allocation
(`Cohomology/AttentionAllocation.lean`), computes the funded subset for a
budget and a candidate list over an ActivityStreams contract face, and
reports tie-set choice bits, source attestation, conformance qualification,
and locally measured resource use. It settles no cash price and claims no
formally verified Lean extraction.

This section was created by moving `attention-allocation-readout` out of
`obsmetrological-services-section/services/` directly, so a section exists
to hold attention-pricing dies as more are added, and the leaf package was
renamed to `attention-allocation-readout-service` in the same move.
