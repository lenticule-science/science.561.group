# The Recurring FOUR

The recurring FOUR is one of the central connective tissues of the live
Obsmetrologia project. It should not be documented as a metaphor. It is a family
of formal carriers, conversions, operations, and frontier obligations that make
the same four-corner pattern recur at successive depths.

The local vocabulary includes:

- articulating corners: `potential`, `active`, `stable`, `absurd`;
- charge readings: `kBot`, `kTop`, `tTop`, `tBot`;
- modal readings: `neither`, `dia`, `box`, `both`;
- nuclear quartet positions: identity, first nucleus, second nucleus, composite;
- regime readings: strict finite, Scott, transfinite bounded, aperiodic.

Do not collapse those into one unproved assertion. The documentation task is to
say which recurrence is currently a Lean witness, which is a Blueprint frontier,
and which is a teaching comparison.

## First Formal Surface

The articulation cell gives the first four-corner carrier. The Blueprint section
`docs/blueprint/src/chapters/articulation-predication/01-four-corner-cell.tex`
names claim-sites for the articulation cell, corner, status correspondence,
corner bijection, four-cell cardinality, initial potential presentation, and
surjectivity over corners.

The Verso and monograph notes describe this as the first finite carrier where
the fourfold shape becomes visible.

## Charge Surface

The charge surface reads the four corners as value. The local charge modules
define Boolean slots, knowledge and truth operations, negation, two order
surfaces, joins, meets, and closure behavior.

The documentation must keep the orders distinct:

- knowledge order tracks accumulation of information;
- truth order tracks truth-facing polarity;
- involutions and order-swap constructions relate them.

## Recurrence Surface

The recurrence becomes explicit in quartet and symmetry modules, where the
project records bijections, symmetry operations, and square laws. The right
documentation shape is not "all fours are the same." It is:

1. name the fourfold carrier;
2. name the conversion or operation;
3. name the theorem or frontier node that relates it to another fourfold
   carrier;
4. state the current status.

## Frontier Discipline

Some recurrence claims are deliberately still frontier. For example, Blueprint
contains red obligations around the regime as another quartet member, FCA
closure identity, Abrams equivalence, and nuclear canonical forms.

A documentation page may teach why those obligations matter, but it must not
write as though they are proved if the carrier is only `\notready`.

## How To Document A New FOUR Instance

Use this template:

- carrier: what fourfold object exists;
- source: which earlier Obsmetrologia object generates it;
- slots: the four local names;
- operation: what maps or symmetries act on it;
- recurrence link: which earlier fourfold surface it is compared with;
- Lean witness: declaration or module, if settled;
- Blueprint node: green or red;
- failure mode: the familiar simplification that would misread it.
