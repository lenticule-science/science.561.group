# Orbit-coloring strong-MLD extension

The chapter's [strong-MLD classifier](strong-mld-via-composed-duality.md) is the 3-element firing-orbit-type set $\{\text{truth-only}, \text{falsity-only}, \top\}$ on $L_{\mathrm{ns}}(\kappa)$. Under the orbit-coloring extension to $\mathcal C^\beta$, **no new firing-orbit type appears**. What changes is the strong-MLD classifier *space*: it acquires a finite 4-fold factor recording which orbits are $\top$-saturated, plus a distinguished singleton class for the both-orbits-saturated boundary case (which has no firings to type). Conditional on closure admissibility (C1)+(C2) from [sub-question 3](orbit-coloring-closure-2-monad-extension.md).

## Statement

Let $(\mathbf L, \mathcal C, E)$ be base parameters with $|E| \geq \omega_1$, $\mathcal C^\beta$ the [boundary-extended predicate category](../objects/boundary-extended-predicate-category.md), and assume the closure family $\mathrm{cl}$ satisfies (C1) boundary stability and (C2) orbit decomposability per [orbit-coloring closure 2-monad extension](orbit-coloring-closure-2-monad-extension.md). Let $v$ be an aperiodic-regime [predication settling](../objects/predication-settling.md) over $\mathcal C^\beta$ with closure ordinal $\kappa \leq \omega_1$ and an *orbit-coloring initial condition* — an initial state $v_0$ obtained from a chapter-standard initial state by $\top$-painting some subset $S \subseteq \{\Delta, \Delta^c\}$ of orbits.

**(M1) Firing types unchanged.** The image of the firing-orbit-type function $\tau^{\mathbb D}_v : L_{\mathrm{ns}}(\kappa, v) \to \{\text{truth-only}, \text{falsity-only}, \top\}$ remains in the chapter's 3-element classifier. No new fourth type is generated by orbit-coloring.

**(M2) Effective firing-ordinal set restriction.** The firings of an orbit-colored settling are confined to the unpainted orbits:

$$L_{\mathrm{ns}}(\kappa, v) \subseteq L_{\mathrm{ns}}(\kappa, v|_{\text{unpainted orbits}}).$$

If $S = \{\Delta, \Delta^c\}$ (both orbits painted), $L_{\mathrm{ns}}(\kappa, v) = \emptyset$.

**(M3) Strong-MLD classifier extension.** The strong-MLD classifier space over $\mathcal C^\beta$ is

$$\mathcal{M}_{\mathrm{sMLD}}^{\beta} \;=\; \mathcal P(\{\Delta, \Delta^c\}) \times \mathcal{M}_{\mathrm{sMLD}}^{\mathrm{aper}}|_{\text{painted}},$$

where the first factor records the orbit-saturation pattern $S$, and the second factor is the chapter's strong-MLD invariant restricted to firings on the unpainted orbits. In particular, the both-painted case $S = \{\Delta, \Delta^c\}$ is a distinguished singleton class with no firings — the "fully saturated boundary class" — sitting outside the 3-element firing-type taxonomy.

**(M4) Strict refinement.** Orbit-coloring is a real strong-MLD distinction, not a definitional artifact: two settlings with the same closure dynamics but different orbit-saturation patterns are not strong-MLD-equivalent (and are not even ordinary-MLD-equivalent).

## Proof

### (M1) No new firing types

A *firing* in the chapter's sense is a non-Scott-continuous closure event $\mu \in L_{\mathrm{ns}}(\kappa)$ — a stage of the [settling endofunctor](../morphisms/settling-endofunctor.md) $F_U(\mathcal E)_\tau = \mathrm{Cl}(\mathcal E) \vee_k u_\tau$ at which the closure $\mathrm{Cl}$ produces a non-Scott-continuous derivation. Firings are produced by $\mathrm{Cl}$, not by the increment sequence $u_\tau$.

Orbit-coloring is an *initial-condition* operation: it modifies $v_0$ by $\top$-painting selected orbits, producing $v_0' = v_0 \vee_k w_S$ where $w_S$ is the painted constant on orbits $S$. It is not itself a closure event and does not appear in $L_{\mathrm{ns}}$.

The firings of the orbit-colored settling are still the closure events. By (C2) orbit decomposability, the closure decomposes per-orbit:

$$\mathrm{Cl}_p(v) = (\mathrm{cl}_p^\Delta(v|_\Delta), \mathrm{cl}_p^{\Delta^c}(v|_{\Delta^c})).$$

On a $\top$-painted orbit $O \in S$: $v|_O = \top$ throughout, and by inflationarity $\top \leq_k \mathrm{cl}_p^O(\top) \leq_k \top$, so $\mathrm{cl}_p^O(\top) = \top$. The closure is fixed; no firings occur on $O$.

On an unpainted orbit $O \notin S$: $\mathrm{cl}_p^O$ acts independently of the painted orbits' content (by (C2)), so its firing structure on $O$ is identical to the chapter-standard firing structure of an unpainted settling on $O$.

Each firing $\mu \in L_{\mathrm{ns}}(\kappa, v)$ is therefore localized to a single unpainted orbit and has the same d-frame generator $D_\mu$ as the corresponding chapter-standard firing. By the [d-frame Verdier composition](../../../../../../../pre-bilattice/content/bilattice/content/predication-fiber-algebra/content/priestley-space/content/paired-priestley-space/content/d-frame/references/d-frame-verdier-composition.md), $\tau^{\mathbb D}(\mu)$ is determined by whether $D_\mu$ is fixed by $\mathbb D_{\mathrm{val}}$ (= $\top$-firing) or paired (= truth-only / falsity-only). The classification produces the same 3-element value as the unpainted case.

The painted constants $\top, \bot \in \mathbf{FOUR}$ are negation-fixed ($\neg \top = \top$, $\neg \bot = \bot$), so any firing they *would* induce would be $\top$-typed — but by (C2) they induce no firings, so the question is moot. No fourth type is generated.

### (M2) Effective firing-ordinal set

By the per-orbit decomposition argument in (M1): firings on a $\top$-painted orbit are eliminated (closure-fixed at $\top$). So $L_{\mathrm{ns}}(\kappa, v)$ contains only firings on unpainted orbits. If $S = \{\Delta, \Delta^c\}$, all orbits are painted and $L_{\mathrm{ns}}(\kappa, v) = \emptyset$.

### (M3) Classifier space refinement

The strong-MLD classifier of [strong-MLD via composed-duality](strong-mld-via-composed-duality.md) over $\mathcal C$ is the pair

$$\mathrm{cl}\text{-}\mathrm{inv}^{\mathbb D}(v) = (\mathrm{cl}\text{-}\mathrm{inv}(v), \tau^{\mathbb D}(v)) \in H^1(\mathbf T^*_{\leq \omega_1}, \mathcal F_v) \times \mathrm{Orbit}(v).$$

Over $\mathcal C^\beta$, with the bitopological settling site extended per [orbit-coloring Verdier extension](orbit-coloring-verdier-extension.md) to $\mathbf T^{*,\beta}_{\leq \omega_1}$ via absurd-point enrichment, the strong-MLD invariant is naturally augmented:

$$\mathrm{cl}\text{-}\mathrm{inv}^{\mathbb D, \beta}(v) = (S(v), \mathrm{cl}\text{-}\mathrm{inv}(v|_{\text{unpainted}}), \tau^{\mathbb D}(v|_{\text{unpainted}})),$$

where $S(v) \in \mathcal P(\{\Delta, \Delta^c\})$ is the orbit-saturation pattern of $v$ and the second and third components are the chapter's strong-MLD invariant of the unpainted-orbit substructure of $v$.

By (M2), the second and third components are well-defined (firings happen only on unpainted orbits) and agree with the chapter's invariants on the unpainted core.

The cardinality of $\mathcal P(\{\Delta, \Delta^c\})$ is 4. The boundary case $S = \{\Delta, \Delta^c\}$ has empty unpainted-orbit substructure; its second and third components are trivial (zero $H^1$, empty $\tau^{\mathbb D}$). So this boundary case is a singleton class — the "fully saturated boundary class" — with no internal firing-type structure.

The other three cases ($S = \emptyset$, $S = \{\Delta\}$, $S = \{\Delta^c\}$) carry full strong-MLD content on the unpainted-orbit substructure, classified by the chapter's existing 3-element type system.

### (M4) Strict refinement — painting is MLD-distinguishing

To show orbit-coloring is a real MLD-distinction (not a definitional artifact), exhibit two settlings with the same closure dynamics but different saturation patterns and verify they are not MLD-equivalent.

Let $v$ be a chapter-standard aperiodic settling (no orbit painted, $S(v) = \emptyset$). Let $v' = v \vee_k w_{\{\Delta\}}$ be the same settling with $\Delta$ additionally $\top$-painted ($S(v') = \{\Delta\}$). Both have the same closure dynamics on $\Delta^c$ (by (C2)), and $v'$ has trivial saturated dynamics on $\Delta$.

Suppose $v \sim_{\mathrm{MLD}} v'$. By [mutually locally derivable](teaching/explanations/mutually-locally-derivable.md), there is an invertible settling-morphism $(\phi, \delta)$ with $v$-cells locally derivable from $v'$-cells and conversely.

Forward direction (every $v$-cell locally derivable from $v'$-cells): $v$'s diagonal cells have whatever values the closure produces from the chapter-standard initial condition — generally not $\top$. We need to derive these from $v'$'s diagonal cells, all of which are $\top$ (saturated). But $\top$ is the $\le_k$-maximal value; it does not locally derive non-$\top$ values (saturation has no inverse — $\top$ does not "remember" specific cell values). So forward derivation fails for any non-trivial $v$.

Hence $v \not\sim_{\mathrm{MLD}} v'$ generically. Strong-MLD inherits this distinction (strong-MLD is finer than MLD). So the saturation-pattern factor in (M3) is a real MLD-level refinement, not a relabeling.

Conversely, $S(v) \neq S(v')$ does not exhaust strong-MLD distinctions — within each saturation pattern, the chapter's $H^1 \times \tau^{\mathbb D}$ classifier still distinguishes settlings on the unpainted orbits. The two refinements compose. $\square$

## Reading

The honest answer to sub-question 5: orbit-coloring does **not** introduce a fourth firing-orbit type. The chapter's 3-element classifier $\{\text{truth-only}, \text{falsity-only}, \top\}$ is closed under orbit-coloring contributions because (i) painted constants $\top, \bot$ are negation-fixed (would-be type: $\top$), and (ii) by (C2), painted constants induce no firings, so the would-be types don't appear in $\tau^{\mathbb D}$ at all.

What orbit-coloring does is augment the strong-MLD classifier space with a finite saturation-pattern factor (4 elements, one of which — both-orbits-painted — is a degenerate singleton class with no firings). This factor is a real MLD-distinction, not a relabeling: $\top$-saturation cannot be locally inverted, so $\top$-painted orbits are MLD-incomparable to their unpainted counterparts.

The question text's phrasing — "natural fourth value would be $\top$-everywhere; whether to count this as a refinement of the strong-MLD classifier or as the trivially-painted limit of the existing three is a definitional question" — is resolved as follows: the $\top$-everywhere class IS a distinguished class, but it's the both-painted boundary case (no firings), not a fourth firing-orbit type within the 3-element classifier. It's a refinement of the *space*, not the *type system*.
