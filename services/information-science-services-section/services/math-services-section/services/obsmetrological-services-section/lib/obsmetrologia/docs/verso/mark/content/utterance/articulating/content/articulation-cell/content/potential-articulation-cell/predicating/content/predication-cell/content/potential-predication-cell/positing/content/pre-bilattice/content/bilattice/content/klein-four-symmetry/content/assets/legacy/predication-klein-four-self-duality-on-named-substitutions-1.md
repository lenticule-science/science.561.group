# Klein-four self-duality on named substitutions

Cross-step example computing the full Klein-four group $\{\mathrm{id}, \neg, -, \neg\cdot-\}$ self-duality structure for each of the corpus's named substitutions. Computed via [`tools/strong-mld-orbits/compute.py`](../tools/strong-mld-orbits/compute.py) extended with the conflation involution.

The bilattice $\mathbf{FOUR}$ has natural Klein-four symmetry generated by:
- **Negation** $\neg$: swaps $\mathbf{t} \leftrightarrow \mathbf{f}$, fixes $\bot, \top$. Fixed-set: $\{\bot, \top\}$.
- **Conflation** $-$: swaps $\bot \leftrightarrow \top$, fixes $\mathbf{t}, \mathbf{f}$. Fixed-set: $\{\mathbf{t}, \mathbf{f}\}$.
- **Double involution** $\neg \cdot -$: swaps $\mathbf{t} \leftrightarrow \mathbf{f}$ AND $\bot \leftrightarrow \top$. Fixed-set: $\emptyset$.

Note the **complementary fixed-sets**: $\{\bot, \top\} \cap \{\mathbf{t}, \mathbf{f}\} = \emptyset$. So at the per-firing level, no value is fixed by both negation and conflation. Only the trivial empty settling is firing-pattern self-dual under multiple involutions simultaneously *if* we require value-fixing in the standard sense. (See remarks below for refinements.)

## Two notions of self-duality, per involution

For each Klein-four element $\sigma$ on $\mathbf{FOUR}$:

1. **Firing-pattern self-duality** under $\sigma$: every firing's value is $\sigma$-fixed. The settling's per-firing structure is invariant under the value-category action of $\sigma$ on $H^1$.
2. **Substitution-rule self-duality** under $\sigma$: the substitution matrix $M$ commutes with the $\sigma$-induced alphabet permutation $P_\sigma$ (where $P_\sigma$ maps each letter to the letter whose value is $\sigma$-image of its own; undefined if no such partner exists).

These two notions are independent — a settling can have one without the other, as we'll see.

## Per-substitution observations

**Fibonacci is conflation-firing-pattern-self-dual.** Both letters $a, b$ have values in the conflation-fixed set $\{\mathbf{t}, \mathbf{f}\}$, so every firing is fixed by conflation. Fibonacci is the smallest case of "all firings on the truth axis" — the bilattice's $\bot/\top$ direction is unused. The substitution-rule conflation check is trivially satisfied (no $\bot$/$\top$ letters means the conflation permutation is the identity). Fibonacci is *not* negation-self-dual (because $a$ and $b$ have different values, $\neg$ swaps them, the firing pattern shifts).

**Thue-Morse is the most Klein-four-symmetric case in the corpus.** Four out of six self-duality conditions hold:
- Conflation FP: same reason as Fibonacci (both letters in $\{\mathbf{t}, \mathbf{f}\}$).
- Negation SR: $M = [[1,1],[1,1]]$ commutes with the swap (the corpus's headline Thue-Morse finding).
- Conflation SR: trivial (identity permutation).
- Double SR: composes the previous two — also commutes.

The two failures are negation FP and double FP — both require some firing in $\{\bot, \top\}$, which Thue-Morse doesn't have under the standard labeling. So Thue-Morse satisfies *every* substitution-rule self-duality condition that's defined for it, plus the one firing-pattern condition compatible with its labeling.

**Padovan and Tribonacci are Klein-four-equivalent under this analysis.** Same default labeling, same firing-pattern types (1 truth-only, 1 falsity-only, 1 $\top$). They differ only in the substitution matrix's action on $\mathbb{Z}^3$ — which the firing-pattern / substitution-rule self-duality analysis doesn't distinguish (since both fail every check). To distinguish Padovan from Tribonacci you have to look at the matrix actions, not the orbit-type classification.

**Tetranacci is the only case where conflation SR analysis is non-trivial but fails.** Tetranacci's labeling uses both $\bot$ (for $a$) and $\top$ (for $d$), so the conflation-permutation $a \leftrightarrow d$ is non-trivial. Computing $M \cdot P$ vs $P \cdot M$ explicitly (where $P$ is the swap of indices 0 and 3): they are not equal. So Tetranacci's substitution rule does *not* respect the conflation involution, even though the alphabet structure looks symmetric.

## What this exhibits, structurally

**Three structural findings:**

1. **The conflation-firing-pattern-self-duality property is realized by Fibonacci and Thue-Morse but no higher-step named cases.** This is because the default labelings for Padovan, Tribonacci, and Tetranacci use $\top$ (and Tetranacci uses $\bot$), placing them outside the conflation-fixed set. So the corpus's Klein-four classification has a striking pattern: at $n = 2$ (Fibonacci, Thue-Morse), conflation-FP is generic; at $n \geq 3$, the bilattice's $\top$ value enters the labeling and breaks conflation-FP. **Conflation-FP self-duality is structurally an $n = 2$ property under standard labelings.**

2. **Thue-Morse is genuinely Klein-four-distinguished.** It's the *only* case satisfying any substitution-rule self-duality condition (negation, conflation, double) besides the trivial-permutation one. The Klein-four group acts on the bilattice; Thue-Morse's substitution matrix realises that action symbolically (M commutes with all three involution-permutations). This is a stronger structural property than just "M commutes with negation" — Thue-Morse is the *full Klein-four-equivariant* substitution among the corpus's named cases.

3. **The complementary fixed-sets give complementary self-duality classes.** Negation-FP requires firings in $\{\bot, \top\}$; conflation-FP requires firings in $\{\mathbf{t}, \mathbf{f}\}$. These are complementary subsets of $\mathbf{FOUR}$. So the negation-FP-self-dual stratum and the conflation-FP-self-dual stratum **partition** the firing-pattern-self-dual settlings (with their intersection being only the trivial empty settling). The classifying tower of self-duality refinements has more structure than the corpus's existing strong-MLD theorem captures, which used only negation.
