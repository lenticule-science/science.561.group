# Tutorials

Learning-oriented. A newcomer builds understanding by *doing* — copy-paste runnable, each step shows
its output, no decisions required. The math is pointed at as it appears, not front-loaded.

Planned:

- **your-first-descent** — mint an utterance, run `articulate → predicate → posit → settle`, read the
  settled charge. By the end you've seen a cell measured to *potential* and know what each stage did.
- **the-two-cones-by-hand** — run `settle` and `brim` on the same cell, watch them bracket
  potential↑stable, and read `vanish` as the slack. Then `adjudicate`/`presume` for the truth order.
- **watching-absurd-get-reached** — feed a cell two conflicting tellings and watch the meet *reach*
  absurd — never seeded — so the "measured, not seeded" idea is something you saw happen.
- **the-laws-are-real** — run a few of the property tests yourself on random charges, so "the suite
  doesn't cheat" is something you verified rather than took on faith.
