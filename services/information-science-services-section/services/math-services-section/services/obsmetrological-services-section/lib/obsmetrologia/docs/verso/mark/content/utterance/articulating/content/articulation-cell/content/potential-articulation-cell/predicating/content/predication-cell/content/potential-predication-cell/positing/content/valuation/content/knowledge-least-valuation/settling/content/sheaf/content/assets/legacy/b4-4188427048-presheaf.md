A **presheaf** on a category $\mathcal{C}$ with values in a category $\mathcal{D}$ is a contravariant functor $F : \mathcal{C}^{\mathrm{op}} \to \mathcal{D}$ [@maclane1971, Ch. III §2; @maclanemoerdijk1992, Ch. I §3]. Equivalently, a covariant functor from the [opposite-category](../../../opposite-category/opposite-category.md) $\mathcal{C}^{\mathrm{op}}$ to $\mathcal{D}$.

The classical case has $\mathcal{D} = \mathrm{Set}$ — Set-valued presheaves. The category of presheaves on $\mathcal{C}$ is the functor category $\hat{\mathcal{C}} = [\mathcal{C}^{\mathrm{op}}, \mathrm{Set}]$.

**`oneOf` value-category discriminator.** The schema uses primary-`oneOf` to distinguish:

- **Set-valued presheaves** (`value-category: "set"`) — the classical case. The branch requires only the `value-category` tag; the codomain is canonically $\mathrm{Set}$.
- **Category-valued presheaves** (`value-category: "category"`) — generalized presheaves for arbitrary target categories. The branch requires an additional `specific-value-category` cell naming the target.

This exercises JSON Schema 2020-12's primary-`oneOf` pattern: one schema, two structurally-distinct branches sharing common fields from `allOf functor`.

**The 561 predication-fiber-functor.** The corpus's [predication-fiber-functor](../../../../../../../../predication-fibration/library/predication-fiber-algebra/predication-fiber-algebra.md) is a category-valued presheaf $F : \mathcal{C}^{\mathrm{op}} \to \mathbf{DBiLat}(\mathbf{L})$ taking each predicate $p$ to its predication-fiber-algebra $A_p$ and each predicate-category morphism $f : q \to p$ to the induced bilattice homomorphism $f^* : A_p \to A_q$. This is the category-valued case with `specific-value-category` being `dbilat`. Typing the predication-fiber-functor as a presheaf-instance puts it in the same framework as other presheaves and lets the Yoneda machinery apply.

**Examples by value-category.**

- $[\mathcal{C}^{\mathrm{op}}, \mathrm{Set}]$ — classical presheaves; the category of presheaves on $\mathcal{C}$.
- $[\mathcal{C}^{\mathrm{op}}, \mathrm{Ab}]$ — abelian presheaves; used in algebraic geometry.
- $[\mathcal{C}^{\mathrm{op}}, \mathrm{Cat}]$ — 2-presheaves; values are categories.
- $[\mathcal{C}^{\mathrm{op}}, \mathbf{DBiLat}(\mathbf{L})]$ — bilattice-valued presheaves; the 561 case.

**Representable presheaves.** A presheaf $F$ is **representable** if there exists an object $A \in \mathrm{Ob}(\mathcal{C})$ and a natural isomorphism $F \cong \mathrm{Hom}_{\mathcal{C}}(-, A)$ — i.e., $F$ is naturally isomorphic to a [hom-functor](../hom-functor/hom-functor.md). The [representable-functor](../representable-functor/representable-functor.md) record carries this property explicitly.

**Yoneda embedding.** The map $\mathcal{Y} : \mathcal{C} \to \hat{\mathcal{C}}$, $A \mapsto \mathrm{Hom}_{\mathcal{C}}(-, A)$, is fully faithful by the Yoneda lemma. Every object of $\mathcal{C}$ is identified with a representable presheaf in $\hat{\mathcal{C}}$. See [yoneda-embedding](../yoneda-embedding/yoneda-embedding.md).
