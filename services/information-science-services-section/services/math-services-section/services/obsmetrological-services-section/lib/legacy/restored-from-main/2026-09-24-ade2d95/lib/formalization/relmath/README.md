# RelMath

A **dependency-free** Lean 4 library (Lean core only — no Mathlib, no `[[require]]`)
that *is* the inductive derivation tree of `561-group/content/`. Read the import
spine top-to-bottom and it is a proof: each module is generated by the one before
it, exactly as the corpus's filepath-as-proof discipline (`generator/generated`,
GENERATED-BY never IS-A) dictates.

Build: `make relmath` (from repo root) or `cd lean && lake build`.
Toolchain: `leanprover/lean4:v4.31.0` (the installed `elan` default).

## The governing rule: no free data past the base

RelMath admits **free data in exactly two modules**:

* `RelMath.Mark` — the arbitrary atomic primitive (the two kinds, token/claim).
* `RelMath.Articulating` — the base morphism, the `[utterance, articulating]`
  recursion.

**Every module below `Articulating` is derived.** None introduces an `axiom`,
`opaque`, `constant`, or `sorry`. Verify:

```sh
grep -rnE '^\s*(axiom|opaque|constant)\b|sorry|admit|native_decide' RelMath/   # → only doc prose
cd lean && lake env lean -e '#print axioms RelMath.Corner.card_eq_four'         # → no axioms
```

Derived theorems depend at most on `propext` (a core logical axiom of Lean's
type theory, not postulated mathematical data).

## The spine implemented so far

Mirrors `content/mark/content/utterance/articulating/content/articulation-cell/…`:

| Module | content/ node | what it derives |
|---|---|---|
| `Mark` | `mark` (+ `token`, `claim`) | the atom; two kinds by position; `two_kinds` |
| `Utterance` | `utterance` | ordered pair (token, claim); articulating's domain |
| `Articulating` | `articulating` | recursive `[utterance, articulating]`; `floor`, `depth` |
| `ArticulationCell` | `articulation-cell` | the four-cell partition; **`Corner.card_eq_four`** |
| `Predicating` | `predicating` | the predication category; object `φ = (s,p,o)`; converse / projections / specialization; **category theory** |
| `Positing` | `positing` | admits value: the FOUR **bilattice** of charges (= the four phases met as value), two orders, six operations, `Valuation`, the ⊥ₖ seed; **value logic** |
| `Settling` | `settling` | closure ◇∘□ to its fixed point; **generates order**: `≤ₖ` a partial order, `∨ₖ`/`∧ₖ` its lub/glb, **Knaster–Tarski** least fixed point |
| `Hyperdoctrine` | `settling/.../predication-hyperdoctrine` | quantifier adjoints over reindexing (`f* v = v∘f`); the converse system `∃ ⊣ f* ⊣ ∀` (self-adjoint bijection), **Frobenius**, **Beck–Chevalley** |
| `Quantifying` | `settling/.../predication-hyperdoctrine` | the **fiber** quantifier adjoints `∃_f ⊣ f* ⊣ ∀_f` for any **finite fibration** (covers the projection generators); list-join/meet = lub/glb; converse is the singleton-fiber case |
| `TruthOrder` | `settling/.../truth-order-closure` | the bilattice's **second** order `≤ₜ` proven a bounded lattice (`∨ₜ`/`∧ₜ` lub/glb, bounds f/t); the truth-order closure `T_t`; **negation is the duality** (reverses `≤ₜ`, preserves `≤ₖ`) |
| `ClosureOrdinal` | `settling/.../closure-ordinal`, `settling-bound` | settling **iterated** to its fixed point; `iter`, `iter_add`; **`settles_by_three`** (κ ≤ 3) — the **strict-finite regime**; no ascending chain of 4 charges |
| `Sheaf` | `settling/.../sheaf`, `settling-cohomology` | the fixed point as a sheaf `{base, section}` (H⁰ = designated cells); **`joinList_congr`** = **H¹ = 0** (CRDT/CALM order-independent merge); gluing = lub; `separated` |
| `Four` | `settling/.../four-bilattice`, `klein-four-symmetry` | the capstone: the recurring FOUR is **one object** (phases = charges = status pairs; `cornerStatus` bijection; four generators); the **Klein-four symmetry** `K₄ = ⟨~,−⟩` — negation/conflation as commuting involutions with their order-dualities and 2-orbits |
| `BigradedDiamond` | `settling/.../bigraded-diamond`, `nuclear-quartet` | the 1-categorical **shadow** below settling: `HeytingAlgebra` + `Nucleus`; **`fix_imp`** (Fix closed under `⇒` — why meet-preservation matters); the **Nuclear Quartet Theorem** (commuting `j₁,j₂` → `π=j₁∘j₂`, `Fix(π)=Fix(j₁)∩Fix(j₂)`, square, corners = phases); **`SquareFamily`/`Varies`** — the **fiberwise recurrence** (the diamond is a *family*, not one square); varying instance on the charge knowledge-Heyting-algebra |

`BigradedDiamond` is the *1-categorical fixed-point shadow* of a genuinely
**2-categorical** structure that is **not yet derived**, and is the real depth below
settling (staying off the agent/system/computer branch):

- the **closure-2-monad** `Cl` — KZ / lax-idempotent (μ a real 2-cell), strict only
  when Scott-continuous (κ=ω); the **temporal-2-category** `T(C,λ)` it lives on;
- the **strict KZ-diamond commutation** of `Cl` (values) with the Emmenegger
  fibration **2-comonad** `ℕ` (indexing) — the actual "diamond";
- the **second adjoint system** `∃^t⊣f*⊣∀^t` (truth order) — `Quantifying` only has
  the knowledge one — and the **two bigradings** it drives (settling-cohomology
  bigrading vs common-knowledge bigrading);
- the **bigraded H¹** `(H¹_t, H¹_⊤)` and the **aperiodic-regime trichotomy**
  (consistent / paraconsistent / mixed) with its internal `ℤ/2` gauge.

Lighter refinements also remain (projection `∃/∀` for infinite entity indices; the
Scott-continuous / transfinite / aperiodic regimes as the closure-ordinal classes).

| `Equality` | `predication-hyperdoctrine/.../{classical,paraconsistent}-equality` | the **second adjoint system** `∃^t⊣f*⊣∀^t` (truth order; truth-order list-join/meet lub/glb); **equality derived, not postulated** — `classicalEq = ∃^t(diagonal t-terminal)` is two-valued `t`/`f`, `paraconsistentEq = ∃^k(diagonal ⊤-terminal)` is `⊤`/`⊥` |
| `ClosureMonad` | `settling/.../closure-2-monad` (+ `aperiodic-settling/{saturating,transferring,commutating}`) | the closure-2-monad's KZ/lax-idempotence **shadow**: **`kz_iff_strict`** (KZ inequality ⟺ strict idempotence on the antisymmetric order — the *Scott-continuity ⟹ strict* shadow); **`no_periodic_orbits`**; η/μ + K1 counit; the settling-endofunctor `F_U=Cl∨ₖu` settles in ≤3 (`settleStep_settles`) |
| `BigradedCohomology` | `settling/.../{settling-cohomology/bigraded-settling-cohomology, inconsistency-sheaf}` + `aperiodic-settling`, `internal-z2-gauge` | the cell split `Δ⁺=Δ⁺ᵗ⊔Δ⁺ᵀ` (disjoint); the bigraded invariant `(H¹_t,H¹_⊤)` (FOUR-shaped); the **aperiodic-regime trichotomy** (`trichotomy`: consistent/paraconsistent/mixed, with `consistent ⟺ F^(⊤)=0`); the internal **ℤ/2 gauge** `~`: `gauge_fixes_inconsistency` (trivial on ⊤-summand), `gauge_flips_truth` (t↔f), `paraconsistent_gauge_stable` |

Received mathematics (order theory, modal/linear logic, category theory) is **not**
imported — it is derived *in place* at the descent stage where its generating
structure first exists, per `content/CLAUDE.md`. Category theory already appears at
`Predicating`; order theory will appear under `settling`.
