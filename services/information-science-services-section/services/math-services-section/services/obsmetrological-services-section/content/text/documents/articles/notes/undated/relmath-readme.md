# RelMath

RelMath was a **dependency-free** Lean 4 library (Lean core only — no Mathlib, no `[[require]]`) that was the inductive derivation tree of `561-group/content/`. Read top-to-bottom, the import spine was a proof: each module was generated by the one before it, per the corpus's filepath-as-proof discipline (`generator/generated`, GENERATED-BY never IS-A).

It has since folded into Obsmetrologia (the living spine at `lib/emsenn/services/561-group/services/science-services-section/services/information-science-services-section/services/math-services-section/services/obsmetrological-services-section/lib/obsmetrologia`), which reached and then passed every result recorded here; this note records what RelMath was for the history.

## The governing rule: no free data past the base

RelMath admitted free data in exactly two modules: `RelMath.Mark` (the arbitrary atomic primitive, the two kinds token/claim) and `RelMath.Articulating` (the base morphism, the `[utterance, articulating]` recursion). Every module below `Articulating` was derived — none introduced an `axiom`, `opaque`, `constant`, or `sorry`. Derived theorems depended at most on `propext`, a core logical axiom of Lean's type theory, not postulated mathematical data.

## The spine as built

Mirroring `content/mark/content/utterance/articulating/content/articulation-cell/…`, in Obsmetrologia's current names: `Mark` (the atom), `Utterance` (ordered pair token/claim), `Articulating` (recursive `[utterance, articulating]`), `Articulating.Cell` (the four-cell partition, `Corner.card_eq_four`), `Predicating` (the predication category, object φ = (s,p,o)), `Positing` (the FOUR bilattice of charges, the valuation, the ⊥ₖ seed), `Settling` (the closure ◇∘□ to its fixed point, generating order: `≤ₖ` a partial order, Knaster–Tarski least fixed point), `Hyperdoctrine` (quantifier adjoints, `∃ ⊣ f* ⊣ ∀`, Frobenius, Beck–Chevalley), `Quantifying` (fiber quantifier adjoints for any finite fibration), `TruthOrder` (the bilattice's second order, bounded lattice, negation as its order-reversing involution, the evidence swap), `ClosureOrdinal` (settling iterated to its fixed point, `κ ≤ 3`), `Sheaf` (the fixed point as a sheaf, `H¹ = 0`), `Four` (the capstone: phases = charges = status pairs = generators are one object; the Klein-four symmetry), `Positing.Bigraded` (two commuting nuclei, the nuclear quartet), `Equality` (the second adjoint system `∃^t⊣f*⊣∀^t`; classical/paraconsistent equality derived not postulated), `Closure.Monad` (the closure-2-monad's KZ/lax-idempotence reduction), `BigradedCohomology` (the aperiodic-regime trichotomy and the internal ℤ/2 gauge).

Beyond the seventeen-module spine, RelMath grew to roughly 90 modules covering received mathematics re-derived in place — order theory, modal and linear logic, category theory, Stone/Priestley duality, type theory with full Church–Rosser, algebra, probability, Lorentzian causal sets, Frobenius/TQFT, moduli stacks — plus a frontier of settling-generated novel mathematics (quantale-enriched sheaves, d-frame theory, the temporal 2-category, synonymy/antonymy as cohomological equivalence, closure-rule/fibration theory, aperiodic firing dynamics, the step-n RG tower, spatiotemporal closure-flow dynamics as a dynamical system with a free-energy Lyapunov function). See the RelMath roadmap note for the module-by-module build history.
