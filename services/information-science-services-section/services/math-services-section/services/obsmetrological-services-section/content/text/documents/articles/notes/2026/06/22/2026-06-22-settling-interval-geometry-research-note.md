# Settling Interval Geometry: A Research Note on Geometry Generated by Closure

## Abstract

This note proposes **settling interval geometry** as the next coherent mathematical layer of `emsenn/relational-math`: a formal geometry generated not by placing fields on a pre-given manifold, but by iterating a closure/settling operator over value-bearing cells until compatibility is forced. The guiding thesis is:

> Geometry is the accounting theory of forced compatibility.

The current Lean library already contains several separately formalized components of this thesis: monotone closure-flow dynamics, firing and smooth steps, finite Boolean causal-set settling, Myrheim–Meyer ordering-fraction combinatorics, Alexandrov topology of posets, settling-associated sheaf cohomology, Lawvere/Tarski order Laplacians, blowup classification of local firings, obstruction/curvature regimes, closure ordinals, and Nat-valued free-energy Lyapunov descent. The next research task is to identify the right common object so these do not remain parallel analogies.

The proposed common object is an **indexed charge-valued settling geometry**:

```text id="0sknep"
Cell        : Type
Val         := Cell → Charge
cl          : Val → Val
seed        : Val
Support     : List Cell
orbit n     := clⁿ(seed)
settled     := fixed point / harmonic state
```

Once `Cell` is allowed to vary, the same theory can be instantiated for predication cells, causal event-pairs, causal intervals/diamonds, clopen-supported sheaf cells, or future interval-layer measures. This makes it possible to state the central bridge theorem:

> For a finite causal interval generated by Boolean causal settling, the settled causal relation determines a causal poset; its Alexandrov topology recovers that poset; its FOUR-valued causal-pair valuation has `H⁰` equal to the apex count; its Myrheim–Meyer ordering fraction is the normalized `H⁰` density; the strict finite regime has vanishing `H¹` obstruction curvature; the Lawvere/Tarski Laplacian reaches the harmonic kernel in bounded settling time; and every nontrivial local blowup on the support strictly decreases the free-energy Lyapunov potential.

This is not a claim that RelMath has solved continuum spacetime, quantum gravity, or Riemannian curvature. It is a more precise claim: RelMath is close to a formally checked **order-spectral interval geometry** in which causal order, dimension input, topology, spectral stabilization, singularity classification, and thermodynamic descent are theorem-linked projections of one closure-generated object.

## 2. The governing distinction: four kinds of “time”

The first discipline is to keep the time notions separate.

**Settling time** is the iteration index of closure. It is `n` in `orbit seed n`. Firing, smoothness, quiescence, closure ordinal, and spectral-gap stabilization all live here.

**Causal time** is the order among events. It is the relation `a <ᶜ b`, generated by Boolean transitive closure of direct causal links. It is not the same thing as the closure iteration index.

**Regime time** is the ordinal/phase complexity of settling: strict, Scott, transfinite-bounded, aperiodic. It classifies the kind of closure process rather than naming a particular event’s causal future.

**Thermal time** is the Lyapunov descent direction of the free-energy deficit. It is not a coordinate. It is the monotone decrease of residual incompatibility along settling time.

A compressed version:

```text id="g7en4m"
settling time   = how closure computes
causal time     = how events order one another
regime time     = what kind of closure ordinal the computation has
thermal time    = how residual incompatibility decreases
```

The proposed geometry becomes coherent only if these are explicitly connected but never collapsed.

## 4. Causal order as settled Boolean closure

The causal layer begins with a direct-link relation:

```text id="quaiq7"
prec0 : E → E → Bool
```

The Boolean closure step is:

```text id="zpg1fk"
T_caus(v)(a,c) =
  v(a,c) OR ∃ b, v(a,b) AND v(b,c)
```

The settled value is the transitive closure of `prec0`. The repository already proves this as `causal_settling_is_transitive_closure`: direct links are settled links, reachability is transitive, causal reachability lies inside the DAG strict order, and reachability is irreflexive/asymmetric. fileciteturn15file0L12-L56

The next cleaned object should be:

```text id="w5txmc"
FiniteCausalOrder E :=
  events : List E
  ltC    : E → E → Bool
  irrefl : ∀ a, ltC a a = false
  trans  : ltC a b = true → ltC b c = true → ltC a c = true
  asymm  : ltC a b = true → ltC b a = true → False
```

Then define:

```text id="lcmrkl"
causalLe a b := a = b ∨ ltC a b = true
```

The first theorem:

```text id="gxtuxr"
causalLe_partialOrder :
  causalLe is reflexive, antisymmetric, and transitive.
```

This converts the settled causal relation into a standard finite poset. That is the point where causal-set mathematics can enter cleanly: causal-set theory treats the causal relation as a locally finite partial order, with order encoding causal precedence and local finiteness encoding discreteness. ([en.wikipedia.org](https://en.wikipedia.org/wiki/Causal_sets?utm_source=chatgpt.com))

## 7. The key bridge: Myrheim–Meyer as `H⁰` density

This is the strongest next theorem.

Define a Boolean-to-FOUR embedding:

```text id="mmbvlj"
boolToCharge(true)  := tTop
boolToCharge(false) := kBot
```

Given a finite causal order:

```text id="r81umn"
causalChargeVal(C) : (E × E) → Charge
causalChargeVal(C)(a,b) := boolToCharge(ltC a b)
```

Define ordered non-diagonal pair support:

```text id="vonkus"
orderedPairSupport(events) :=
  [(a,b) | a ∈ events, b ∈ events, a ≠ b]
```

Then prove:

```text id="badpqi"
causalCharge_designated_iff_related :
  designated(causalChargeVal C)(a,b) ↔ ltC a b = true
```

Now the bridge theorem:

```text id="oj7slr"
causal_H0_eq_apexCount :
  H0ᵢ (orderedPairSupport events) (causalChargeVal C)
    = apexCount events ltC.
```

This connects two already-existing strands. `SettlingCohomologyH1` says `H⁰` is the count of designated truth cells. fileciteturn27file0L25-L33 `LorentzianMyrheimMeyer` says `apexCount` is the number of strictly causally ordered pairs and uses it to compute the rational ordering fraction. fileciteturn16file0L36-L47

Therefore:

```text id="zwb8jx"
orderingFraction_eq_H0_density :
  orderingFraction events ltC
    = mkFrac (2 * H0ᵢ orderedPairSupport causalChargeVal)
             (events.length * (events.length - 1)).
```

This is the theorem that makes the Myrheim–Meyer layer endogenous to settling.

It says:

> The Myrheim–Meyer ordering fraction is the normalized degree-zero settled causal truth mass.

That is a real bridge from causal-set dimension input to settling cohomology.

It also clarifies the role of `H⁰` and `H¹`:

```text id="uski9v"
H⁰ = amount/density of settled causal comparability
H¹ = obstruction to gluing local settled data
```

So dimension-like data and curvature-like obstruction data are independent axes, not synonyms.

RelMath already proves this independence in a concrete form: the diamond, chain, and antichain share strict-regime classifying/topological data but have different ordering fractions. fileciteturn17file0L114-L122 fileciteturn17file0L143-L162

## 8. Three notions of curvature/singularity

The memo must keep three concepts apart.

### 8.1 Successor singularity

A successor singularity is a local nontrivial firing:

```text id="j4i1t0"
orbit n ≠ orbit (n+1)
```

The blowup is:

```text id="0w21bl"
Blowup n := (predecessor n, actual n)
```

RelMath already proves that nontrivial firing is a strict knowledge-order jump, and that local data classifies the blowup. fileciteturn9file0L10-L34 fileciteturn7file0L31-L56

This is **local singularity theory**.

### 8.2 Obstruction curvature

Obstruction curvature is nonzero `H¹` / non-Scott failure.

RelMath already proves:

```text id="e0he2e"
flat   ↔ strict or Scott ↔ H¹ = 0
curved ↔ transfinite-bounded or aperiodic ↔ H¹ ≠ 0
```

via the curvature-regime correspondence. fileciteturn4file0L29-L38 fileciteturn5file0L41-L78

This is **cohomological curvature**: failure of gluing / failure of Scott-continuous limit behavior.

### 8.3 Causal-set scalar curvature

Causal-set scalar curvature, in the Benincasa–Dowker sense, is a different external object. Benincasa and Dowker introduced retarded Lorentz-invariant nonlocal operators on causal sets that approximate the continuum d’Alembertian in Minkowski spacetime and approximate `□ - 1/2 R` in curved spacetime, making it possible to define an approximately local causal-set action. ([arxiv.org](https://arxiv.org/abs/1001.2725?utm_source=chatgpt.com))

So the rule is:

```text id="88tr0e"
successor firing ≠ obstruction curvature ≠ causal-set scalar curvature
```

The future bridge should not assert `H¹ = Ricci scalar`. A better bridge is:

```text id="kykl18"
Myrheim–Meyer dimension input = total pair-layer mass
Benincasa–Dowker-like action = weighted pair-layer mass
H¹ obstruction = failure of local interval portraits to glue
```

This would make causal-set scalar curvature a weighted interval-count functional on the same order-generated substrate, while RelMath curvature remains a sheaf/cohomological obstruction to compatibility.

## 10. Energy accounting: local singularities spend deficit

RelMath already proves that free energy strictly decreases when a support cell changes across a closure step. fileciteturn38file0L8-L14 But the more informative theorem is an accounting identity.

Define:

```text id="0pq1iq"
heightGain(cells, v, v') :=
  Σ φ∈cells (kHeight(v' φ) - kHeight(v φ))
```

Assuming:

```text id="t08fyi"
v ≤ₖ v' ≤ₖ w
```

prove:

```text id="3e613s"
deficit_decomposes_over_step :
  deficit cells v w
    = heightGain cells v v' + deficit cells v' w.
```

This says:

> the free energy lost during a step is exactly the knowledge-height gained during that step.

Then connect it to blowups:

```text id="nbcmw0"
blowup_incidence_energy_drop :
  if localData(M,seed,n).incidence φ = true
  and φ ∈ cells
  then heightGain cells (predecessor n) (actual n) > 0
  and freeEnergy(n+1) < freeEnergy(n).
```

This theorem composes two existing facts: incidence means the predecessor and actual value differ at that cell, and strict cell change implies strict free-energy descent. fileciteturn7file0L4-L11 fileciteturn38file0L8-L14

This is one of the most elegant bridges:

> A local singularity is an energetic event.

It connects local blowup classification to thermodynamic descent without importing any real-valued entropy.

## 11. Order-spectral geometry: gap as stabilization

```text id="0lhri0"

  Val       := Cell → Charge
  L         : Val → Val
  Harmonic v := L v = v

RelMath’s Lawvere Laplacian is already the closure operator, and harmonic states are fixed/quiescent states. fileciteturn10file0L118-L153 fileciteturn11file0L139-L170

gapBound_no_firing_after :

  GapBound g → freeEnergy g = 0
```

This interprets spectral gap as stabilization time of the order-Laplacian diffusion. It is not eigenvalue geometry, but it is a genuine spectral-gap analog in the Tarski/Lawvere fixed-point setting.

## 13. Closure ordinal as renormalization complexity

Closure ordinal should be interpreted carefully.

In finite FOUR-valued settling, RelMath proves every inflationary endomap settles by step 3. fileciteturn30file0L68-L90 In the transfinite picture, `Ordinal` builds Brouwer/tree ordinals with zero, successor, and limit, proves limit-as-LUB, and proves that the old Boolean regime classifier is a projection of ordinal shape. fileciteturn31file0L199-L224

So:

```text id="9tgx9x"
causal time    = event order
settling time  = closure iteration
closure ordinal κ = complexity of reaching compatibility
free energy Φ  = analytic projection of remaining incompatibility
```

RelMath already proves the free-energy module’s version of this: the number of settling steps to fixed point is bounded by initial free energy. fileciteturn39file0L5-L19

The proposed theorem:

```text id="sbvxea"
interval_kappa_bounded_by_energy :
  closureOrdinal(interval) ≤ initialFreeEnergy(interval) + 1
```

In finite strict settings, this is a bounded compatibility-complexity theorem. In later transfinite settings, it becomes a statement about how ordinal settling complexity relates to obstruction/energy growth.
