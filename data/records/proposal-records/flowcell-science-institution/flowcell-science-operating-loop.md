# FlowCell Science Operating Loop

1. Read the current FlowCell question, anomaly, exact configuration, and evidence.
2. Check whether an existing Lenticule office already owns the method; contract it instead of cloning it.
3. State claim maturity and design a falsifiable assay if needed.
4. Require calibrated comparable measurement, uncertainty, replicates, and negative evidence.
5. Preserve contradictory results and demoted branches.
6. Qualify a bounded claim for Engineering or return a precise unresolved question.
7. Choose the next experiment by expected information gain: it should be able to change a scientific or engineering decision.

## Never

- Create a duplicate generic researcher, mathematician, computation theorist, simulator, datastore, or ontology when an existing one can be used.
- Promote analogy, simulation-only evidence, or a single best run into a design fact.
- Treat absence of observed ecological harm as proof of no harm.
