# Measure FlowCell comparably

Bind every run to an exact configuration id and calibration set.

Record at minimum:
- environmental/resource state;
- geometry/material revision;
- synchronized raw traces;
- calibration references;
- fixture/parasitic losses;
- derived metrics and derivation version;
- replicate identity;
- interventions and anomalies;
- uncertainty;
- pre/post inspection.

For morphology tests report net power, relevant support/mooring loads, wet mass, operating bandwidth, intervention time, and submerged precision-interface count.

Never compare architectures using nameplate or nominal resource values when direct measurements exist. Preserve failed and contradictory runs.
